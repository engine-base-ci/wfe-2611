## ② 行為の背骨

### 最初の一周（walking skeleton）

```
A01 アカウントを作る
 → A09 自分のPCをつなぐ（Bridge）── これが無いと自分のAIは話せない
 → A06 自分のAIに会社のことを話す（訊かれたことに答える）
 → A07 自分のAIが作ったたたき台（目標・台帳・AI社員）を見る
 → A08 違うところを言って直させる
 → A11 AI社員をテストで動かして結果を見る
 → A12 本番に切り替える
 → A14 今日ひらいて、自分のAIの申し送りを読む
 → A15 自分のAIが上げてきたものを承認する／止める
 → A19 案件を次の段階へ動かす
 → A22 目標の進みを見る
```

## ③ オブジェクト（OOUX）

| オブジェクト | 何か | 関係するもの |
|---|---|---|
| **会社モデル** | 目標・台帳定義・担当業務・組織・ポリシー・記憶を1つにした定義。画面もAI社員も自動実行もここだけを読む | 目標 / 台帳の定義 / 担当業務 / メンバー / ルール / 記憶 |
| **自分のAI** | 1人1体。自分自身の写しでありweb内の代理人。人と会話し、AI社員に指示を配り、上がってきた結果を一次確認する | 会社モデル / AI社員 / 申し送り / 承認待ち / 記憶 / 会話 |
| **AI社員** | 決められた仕事を持つ働き手。運営配布/会社作成/個人作成の3経路。託されたものは使えるが定義は編集できない | 担当業務 / 自分のAI / スコープ / 差し戻し |

| **覚えた操作** | 外部サービスでの手順。座標ではなく意味で記録する。壊れたらAIが覚え直す | 担当業務 / サービス台帳 / Bridge |
