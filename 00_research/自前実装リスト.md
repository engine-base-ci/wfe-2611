# Kaname 自前実装リスト ── 何を作り、何を借りるか

作成 2026-09-07 / 目的：**「Claude Code ができることを全経路で使える」を実現するために、
具体的に何を作る必要があるか**を漏れなく列挙する。前回の 15 項目は浅すぎた。

---

## 0. 訂正 ── ハーネスは自前で作らない

「サーバー経路のエージェントループを自前で作る」は誤り。**各社が Agent SDK を出している。**

| 経路 | ハーネス | 言語 | ライセンス | 状態 |
|---|---|---|---|---|
| **Bridge** | Claude Code CLI | — | **Anthropic 商用規約** | 顧客のサブスクで動く |
| **サーバー・Claude** | **Claude Agent SDK** | TS ★1,732 / Python ★8,034 | **TS 版＝Anthropic 商用規約 / Python 版＝MIT**（要一次確認） | Claude Code と同じハーネス |
| **サーバー・OpenAI** | **OpenAI Agents SDK** | TS ★3,759 | **MIT** | — |
| **サーバー・Gemini** | **TS 版が無い**（ADK は Python のみ ★21,423） | — | Apache-2.0 | **自前ハーネスが要る** |
| **サーバー・ローカル LLM** | **LangGraph.js** | TS ★3,252 | **MIT** | 自前ハーネスの土台 |

**結論：ハーネス（ループ・ツール実行・コンテキスト圧縮・並列）は借りられる。**
ただし **Gemini とローカル LLM は LangGraph.js で自前ハーネスを組む**必要がある。

**★ライセンス注意**：Claude Agent SDK の TypeScript 版は MIT ではなく Anthropic の商用規約。
Anthropic の API を使う以上は規約に従うので実害は無い見込みだが、**改変・再配布はできない**。

## 3. Python が要る範囲（再確認）

**「取り込みサービス」1 つだけ。** 独立サービスとして切り、型がまたがらない。

| 機能 | OSS | 段階 |
|---|---|---|
| 文書理解（PDF/Office の表・レイアウト・読み順） | **docling**（MIT・61k★） | 1 |
| 音声の文字起こし | **faster-whisper**（MIT・25k★） | 5 |

**Gemini・ローカル LLM のハーネスは LangGraph.js（TS）で組む**ので、Python は不要。

## 4. この表の使い方

- 実装に入る前に、各項目を **task-decomposition** でタスクに落とす
- 各項目に **テストラダー L1 の行**を同時に作る（test-ladder 規約）
- 「借りるもの」欄が空でない項目は、**ライセンスを実ファイルで確認済み**であること

> **2026-09-10（D-055）**：段階1の実行経路は Bridge（本人サブスク）だけ。BYOK・運営マネージド・ローカルは段階2以降。経路解決の抽象（`llm_route`）は残す。
