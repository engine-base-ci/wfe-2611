- **答え → 部品の値（`invoice-template-shape.ts`・画面の外の純粋な関数・`@/` を読まない）**：
  - `viewOf(a, now)` → `{ values: { company, address, regNo, contact, bank, note }, aside }`。`aside` は `updated_at` と `updated_by_name` が在れば「<MM/DD（日本時間）> に <名前> が直した」（下絵「11/01 に 佐野 が直した」）、無ければ null（箱の右の字を出さない）
  - `bodyOf(values, version)` → `{ company, address, reg_no, contact, payee, note, version }`（7 つの鍵・前後の空白を落とす・登録番号は全角の英数字を半角に・大文字の T に）
  - `errorsOf(values)` → 欄ごとの字（空・空白だけ：「会社名を書いてください」「住所を書いてください」「連絡先を書いてください」「振込先を書いてください」／登録番号の形：「登録番号は T と 13 けたの数字で書いてください」／字数：会社名 100・住所・連絡先・振込先 200・備考 500 を超えたら「<N> 字までにしてください」）。誤りが 1 つでもあれば送らない（字は D-156.75）
- **押したとき**：［直す］＝欄にする（値は今の値）。［やめる］＝欄の値を捨てて見るに戻る（口を呼ばない）。［保存する］＝`errorsOf` が空なら `PUT /api/v1/ops/invoice-template`（体は `bodyOf(values, 読んだ version)`）→ 200 の答えで見るに戻り、鍵を読み直す。送っている間は 2 回目を送らない
- **本人確認の取り直し**：403 `STEP_UP_REQUIRED` なら K-972 の形（`getMySecurity` を 1 回・小窓「本人か確かめます」・［パスキーで確かめる］で `stepUp` を 1 回）→ 同じ体で 1 回だけやり直す
- **保存できなかった**（下絵 op-invoice-template-failed）：409 E-BILL-007・503・網の切れは、欄の上の赤い箱「保存できませんでした」「通信が切れたか、ほかの人が先に直しました。書いた値はそのまま残っています。もう一度「保存する」を押してください」。書いた値は残し、欄のまま。409 のときは裏で 1 回読み直して版だけを新しくする（書いた値は替えない＝もう一度押すと書いた値で保存できる）
- **読めない**：読む口が 503・網の切れ・形が違うなら ErrorState（E-PAGE-007・「もう一度」で読み直す）。ふつうに見せない（G-15）
- **部品に足す物（見た目と並びは変えない・任意の props だけ・K-956 の形）**：`views-invoice-template.tsx` の `InvoiceTemplatePage` に `values`・`aside`・`onChange(name, value)`・`errors`・`onEdit`・`onCancel`・`onSave`・`busy`（欄を書ける形にする＝渡したときだけ readOnly を外す）。`BillsPage` の `templateHref` は K-984 が足す（渡したときだけ押せるリンク・渡さなければ href の無い押せない形・既定の道を持たない＝本番に開発の道を出さない。K-994・K-1111 の `newHref` と同じ形）。この葉は部品 `views-bills.tsx` を直さず、入れ物 `bills-screen.tsx`（K-984）に `templateHref="/ops/billing/template"` を 1 行足すだけ。渡さない呼び方（モック）は今の見た目のまま
