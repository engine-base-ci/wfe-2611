## 目的

古い K-89 の画面の分。「PC と使った量」（/setup/bridge・K-57 の `features/F3/connect-pc`）の「つないでいる PC」の行に、その PC の Claude Code の足りない物（入っていない・本体が落ちてきていない・ログインしていない）と直し方を出す。人はターミナルを触らない（D-091）。

- **この PC の行**（この PC の Bridge の /ping の device_id と行の id が同じ・K-359）：直し方のボタン（「Claude Code を入れる」／「Claude Code を取り直す」／「ログインする」）が押せる。押すとこの PC の口（K-359）が動き、入れている途中の行・結果が行の中に出る。ログインは入口のリンクとコードの欄を出し、Bridge が `claude auth status` で確かめて「できた」と返したら区画が消える
- **ほかの PC の行・Bridge の無い端末で開いたとき・古い Bridge**：足りない物と「Bridge が入っている PC でこの画面を開いてください」だけ。押せるボタンは出さない（D-091「どこから押せるか」）
- **眠っている PC の古い報告**：「〈MM/DD HH:MM〉の報告」と時刻を添える（一覧の health_at・K-360）
- **スマホ・タブレット（Bridge を入れられない端末）で開いたとき**の「＋ PC をつなぐ」を押せない形と、区画の見た目のモックとの突き合わせは、K-373 に分けた（2026-11-19 PM の決め・この葉の見込みが上限 1 時間を超えたため）
- 行に部品を差す所（`PcList` の `renderExtra`）と行の印（`li.k-pc-row` の `data-device`）は、新しい葉 K-349 が先に入れる（2026-11-19 夜 PM の決め）。この葉は、どの行に何を出すかの出し分けの置き場 `pc-row-extra.tsx`（K-349 が中身を空で置く hook `usePcRowExtra`）に Claude Code の分を書く。並べる所 connect-pc.tsx と pc-cards.tsx は触らない。後の画面の葉も同じ hook に足す：AI が使うブラウザの欄は K-368、Bridge を入れ直す一手は K-375（K-361 → K-368 → K-375 の順に、自分の分かれ道を足す）。外す（K-363）は行の「…」に差す別の置き場 `pc-row-more.tsx` を使うので、この葉とファイルが重ならない（順が無い・並べて作れる）。口と DB だけの葉 K-364・K-365 は画面のファイルを変えない

入っていてログイン済みなら何も出さない（済んだ手順を見せ続けない）。Claude Code が無くても、チケットを作る・自分で進めることはできる（D-125.142・D-125.143）。この区画に「入れるまで先へ行けない」の道は作らない。
