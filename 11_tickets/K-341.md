## リスクと懸念

- K341-CI-003 は直す前の版を git の中の blob（c27ded84…）として読む。本線の歴史に在る物なので CI（fetch-depth: 0）でも読める。後で G56 の決まりをわざと変えるチケットは、この行の比べる相手を自分の版に替えるか、決まりの変わる写しを外す
- 新しい git の選び（`--diff-merges=off`）は git 2.31 から。CI の台の git が古ければ止まる（その時は外して既定の動きに任せる）
