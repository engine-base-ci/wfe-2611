## 目的

K-567 の部品（本文を見たまま編集する核）に、本文の道具の残りをつなぐ（D-150.48・D-150.61）：**文字の色・背景の色**（よく使う色・ブラウザの色の選び方で選ぶ「ほかの色」・色を外す。値は `#rrggbb`）・**表**（入れる・行と列を足す・消す・表を消す・セルをつなぐ・分ける・見出しの行／列／セルの切り替えを 1 つのメニューに全部並べる）・**Markdown を貼ると変換**（見出し・箇条書き・番号つき・チェック・表・太字・取り消し線・行の中のコード・区切りの線・引用・コードの段・リンク）。画像のボタンと帯の全体の見た目は K-587 が持つ。

K-567 が、これらの節・印を読み込みと書き出しのために組んである（色・背景・表・寄せを含む文書を渡すと見えて、触らなければそのまま返る）。この葉は帯の 3 つ（文字の色・背景の色・表）を動かし、色の小さな画面・表のメニュー・Markdown の貼り付けを足す。

## 前提と制約

分類: CRUD

- **Markdown の解析は、すでに入っている remark を使う**（`unified`＋`remark-parse`＋`remark-gfm`＋`remark-cjk-friendly`。木 mdast を作るところまで。描かない）。選びの訳：返事の書式の描画（`components/ai/markdown.tsx`・境界 B8）が `react-markdown`・`remark-gfm`・`remark-cjk-friendly` を前から使っていて、lockfile に `remark-parse` 11.0.0・`unified` 11.0.5・`mdast-util-from-markdown` が前から在る（新しい版は入らない）。**日本語の強調**（`**「太字」**と` のように句読点の次に日本語が続く形）は、`remark-cjk-friendly` が無いと CommonMark の規則で太字にならない（B8 が同じ理由で入れた）。落とした案：`@tiptap/markdown`（中は `marked` で、日本語の強調の手当てが無く、Markdown の解析が 2 つになる）・`marked`・`markdown-it` を別に入れる。**mdast → K-561（K-584 が広げた形）の Doc への写しは自前**（番号つきの並び・画像・生の HTML を決めた形にするため、写しを自分で持つほうが確かめやすい）。**写した結果は必ず `fromEditorJson` を通さず直に Doc で組み、`validateDoc` を通す**
- **変換の決め**（K568-UN-001〜007 が見る・本文の道具に在る物にそのまま写す・D-150.61）：`#` は見出し 1（level 2）・`##` は見出し 2（level 3）・`###` 以降は見出し 3（level 4）／`-`・`*`・`+` の並びは箇条書き（入れ子も）・`- [ ]` と `- [x]` はチェックの箱・`1.` の番号つきは番号つきの並び（始まりが 1 なら start を持たず、5. からなら start が 5）／GFM の表は表（1 行目が見出し行・揃えの印は読み捨てる）／`**`・`__` は太字・`*`・`_` は斜体・`~~` は取り消し線・インラインのコードは行の中のコード／`---` は区切りの線／``` で囲んだ所はコードの段（言語名は捨てる）／`>` は引用／`[字](https://…)` はリンク（許された href だけ・それ以外は字だけ）／`![代わりの字](…)` は代わりの字の段落（画像の置き場にはしない・画像が入るまで）／生の HTML は HTML として読まず字のまま
- **いつ変換するか**（`looksLikeMarkdown`）：貼ったものが **`text/plain` だけ**（`text/html` が無い）で、かつ Markdown らしいとき（行頭の `# `・`- `・`* `・`+ `・`1. `・`> `・`- [ ]`・``` ・表の区切り行・`**太字**`・`~~消す~~`・`[字](…)`）だけ変換する。`text/html` を持つ貼り付け（Web ページ・Word など）は K-567 の HTML の道のまま（Markdown と読まない）。Markdown らしくない普通の文は、行ごとの段落（既定の貼り付け）。「a * b = c」「価格は 100 円 - 税込」「a_b@example.com」は変換しない
- **上限**：貼る文の変換結果が文書の深さの上限（K-561 の `DOC_MAX_DEPTH`＝12）を超える（`too_deep`）か、文書全体が `DOC_MAX_BYTES`（1 MB）を超える（`too_big`）なら、**貼らず**、書いてある文書は変えず、`role="status"` で『貼る文が大きすぎるか入れ子が深すぎるため、貼れませんでした』と知らせる（次に何かを打つか 5 秒で消える。画面の文は勧め・代表に聞くこと 1）
- **1 回で戻せる**：Markdown の貼り付けは 1 回の変更として履歴に入り、Ctrl／⌘+Z 1 回で貼る前に戻る
- **文字の色・背景の色**（代表 2026-11-22「色がすごく制限されている」）：帯の『文字の色』『背景の色』を押すと小さな画面（`role="dialog"`・名前は押した道具と同じ『文字の色』『背景の色』・`div.k-f4d-pop.k-f4d-colors`＝下絵 v2 の `f4v2-editor-color` と同じ class）が開く。中身は ① よく使う色の並び（文字の色 10 個：黒・灰・赤・橙・黄・緑・青緑・青・紫・桃／背景の色 9 個：灰・赤・橙・黄・緑・青緑・青・紫・桃。`aria-label` が色の名前・押せる四角 `button.k-f4d-swatchbtn`・いま付いている色は `aria-pressed` が真）② 『ほかの色』（`input type="color"`・ブラウザの色の選び方。選ぶと付く）③ 『色を外す』。選ぶと選んでいる字に `color`（文字の色）／`highlight`（背景の色。`attrs.color`）の印が `#rrggbb` で付く／外れる。**色の値は `#rrggbb` だけ**（ブラウザの色の選び方は小文字の 6 桁を返す）。見た目は付けた色のまま（文書の中身の色）。色の見本の値（`#rrggbb` の並び）は `features/F4/doc/color-swatches.ts`（下絵と本物が同じ物を読む・K-431 が運ぶ）で、TS の定数として持ち、見本の四角にだけ inline style で当てる。**旧い名前の色（red・teal・amber）で付いた字は今までどおり読める**（色の小さな画面の四角には出さない）。小さな画面は Esc・画面の外を押す・色を選ぶで閉じ、閉じたら押した道具に戻る。Enter で開き、Tab で四角に移り、Enter で付ける。画面の外にはみ出さない。**出来合いの UI との関係**：背景の色は `color-highlight-popover` の hook（`use-color-highlight`）を写す（色の並び `HIGHLIGHT_COLORS` は CSS 変数なので `#rrggbb` の並びに差し替える）。文字の色の出来合いの UI（`color-text-popover`）は有料 plan の部品で使えない（K-567 の確かめ）ので、同じ形で `use-text-color.ts` を自前で書く
