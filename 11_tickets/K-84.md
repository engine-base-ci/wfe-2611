## 目的

使う人に見せる住所（例：画面 app.〇〇・API api.〇〇）を決め、Vercel に向ける。

## 完了の条件

- [ ] 画面と API のドメイン名を決めた
- [ ] DNS に Vercel の記録を足し、Vercel で Valid になった
- [ ] `BASE_URL`・`WEB_BASE_URL`・`NEXT_PUBLIC_API_BASE` を新しい住所にした

## 前提と制約

- staging は Vercel の既定の URL のままでもよい。本番の前に必須

## 実施事項

1. ドメイン名を決める
2. Vercel の各プロジェクト → Settings → Domains に足す
3. DNS（ドメインを買った所）に、Vercel が出す記録を足す
4. 環境変数の URL を直して Redeploy

## テスト仕様と確認の結果

- 確かめは新しい住所で /health が 200・画面が開く

## 成果物

- ドメインと DNS の記録
