## 目的

GitHub Actions が手順の前に 2 秒で落ちる形で止まっている（2026-11-04・利用枠か支払いの疑い）。ai-team-delivery のスキルの CI（dagci）を Kaname に入れ、GitHub の v3-gate と同じ検査をこの台の容れ物の中で流す。

## 完了の条件

- [x] ci.yaml を置き、段は v3-gate.yml から機械で導く（scripts/ci/ci_stages.py・手で写さない）
- [x] GitHub の検査がどれも段に 1 対 1 で入っているかを機械で確かめる（ci_stages.py --check・G52）
- [x] CI の正をローカルの dagci にする（D-128.132）。既存のコードは今まとめてテストし直さず、使うチケットで確かめる
- [x] 全部の段（dagci run --all）が手元だけで緑：50 段・赤 0（f1169c6・2026-11-04・記録 /root/.cache/dagci/runs/kaname/20261104-165645-19270）
- [x] わざと壊したコード（型の誤り）で G2 が赤・dagci の終わり方 1 になる（赤を出せる）
- [ ] 最初のチケットの変わった所に関係する段（dagci run --affected）が緑
- [ ] v3-gate.yml の検査の番号の重なり（G27・G28 が static と spec に 2 回ずつ）を直す

## 前提と制約

- 外す job：task-gate（task/ の枝の PR だけ）・e2e（staging が要る・K-37）・auto-merge（GitHub の取り込みの道具）
