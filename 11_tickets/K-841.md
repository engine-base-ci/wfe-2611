## 目的

自分で、入っているワークスペースの 1 つから抜けられるようにする（行為 A74）。プロフィール（K-839）の「入っているワークスペース」の行の［抜ける］で小窓を開く。口 `leaveWorkspace`（K-838・道の id は抜ける会社の id）。抜けられるのは、その会社に**担当が残っていなくて**、**最後の管理者でない**とき。抜けると、その会社の個人の物（個人の記憶・会話・預けたログイン情報・PC の接続）はいつも消え、その会社の画面と PC のセッションが切れる（D-154.20）。30 日のあいだは同じメールで招かれるとグループと役割が戻る（D-154.26）。

**分身の記憶を消すかどうかは選べない**（口の体は空）。下絵の［分身が覚えたことを消す］のチェックは外し、「いつも消えます」の説明にする。抜ける前の確かめの材料（担当しているチケットの一覧・最後の管理者か）は K-833 の `getMe` の `workspaces[]` にあり、小窓を開くときは口を呼ばない。

## 前提と制約

分類: CRUD, PERM

- **口の答えの形は K-838・K-833 の「画面が使う答えの形」**：`leaveWorkspace` → 200 `{ data: { tenant_id, left: true, restorable_until } }`・体なし。小窓の材料は `getMe` の `workspaces[i]`：`{ tenant_id, name, role, group, current, own, last_admin, assigned_total, assigned: [{ id, number, title }]（先頭 10 件） }`。断りの番号：E-ME-050（担当が残っている・409）・E-ME-051（最後の管理者・409）。違えば `f10-ops-kit.ts` の `me()`・`leave` の既定だけを合わせる
- **入口**：K-839 の登録口 `PROFILE_DIALOGS` に `leave: LeaveWorkspace` を 2 字下げの 1 行で足す（足すと［抜ける］が押せる形に変わる・K839-UI-016）。［抜ける］を押した行の `tenant_id` で小窓を開く。**自分だけの場所**（`own`）の［抜ける］は押せない形のまま（小窓を出さない・K839 の部品どおり）
- **小窓の 3 つの形**（下絵 me-leave・me-leave-ready・me-leave-last-admin）：題「<会社名> から抜ける」・サブ「あなたは <役割>」（管理者・マネージャー・メンバー・閲覧のみ・依頼する側（仮））・説明「抜けると、<会社名>のチケット・ナレッジは見られなくなり、あなたの分身もそこでは動かなくなります。」。形は答えから決める（口の順と同じ＝**最後の管理者が先**）：
  - `last_admin` が true → **最後の管理者**：箱「最後の管理者です」＋「あなたはこのワークスペースの最後の管理者です。ほかの人を管理者にしてから、抜けてください」・足のボタン［やめる］［管理者を決めにいく］［抜ける］（押せない）。K-833 の申し送り（押せない形）を、下絵に合わせて「押せる形で小窓が理由を出す」に改める
  - `assigned_total > 0` → **担当が残っている**：箱「担当しているチケット N 件」（N は `assigned_total`）＋ `assigned` の「<番号> <題>」を並べ（10 件を超える分は「ほか M 件」）＋「抜ける前に、ほかの人に渡してください（受けてもらうまで抜けられない）」・足のボタン［やめる］［担当を渡しにいく］［抜ける（渡し終わってから）］（押せない）
  - どちらでもない → **抜けられる**：箱「担当しているチケットはありません。このまま抜けられます」・足のボタン［やめる］［抜ける］（押せる）
  - どの形でも：チェックは無く、説明「あなたの分身が <会社名> で覚えたことは、抜けるとすべて消えます（消えたものは戻りません）」（**仮**・下絵は切る段でこの形に直してある）・注「<会社名> のワークスペースに残るのは、あなたが書いたやり取り・決定ログだけ。抜けたあとでも、招待されればまた入れる」（会社名は短い名でなく同じ字・下絵の「京蟻」を直す）
- **［担当を渡しにいく］・［管理者を決めにいく］**（どちらも押せる形）：今いる会社（`current`）なら切り替えずに `/tickets`・`/members` へ移る。**別の会社なら、切り替えの口 `switchWorkspace`（K-851・D-154.81）でその会社に切り替えてから移る**：`call("switchWorkspace", { params: { id: <tenant_id> }, body: {} })` を 1 回 → 200 で `window.location.assign("/tickets")`／`("/members")`（画面を開き直して読みの鍵を全部捨てる・K-844 と同じ）。答えを待つ間は 2 つのボタンと主ボタンが押せず、二度押しでも口は 1 回。**404**（止められた・抜けた・会社が無い）→ 小窓を閉じ、自分を 1 回読み直して行が消え、プロフィールの赤い箱に「そのワークスペースには入れません」（**仮**・K-844 と同じ字）・道は変わらない。**503**・網の切れ → 小窓の中に正本 E-PAGE-003 の文の赤い箱・開いたまま・移らない・もう一度押せる。401 → `call` が入り直しへ
- **抜ける**：`call("leaveWorkspace", { params: { id: <tenant_id> } })`（体なし・グループ・役割の鍵は無い＝兼務の人も会社単位・D-154.15）。処理中は主ボタンが処理中で二度押しでも 1 回。200 → 小窓を閉じ、自分を読み直し（`reloadMe()`・1 回）、行が消える。`role="status"`「<会社名> から抜けました。30 日のあいだは、同じメールで招かれるとグループと役割が戻ります」（**仮**）。**今いる会社を抜けたとき**（`current`）はその会社のセッションが切れるので、画面は入り直し（`/login`）へ移る（読み直さない）。**403 STEP_UP_REQUIRED** → `getMySecurity` を 1 回読んで `StepUp`（features/F1/security/step-up.tsx・パスキーだけの人はパスキー・D-154.3）。理由「<会社名> から抜ける前に、本人か確かめます」（**仮**）。通ったら同じ口で 1 回だけやり直す・やめたら何も送らず抜ける小窓に戻る（K-363 と同じ形）。**409 E-ME-050・051**（開いている間に変わった・TP-CRUD-01）→ 自分を読み直して小窓を新しい形に替える（押し直さなくてよい・抜けない）。**404**（もう抜けた・会社が無い）→ 小窓を閉じ、自分を読み直して行を消し、赤い箱に正本 E-PAGE-001 の文。**503**・網の切れ → 小窓の中に E-PAGE-003 の文の赤い箱・開いたまま・行は残る・もう一度押せる
- 小窓を開くだけでは口を呼ばない（自分の読みは 1 回のまま）
- スマホ（767 以下）は崩れず読めて押せる（D-154.13）。幅 320 でも小窓 3 つの形・100 字の会社名・担当 10 件の一覧で横のはみ出し 0
