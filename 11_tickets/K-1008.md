## 目的

運営がワークスペースを止めると決めたとき・止めたとき・中を見ている間に、それが顧客の画面で分かるようにする（行為 A127・A64・D-156.23・D-128.68）。

- 止める日が決まった帯（管理者だけ・口が絞る）：「<日> にこのワークスペースを止めます」・理由・「問い合わせる」
- 止めた後に入ると、止められた画面（理由・止めた日・運営の宛先・「問い合わせる」だけ使える）。困ったとき・お知らせと問い合わせの道は開ける（D-156.23）
- 中を見られている間の帯：見ている先・理由・残りの時間・「見るのをやめる」（下絵 uh-peek・運営が顧客の画面を見ている間の上の帯と枠）
- 障害・メンテの帯と画面いっぱいの形は K-957（この葉は K-957 から分けた：止める・中を見るの口〔K-970・K-969〕は運営の側の葉で、待つと障害の帯が遅れる）

- **代表の答え 2026-11-23（D-156.23）**：止める日までの間はその会社の管理者にお知らせと画面の上の帯（管理者だけ）。止めた後に入ると止められた画面（理由・問い合わせ先・「問い合わせる」だけ使える）。実行中は区切りまで進めて止め、実行待ちは残す（口の葉 K-970）
- **帯の形（K-1004 の bands・K-970・K-969 が返す形を前提にする）**：
  - 止める：`{ kind: "stop", title: <理由>, from: <止める日（止めた日）の時刻>, closable: false, more: 0 }`。止める日が先なら **管理者だけ** に返す（口が絞る）。止めた後は **その会社の全員** に返す（K-970）
  - 中を見る（運営の側）：`{ kind: "peek", notice_id: <中を見るの許可の id＝closePeek の id>, title: <見ている先の字>, state: <理由>, to: <期限>, closable: false, more: 0 }`（K-969）
  - 中を見る（顧客の側・D-128.68・PM の決め 2026-11-23）：`{ kind: "peek", notice_id: null, title: "運営が中を見ています", state: <理由>, to: <期限>, closable: false, more: <ほかの許可の数> }`（K-969）。会社の人の画面に、運営が中を見ている間だけ出す
- **読み替え（K-957 の `bands-shape.ts` に足す・純粋）**：
  - `stopView(band, now)`：`from > now` なら `{ mode: "soon", day: <M/D・日本時間>, reason }`、ほかは `{ mode: "stopped", since: <M/D>, reason }`
  - `gateOf(status, now, path)`：K-957 の形（メンテ中が先・画面が down）に、**止めた後の stop の帯があり、道が `/notices`・`/inquiry`（とその下）でなければ** `{ kind: "stopped", since, reason }` を足す。`now`・`path` を渡さない呼び方は K-957 のまま
  - `peekView(band, now)`：`{ side, id, who, reason, rest: "<残りの分（切り上げ・0 より下は 0）> 分" }`。`side` は notice_id があれば `"ops"`（運営の側）、null か欄が無ければ `"customer"`（顧客の側・id は null）
- **止める日の帯**：`StopSoonBand`（× を出さない）。「問い合わせる」は `/inquiry?from=<今の道>`（K-953）
- **止められた画面**：`StoppedView`（`since`・`reason`・`contact`＝運営の宛先）。外枠と本文は描かない。押せる物は「問い合わせる」だけ（`/inquiry?from=<今の道>`）。困ったとき・お知らせ（`/notices`・`/notices/[id]`）と問い合わせ（`/inquiry`・`/inquiry/[id]`）は止めた後も開ける（問い合わせて返事を読むため）。止めるのは口の入口（K-970）で、画面の出し分けは見せ方だけ
- **運営の宛先**：設定 `legalValues().operator.email`（K-315 の `/help` と同じ・画面に直書きしない）。ルートのレイアウト（`app/layout.tsx`・サーバー）で読み、`ops-contact.tsx` の `OpsContactProvider` で渡す
- **中を見られている間の帯**：`PeekBar` を外枠の上に重ねる（`.k-uh-peek-host`・下絵の形）。残りの分は 1 分ごとに描き直し（`setInterval` 60 秒）、期限を過ぎたら稼働状況を 1 回読み直す（帯が消える）。「見るのをやめる」は `closePeek`（`DELETE /ops/peeks/<id>`）を 1 回・成功で運営の場所 `/ops` へ・失敗は帯の中の赤い箱（E-PAGE-003・E-PAGE-007）で帯は残る
- **顧客の側の「運営が見ています」の帯**（side customer）：`PeekBar` と枠は出さず、上の帯の並び（`.k-uh-bands` の `.k-band`）に 1 本出す。字は「運営が中を見ています」・「理由：<理由>」・「残り <N> 分」。閉じる × も「見るのをやめる」も出さない（閉じられない・顧客は閉じる口を呼べない）。残りの分は運営の側と同じく 1 分ごとに描き直し、期限を過ぎたら稼働状況を 1 回読み直す。下絵は `uh-peek-customer`（下絵の担当が足す・`ticket: K-1008`）。下絵ができたら mock: と K1008-UI-001 の突き合わせに足す（まとめ役）
- **読めない**：稼働状況が読めないときは、止められた画面にしない（読めないのに止めない。止めるのは口の入口）
- **部品に足す物（見た目と並びは変えない・任意の props だけ）**：`status-parts.tsx` の `StopSoonBand`（`onAsk`）・`StoppedView`（`onAsk`）・`PeekBar`（`onStop`・`stopping`・`notice`〔赤い箱〕）。渡さない呼び方（モック）は今の見た目のまま
