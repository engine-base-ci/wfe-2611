## 目的

K-171 の CI（2026-11-12）で、web の組の試験は全部通った（262 本・14 本）のに、JUnit の記録を上げる段（junit-web・記録が無ければ赤）で赤になった。
K-172 で web の組に `PLAYWRIGHT_JUNIT_OUTPUT_NAME` を置いたが、apps/web/playwright.config.ts に junit の reporter を足しておらず、記録が出ていなかった。
K-172 のときは web の組がチケットの範囲に入らず流れなかったので、見つからなかった。あわせて、web の組は 2 回（G48・G59）試験を流すので、同じ名前だと後の回が前の記録を上書きする。

## 完了の条件

- [ ] playwright.config.ts が、PLAYWRIGHT_JUNIT_OUTPUT_NAME があるときだけ junit の reporter をその置き場に出す（無いときは今と同じ）
- [ ] web の組の G48 と G59 が、根の junit/ に別々の名前（web.xml・web-skeleton.xml）で記録を出す（置き場は組の作業場所の絶対の道）
- [ ] 試験 K176-CI-001〜002 が緑・チケットの CI が緑（web の組が流れる）

## 前提と制約

- Playwright の reporter の outputFile は設定のファイルの置き場（apps/web）からの道になるので、絶対の道で渡す
