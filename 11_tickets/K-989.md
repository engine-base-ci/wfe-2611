- **変わる月の式**（`app.plan_existing_from(p_policy text, p_days int, p_immediate boolean, p_from date) returns date`・immutable・月の 1 日を返す）：keep → null（いまの顧客は前の版のまま）／immediate → `p_from` の次の月の 1 日／after_days → `p_from + p_days` 日以後で最初の月の 1 日（その日がちょうど 1 日ならその月）。`p_from` は日本の日付（影響を見るときは今日・決めるときは決めた日＝K-990）

- **月の売上の差**（monthly_revenue_diff）：変わる月が null なら 0。ほかは、止めていないいまの顧客の数 ×（案の値段 − 今の値段）（税別の円・人数で掛けない＝D-156.31）
- **ワークスペースごと**（by_workspace）：名前の順・全部（v1 は数十社・ページを持たない）。1 行は `{ workspace: { id, name }, members, now_price, after_price, from_month, stopped }`。止めている会社は `after_price`・`from_month` が null・`stopped` true（下絵「止めている／再開した月〜」）。`members` は **`app.tenant_seat_count(T)`**（K-961 の 1 か所・社内の人だけでゲストは数えない・D-156.51）。顧客の「いま N 人 / M 人まで」と同じ数
