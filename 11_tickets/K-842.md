## 目的

誰でも、自分が入っている端末（画面・API・PC）を見て、覚えのない端末を自分で切れるようにする（行為 A74）。場所は自分の設定 › ログインと安全（道 `/mfa-setup`・第 2 ナビ `MeSub` の「ログインと安全」が前から指す道・本文は段 2 の K-318 の `SecurityScreen`）。この葉は、K-318 が「準備中」のグレーで出していた 2 つの区画「入っている端末」「最近の安全の記録」を、下絵 me-sessions・me-session-revoke の部品（K-801 の `features/F10/account/login.tsx`）に差し替えて口につなぐ。上の 3 区画（入り方・2 段階認証・パスキー）は K-318 のまま変えない。

口は `listMySessions`（1 回読む）・`revokeMySession`（1 つ切る）・`revokeOtherSessions`（この端末以外をすべて切る）。切る 2 口は本人確認を取り直す（D-154.52・403 STEP_UP_REQUIRED → 今の取り直しの小窓 → 通ったら 1 回だけやり直す・K-363 と同じ形）。**記録の画面（/audit）へのリンクは置かない**（D-154.2・切り方 5 章：管理者でない人の記録の入口は作らない）。

## 前提と制約

分類: AUTH, CRUD

- **口の答えの形は K-836 の「画面が使う答えの形」**：`listMySessions` → `{ data: { sessions: [{ id, kind: "web"|"bridge"|"api", name, place: string|null, issued_at, last_seen_at, current }], events: [{ id, kind, occurred_at, device: string|null, place: string|null }] } }`（並びは今の端末が先頭・あとは最後に使った順。`events` は同じログインの安全の記録の新しい順 10 件）・`revokeMySession` → 200 `{ revoked: true }`・`revokeOtherSessions` → 201 `{ revoked: <切った数> }`。`events` は K-836 が持つ（D-154.79）。違えば試験の `sessionsBody()` だけを合わせる
- **差し込み口**：K-318 の `SecurityBody`（features/F1/security/views.tsx）に任意の props `sessionCards?: ReactNode` を足す。渡されたときは今のグレーの 2 区画（sec-sessions・sec-events）の代わりにそれを描き、渡さない呼び方（モック /dev/mock/f1 の sec-*・段 2 の試験）は今のまま。`SecurityScreen` が `sessionCards={<SessionsArea … />}` を渡す（付けるまで進めない形 `SecurityForced` には出さない）
- **区画の部品**：K-801 の `login.tsx` の `DevicesCard`・`EventsCard` を export し、任意の props を足す（見た目と並びは変えない）：`DevicesCard` に `devices?: readonly Device[]`（`Device` に任意の `icon?: "laptop"|"phone"|"monitor"`）・`allDisabled?: boolean`・`notice?: ReactNode`・`onRevoke`。`EventsCard` に `events?: readonly [string, string][]`・`empty?: string`。渡さない呼び方（モック）は今の見本の値
- **端末の行**（`sessions-shape.ts` の `toDevices(answer, now)`・純粋な関数）：名前は `name`（空なら「名前の分からない端末」＝**仮**）。2 行目は「<場所> ・ <最後に使った>」：場所は `place`（null なら「場所は分からない」＝**仮**）、最後に使ったは 今の端末＝「いま」・1 時間未満＝「N 分前」・24 時間未満＝「N 時間前」・それより前＝日本時間の「M/D」。札：今の端末＝「この端末」（success）・**見覚えは？**＝今の端末でなく、最後に使ったのが 7 日より前（札 warning「見覚えは？」と 2 行目の後ろに「 ・ 覚えがなければ切る」・D-154.79）。絵：名前に iPhone・iPad・Android があれば phone、今の端末は laptop、ほかは monitor。今の端末には「切る」を出さない
- **1 つ切る**：「切る」→ 確かめの小窓（`Confirm`・components/k。下絵 `RevokeConfirm` と同じ見た目と字の形）。題「<名前> を切ります」・説明「<場所> で <M/D> に入った端末です。切ると、この端末は入り直すまで使えません。覚えがなければ、パスワードかパスキーも見直してください」（場所が null なら「<M/D> に入った端末です。…」・M/D は `issued_at`）。PC（kind bridge）なら説明の後ろに「PC の接続も切れ、この PC で動いている分身の仕事は止まります」（**仮**）。主ボタン「本人確認して切る」。押すと `call("revokeMySession", { params: { id }, screenId: "account", keepOn401: true })`
- **この端末以外をすべて切る**：区画の右上のボタン → 確かめの小窓。題「この端末以外をすべて切ります」・説明「<ほかの端末の名前を「と」でつなぐ> が切れます。この端末はそのまま使えます。切れた端末は、入り直すまで使えません」（4 台を超えたら先頭 3 つ＋「ほか N 台」）。主ボタン「本人確認して切る」→ `call("revokeOtherSessions", { body: {}, screenId: "account", keepOn401: true })`。ほかの端末が無いとき、このボタンは押せない形（aria-disabled・title「ほかの端末はありません」＝**仮**・口を呼ばない）
- **切れたあと**：小窓を閉じ、知らせ（toast）「<名前> を切りました」／「<N> 台の端末を切りました」（**仮**）。一覧を 1 回読み直す（安全の記録に「端末を切った」が増えるので、答えで差し替えず読み直す）
- **本人確認の取り直し**（D-154.52・D-154.3）：切る口が 403・STEP_UP_REQUIRED なら確かめの小窓を閉じ、`StepUp`（features/F1/security/step-up.tsx）を開く。理由「端末を切る前に、本人か確かめます」（**仮**）。`withCode` は `SecurityScreen` が読んだ `two_factor`・`withPasskey` は `has_password` が偽のとき（パスキーだけの人は `stepUpWithPasskey` で指 1 本）・`screenId: "account"`。通ったら同じ口で 1 回だけやり直す。2 回目も 403 なら繰り返さず、確かめの小窓を開き直して口の文を出す。「やめる」は何も送らず一覧に戻る（取り直しの読みは `SecurityScreen` の答えを使い、getMySecurity を読み直さない）
- **断り**：409 E-ME-030（今の端末）→ 小窓の中に正本の文・開いたまま。404（もう切れている・ほかで切った）→ 小窓を閉じ、一覧を読み直し、知らせに正本 E-PAGE-001 の文。503・網の切れ → 小窓の中に E-PAGE-003 の文の赤い箱・開いたまま・もう一度押せる。401 → `call` が入り直し（/login）へ。処理中は主ボタンが処理中で、二度押しでも 1 回
- **最近の安全の記録**（`toEvents(answer, now)`）：1 行＝「<字>」と時刻（今日なら「今日 HH:mm」・ほかは「MM/DD HH:mm」・日本時間）。字は `kind` から（**仮**）：passkey_added「パスキーを足した」・passkey_removed「パスキーを外した」・password_changed「パスワードを変えた」・step_up「本人確認を取り直した」・sessions_revoked「端末を切った」・suspicious_connection「場所か端末が急に変わったので、入り直しにした」・ip_changed「つないでいる場所が変わった」・email_changed「ログインのメールを変えた」・bridge_connected「PC をつないだ」・device_removed「PC を外した」・login_blocked「止められていて入れなかった」。知らない `kind` は「安全に関わる操作をした」（内部の名前を画面に出さない）。`device` が在れば「<字>（<device>）」。0 件は「まだ記録はありません」（**仮**）。**区画にも本文にも記録の画面へのリンクを置かない**（D-154.2）
- **読めない**：listMySessions が 503・網の切れなら、2 区画の場所に「入っている端末」の区画だけを出し、中に `ErrorState`（E-PAGE-003 の形）＋「もう一度読む」。上の 3 区画（パスキーほか）は今までどおり使える
- 本人だけの画面（どの役でも開ける）。スマホ（767 以下）は崩れず読めて押せる（D-154.13）。幅 320 でも長い端末の名前で横のはみ出し 0
- 作らない物：記録の画面へのリンク・端末の名前を変える・2 段階認証を戻す（後のフェーズ）
