## 目的

自分の設定 › プロフィールの「入っているワークスペース」の［抜ける］（下絵 me-leave・me-leave-ready・me-leave-last-admin）が呼ぶ口。自分で、入っているワークスペースの 1 つから抜ける。

- `leaveWorkspace`（DELETE /api/v1/me/workspaces/:id・`:id` は抜ける**会社の id**）：抜けられるのは、その会社に**担当が残っていなくて**、**最後の管理者でない**とき。抜けると、その会社の個人の物（個人の記憶・会話・預けたログイン情報・PC の接続・出した招待）をすぐ消し（外されたときと同じ・D-128.96）、その会社の画面・PC のセッションを切る（G-14）。同じログインのほかの会社には触らない
- 本人確認の取り直しが要る（契約の `stepUp: "always"`・D-154.18。画面は今の取り直しの小窓で通ったら 1 回だけやり直す・K-363 と同じ形）

**画面が使う答えの形**（K-841 の正）：200 `{ data: { tenant_id, left: true, restorable_until: ISO 8601 } }`（30 日のあいだは同じメールで招き直すとグループと役割が戻る・D-154.26）。**抜ける前の確かめの材料（担当しているチケットの一覧・最後の管理者か）は読む口 getMe の `workspaces[]`（K-833）にある**（この口は確かめの読みを持たない）。画面は 409 の番号で出し分ける：E-ME-050＝担当が残っている・E-ME-051＝最後の管理者。

**下絵の［分身が覚えたことを消す］のチェック**：個人の記憶・会話は外されたときと同じく**いつも消える**ので、この口は選べる欄を持たない（体なし）。画面の葉 K-841 は、チェックを外して「消えます」の説明にする（D-154.51）。

- **会社ごとの錠**（D-154.21・G-16）：K-800 の `app.admin_lock()` と同じ鍵（`pg_advisory_xact_lock(hashtextextended('f10:' || p_tenant::text, 0))`）を p_tenant で取る（`app.admin_lock()` は今の会社しか取れないので、同じ式を p_tenant で書く）。同時に 2 人の管理者が抜けても、最後の 1 人は 409・E-ME-051
- **抜ける中身**（1 取引）：K-849 の `app.member_erase(p_member, p_removed_by)` を呼ぶ（個人の記憶・1 人だけの会話・預けたログイン情報・出した招待・セッション（画面・PC・API を全部）と PC の仕事・所属の行・権限の行・所属 status を left・人の行に deleted_at）。**p_removed_by は本人**（だから K-849 は理由 'member_left' で `app.admin_cut_sessions` を呼び、やめた PC の仕事の字は「担当の人がワークスペースを抜けたので、この仕事はやめました」・代表の答え e0920e503c99・字の試験は K-814 の K814-DB-016）。勧めた記憶・書いたやり取り・決定ログ・成果物・グループの記憶・名前は残る。外した印と所属の消した印は同じ時刻（K-817 の 30 日の招き直しの元・新しい表を作らない）

- **同じログインのほかの会社**：members・所属・セッション・個人の物は変えない。今のセッションの会社から抜けた場合（今の会社を抜ける）、その会社のセッションは切れて次の要求から 401。画面はそのとき入り直しへ（K-841）

## リスク

- 「担当が残っていれば抜けられない」は、渡しの受け取り待ちの間も担当のままなので抜けられない（下絵「受けてもらうまで抜けられない」と合う）。担当を持つ人が抜けたい場合は、管理者に外してもらう道（K-816・引き継ぎ先を選べる）が別にある
- 同じログインが入る会社がほかに無い人が抜けると、入れる会社が 0 になる。新しいワークスペースを自分で作るのは段 14（代表の答え）。招き直しは、抜けた人も外された人と同じ形（この葉は K-849 の `app.member_erase` で抜けるので members.deleted_at が入り、止めの印は入らない）なので、本人宛ての使える招待のリンクから来ればログインの門を通って参加し直せる（D-154.86〜D-154.90・門と戻す手順は K-852。30 日の内なら役割とグループも戻る・D-154.26）。この葉は門を変えない。画面の葉 K-841 は、最後の 1 社を抜けるときの字を出すかを決める
- 会社の文脈を関数の中で切り替える（記録を抜ける会社に書くため）。切り替えを戻し忘れると以降の文がほかの会社の文脈で動く。K838-API-001・011 が会社の記録と受け箱の場所を見る
