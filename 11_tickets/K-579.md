## 目的

版と差分の頁（K-449・`/tickets/:id/versions`）の「項目の変更」で、比べた 2 つの点の間に変わった項目を、元の点の形に戻せるようにする（行為 A101・D-150.52）。K-449 は「項目の変更を版 N に戻す」を押せない形で置いた（口 K-576 が無かったため）。この葉が押せる形にし、口 `restoreTicketItems`（POST /api/v1/tickets/:id/item-changes/restore・K-576）につなぐ。

- **押すとそのまま戻す**（確かめの小窓を挟まない・下の「代表に聞くこと」1）。本文の戻す（K-449）と同じ：追記だけで、戻した後にまた戻せる。体は `{ from, to }`：`from`＝比べる元の点の番号（ボタンの「版 N」の N）・`to`＝一覧の先頭の点＝いまの最新の番号（口が「今見ている点が古い」を 409 E-ITM-002 で見る）。頭 Idempotency-Key
- 口は**戻せる物だけ戻し**、戻せなかった項目と訳を返す（200 `{ changed, restored[{field,name}], skipped[{field,name,why}] }`）。戻せるのは 開始日・期限・優先度・予定時間・会社が足した項目（予定時間は K-583 の組が出来たので戻せる・2026-11-22）。状態・担当者・親は戻せない（K-576 に従う）。画面は**戻せなかった項目を頁の中の並びに出す**（名前「戻せなかった項目」・1 行は「項目名：訳」・訳は口の答えの字そのまま）。戻せた項目は並びに出さず、読み直した差分（逆向きの行）で見える
- 戻せた物が在れば（`changed` が true）、知らせ「項目の変更を版 N の形に戻しました」を出し（5 秒で消える）、URL から `from`・`to` を外して項目の変更を読み直す（新しい点が先頭・差分は 前の最新 → 新しい点）。戻せた物が無ければ（`changed` が false）、知らせ「戻せる項目がありませんでした」と並びだけを出し、点は増えないので読み直さない
- 完了したチケット・書けない人・差分が空のときは、押せない形（下の「押せない形にする条件」）。断り（409 E-ITM-001〜003・403・404・503・網切れ・401）は赤い箱（戻すボタンの下）に正本の文で出し、押し直せる
- 正の絵は下絵 v2 の `f4v2-versions-items`（K-449 が持つ・ボタンと注）と、**この葉が持つ新しい状態 `f4v2-versions-items-restored`**（戻した後・戻せなかった項目の並び）。新しい状態は 2026-11-22 に下絵 v2 へ足された（`SkippedList`・`ul.k-f4d-skipped`・css は `doc/extra.css`・代表に見せてから始める）。部品は K-431 が運ぶ `features/F4/doc/detail-views.tsx` の `VersionsView` と css。**この葉は css を足さない**（`k-f4d-skipped` は下絵の `extra.css` に在る）
- 画面は役の名前で出し分けず、口の答え（`meta.can_restore`・断り）で出し分ける。業務の型は無くした（D-150.60）・この葉は読まない・書かない

## 前提と制約

分類: CRUD, PERM

- **口**（口の葉 K-576・答えの形はその「前提と制約」が正）：`restoreTicketItems`（POST /api/v1/tickets/:id/item-changes/restore）← `{ from, to }`（strict・整数・1 以上）。→ 200 `{ data: { changed, restored: [{ field, name }], skipped: [{ field, name, why }] } }`（何も戻せなくても 200・`changed` false）／409 E-ITM-001（完了）・E-ITM-002（今見ている点が古い）・E-ITM-003（戻す物が無い）／403／404／503。読む口は K-449 と同じ（`listTicketItemChanges`・`getTicket`・`listTicketVersions` の `meta.can_restore`）
- **`to` は一覧の先頭の点**（`points[0].n`）。比べる先が最新でなくても `to` は最新を送る（口が正味の変わりを `from` から最新まで取って戻す）。画面の差分の見出し（版 A → 版 B）と戻す範囲が違いうるが、ボタンの字は「項目の変更を版 N に戻す」（N＝比べる元）のまま（本文の戻すと同じ言い方・K-449）
- **押せない形にする条件**（`aria-disabled="true"`・薄く・口を呼ばない）は K-449 から**項目の変更の側の「まだ使えません」を外し**、残りは同じ：チケットが完了している（`getTicket` の `completed`。title は付けず、注の場所に正本 E-ITM-001 の文を出し、「戻すと…」の注は出さない）／口の `meta.can_restore` が false（title「このチケットを直せる人だけが戻せます」）／変わった項目が無い（差分が空・K-449 のとおり）／点が 1 つだけ（戻す先が無い→戻すもコピーも出ない・K-449 のとおり）。**差分に戻せない行しか無い**（担当者だけ）ときは押せる形のまま押せる（口が決めて 200・changed false・K579-UI-005）
- **戻せなかった項目の並び**：`ul`（名前「戻せなかった項目」・見出しに当たる小さな字も同じ字）・1 行は「項目名：訳」。訳が null なら項目名だけ。口が返した順。次のどれかで消える：もう一度戻す・比べる元／先を選び直す・比べる物の切り替え・頁を開き直す。戻した直後の読み直しが失敗しても残る。「戻せた項目」の並びは作らない（差分で見える）
- **知らせ**（5 秒で消える・`useNotify`）：戻せた＝「項目の変更を版 N の形に戻しました」（N＝比べる元）／戻せなかった＝「戻せる項目がありませんでした」。下絵に字が無いので PM の字（下の「代表に聞くこと」2）。口の答えの `restored` の数は字に入れない
- **戻すの失敗**（赤い箱 `role=alert`・戻すボタンの下・押し直せる・K-449 の本文の戻すと同じ場所）：409・E-ITM-002（先に項目が変えられた）は口の `message` をそのまま出し、項目の変更を読み直す（比べる元の選びは残す・もう一度押すと新しい最新を `to` に付けて送る）／409・E-ITM-001（完了後）は正本の文を出し、`getTicket` を読み直して戻すを押せない形にする／409・E-ITM-003 は正本の文（「戻す項目がありません」）・読み直さない／403 は「この操作をする権限がありません。権限が変わったかもしれません。画面を読み直してください」（K-449 と同じ字）／404（E-PAGE-001・NOT_FOUND）は E-PAGE-001／503 は E-PAGE-003／網が切れたら E-PAGE-008。401 は共通の入り直し（`/login`）。文は全部正本 `errors.json` から引く（画面で作らない）
- **戻した後の読み直し**：項目の変更の口を 1 回（`from`・`to` を付けない・今の最新とその 1 つ前が選ばれる）。getTicket・版の一覧は読み直さない（完了後の 409 のときだけ getTicket）。読み直しが失敗（503・404）したら、K-449 の「項目の変更の口が失敗」と同じ出し方（差分の場所に赤い箱と「もう一度読む」）で、知らせと並びは残す
- **二度押し**：送っている間は押せない形（口は 1 回）。押し直しは同じ操作として扱わず、答えが来てから新しい Idempotency-Key（`useRef` で操作ごとに作る・K-449 の戻すと同じ作り）
- 並びと知らせは**新しい値を作って入れ替える**（直に書き換えない）。K-449 の `use-versions.ts` の状態に、戻した結果（`restoreNote: { kind: "done" | "none"; from: number; skipped: { name: string; why: string | null }[] } | null`）を 1 つ足す
- 前の下絵の通り、`f4v2-versions-items` の「同じ行（優先度：中）」は出ない（K-449 の「代表に聞くこと」3）。この葉の下絵の状態も、戻した後の差分は「変わった項目だけ」
