## 目的

承認待ちを種類で絞り、並べ替えられるようにする（D-153.10・D-153.30）。押した札と並べ替えは道（URL）に残し、開き直しても・共有しても同じ一覧になる。正の絵は下絵 `/dev/mock/f5/queue-filter-*`（代表が 2026-11-23 に OK）。**字・並び・ボタンは下絵が正**。

- 札：「すべて N」「AI の成果物 N」「渡された N」は押せる。「上位の承認」「判断を仰がれた」は押せない形（物がまだ無い）。「決まりの例外」「やり方を広げる」は札から外す
- 並べ替え：「期限の近い順 ▾」を押すと箱（期限の近い順・新しく承認待ちになった順・題名の順）
- 絞った札で 0 件：「「〈札〉」で決めるものはありません」と［すべてに戻す］

口は新しく作らない（`apis: []`）。K-730 の差し込み口の先 `features/F5/more/fills/queue-tools.tsx`（`QueueToolsFill`・`QueueEmptyFill`・`useQueueQuery`）の中身だけを本物に替える。

## 前提と制約

分類: LIST

- **道の形**：札は `?kind=artifact`（AI の成果物）・`?kind=handover`（渡された）、並べ替えは `?sort=waiting`（新しく承認待ちになった順）・`?sort=title`（題名の順）。「すべて」と「期限の近い順」は道に何も付けない（既定）。道のほかの欄は残す。決まった値でない（`?kind=foo`・`?sort=`）は既定として読み、口には送らない（口の 422 を出さない）
- **`useQueueQuery()`**（`fills/queue-tools.tsx`）：道の `kind`・`sort` を読み、決まった値だけを `query` に入れ（既定は入れない）、`key` は `[kind ?? "all", sort ?? "due"]`。`queue.tsx`（K-730 の版）はこれを `listApprovalQueue` の問い合わせと鍵に足すので、札・並べ替えが替わると頭から読み直し、続きの鍵（`meta.cursor`）は同じ札・並べ替えの間だけ使われる（K-748 の申し送り）
- **札**（`QueueToolsFill`・table と card の両方）：下絵の `QueueTools` の札と同じ形（`.k-ap-chip`・数は `<span className="k-more-count">`・`aria-pressed`）。札の名前（読み上げ）は「〈字〉 〈数〉」（字と数の span の間に空白 1 つ・前からの仕様の表の行「すべて 3」と同じ名前）。数は口の `meta.counts`（`total`・`artifact`・`handover`・絞っても全体の数）。`counts` に `artifact`・`handover` が無い（前の口の答え）ときは字だけで数を付けない。押すと道を `router.replace` で替える（履歴を積まない）。押せない 2 つは `aria-disabled="true"`・`tabIndex=-1`・title「まだ使えません」・押しても道は変わらない
- **並べ替え**（table だけ・スマホは札だけ＝下絵）：ボタン（`.k-more-sortbtn`・`aria-haspopup="listbox"`・`aria-expanded`）「〈今の並べ替え〉 ▾」。押すと `role="listbox"`（aria-label「並べ替え」）に 3 つの `role="option"`（今の物に `aria-selected="true"`）。選ぶと道を替えて閉じる。Esc・外を押すと閉じる。↑↓ で選び Enter で決める
- **0 件**（絞った札で `data` が 0 件）：K-730 の差し込み口 `QueueEmptySlot` の先 `QueueEmptyFill`（同じ `fills/queue-tools.tsx`）が、道に札（`kind`）があるときだけ受けた空の画面の代わりに下絵の `FilteredEmpty` と同じ形を出す：見出し「「〈札〉」で決めるものはありません」・説明「ほかの札には、決めるものが残っています」・［すべてに戻す］（道の `kind` を外す）。札が無いときは受けた空の画面（「いま決めるものはありません」）のまま。札の行（道具の行）は 0 件でも出す（下絵 queue-filter-empty は道具の行の無い形なので、突き合わせは空の箱だけを比べる）
- 読めない（422・503）：今の画面のまま「承認待ちを読み込めませんでした。もう一度お試しください」と［もう一度］
- 文は全部文字として出す。生の色・大きさを書かない
