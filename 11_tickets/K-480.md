## 目的

グループを選んだとき、見え方のタブ「概要」から、そのグループの今の様子（状態の内訳・最近の更新・節目）を 1 画面で見られるようにする（行為 A58・D-128.10）。口は K-477 の `getScopeOverview`（GET /api/v1/scopes/:id/overview）。画面は 1 回読んで描くだけで、書かない。

- 正の絵はモック `/dev/mock/f7/f7-overview`。部品は K-460 が運んだ `features/F7/overview/panels.tsx`（`OverviewPanels`・`UpdateFeed`・`StatusBar`・`RemainingLine`・`MilestoneList`・`ClassCounts`）をそのまま使い、値と動きを渡す
- 差し込み口は K-600 の `OverviewSlot({ scopeId })`（一覧の本体の代わりに描く）と `viewReady("overview")`。この葉は `features/F7/overview/overview-slot.tsx` の `READY` を true にして中身を本物にする。`list-page.tsx`・`list-views.tsx` は触らない
- 契約どおりに出すのは 状態の内訳・節目の進み・最近の更新。節目は列が無いので 0 件（口がいつも空の並び）。絵の「残りの量」「分類ごと」は契約にも決定にも無いので、空の枠のグレー（押せない形・D-145.9・D-151.10）
- メンバーの顔・メンバー数・AI の数（絵の見出しの右）は、口にも前からの口にも値が無いので出さない（D-144.3）。見出しは K-600 が出す「営業 （EG）」のまま
- 「決定」の更新の種類の札は、口に決定の種類が無いので押せない形
- **左のメニューのグループの行を押せる形にする（グループを選ぶと概要が開く・D-125.13）**：外枠のファイル（`ticket-shell.tsx`・`components/k/shell.tsx`・nav）はこの葉は触らない。入口は K-599 が置いた差し込み口 `groupHref(scopeId)`（`features/F7/overview/group-link-slot.tsx`・K-466 が外枠の `groups` で呼ぶ）で、この葉は区画のファイル `group-link-slot.tsx` の `READY` を true にするだけ（`overview-slot.tsx` の `READY` と一緒に）。true になると行は `/tickets?view=overview&scope=<id>` へのリンク（`pending` でなくなる）。行を押すと概要が開く
