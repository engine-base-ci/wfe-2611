## 目的

ログインの画面（/login）を、段 2 の部品（K-300 が入れた `features/F1/login/views.tsx` の LoginMain・LoginCode・LoginBlocked）に載せ替え、契約の口だけを呼ぶようにする。メールとパスワード・確認のコード（6 けたとバックアップコード）・違う・ロック・送りすぎ・確認のコードの止め・待ちの印が切れた・止められた人と会社 を、口の答えのとおりに出す。

パスキー・スマホの QR・端末をなくした（ログインの画面と、確認のコードの画面の「認証アプリが使えない」の下の 2 か所・代表の答え ④）・いまの様子の帯・別のアカウント・ログアウトは K-317。このチケットではそれらを今のまま **出すがグレーで押せない**（D-145.9）。

## 前提と制約

分類: AUTH

- 先に要るチケット：K-300（views と部品とモック）・K-302（verifySignInCode と E-AUTH-013・014）・K-303（止めの E-AUTH-011・012）。K-302 は K-301（signInWithPassword・ロックの新しい文 E-AUTH-002）に依存する。エラーの番号は精査の後の決めの 1 で決め打ち（E-AUTH-002・011・012・013・014）。本線とぶつかったら段 2 の全部の葉で一括に付け替える（K-300 の申し送り）
- **前の道すじ `/api/auth-ext/sign-in`・`/api/auth-ext/two-factor/verify` を消すのはこのチケット**（精査の後の決め 3）。K-301・K-302 は契約の口を作るだけで消さない。前の道すじを直に呼ぶ前からの試験もこのチケットが替える。`/api/auth-ext/*` のほかの道は K-21 の受け持ちのまま
- 「パスワードを忘れた」を押したとき、メールの欄に入っていれば sessionStorage `kaname.reset-email` に（前後の空白を落として）置いてから /password-reset へ移る（URL にメールを載せない・K-320 の頼み）。読んで消すのは K-320
- 口の答えの形は口の葉が契約に書く。K-301・K-302 の形：成功 `{ data: { token, two_factor, pending } }`・verify の体 `{ pending, code }` か `{ pending, backup_code }`（strict）・失敗 `{ code, message, remaining?, retry_after_sec? }`。送りすぎは 429・`RATE_LIMITED`（精査の後の決め 2）
- 見た目は views のまま。新しい見た目を書かない。足してよいのは **値と押したときの関数を受ける口**（今の LoginMain は欄が defaultValue だけで、送るときに値を渡さない）と、**K-317 までパスキー・QR・端末をなくした をグレーにする印**（例：`passkeyOff`・`recoverOff`。モックは印を渡さないので今の形のまま）
- 「この端末を信頼する」（trust_device・30 日 6 けたを省く）は送らない（D-128.60「入るたびにアプリの 6 けた」・K-74 の決めた判断）
- 待ちの印（pending）は画面のメモリだけに持つ（再読み込みで最初に戻る・K316-UI-015）
- 送りすぎ（429 で code が E-AUTH-002・E-AUTH-014 でない）の文は画面で作る：「続けて押されました。{秒} 秒たってから、もう一度押してください」（前からある connect-pc.tsx と同じ文。D-128.146 は「文言の一覧に足す」としているので、一覧に在ればそれを読む）
- ロックと送りすぎは `retry_after_sec` の間だけ「次へ」を押せない。時間がたつと押せ、文は消える
- 止め（403 の E-AUTH-011・012・007）は LoginBlocked（h1「ログインできません」・赤の箱に口の文・「ログインの画面に戻る」）。戻るとメールは残し、パスワードは空にする（切る段の決め）
- 待ちの印が切れた（401・E-AUTH-013）と確認のコードの止め（429・E-AUTH-014）は LoginCode の stopped。切れたときは「最初からログインし直す」でメールとパスワードの画面へ（メールは残し、パスワードは空）
- 口が落ちた（5xx）・網が切れたときは文を出してログインの画面のまま。網が切れたときの文は今の「うまくいきませんでした。もう一度試してください」
- 本人の Bridge（127.0.0.1:38617）に届かせない（試験は網の手前で 404）
- 試験を書いた後は変えない（D-128.125）
