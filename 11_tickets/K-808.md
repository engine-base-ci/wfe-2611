## 目的

代表の答え（D-154.1・answer=2fe7b9f429d4・48a7438c1bb5）：メンバーの一覧の各行に **「最後に使った日（いつから使っていないか）」を出すだけ** にする。PC をつないでと催促する「知らせる」ボタンは作らない（nudgeMember は契約から外す・K-800）。

その元になる値を、メンバーの並びを読む口 `getWorkspaceMembers`（K-419）の答えの人ごとに足す。**口のコード・契約の形（groups・invitations・alerts・count）は変えない**（答えの JSON は DB の関数が組む）。K-419 の DB の関数 `app.workspace_members()` を作り直し、人の行に 2 つの鍵を足す。

**画面が使う答えの形**（K-818 が使う）：`groups[].members[]` の 1 人の鍵は 13：K-419 の 11（id・name・email・role・group_role・primary・other_groups・self・suspended・pc・pc_days_away）に **last_used_at**（最後に画面を使った時刻・ISO 8601・時差つき・1 度も無ければ null）と **last_used_days**（今から何日前か・24 時間ごとに切り捨て・今日は 0・1 度も無ければ null）を足す。画面は last_used_days が null のとき「まだ使っていません」・0 のとき「今日」・n のとき「n 日前」（画面の字の仮は K-818 が決める）。兼ねる人は両方のグループの行に同じ値が出る。

## 前提と制約

分類: LIST, PERM

- **何を「使った」と数えるか**（この葉の決め・D-154.n にした＝D-154.32）：その人の **画面（ブラウザ）のセッション**（`sessions.kind_id = 'web'`・消していない `deleted_at is null`）の `last_seen_at` のいちばん新しい物。**失効した行も数える**（ログアウトしても「最後に使った」は残る）。**PC（bridge）の行は数えない**（PC は動いたまま放っておかれる物で、人が使った印にならない。PC の様子は今のまま `pc`・`pc_days_away` が別に持つ）。画面のセッションが 1 つも無い人（招いて入ったがまだ画面を開いていない・PC だけ）は null
- **last_seen_at が更新される条件**：画面のセッションの要求のたびに `app.session_check`（0083・`packages/auth/src/resolver.ts` が毎回呼ぶ）が今にする（間引きは無い）。`app.touch_session`（0004）はどこからも呼ばれていない。この葉はどちらも変えない
- **last_used_days**：`floor(extract(epoch from (now() - last_used_at)) / 86400)` の整数。23 時間 59 分前は 0・24 時間前は 1・48 時間前は 2（日本時間の暦の日でなく 24 時間ごと。画面は「n 日前」を出すだけで暦の日付は出さない）
- **全員に出す**：止めた人（suspended）・閲覧のみ・依頼する側にも出す（止めた人が「いつから使っていないか」を見たいので）。外した人（left）・消した人は並びに出ない（K-419 のまま）
- **見える人**：K-419 のまま（members の view を持つ人＝管理者と個別に付けた人。メンバー・閲覧のみは 403）。**管理者でない人が「自分の記録」を開く入口は作らない**（D-154.2）ので、この値は一覧の行にだけ出す。別の会社の人の使った日は出ない（`sessions.tenant_id` ではなく members の会社で数える）
- **作り直しの決まり**：K-419 の migration `20261121091900_workspace_invitations.sql` の `app.workspace_members()` を **そのまま写して** 2 か所だけ足す（`seats` に使った日を横に引く 1 つ・`members` の JSON の鍵 2 つ）。K-419 が作った条件（人の集合・招待中の条件・PC の様子・並び順）を変えない。**後ろの段が同じ関数を作り直す**（段 12 の K-876 は guest の人を並びから外すので同じ関数を作り直す）ときは、**この葉の版（last_used の 2 つの鍵を持つ）から写す**（まとめ役に申し送り）

- 断る番号は K-419 のまま（権限が無い 403・ログインしていない 401）。この葉は新しい断りを足さない
