## 目的

自分の設定 › プロフィール（下絵 me-profile・me-saved・me-name-error）が使う読む口と直す口。

- `getMe`（GET /api/v1/me）：自分（名前・呼ばれ方・メール・顔・見え方）・入っているワークスペースの一覧（役割・主のグループ・今いる会社か・自分だけの場所か・抜けられるか・担当が残っているか）・今いる会社の名前を 1 回で返す
- `updateMe`（PATCH /api/v1/me）：名前・呼ばれ方・言語・見た目・週のはじめ・時間帯を、変えたらすぐ保存（保存のボタンは無い）。**アカウント全体に効く**（下絵「アカウント全体に効く」）ので、同じログインの全部のワークスペースの人の行に書く

**画面が使う答えの形**（画面の葉 K-839・K-841・K-844 の正）：

```
getMe 200 { data: {
  member: { id, name, call_name: string|null, email, avatar: { kind: "text"|"image", initial, url: string|null },
            language: "ja", theme: "system"|"light"|"dark", week_start: 0|1, timezone: "Asia/Tokyo"|"UTC", email_pending: string|null },
  workspaces: [{ tenant_id, name, role: "admin"|"manager"|"member"|"viewer"|"requester", group: string|null, current: boolean,
                 own: boolean, last_admin: boolean, assigned_total: number, assigned: [{ id, number, title }] }],
  workspace_name: string|null } }
updateMe 200 { data: { member: <getMe の member と同じ形>, saved_at: ISO 8601 } }
```

`avatar.initial` は呼ばれ方（無ければ名前）の 1 文字目。`email_pending` は確かめ待ちの新しいアドレス（K-835 が本物にする・この葉では常に null）。`workspaces[].assigned` は担当している終わっていないチケットの先頭 10 件（`assigned_total` は全部の数）で、抜ける小窓（K-841）が「担当しているチケット N 件」を出す元。`last_admin` が true の会社の「抜ける」は押せる形で、押すと小窓（K-841）が E-ME-051 の理由を出す（D-154.75）。`own` が true の会社（自分だけの場所）は押せない形。

## 前提と制約

分類: CRUD, PERM

- **だれが呼べるか**：本人だけ（契約の PERMS のまま・member の束）。会社を指す欄は持たない（今のログインの人だけ。別の人・別の会社は指せない）。入口の共通（401・429・同意し直し 403・strict の形・NUL 422）が先に効く
- **名前**：前後の空白（全角を含む `/^[\s　]+|[\s　]+$/g`）を削ってから 1〜100 字（`Array.from` で数える＝サロゲート対は 1 字。K-827 の会社の名前と同じ数え方）。空・空白だけは 422・E-ME-001・101 字は 422・E-ME-002
- **呼ばれ方**：削ってから 20 字まで。空文字か null は「消す」（call_name を null に戻す・200）。21 字は 422・E-ME-003。画面の字（下絵に無いので**仮**）：「呼ばれ方は 20 文字までです。短くしてください」
- **見え方**：言語は `ja` だけ（「いまは日本語だけ」）・見た目は `system`・`light`・`dark`・週のはじめは `0`（日曜）か `1`（月曜）・時間帯は `Asia/Tokyo` か `UTC`（契約の enum で 422・欄の名前つき）。下絵の時間帯の選択肢は東京・大阪・世界標準の 3 つだが、大阪は `Asia/Tokyo` と同じ時間帯なので、画面の葉 K-839 が 2 つにそろえる（申し送り）
- **体は strict**：欄は name・call_name・language・theme・week_start・timezone だけ。1 つも無い体・知らない欄（member_id・role_id・avatar_ref・email を含む）は 422（顔は K-834・メールは K-835 の口）
- **アカウント全体に書く**（D-125.150）：同じログイン（`tenant_memberships.auth_user_id` が同じ）の、抜けていない全部のワークスペースの `members` 行に、送った欄だけを 1 つの取引で書く。顔（avatar_ref）は会社ごとの置き場なので今いる会社の行だけ（K-834）。抜けた会社・別のログインの人は変えない
- **「入っているワークスペース」**：同じログインの active か suspended の所属。`own` は、その会社の有効な人が自分だけ。`last_admin` は、その会社の管理者（所属の role が admin で status が active の人と、所属の行を持たない owner）が自分だけ（止めた管理者は数えない・K-800 の `app.admin_is_last_admin` と同じ決め）。`group` は主のグループの名前（兼務があっても主だけ）。`assigned*` は、その会社で自分が担当で `completed_at` が空・消していないチケット
- **外枠の会社名 `workspace_name`**：今いる会社の `tenants.name` の前後の空白（全角を含む）を削り、空なら null（K-253 の決めと同じ）。外枠が今読んでいる手で書いた道すじ `GET /api/auth-ext/me` は**変えない**（外枠を getMe に切り替える葉は別・申し送り）
- **記録**：自分の設定の保存（名前・呼ばれ方・見え方）は会社の記録（audit_events）に載せない（会社の大事な出来事ではない・D-154.55）。同じ値への保存は 200 のまま何も書かない
- **同時**：同じ人の同時の保存は、送った欄ごとに後に通った方が残る（別の欄どうしは両方残る）
- DB の失敗は 503（E-PAGE-003・何も残らない・ログに名前・メールを出さない）。読む口の答えは `Cache-Control: private, no-store`
- 断る番号は控え帳どおり（422＝契約に書ける形の誤り／404 は欄・details を付けない／409／503）
