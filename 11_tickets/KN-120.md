## 目的

eslint 9.39.5 は面倒を見てもらえない版になっていた。道具（Electron の組み立てなど）の奥の部品 12 件も非推奨。本番の画面と API には入らないが、eslint は新しい版に上げ、奥の部品は上の道具を上げて消えるものを消す。

## 完了の条件

- [x] eslint を面倒を見てもらえる版に上げ、G1 が緑
- [x] 道具の奥の部品のうち、上の道具を上げて消えるものを消す。残るものは理由を記録に書く
- [ ] CI が緑（push 後に確かめる）

## 前提と制約

- 見つけたもの（D-128.123）：前からあったもの。KN-116 で pnpm に解き直させたとき、lockfile に上流の「非推奨」の印が出て見つけた。記録（scripts/ci/deprecated_baseline.json）にして、増えたら赤（G46 の S4）
- 部品は出てから 21 日を過ぎた版だけ（D-128.124）

## 実施事項

- [x] eslint の版を上げる（設定の書き方の変化を直す）
- [x] 奥の部品の出どころを調べる（electron-builder・node-gyp など）
