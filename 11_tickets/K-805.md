## 目的

管理者が、メンバーの画面の「＋ グループ」から**グループを足せる**ようにする（行為 A117・段 10 から移った物・D-152.21）。小窓の欄は名前・短い名前（番号の頭・作ったあとは変えられない）・層（ふだんの ▾ に「＋ 層を足す」）・マネージャー・メンバー（札）・色 6 つ。足すと、メンバーの画面に新しいグループの行（人がいなければ「0 人」）が出る。グループは消せない（D-154.8）。

## 前提と制約

分類: CRUD, PERM

- **口の答えの形**：足す＝`createScope`（`POST /api/v1/scopes`・K-802）の体 `{ name, ticket_prefix, layer_id?, manager_member_ids?, member_ids?, color? }`・答え 201 `{ data: ScopeCreated }`（K-802 の「画面が使う答えの形」・鍵 10）。層を足す＝`createLayer`（`POST /api/v1/layers`・K-803）の体 `{ label }`・答え 201 `{ data: LayerCreated }`（鍵 6）。層の一覧＝`listLayers`（`GET /api/v1/layers` → `{ data: LayerUpdated[] }`・order_no 順・K-803 が足す口）。小窓の「層 ▾」と、K-806 の層の小窓が読む。マネージャーの選び・メンバーの札は、並びの口 `getWorkspaceMembers`（K-420 の入れ物が読み済み）の人から作る（口を増やさない）
- **開く**：頭の「＋ グループ」で小窓「グループを足す」（副題「グループは日々のチケットの置き場。チケットの番号の頭になる」）。名前に焦点。開くたびに層の一覧を 1 回読む（読めないとき＝503 は小窓の赤い箱＋層の ▾ は「＋ 層を足す」だけ・K805-UI-018）。マネージャーの選びと札の候補は、並びの人を **id で重ねずに**（兼ねる人は 1 度・D-154.15）・招待中の人を除く
- **入力の整え・確かめ**：名前＝前後（全角の空白も）を削る・空は「名前を入れてください」（下絵 gr-add-error）。短い名前＝NFKC・前後の空白を削り・大文字にし、英字で始まる 1〜8 字（T 1 字は使えない）でなければ「短い名前は、英字で始まる 1〜8 字で入れてください（T だけは使えません）」（仮・K-802 の正本の確かめと同じ）。口を呼ばない・小窓は閉じない・欄に aria-invalid。番号の見本は「<短い名前>-1、<短い名前>-2 …」（下絵のまま）
- **色**：6 つ（青緑・赤紫・藍・黄土・朱・若草）＝画面のトークンの tone の鍵（`teal`・`plum`・`indigo`・`amber`・`coral`・`sage` の順・`--k-d-*` の 6 つ・K-800 の VALUE_RANGES・K-802）。既定は青緑（`teal`・口の既定と同じ）。体の `color` は tone の鍵で送る（画面の字でなく。部品 `GroupDialog` の `GroupTone` をそのまま送る）
- **足す**：体は入力のとおり。`layer_id` は選んだ層（「＋ 層を足す」のときは足した層の id）。`manager_member_ids`・`member_ids` は人の id（選んでいなければ送らない）。**上のグループ `parent_id` は送らない**（口が会社のいちばん上の下に置く・D-154.31）。成功（201）：小窓を閉じ・知らせ「「<名前>」を足しました」（useNotify）・並びを読み直す。足す間は「足す」を押せない（`useRef` で二度押しを止める）
- **層を足す**：層の ▾ で「＋ 層を足す」を選ぶと「新しい層の名前」の欄（下絵 gr-layer-add）。足すと `createLayer` → 成功したらその id で `createScope`（口の順は createLayer → createScope）。名前が空なら「名前を入れてください」で口 0 回。409 E-GRP-013（層は 8 つまで）・409 E-GRP-019（同じ名前）は新しい層の欄の下に正本の文・`createScope` は呼ばない。**層は足せたがグループが足せなかった**ときは、足せた層の id を覚えて、押し直したら `createLayer` を呼ばず `createScope` だけを送り直す（層を二重に作らない）
- **口の誤りの字は、その欄を直すまで残る**：409 E-GRP-010（短い名前）・E-GRP-011（名前）の欄の下の字は、その欄の値を変えるまで消さない。ほかの欄の入力の誤り（名前を空にして押す等）で口を呼ばなかった回も残る（下絵 gr-add-error は、名前が空の字と短い名前がもう使われている字が 2 つ同時に出る形＝先に 409 を受け、その後に名前を消して押した回・K805-UI-001・012）
- **口の失敗の出し分け**（答えの code と detail で決める）：409 E-GRP-010（短い名前がもう使われている）→ 短い名前の欄の下に「この短い名前は、もう使われています」（下絵）／409 E-GRP-011（名前が重なる）→ 名前の欄の下／409 E-GRP-012（グループは 200 まで）・404 E-GRP-014・015・020（層・人が無い）・409 E-GRP-016（止めた人・detail の名前）・409 E-GRP-017（閲覧のみ・detail の名前）・403 FORBIDDEN・503 E-PAGE-003 → 小窓の上の赤い箱（`NoticeBox`・正本の文・人の名前は detail から）。404 のときは層の一覧と並びも読み直す。どれも書いた中身は残り、押し直せる
- 取り直し（本人確認）は要らない（グループを足す口は本人確認を求めない・K-802）
- スマホ（767 以下・D-154.13）：小窓が画面の中に収まる（横のはみ出し 0）・足すボタンが押せる
- **並びが読めない間**（getWorkspaceMembers が 503）は「＋ グループ」も押せない（K818-UI-020 の字のまま。試験は「＋ 招く」を見るので替えない）。読めたら押せる
- 部品に足す物（**見た目は変えない・任意の props だけ**・渡さない呼び方＝モックは今のまま）：`GroupDialog`：`onName`・`onCode`・`onLayer`・`onNewLayer`・`onManager`・`onQuery`・`onAddMember`・`onRemoveMember`・`onTone`・`onSubmit`・`onCancel`・`busy`・`layers?`（層の名前の並び）・`people?`（`{ id, name }[]`）・`editLayersOption?: "show" | "disabled" | "hide"`（層 ▾ の中の「層の名前と並びを直す」・D-154.53。渡さなければ "show"＝下絵のまま）。この葉は層の一覧が読めたら "disabled"（つなぐのは K-806・キャンバスに在る物は隠さず押せない形で出す）、読めない（503）なら "hide"（K805-UI-018 の選び肢はちょうど「＋ 層を足す」だけ）。`MembersPage`：`onAddGroup`・`disabledButtons` から `addGroup` を外す（K-818 の props）
