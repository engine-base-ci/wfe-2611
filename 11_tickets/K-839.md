## 目的

誰でも、自分の名前・呼ばれ方・顔・見え方を、保存のボタン無しでその場で直せるようにする（行為 A74）。道 `/account`（flow.json の画面 `account`・自分の設定の「プロフィール」）。口は `getMe`（K-833・1 回読む）・`updateMe`（K-833・直した欄だけ送る）・`uploadAvatar`（K-834・顔の写真）。**アカウント全体に効く**（口が同じログインの全部のワークスペースに書く）。

この葉は**読む・名前・呼ばれ方・見え方・顔**まで。メールを変える小窓は K-840、ワークスペースから抜ける小窓は K-841。それまで「メール［変える］」「［抜ける］」は押せない形（グレー・隠さない）。ほかの自分の設定の画面（ログインと安全・知らせ）は K-842・K-843 が、この葉が作る外枠 `MeShell` を使って足す。

## 前提と制約

分類: CRUD, FILE

- **口の答えの形は K-833・K-834 の「画面が使う答えの形」**：`getMe` → `{ data: { member: { id, name, call_name, email, avatar: { kind, initial, url }, language: "ja", theme, week_start: 0|1, timezone: "Asia/Tokyo"|"UTC", email_pending }, workspaces: [{ tenant_id, name, role, group, current, own, last_admin, assigned_total, assigned }], workspace_name } }`・`updateMe` → `{ member, saved_at }`・`uploadAvatar` → 201 `{ avatar }`。違えば `f10-ops-kit.ts` の `me()` だけを合わせる
- **外枠**：道は `app/(work)/account/page.tsx`（PC をつないでいなくても開く・どの役でも開ける）。`me-shell.tsx` の `MeShell`（`TicketShell` screen `account`・パンくず「自分の設定（押せない）› プロフィール」＋ `k-me-wrap` ＋ `MeSub current="profile"`）の中に `ProfileBody`（K-801 の部品）。`MeShell` は `current` を受け、K-842・K-843 が同じ外枠を使う。第 2 ナビ `MeSub` は components/k に在る物（道の一覧で押せる形が決まる）
- **名前**（保存のボタンは無い）：打つたびに誤りを出す（空・空白だけ「名前を入れてください」・101 字「名前は 100 文字までです。短くしてください」。`Array.from` で数える＝絵文字は 1 字）。**欄を離れたとき・Enter で保存**：前後の空白（全角を含む）を削り、今の値と同じなら送らない・誤りがあれば送らない。`updateMe { name }`。200 → 「✓ 保存しました ・ HH:mm」（`saved_at` を日本時間）・「N ／ 100」・答えで差し替える（読み直さない）。処理中の Enter は無視（二度押しで 1 回）。**失敗（503・網の切れ）**→ カードの上に赤い箱「保存できませんでした。通信を確かめて、もう一度入れ直してください」（下絵 me-name-error のとおり・入れた字は残す・次の保存の成功で消える）。422（E-ME-001・002）→ 欄の下に口の文
- **呼ばれ方**（20 字まで）：同じく欄を離れたとき・Enter で `updateMe { call_name }`。空にすると `{ call_name: null }`（文字に戻る）。21 字は「呼ばれ方は 20 文字までです。短くしてください」（**仮**・口 K-833 の E-ME-003 と同じ字）で送らない。顔の 1 文字（呼ばれ方の 1 文字目・無ければ名前の）は答えの `avatar.initial` を出す
- **見え方**（言語は「日本語」の札だけ・選べない）：見た目（明るい＝light・暗い＝dark・PC に合わせる＝system）・週のはじめ（日曜＝0・月曜＝1）・時間帯（東京（UTC+9）＝Asia/Tokyo・世界標準（UTC）＝UTC の 2 つだけ。下絵の「大阪」は Asia/Tokyo と同じなので外す・K-833 の申し送り）。選ぶと**選んだ欄だけ** `updateMe` で送る（`{ theme }`・`{ week_start }`・`{ timezone }`）。成功したら見た目は `applyTheme`（components/k/theme）で今の画面も切り替える。失敗（503）は選びを前に戻し、見た目も切り替えず、カードの上に E-PAGE-003 の文の赤い箱
- **顔の写真**：「写真を選ぶ」でファイルを選ぶ（`input[type=file]`・`accept` は `image/png,image/jpeg,image/webp`・送ったあと欄の値を空に戻す）。**5 MB（5×1024×1024 バイト）を超える物は口を呼ばず**赤い箱「写真は 5 MB までです。小さい写真を選んでください」（ちょうど 5 MB は送る）。送るのは `call("uploadAvatar", { form })`（multipart の `file` 欄・`call` の form は K-831 が足す）。201 → 顔を `img`（クラス `k-f10a-photo`・`src` は答えの url・alt「顔の写真」）に・「文字に戻す」を押せる形に・赤い箱を消す。413（E-ME-010）・422（E-ME-011）・502（E-ME-012）→ 口の文を赤い箱に（どれも前の顔のまま）。503・網の切れ → E-PAGE-003 の文。「文字に戻す」は `form` に `reset=true` の欄だけ（`file` なし）。成功で顔が文字に戻り、ボタンは押せなくなる
- **メールの行**：今のメールの札と「変える」。**小窓の登録口** `profile-dialogs.tsx`：`export const PROFILE_DIALOGS = { /* K-840 が email、K-841 が leave を 2 字下げの キー: 部品, の形で 1 行ずつ足す */ }`・`useOpenDialog()`。登録の無い操作（「変える」「抜ける」）は aria-disabled・title「まだ使えません」にする（K839-UI-015・016 が登録の有無を字で読む：`^ {2}(email|leave)\s*:`）。登録された小窓には `{ me, workspace?, onClose, reload }`（答えの差し替えと読み直しの関数）を渡す。確かめ待ちの宛て（`email_pending`）の見せ方は K-840 が足す
- **入っているワークスペース**：答えの `workspaces` を並べる（名前・「<役割> ・ <主のグループ>」・自分だけの場所は「自分だけ」）。役割の字は管理者・マネージャー・メンバー・閲覧のみ・依頼する側（**仮**）。主のグループだけを出す（兼務があっても主だけ・D-154.15。兼務の見せ方はメンバーの画面）。「抜ける」：自分だけの場所（`own`）は押せない形。抜けられる場所は登録（leave）があれば押せる・無ければ押せない形。最後の管理者の場所の「抜ける」は K-841 の小窓が理由を見せるので押せる形（K-833 の「押せない形」の申し送りを、下絵 me-leave-last-admin に合わせて改める・申し送り）
- **読めない**：503・網の切れは `ErrorState`（E-PAGE-007 の形）＋「もう一度読む」。401 は call が入り直しへ送る
- スマホ（767 以下）は崩れず読めて押せる（D-154.13）。幅 320 でも 100 字の名前・長いメールで横のはみ出し 0
- 作らない物：下絵 me-saved の「ほかの画面での見え方」の区画（長い名前の見本を見るための物で本番には出さない・突き合わせはその区画を含まない役だけを比べる）・書き出し・退会の操作
