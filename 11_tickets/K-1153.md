- **値の形**（K-564）：短い文字・長い文章＝文字（前後の空白を落とす）／数＝`parseNumber`（NFKC・前後の空白とカンマを落とす・数でなければ欄の下「〈名前〉は数で入れてください」で口を呼ばない）／日付＝`YYYY-MM-DD`／1 つ選ぶ＝選択肢の id（必須でなければ選択肢の先頭に「選ばない」＝null）／複数選ぶ＝選択肢の並びの id の並び（全部外して決めると null）／チェック＝真偽（**必須でない箱を外すと false を送る**。null ではない）。空（空の文字・空白だけ・空の数・空の日付）は null
- **必須の項目を空にして決める**：口を呼ばず、欄の下に K-569 の型ごとの言い方（日付・選ぶ・複数選ぶ＝「〈名前〉を選んでください」・文字＝「〈名前〉を書いてください」・数＝「〈名前〉を入れてください」）。入力は開いたまま。必須の 1 つ選ぶには「選ばない」を出さない。**必須のチェックは外せない**：押すと箱は付いたままで、欄の下に「〈名前〉にチェックを付けてください」を出し、口を呼ばない
- **断りの出し分け**（段 9 の D-148.30〜38 の分け方）：409 の E-FLD-001（その種別に出ない）・002（選択肢に無い）・003（型に合わない）・004（必須が空）と 404 の E-PAGE-001（項目が消された）は、その行の欄の下の赤い字に正本の文（`errorText`・答えの体は `{ error, code }` だけで文を持たない）をそのまま出し（**手元の誤りも口の断りも、文は `CustomInput` の `error` に渡す**。枠が誤りの色になり `.k-err` は部品が出す。自分で文の要素を作らない）、入力は開いたまま残る（もう一度直せる）。422（契約の形の誤り）は E-FLD-003 の文を欄の下に出す。404 のときだけ getTicket の読み直しを 1 回する（答えに項目が無ければ行が消える・在れば欄の下の文が残り入力は開いたまま・読み直し自体が失敗したら今の表示のまま）。403 と 503 は **5 秒で消える小さな知らせ**（`useNotify` の既定の type＝5 秒。type error は自分で閉じるまで残るので使わない）：403 は「この操作をする権限がありません。権限が変わったかもしれません。画面を読み直してください」で元の値に戻して入力を閉じる・503 は E-PAGE-003 の文で入力を残す（もう一度押せば通る）。画面は役の名前で出し分けず、口の答えで出し分ける
