## 目的

管理者が、メンバーの 1 人の画面で、その人の**グループを移し（主の所属）**、**兼ねるグループを足し・外せる**ようにする（行為 A61「所属・権限を決める」・D-154.34）。1 人が複数のグループ（違う層のマネージャーを兼ねる・別の部署に作業員として入る）に入れる形（D-154.15）を、画面と試験で通す。人ごとの「できること」は作らない（D-154.10）。

## 前提と制約

分類: PERM

- **口の答えの形は K-812 の「画面が使う答えの形」**：`updateMemberGroups`（`PATCH /api/v1/members/<id>/groups`）の体 `{ primary_scope_id?, add_scope_ids?, remove_scope_ids?, role_key? }`（1 つは要る）・答え 200 `{ data: { member_id, company_role, groups: [{ id, name, code, primary, role }] } }`（主が先）。口は 外す → 移す → 足す の順で 1 つの取引（K-812）
- **開く**：詳細の「グループを移す」「＋ 兼ねるグループを足す」で小窓を開く／直に `?do=move`・`?do=also`（K-819 の登録口・開いたら URL から `do` を消し、読み直しでは開き直さない）。`detail-dialogs.tsx` の `DO_DIALOGS` に `  move・also: `MoveDialog`・`AlsoDialog` の入れ物,` を 2 字下げの 1 行で足す（K-819 が置いた登録口。K819-UI-018 がこの形の字を読んで、足した操作のボタンを押せる形に数える）。開くとき、グループの一覧を `getWorkspaceMembers` の `groups[]`（id・name）で 1 回読む（口を増やさない）
- **グループを移す**（小窓「グループを移す」・副題「<名前> の、いまのグループ：<主のグループ>」）：移す先の選びは、いまの主のグループを除いた全部（初めは先頭）。移せるグループが無い（会社に 1 つだけ）ときは「移せるグループがありません」で足のボタンは押せない。足のボタン「本人確認して移す」→ 体は `{ primary_scope_id }` だけ（足す・外すは送らない）。主を移すと前の主のグループからは外れる（口の決め・K-812）。成功：小窓を閉じ・区画「グループと役割」を答えの `groups` で差し替え・知らせ「<名前> を <移し先> に移しました」・メンバーの並びの読み直しの印（`reloadMember`・並びの鍵の invalidate）を付ける
- **兼ねるグループを足す・外す**（小窓「兼ねるグループを足す・外す」・副題「<名前> は、ほかのグループも兼ねられる」）：いま兼ねているグループ（主でないグループ）を「<グループ>を外す」ボタン付きで並べる（外す＝その場で外す印を付けて消える・口は保存まで呼ばない）。「足すグループ」の選びは、主でも兼ねてもいないグループだけ。足すグループの選びに空の選び肢は置かない（選ぶまで保存は押せない）。足のボタン「本人確認して保存する」→ 体は足す分だけ `add_scope_ids`・外す分だけ `remove_scope_ids`（1 つの体に両方入れてよい）・**`role_key` は送らない**（新しく足すグループはメンバーで入る・口の既定）。主のグループは外せない（外すボタンを出さない・口も 409 E-MEM-008）。何も変えていなければ保存は押せない。成功：閉じて区画を答えで差し替え・知らせ「<名前> の兼ねるグループを直しました」
- **兼務（D-154.15）**：1 人が 3 つ以上のグループに入れる（上限なし）。営業の主＋受託開発のマネージャーを兼ねる人に、経理を作業員として足しても、受託開発の役割（マネージャー）と主は変わらない（答えの `groups` で区画が「受託開発・経理」になる）。役割の変更はメンバーの画面の役割の ▾（K-818）が持つ
- **本人確認の取り直しは今の部品 `StepUp`（features/F1/security/step-up.tsx・パスキーなら指 1 本の stepUpWithPasskey も同じ部品の中・D-154.3）を使い、K-363 と同じ形：口が 403 STEP_UP_REQUIRED（kind `step_up`）→ `getMySecurity` を 1 回読んで `StepUp` を開く → 通ったら同じ体で **1 回だけ**やり直す・やめたら何も送らない**。理由の字＝「グループを移す前に、本人か確かめます」（兼ねるは「兼ねるグループを直す前に、本人か確かめます」）・（仮）
- **失敗の出し分け**（答えの code と状態で決める）：404 E-MEM-002（もう居ない）→ 小窓を閉じて詳細を読み直す（→「見つかりません」）／404 E-MEM-006（グループが無い）・409 E-MEM-007（その人がそのグループに居ない）→ 小窓の赤い箱＋グループの一覧を読み直して選びを新しくする（小窓は閉じない）／409 E-MEM-003（自分）・403 FORBIDDEN・503 E-PAGE-003 → 小窓の赤い箱（中身は残る・押し直せる）
- **自分**：自分の詳細では「グループを移す」「＋ 兼ねるグループを足す」は aria-disabled（title「自分のグループは、自分では変えられません」）・`?do=move` でも開かない（口 409 E-MEM-003 を待たない）
- 答えを待つ間は足のボタンを押せない（`useRef` で二度押しを止める）。やめる・Esc で焦点は開いたボタンへ戻り、開き直すと選びは初めの値
- スマホ（767 以下・D-154.13）：2 つの小窓が画面の中に収まる（横のはみ出し 0）
- **部品に足す物**（見た目は変えない・任意の props だけ）：`MoveDialog`・`AlsoDialog`：`groups?`・`value`・`onChange`・`onSubmit`・`onCancel`・`busy`・`notice`・`error`・（also）`onRemove(code)`・`removed`・`addable`。`MemberPage`（`features/F10/member/views.tsx`）：`disabledActions` から move・also を外す（K-819 の props）。**自分の扱いを部品に足す**：今の部品は自分のとき止める・外すにだけ自分の title を付け、「グループを移す」「＋ 兼ねるグループを足す」の `RowButton` は自分の扱いを持たない。そこで `MemberPage` が `d.self` のとき move・also の `RowButton` にも `aria-disabled`・`tabIndex -1`・title「自分のグループは、自分では変えられません」を付ける（止める・外すと同じ書き方・自分の title が disabledActions の「まだ使えません」より勝つ・K-819 の前提）。新しい props は足さない（`self` は今の `MemberDetailData` に在る）。下絵の md-self は自分なので、この字が下絵にも出る（下絵の見た目の形・大きさは変えない）
- **下絵との突き合わせ（K820-UI-001）**：下絵の md-move・md-also は頭の「一時的に止める」「ワークスペースから外す」を押せる形で描き、本番はこの葉では登録（K-821・K-822）が無いので aria-disabled（不透明度 0.55）。押せない入口がある間は matchMock に `skip: ["acts:opacity", "acts:color"]` を渡す（K-420・K-819 と同じ訳。数・大きさ・字は比べる）
