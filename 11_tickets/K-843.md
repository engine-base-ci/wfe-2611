## 目的

誰でも、ワークスペースごとに「何を・どこに（ベル／メール）・いつ知らせてもらうか」を、保存のボタン無しでその場で決められるようにする（行為 A74）。道 `/notifications`（第 2 ナビ `MeSub` の「知らせ」が前から指す道・自分の設定 › 知らせ）。外枠は K-839 の `MeShell`（`current="notices"`）。口は `getNotificationSettings`（タブを開いたワークスペースごとに 1 回読む）・`updateNotificationSettings`（押した項目だけ送る）・`copyNotificationSettings`（ほかのワークスペースに写す）。

**保存だけ**（D-154.24）。受け箱やメールを実際に出す・止めるのは F7（K-67）で、この画面は受け方を決めるだけ。

## 前提と制約

分類: CRUD, PERM

- **口の答えの形は K-837 の「画面が使う答えの形」**：GET・PATCH 200 `{ data: { workspace_id, email_digest, quiet_hours: { preset }, paused_until: ISO|null, urgent_override: ("approval_due_today"|"clone_stopped")[], events: [{ key, bell, mail, fixed }] } }`（7 つ・K-837 の順）・copy 201 `{ data: { copied_to: [workspace_id…] } }`。違えば試験の `settingsOf()` だけを合わせる。ワークスペースの一覧は K-839 の `use-me.ts`（鍵 `["k839","me"]`）の `workspaces` を使う（読み直さない）
- **外枠**：道は `app/(work)/notifications/page.tsx`（どの役でも開ける・PC をつないでいなくても開く）。`MeShell current="notices"`（パンくず「自分の設定（押せない）› 知らせ」。`MeShell` が `current` に合わせて最後の字を出す形でなければ、この葉が `me-shell.tsx` に字の表を足す）。本文は K-801 の `NotifyBody`
- **タブ**：`workspaces` の順にタブ（字は会社名）。初めに開くのは `current` のワークスペース。タブを開いたときだけ、そのワークスペースを `call("getNotificationSettings", { query: { workspace_id }, screenId: "account" })` で 1 回読む（鍵 `["k843","notify",workspace_id]`・`staleTime: Infinity`）。開き直しても読み直さない
- **出来事**（`notify-shape.ts` の `EVENT_ROWS`：key → 字と補足。下絵の字のとおり）：approval_waiting「承認を待っている」（自分が承認する人のとき）・mentioned「@ で呼ばれた・やり取りで知らせる人にされた」・handed_over「渡された・配られた」（返事の期限つき）・clone_stopped「分身が止まった・落ちて直せない」（PC が切れた・ログイン情報が切れた など）・clone_finished「分身が実行を終えた」（やったことは分身の部屋でも見られる）・ticket_changed「自分が担当・承認するチケットが動いた」（状態・期限の変化）・new_device「新しい端末で入った」（安全のため止められない）。並びはこの順（答えの順に依らない）。`fixed` が真の行のチェックは押せない（disabled）
- **押したら保存**：ベル・メールのチェックを押すと、その行だけ `updateNotificationSettings { workspace_id, events: [{ key, bell, mail }] }`（押した後の 2 つの値）。答えで差し替える（読み直さない）。その行は答えが返るまで押せない（二度押しで 1 回）。**失敗**（503・網の切れ）→ チェックを前に戻し、その行の補足を「保存できませんでした。もう一度、押してください」に替え、本文の上に赤い箱「保存できませんでした。通信を確かめて、もう一度押してください」（下絵 me-notify-failed の字・次の保存の成功で両方消える）。409 E-ME-040（止められない出来事）→ 前に戻して赤い箱に口の文。401 → `call` が入り直しへ
- **静かにする時間**：「夜と休みの日」の ▾ の 4 つ（weekdays_night_weekend「平日 20:00〜8:00 ・ 土日」・every_night「毎日 20:00〜8:00」・weekend_only「土日だけ」・off「使わない」）。選ぶと `{ workspace_id, quiet_hours: { preset } }`。ボタンの字は答えの preset の字＋「 ▾」。失敗は前に戻して赤い箱（同じ字）
- **いま止める**：「1 時間」「今日いっぱい」「明日の朝まで」→ `{ workspace_id, pause: "1h"|"today"|"tomorrow_morning" }`。答えの `paused_until` が在れば帯（下絵の `Band` tone wait）「いま止めています ・ <いつまで>」・副「メールは止まっています。受け箱にはたまります」・［止めるのをやめる］→ `{ workspace_id, pause: null }`。<いつまで>は、その人の時間帯（getMe の `member.timezone`）で `paused_until` が次の 0:00 なら「今日いっぱい」・明日の 8:00 なら「明日の朝まで」・ほかは「HH:mm まで」（**仮**・D-154.80）。`paused_until` が過ぎていれば帯を出さない
- **止めていても知らせる**：「承認を待っている（期限が今日）」（approval_due_today）・「分身が止まった」（clone_stopped）の 2 つのチェック。押すと `{ workspace_id, urgent_override: [<真の物>] }`（空にしてよい）
- **メールのまとめ**（email_digest）は下絵に操作が無いので出さない（注の字だけ・送らない）
- **ほかのワークスペースにも写す**：見出しの右の［この設定をほかのワークスペースにも写す］→ 小窓（K-801 の `CopyDialog` と同じ見た目）。副題「いま開いている「<開いているタブの会社名>」の知らせの受け方を、選んだ場所に写します」。開いているタブのほかのワークスペースをチェックで並べる（初めは何も選ばない）。注「写すと、向こうの今の受け方は置き換わります。静かにする時間も一緒に写ります」。［写す］は 1 つ以上選ぶまで押せない。押すと `call("copyNotificationSettings", { body: { from_workspace_id, to_workspace_ids }, screenId: "account" })`。201 → 小窓を閉じ、知らせ（toast）「<N> つのワークスペースに写しました」（**仮**）・写した先のタブの読みを捨てる（次に開いたとき 1 回読む）。503・網の切れ → 小窓の中に E-PAGE-003 の文・開いたまま。404（もう抜けた会社が混ざった）→ 小窓の中に E-PAGE-001 の文・自分を読み直す（`reloadMe()`）。ワークスペースが 1 つしか無ければ［この設定を…写す］は押せない形（aria-disabled・title「写す先のワークスペースがありません」＝**仮**）
- **読めない**：タブの読みが 503・網の切れ → そのタブの中に `ErrorState`（E-PAGE-003 の形）＋「もう一度読む」（下絵 me-notify-failed の 3 つめのタブの形）。404（もう抜けた会社）→ そのタブの中に E-PAGE-001 の文。ほかのタブは使える
- 本人だけの画面（どの役でも開ける）。送る体に人を指す欄を持たない（`workspace_id` は会社だけ）。スマホ（767 以下）は崩れず読めて押せる（D-154.13）
- 作らない物：デスクトップとスマホへの知らせ（後のフェーズ・注の字だけ）・メールのまとめの操作・受け箱・記録への書き込み（自分の受け方は記録しない・D-154.55）
