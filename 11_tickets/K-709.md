## 目的

管理者が「チケットの設定 › 項目」で、会社が足した項目（チケットの項目の表に、用意した項目と同じ形で並ぶ物）の名前・型・選ぶ物・必須・説明・どの種別で出すかを直せる画面（行為 A118・下絵 v2 の set-fields）。読む口は K-706（`listTicketFieldMaster`）と種別の口、直す口は K-717（`updateTicketField`）。入れ物（道・外枠・タブ・管理者だけ）と小窓の部品は K-707 が作ってあり、この葉は **「項目」のタブの中身**を登録口 `tab-panels.tsx` に 1 行足して入れる。

**項目を足す・消す（小窓つき）は、別の葉に分けた**（この葉の試験の行が 30 を超えるため）。この葉は差し込み口 `fields-slots.ts` を置き、「項目を足す」「この項目を消す…」を押せない形で出す。別の葉が口 `createTicketField`・`deleteTicketField` につないで 1 行足す。

- **差し込み口（`fields-slots.ts`・別の葉が自分の 1 行だけ足す）**：`FieldSlot = { add?: () => void; delete?: (id: string) => void; overlay?: ReactNode }`（`overlay`＝画面に重ねる小窓。K-720 が使う。`mergeFieldSlots` は小窓を**先に出した物 1 つ**にまとめ、`fields-container.tsx` が `merged.overlay` を描く 1 行をこの葉が持つ。この欄の動きは K-720 の K720-UN-004 が見る。この葉の時点は誰も載せない）・`FIELD_SLOTS: readonly ((ctx: FieldCtx) => FieldSlot)[]`（この葉の時点は空）・`FieldCtx = { fields, kinds, selectedId, select(id), reload(), notify(text) }`・`mergeFieldSlots(slots, ctx)`・`isInertField(merged, "add" | "delete")`。**動きの無い操作は押せない形**（`aria-disabled="true"`・押しても何も起きない）で出す（実装が無いのに押せる死にボタンを作らない）。モック（props を渡さない）は今の見た目のまま
- **項目の欄（`fields-container.tsx`）**：右の欄は選んだ項目（`?id=`・無い id は先頭）。**型の欄**：値が 1 つでも入っている項目（`value_count > 0`）は選べない形（`disabled`）で「値が入っている項目は、型を変えられません」を欄の下に見せる。値が無い項目は 7 つの型から選べる。**選ぶ物の欄**は選ぶ型（1 つ選ぶ・複数選ぶ）のときだけ出る：1 行ごとに つまみ・名前の欄・「外す」、下に「選ぶ物を足す」（足すと空の欄が増えて焦点）。**並べ替えはつまみのキーボード**（Enter でつかむ〔`aria-pressed="true"`〕→ ↑↓ → Enter で落とす・Esc で戻す）。マウスで掴む並べ替えは作らない（選ぶ物は欄が短く、保存と一緒に送るため）。**必須**はチェック・**説明**は 1 行の欄・**どの種別で出すか**は種別の数だけのチェック（種別の色の点つき）
- **保存**は「保存する」で書く口 1 本（`updateField`）：差分が `{}` のあいだは押せない形（口を呼ばない）。入力の確かめは JS が先に働く（`<form noValidate>`）：問題の文は**その欄の下**（名前・選ぶ物・種別それぞれの `fieldset`／欄の中の `.k-err`・`aria-invalid`）に出し、口を呼ばない。成功でお知らせ「項目「<名前>」を保存しました」・一覧を読み直す。**二度押し**は答えを待つ間「保存する」を押せない（口 1 回）
- **口が断る番号**（土台-settings.md の 3 章）：409 E-FMS-001（同じ名前）は名前の欄の下／409 E-FMS-004（同じ名前の選ぶ物）は選ぶ物の欄の下／409 E-FMS-002（値が入っている間は型を変えられない・別の人が値を入れた直後）は型の欄の下に正本の文で、選んだ型・中身は残す／403 → E-PAGE-002（束を外された直後に「保存する」を押した）＝赤い箱に正本の文／409 E-FMS-005（選ぶ型でない項目に選ぶ物だけ・画面は送らないので最後の砦）は赤い箱に正本の文／503・網の切れは赤い箱（`NoticeBox`・role=alert）／404 E-PAGE-001（開いている間に消された）は赤い箱に正本の文＋項目を読み直す（一覧から消える）。**どれも書いた中身は残り、押し直せる**
- **会社が足した項目が 0 件**：「会社が足した項目はまだありません」（`Empty`・**仮**）。右の欄は出さない。「項目を足す」は一覧の下に出す（差し込みが入るまで押せない形）
- **保存していない変更を持ったまま離れるとき**（別の項目・別のタブ）：K-707 の `unsaved-guard.tsx`（名前・型・選ぶ物・必須・説明・種別が元と違えば `setDirty(true)`）。小窓「保存していない変更があります」（捨てて移る／戻る）
- **部品に足す物（見た目と並びは変えない・任意の props だけ）**：`views.tsx` の `FieldsPanel`（`hrefOf`・`onSelect`・`live`＝値・問題の文・型の固定・選ぶ物の動き・保存・`addInert`／`deleteInert`）。渡さない呼び方（モック）は今の見た目のまま。`settings.css` は正本のトークンだけ。**K-707・K-708 も同じファイルに足す**（`overlap_ok` はまとめ役）
