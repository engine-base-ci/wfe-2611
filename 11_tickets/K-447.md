- **書き始める**：開いた版 `baseVersion = detail.body?.version ?? 0`・`baseDoc = detail.body?.doc ?? 空の木（{ type: "doc", content: [] }）`。口は 0 回（getTicket の答えにある物だけ）。開いたとき最初に `DocEditor` に焦点が行く
- **書き終える**（`use-body-edit.ts`・`finish()`）：①送っている間は二度目を送らない（ボタンは `disabled`・`aria-busy`）②`doc` が `baseDoc` と同じ（木の JSON が同じ）なら口を呼ばず、読み直さず閉じて写しを消す ③`call("updateTicketBody", { params: { id: ticket.id }, body: { version, doc }, keepOn401: true })`。**送る鍵は `version` と `doc` だけ**（text は送らない・口が作る・K-432）。薄い節（`attrs.ghost`）は本文に入っていない前提（K-567 の出力のまま送る） ④通ったら（`changed` が偽でも）`ticket.reload()` して閉じ、写しを消す
- **先に直されたとき**（口の 409・E-SEC-004）：`stale` の印を立てて `ticket.reload()` し、本文の上に帯を出す。**字は決定 D-150.13 のとおり固定**（口の文は使わない）：題「ほかの人が先に直しました」・要約「読み直してから、もう一度直してください。」・「比べる」「読み直す」。書いた字は消さず編集の形は開いたまま。次の「書き終える」は、読み直した最新の `detail.body.version`（最新の props を指す ref から読む。`reload()` は版を返さない）に取り替えて送る。もう一度 409 なら同じ流れ
- **「比べる」**（勧め）：新しいタブで `versionsHref(ticket.id)`（K-449）を開く（`<a target="_blank" rel="noopener">`）。書いている画面・字・帯は変えず、口は呼ばない
- **「読み直す」**（勧め）：確かめなしで、書いた字を捨てて先に直された本文（読み直し済みの `detail.body.doc`）を編集欄に読み込む。帯が消え、写しの元の版を今の版に替える。口は呼ばない（先に「比べる」で見られる）
- **失敗の出し方**：409・E-SEC-004＝帯／**409・E-SEC-005（完了にされた）＝赤い箱に正本の文**／401＝ログイン切れの赤い帯（下）／413＝口の答えの `message`（「送る内容が大きすぎます」）／それ以外（403→E-SEC-006〔書く操作の断り・PM の決め 2026-11-28〕・404〔code E-PAGE-001 も NOT_FOUND も〕→E-PAGE-001・503→E-PAGE-003・つながらない＝`fetch` が投げる→E-PAGE-008）は赤い箱（`NoticeBox`・`role="alert"`・`errorCodeOf` の正本の文）。赤い箱は編集の形の上。どれも書いた字は残り、編集の形は開いたまま、もう一度押せる。送り直しが通ったら赤い箱は消える
- **ログインが切れたとき（口の 401）**：入り直しへ勝手に移さず（`keepOn401`）、本文の上に赤い帯（`role="alert"`・題「ログインが切れました」・要約「入り直すと、いま書いている内容は消えます。必要なら、先に別の場所へ写してください。」・ボタン「ログインし直す」）。書いた字は欄に残る。「ログインし直す」は `clearDraftCopies()`（`@/lib/api/client`）で写しを消して `/login?next=<今の道>` へ移す。続きから書けるとは約束しない（共有の PC で次の人に見せない守りのまま）
- **自動保存はこの PC の写し**（口には書き終えたときだけ送る・K-432 の決め）：直すたびに 0.6 秒まとめて `localStorage` の `kaname.ticket-draft.body.<チケットの id>` に `{ savedAt: ISO の時刻, doc, base: <書き始めた版> }`（チケットごとに 1 つ・本文は 1 枚）。鍵の頭 `kaname.ticket-draft` はログアウトとほかの 401 の `clearDraftCopies` が消す頭。印は「自動で保存しました（HH:MM）」（日本時間・保存した時刻・下絵の字）。印の `title` に「この PC のブラウザの中に残しています。ほかの端末では続きを書けません」（勧め・字は下絵のまま）。置けない（例外）ときの印は「自動で保存できませんでした。書き終えるまで、この画面を閉じないでください」（`data-kind="failed"`・勧め）で、書き続けられ書き終えるも通る。書き終える・やめるで写しを消す
- **開き直し・再読み込み**：写しがあれば編集の形で開き直し、欄は写しの `doc`・印は写しの時刻。写しの `base` が今の版と違えば、帯「ほかの人が先に直しました」を出す（口は呼ばない・書き終えると上と同じ 409 の流れ）。**読めない写し**（JSON でない・`doc` が木でない・`base` が整数でない）は捨てて読む形のまま開く（エラーは出さない）。完了したチケット・前の形のチケットの写しは使わず捨てる
- **別のタブ**：写しはタブをまたいで同期しない。先に書き終えたタブの後、もう一方で書き終えると 409 の帯（上の流れ）
- **「やめる」**（勧め）：直していなければ確かめなしで読む形に戻り、写しを消す。**直した後は小窓**「書いた内容を捨てますか」（本文「やめると、いま書いている内容は消えます。」・ボタン「書き続ける」「捨てる」）。「捨てる」で本文は元のまま・写しを消す。口は呼ばない
- 画面は役の名前で出し分けず、口の答えで出し分ける（K-411 と同じ決め）。本文は字として描く（`dangerouslySetInnerHTML` を使わない）。編集の部品の中身（Tiptap の型）をこの葉で import しない（`features/F4/doc/editor` の公開口 `DocEditor` だけ・K-567 の境界）
- 読み上げ・キーボード：入口は button「本文を直す」・編集の欄は textbox「本文」（K-567）・帯のボタンは「やめる」「書き終える」・印は `role="status"`・帯は `role="alert"`。Tab の順は 道具の帯 → 本文 → やめる → 書き終える
