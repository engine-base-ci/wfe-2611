## 目的

デザインの検査 `scripts/ci/design_gate.py`（D1〜D7）は、色・字の大きさ・書体・角丸・部品の値しか見ない。画面の CSS に生で書いた大きさ・余白・間・行の高さ・影（`padding: 10px 12px`・`gap: 6px`・`max-width: 720px`・`line-height: 1.9`・`box-shadow: 0 8px 24px …`）は、どの検査も見ずに通る。そのせいで画面のチケットが 7 本続けてレビューで差し戻しになった（代表の指示「汎用的に通用するように更新もして完璧にしてくれ」）。

新しい段 D8 を足す。画面の CSS の宣言の値に、トークン（`var(--…)`）を通らない生の長さがあれば赤。今ある生の値は台帳に載せて通し、台帳は減らすだけにする（直したら台帳から消す・足したら赤）。

分類: TOOL

- 決まりは汎用に書く：見る置き場・トークンの定義元・許しの値・見ない性質・台帳の道は、プロジェクトの `design-gate.json` の `raw_lengths` から読む（スキル側の design_gate に同じ形の検査が要るときも、台本を写して設定を書けば動く）。台本はプロジェクトの名前・道を決め打ちしない
- D8 は `--raw-lengths` を付けた回だけ流す（G37・キャンバスの G71・K-218 の試験は今のまま）。付けたのに設定が無い・比べ方（`--ledger-base-ref <版>` か `--no-base`）の指定が無いときは赤（黙って緑にしない・L-021）
- 見る性質は決め打ちしない：どの性質の宣言も見る（表に名前の無い text-indent・scroll-margin・background-size なども）。外すのは別の段が比べる値だけ（font-size の px は D4・border-radius の px は D3。font-size の rem や 角丸の %・角ごとの角丸は D3・D4 が比べないので D8 が赤）
- 生の長さ：数と長さの単位（px・rem・em・%・vw・vh・vi・vb・vmin・vmax・svh/lvh/dvh などの小・大・動の単位・ch・ex・cap・ic・lh・rlh・rem/rex/rch/ric/rcap・cqw/cqh/cqi/cqb/cqmin/cqmax・pt・pc・cm・mm・in・q。指数の書き方 1e1px も）と、line-height の単位の無い数。0（どの単位でも）と 100% は設定の許しの値（理由つき）。auto・normal は数でないので見ない
- 見ない物：@media・@container の条件の区切りの幅・@keyframes の区切り（宣言ではない）・色の関数（rgb・hsl・color-mix など）の中・文字（"…"）と url(…) と注釈の中・時間（s・ms）・数だけの値（z-index・opacity・flex の伸び）
- 抜け道も赤：var の予備の値（`var(--k-x, 12px)`）・calc／min／max／clamp の中・入れ子・@layer／@supports／@media の中・!important

- 置き場の集め方：paths の下の .css を全部。node_modules・.next・dist・build・out・coverage・test-results・playwright-report・.git の下は読まない（CI で組み立てた後でも数が変わらない）。D1〜D7 の ignore_files は D8 に効かない
- 分かれ目との比べ方：分かれ目の設定（design-gate.json）が指す台帳と比べる（台帳の道を変えても逃げられない）。足した行・増やした count・入れ替え（1 行消して別の 1 行を足す）は赤。分かれ目の設定に raw_lengths が無い回（台帳を入れる回＝このチケット）だけ比べずに通す。設定は在って台帳が無ければ赤
