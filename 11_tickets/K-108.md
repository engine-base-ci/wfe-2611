## 目的

K-107 の 2 回目の精査（2026-11-06）で見つかった、前からある物。.github/workflows/v3-gate.yml の task-gate に `echo "TASK_ID=${{ github.head_ref }}"` があり、枝の名前に `$(...)` などを入れると命令が動く形（GitHub の案内でいう script injection）。今は pull_request で動かないので害は無いが、GitHub で pull_request を受けるようにした時点で穴になる。K-107 の CS-034 は inputs・needs の値だけを見ていて、github. の値は見ていない。

## 完了の条件

- [ ] workflow の run の中に、外から来る値（github.head_ref・github.event.*・inputs.*・needs.*.outputs.*）を `${{ }}` で直に書いている所が 0。どれも env で渡し、引用符で使う
- [ ] その形を CI の検査で赤にする（K-107 の CS-034 を github. の値まで広げる）
- [ ] workflow の全部（act）が緑

## 前提と制約

- K-107 の検査の形に合わせる（同じ検査を 2 つ作らない）

## 実施事項

- [ ] 作る役：run の中の `${{ github.` を全部洗い出し、試験の行を書く

## テスト仕様と確認の結果

| 確認項目 | 種類 | 判定のしかた | 結果 |
|---|---|---|---|
| run の中に外から来る値の `${{ }}` が無い | ① 単体 | workflow を読んで検査を流す。わざと 1 か所書いた写しで赤 | |
