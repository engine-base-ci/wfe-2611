## 目的

ワークスペースの大事な出来事（権限が変わった・外に出した・新しい端末で入った・分身に許可した・消した）を、新しい順に読み、ことばと札で探せるようにする（行為 A33・A40）。道 `/audit`（flow.json の画面 `audit`）。口は `listAuditEvents`（K-823 が札・人・チケット・期間・続き、K-850 がことば q）を読むだけ。**管理者は会社全体、マネージャーは自分のグループの分だけ**（D-154.11）。メンバー・閲覧のみは開けない。

作らない物：書き出し（記録の「書き出す」・持ち出しの札・小窓・D-154.4）・自分の記録を開く入口（D-154.2）・記録を消す／直す操作（追記だけ・D-154.25）・「戻す」の実際の動き（F7 の口 restoreTicket が入るまで押せない形・D-145.9）。

## 前提と制約

分類: LIST, PERM

- **口の答えの形は K-823・K-850 の「画面が使う答えの形」**：`{ data: { entries: [{ id, occurred_at, kind, action, actor: {id,name}|null, target, text, reason, device, step_up, deleted }], next_cursor, scope: "all"|"groups", scan_capped? } }`。問い合わせは `kind・member_id・ticket_id・q・cursor・limit`（from・to は画面から送らない）。違えば `f10-ops-kit.ts` の `auditBody` だけを合わせる
- **外枠と 2 つの形**：道は `app/(work)/audit/page.tsx`（PC をつないでいなくても開く）。外枠は前からの `TicketShell`（screen `audit`）。答えの `scope` で形が決まる：
  - `all`（管理者）：パンくず「ワークスペースの管理 › 記録」・`WsHead`・`WsSub active="log"`・`k-me-wrap` の中に本文（下絵 lg-list）。見出しの下「ワークスペースで起きた大事なこと。消せない・直せない」・札 6 つ
  - `groups`（マネージャー）：パンくず「記録」だけ・頭と第 2 ナビは出さず本文だけ（下絵 lg-manager・マネージャーは設定とメンバーを開けない）。見出しの下「自分のグループのチケットと、その人たちの操作の記録（仮）」・札は出さない（下絵のとおり・口は札を受けるが画面は出さない）・下の字「ワークスペース全体の記録は、管理者だけが見られる（仮）」
  - 答えが来るまでは本文の場所に `Loading`（形を決めない）。第 2 ナビ（`WS_ITEMS`）の記録の行き先を `/audit` にするのは K-831（設定と同じ 1 回の直し）。この葉はその行き先を試験で見る
- **権限**：口が 403 なら本文を `NoAccess`（外枠の中の `section aria-label="記録"`・「この画面を見る権限がありません」）に替える。**閲覧のみ（`useMyRoles()` が R4＝`lib/auth/role.tsx` の viewer）は口を呼ばずに同じ画面**（閲覧のみは記録を読めない・D-154.11）。**R3（staff＝メンバーとマネージャー）は口を呼び、403 か `scope` で決まる**（マネージャーかどうかは口にしか分からない・メンバーは 403・マネージャーは `scope: groups`）。R1・R2（管理者）は口を呼んで `scope: all`。続きを読むときの 403（権限を外された直後・TP-PERM-02）も同じ画面に替える
- **URL が状態**（TP-LIST-03）：`/audit?kind=<札>&q=<ことば>&member=<uuid>&ticket=<uuid>`。画面の絞りは `router.replace` で URL に書き、開き直しても同じ絞り。口へは `kind・q・member_id・ticket_id` で渡す。値の確かめ：kind は 6 つのどれか・member・ticket は uuid・q は前後の空白を削って 1〜100 字。**確かめに通らない値・知らない鍵（`mine` など）は口に送らず、絞りなしで読む**（D-154.2：自分の分の入口の鍵は持たない）
- **札**：権限が変わった（perm）・外に出した（out）・新しい端末で入った（device）・分身に許可した（ai）・消した（30 日は戻せる）（deleted）・運営がしたこと（ops）。押すと絞り・もう一度押すと外す。「運営がしたこと」は下絵どおり押せない形（aria-disabled・口を呼ばない）
- **ことばで探す**：Enter で送る（打つたびには送らない）・前後の空白を削る・欄は 100 字まで（`maxLength`）。空にして Enter で絞りなし。探した（q か札か人がある）ときは「N 件見つかりました」（読んだ行の数）・続きがあれば「N 件以上見つかりました」。0 件は `Empty`「見つかりませんでした」＋「ことばを変えるか、札をはずして探してみてください」。`scan_capped` が true の 0 件は「ここまでしか探していません。ことばか札を変えてみてください」（仮）
- **行の字**（`audit-shape.ts`・純粋）：when＝`occurred_at` を日本時間の `MM/DD HH:mm`・who＝`actor.name`（無ければ「Kaname」・仮）・text＝口の `text`（空か `<action> を行った` の形のときは内部の字を出さず「ほかの操作を行った」）・reason・device・stepUp（本人確認を取り直した）・deleted。下の 1 行は「理由：… ・ … ・ 本人確認を取り直した」を「 ・ 」でつなぐ（部品のとおり）
- **消した行の「戻す」**：部品のとおり出すが押せない形（aria-disabled・title「まだ使えません」・押しても何もしない）。口は呼ばない
- **続きを読む**：`next_cursor` があれば下に「続きを読む」（outlined・字は仮）。押すと `cursor` を付けて読み、行の下に足す（重ねない）。処理中は押せない（二度押しで 1 回）。失敗（503）は出した行を残し、その下に「続きを読めませんでした。もう一度押してください」（仮）。最後（`next_cursor` が null）で消える
- **読めない**：503・網の切れは `ErrorState`（E-PAGE-007 の形・下絵 lg-failed）に「もう一度読む」。1 回目の読みだけ（続きの失敗は上の字）
- スマホ（767 以下）は崩れず読めて押せる（D-154.13）：札は折り返し・行は 1 列。幅 320 でも横のはみ出し 0
- 書き出し・持ち出し・ダウンロード・消す・直すの操作は画面に無い（K825-UI-025）
