## 前提と制約

分類: AI, PERM

- **タブのボタン**（`TicketAiTabButtonFill({ me, active, onTab })`）：今の押せない形を、押せるボタン（Bot の印・字 `${me}のAI`・今のタブなら `aria-current="page"`）に替え、押すと `onTab("ai")`（K-730 が `PanelTab` に足した `"ai"` に切り替わる・`usePanelTab()` の `setTab`）
- **先の部品の名前**：K-730 の決め（`<器の名前>Fill`・K730-UI-005 が `fills/talk.tsx` に探す）のとおり `TalkActFill`・`TicketAiTabButtonFill`・`TicketAiTabFill`
- **詳細の側の 3 つ**（`features/F4/create-ticket/ticket-detail.tsx`・同じファイルの持ち主の葉の版の上に足す）：①道の `?ai=1` で開いたら、一度だけ `usePanelTab()?.setTab("ai")`（タブを替えても道は書き換えない）②窓の合図 `kaname:f5:open-ai-tab`（`CustomEvent`・detail は `{ ticketId }`・定数は `fills/talk.tsx` の `OPEN_AI_TAB_EVENT`）を聞いたら、閉じていればパネルを開き（今の `panelOpen` の state）、AI のタブにし、書く欄に焦点を送る ③AI のタブの間は `.k-detail` に `data-mtab="ai"` を付け、767 以下では本文の区画を出さず全画面の別画面にする（room.css の `.k-detail[data-mtab="ai"]` の決まり・K-755 が組み方を直した版）。頭の帯（`TicketMobileBar`・`‹ <番号> <題名>`・「AI との相談」）は `.k-detail` の直下の先頭に置き、帯は `.k-room-mband` に写す（下絵の TicketFrame と同じ並び）。「‹」は `setTab("attr")`
- **番号と題名**：`TicketAiTabFill` の props は `{ ticketId, me }`（K-730 の表）。番号と題名は詳細の問い合わせ（getTicket・ticket-detail.tsx と同じ鍵）の答えを読む（二重に呼ばない）
- **タブの中身**（`TicketAiTabFill({ ticketId, me })`→ `room/ticket-talk-panel.tsx` の `TicketTalkPanel`）：開いたときに `getTicketAgentSession` を 1 回読み（鍵 `["k764", "session", ticketId]`・開くまで読まない）、`AiPanel`（`ticket-talk.tsx`）に値を渡す。`ticket` は番号（詳細の答えの number）。行は K-762 の `talk-words.ts` の `toEntries` で組む（「見たもの」を読まない）。会話が無ければ空の形（「まだ話していません。このチケットで…」）
- **言う**：書く欄（K-762 の `ChatComposer`・placeholder「このチケットのことを話す」）に書き［送る］か ⌘／Ctrl＋Enter で `sendTicketAgentMessage`（体 `{ text }`）1 回。答えを待つ間は処理中で二度押しでも 1 回。201 で欄を空にして会話を読み直す。会話が無いときも同じ口（口が会話を作る・K-763）
- **言う口の断り**（書いた字は欄に残す・書く欄は書けるまま）：409・E-TALK-050 → 書く欄の上に黄色の箱「PC がまだつながっていません」（部品の noPc の箱と同じ文・箱を出すだけで欄は書ける）／409・E-TALK-012 → 書く欄の注（正本の文）／403 → 「このチケットを直す権限が無いので、AI と話せません」（仮の字・下の代表に聞くこと 2）／404 → 「このチケットは見られません」／503 ほか → 帯「送れませんでした」と口の返した code の正本の文（無ければ E-PAGE-003）／401 は /login?next=<このチケットの道>
- **作業中・書きながら・止める・止まった理由**：K-762 と同じ（`work.status`・`work.partial`・［止める］は `stopConversation`（会話の id）・`stopping` の間は押せない・止まった理由の帯）。流れは区画を開いている間だけ会話の id で 1 本（K-762 の `talk-stream.ts`）、ほかのタブへ移ったら閉じる（要求を取り消す）。最初の ready では読み直さず（K-762 の決め）、つなぎ直しの ready と change で読み直すのは `getTicketAgentSession`（会話の `getConversation` ではない）。止める口が失敗したら区画の中に正本の文を出して読み直す
- **PC がまだ**（`getMyClone` の pc.state が none）：部品の `noPc`（「まだ話していません」・黄色の箱・書く欄は書けない）
- **読めない**：404 は区画に「このチケットは見られません」・503 ほかは読めない箱と［もう一度］
- **道に残す**：`/tickets/<id>?ai=1` で開いたら、`TicketAiTabButtonFill` が一度だけ `onTab("ai")` を呼び、AI のタブが開いた形で始まる（作った直後に作る画面から来る入口・K-767 が使う）。タブを替えても道は書き換えない
- **帯のボタン**（`TalkActFill({ ticketId, run, kind })`）：押すと窓の合図 `kaname:f5:open-ai-tab` を出す（パネルを開いてタブを替えるのは詳細の側・上の②）。横の詳細（一覧の右に開く詳細・layout side）には右のパネルが無いので、押すとそのチケットの詳細を `/tickets/<id>?ai=1` で開く。`kind="talk"`（作っている・任せました）は［AI と話す］（outlined）。止まった帯の［直し方を AI に伝える］は無い（`kind="fix"` は K-730 の差し込み口から外す（代表の決め answer=4d049789b537：止まった帯の［直し方を AI に伝える］は要らない・やり取りで直す））。書く欄に焦点（字は入れない）。口は呼ばない。帯のどこに出すかは K-730 の差し込み口の場所のまま（任せる前・承認待ちには出ない）
- **スマホ**（767 以下）：AI のタブは詳細の下に積まず全画面の別画面（部品の `TicketMobileBar`「‹ <番号> <題名>」と「AI との相談」）。「‹」で詳細（本文のタブ）へ戻る（`setTab("attr")`）
- **部品の任意の props**（`ticket-talk.tsx`・持ち主）：`AiPanel` の `onText`・`onSend`・`onStop`・`stopping`・`state`（読み中・読めない・見られない）、`TicketMobileBar` の `onBack`、`RunningBandTalk` は使わない（`StoppedBandTalk` は下絵から消した）（帯のボタンは差し込み口の先が出す）。props を渡さなければ今の見た目のまま
- 「見ている：<番号> 本文」の 1 行は部品のまま出す（チケットの文脈を AI が読む印・D-153.34 の「見たもの」ではない）
