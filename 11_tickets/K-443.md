## 目的

チケットの親を、画面から決める・変える・外せるようにする（行為 A103・D-125.32・D-128.65）。入口は 2 つの面：**作る面**（下絵 v2 の `CreateForm`）では、見出しの上の入口（`k-f4d-parent`）と項目の表の「親」の行の **2 か所に同じ値**を出す（K-442 の差し込み口 `ParentSlot`）。**詳細**では、右のパネルの「関連」の区の「親」の行（K-571 の差し込み口 `ParentRowSlot`）。どれも同じ小窓（探して 1 つ選ぶ・親の期限の注意・3 段目は選べない）を開く。

> **見直し（2026-11-21・新しい形）**：小窓の動き・口・断りの文は前の版のまま。変わったのは置き場所（作る面の「振り分けの箱の最下段」→ 見出しの上の入口と項目の表の「親」の行・詳細の「分類」の行 → 「関連」の区の行）と、置く入れ物（K-431 が置く区画のファイル → K-442 の `create-slots.tsx`・K-571 の `detail-entry-slots.tsx` の差し込み口。**その先は葉ごとのファイル**：この葉の `parent/create-slot.tsx`〔`ParentSlotFill`〕・`parent/detail-row-slot.tsx`〔`ParentRowSlotFill`〕を K-442・K-571 が中身の無い形で先に置き、この葉はその 2 つだけを直す）、探して選ぶ道具をこの葉が置くこと、当たる字（下の行 UI-001・007・009・013 と道具）だけ。

- 作る面では、決めた親を札（番号と題名と「親を外す」）で出し、作る口（createTicket）へ親の id を渡す。**「親の担当・節目を写す」は作るときだけ**（既定は入っている）。写せるのは今は担当者だけ（節目は押せない形で値を持たない）：入っていて親に担当者がいれば、親にした時に担当者の欄を親の担当者にする
- 詳細では、親を決める・外す・変える（札を押して選び直す）を、口 updateTicket（K-440）の 1 回で行う。小窓に「写す」は出さない（あとから直すときは写さない・D-150.16）
- 正の絵は下絵 `/dev/mock/f4` の f4-parent-dialog・f4-parent-none・f4-parent-limit（小窓の 3 つの状態。背景は下絵 v2 の作る面）と、入口の置き場所は下絵 v2 の `f4v2-create-*`（`k-f4d-parent` と項目の表の「親」の行）。部品は K-431 が運ぶ `features/F4/parent/views.tsx`（`ParentDialog`・`ParentEntry`）をそのまま使い、値と動きを渡す（views.tsx は触らない）
- 画面は役の名前で出し分けず、口の答えで出し分ける。書けない人は押すと口が 403 を返し、小窓の上の赤い箱に出る
