## 前提と制約

分類: PERM

- **口の答えの形は K-814 の「画面が使う答えの形」**：止める `suspendMember`（`POST /api/v1/members/<id>/suspend`）・戻す `resumeMember`（`POST /api/v1/members/<id>/resume`）の体はどちらも `{}`・答え 200 `{ data: { member_id, suspended, suspended_at } }`。止めた瞬間に、その人の画面と PC のセッションが切れ、動いている PC の仕事は取り消される（口の仕事・戻してもセッションと仕事は戻らず入り直し・D-154.33）
- **止める**：詳細の頭の「一時的に止める」（直に `?do=suspend`）で確かめ `Confirm`「<名前> さんを一時的に止めますか」・文「入れなくなり、分身も止まります。担当しているチケットはそのままです。いつでも戻せます」・「本人確認して止める」「やめる」（開いたときの焦点は「やめる」・やめると焦点は「一時的に止める」へ戻る）。`detail-dialogs.tsx` の `DO_DIALOGS` に `  suspend・resume: `SuspendConfirm`・`ResumeConfirm` の入れ物,` を 2 字下げの 1 行で足す（K-819 が置いた登録口。K819-UI-018 がこの形の字を読んで、足した操作のボタンを押せる形に数える）。押すと口を体 `{}` で 1 回。成功：確かめを閉じ・知らせ「<名前> を一時的に止めました」・詳細を読み直して帯「一時的に止まっています」と「戻す」が出て「一時的に止める」が消える・メンバーの並びの読み直しの印を付ける
- **戻す**：止まっている人の帯の「戻す」（直に `?do=resume`）で確かめ `Confirm`「<名前> さんを戻しますか」・文「また入れるようになり、分身も動きます。止めていたあいだの担当はそのままです」・「本人確認して戻す」。成功：知らせ「<名前> を戻しました」・詳細を読み直して帯が消え「一時的に止める」が出る
- **本人確認の取り直しは今の部品 `StepUp`（features/F1/security/step-up.tsx・パスキーなら指 1 本の stepUpWithPasskey も同じ部品の中・D-154.3）を使い、K-363 と同じ形：口が 403 STEP_UP_REQUIRED（kind `step_up`）→ `getMySecurity` を 1 回読んで `StepUp` を開く → 通ったら同じ体で **1 回だけ**やり直す・やめたら何も送らない**。理由の字＝「<名前> を一時的に止める前に、本人か確かめます」（戻すは「<名前> を戻す前に、本人か確かめます」）・（仮）。取り直しをやめると確かめの小窓に戻る
- **失敗の出し分け**（答えの code と状態で決める）：409 E-MEM-004（最後の管理者を止める）→ 確かめを閉じ、上の赤い箱 `Callout` 題「止められません」・文「<名前>は、いまの管理者の最後の 1 人です。先にほかの人を管理者にしてから、止めてください」（下絵 md-remove-last-admin と同じ言い方・仮）／409 E-MEM-009（もう止まっている）・409 E-MEM-010（もう戻っている）→ 詳細を読み直し（帯が出る・消える）・正本の文で赤い箱／409 E-MEM-005（自分）・403 FORBIDDEN・503 E-PAGE-003 → 確かめを閉じて正本の文で赤い箱（押し直せる）／404 E-MEM-002（もう居ない）→ 読み直して「見つかりません」
- **自分**：自分の詳細の「一時的に止める」は aria-disabled（title「自分は止められません。抜けるのは自分の設定から」・部品のとおり）・`?do=suspend` でも開かない
- **2 段階認証を戻す（D-154.3）**：認証アプリを付けた人のログインの区画に、押せない形（aria-disabled・title「まだ使えません」）のボタンと「パスワードで入る人が認証アプリをなくしたときに 2 段階認証を戻す操作は、あとで使えるようになります」の説明が在る（部品のまま）。押しても口も小窓も出ない。認証アプリの無い人にはボタンが出ない
- **兼務（D-154.15）**：営業と受託開発を兼ねる人を止めると、メンバーの画面では**両方のグループの行**が「一時的に止まっている」になる（口の仕事・画面は読み直した並びで確かめる）。戻すと両方が元の状態の字に戻る
- 答えを待つ間は確かめのボタンを押せない（`useRef` で二度押しを止める）
- スマホ（767 以下・D-154.13）：確かめの小窓・帯が画面の中に収まる（横のはみ出し 0）
- **部品に足す物**（見た目は変えない・任意の props だけ）：`SuspendConfirm`・`ResumeConfirm`：`busy`・`onConfirm`・`onCancel`。`MemberPage` の `disabledActions` から suspend・resume が外れるのは、入れ物が `DO_DIALOGS` の登録から作るので、この葉は `views.tsx` を触らない（自分のときの title は部品に前から在る）
- **下絵との突き合わせ（K821-UI-001）**：下絵の md-suspend・md-resume・md-2fa-reset は頭の「ワークスペースから外す」を押せる形で描き、本番はこの葉では登録（K-822）が無いので aria-disabled（不透明度 0.55）。押せない入口がある間は matchMock に `skip: ["acts:opacity", "acts:color"]` を渡す（K-420・K-819 と同じ訳。数・大きさ・字は比べる）
