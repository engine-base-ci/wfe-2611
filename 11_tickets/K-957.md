## 目的

障害の間・メンテの予定があるとき、ログイン後のどの画面でも上に帯を出し、メンテ中・大きな障害のときは画面いっぱいの形で知らせる（行為 A68・D-125.127・D-128.71）。帯は外枠の **1 つの差し込み口** に並べる（D-156.10）。

- 帯：障害（閉じてもその画面だけ・次の画面でまた出る）・メンテの予定（閉じたら消える・覚える）。重なったら頭の 1 つと「ほか N 件のお知らせ」（D-156.27）。「詳しく」はそのお知らせ 1 件（K-956 の `/notices/[id]`）
- 画面いっぱい：メンテ中（`maintenance_now` があるとき）・障害（稼働状況の「画面」が止まっているとき）
- 止める日の帯・止められた画面・中を見られている間の帯は K-1008（この葉から分けた：止める・中を見るの口〔K-969・K-970〕を待たずに、障害とメンテの帯を先に入れる）

- **帯の読み替え（`bands-shape.ts`・純粋・画面の外の 1 か所）**：
  - `pickBand(bands, closed)`：並びの頭から、閉じられる帯で閉じた印のある物を飛ばして最初の 1 つ。`others` ＝ 残りの帯の数＋その帯の `more`。無ければ null
  - `bandView(band, notice)`：障害 → `{ title: "<題>（MM/DD HH:MM〜）", state: <状態の字>, note: <帯の `note`（K-955 が返す・D-156.45）。無ければ最新の続報の本文・無ければ本文の 1 行目・お知らせが無ければ空>, href: "/notices/<notice_id>" }`／メンテ → `{ window: "11/10（月）2:00〜3:00", impact: <maintenance.impact・無ければ本文の 1 行目>, href }`。**`notice`（一覧の答え `["k956","notices"]` にその notice_id の物）が無いとき `href` は null で「詳しく」を出さない**（出す場所が帯だけのお知らせは一覧の口に出ない＝K-954。1 件の画面 K-956 は一覧の答えから id で選ぶので、押すと「見つからない」になる行き先を作らない・G-04。帯の題と 2 行目で足りる）。時刻と状態の字は K-956 の `help-shape.ts`（`jstWhen`・`windowOf`・状態の表）を使う（同じ読み替えを 2 つ作らない）
  - `gateOf(status)`：`maintenance_now` があれば `{ kind: "maintenance", window }`、なければ components の key `web` が `down` なら `{ kind: "down" }`、ほかは null（メンテ中が先）
  - `downView(band, notice)`：`{ updated: <最新の続報の時刻か始まり・HH:MM>, note: <最新の続報の本文>, since: <始まり HH:MM>, no: <帯の `ref`（障害の番号「INC-<YYMM>-<NN>」・K-955 が返す・D-156.45）。無ければ notice_id の頭 8 字を大文字>}`
  - 段 1 の `to-incidents.ts` はログイン前の口（getServiceStatus）の形（incidents・maintenance）を読む物で、ログイン後の bands の形は読めない。ログイン前の読み替えはそのまま使い、ログイン後の帯の読み替えはこの 1 か所に置く
- **閉じる**：障害の帯の × はその画面の中だけ（外枠の状態。別の画面に移ると外枠を描き直すので、また出る）。メンテの帯の × は `localStorage` の `k-band-closed` に notice_id を足して覚える（読めない・書けない環境では画面の中だけ）。閉じられない帯（`closable: false`）は × を出さない
- **画面いっぱい**：メンテ中は `MaintenanceView`（`window`・`noticed`＝そのメンテのお知らせの出した日 MM/DD。見つからなければ「お知らせは … に出しました」の行を出さない）。障害は `DownView`（「もう一度」で稼働状況を読み直す・「いまの様子を見る」はログイン前の `/help`）
- **読めない**：稼働状況が 503・網の切れ・形が違うときは、帯も画面いっぱいも出さず、画面はふつうに使える（読めないのに止めない。「ふつう」と言う所は無い＝G-15 に当たらない）
- **部品に足す物（見た目と並びは変えない・任意の props だけ）**：`status-parts.tsx` の `IncidentBand`・`MaintBand`（`onMore`＝詳しく・`onClose`・`closable`・`others`＝あれば帯の下に「ほか N 件のお知らせ」の `/notices` への行（仮））・`MaintenanceView`（`noticed` を省ける）・`DownView`（`onRetry`・`statusHref`）。渡さない呼び方（モック）は今の見た目のまま
- 画面の字は下絵が正。下絵に無い字は仮（「ほか N 件のお知らせ」・障害の番号の形）
