## 目的

staging の画面を出す場所を用意する（infra/STAGING.md S4）。

## 完了の条件

- [ ] Vercel のプロジェクト `kaname-web`（Root Directory `apps/web`）がある
- [ ] `NEXT_PUBLIC_API_BASE` に API の URL を入れた
- [ ] この画面の URL を K-80 の `WEB_BASE_URL` に入れて API を Redeploy した

## 前提と制約

- 秘密ではない値だけ
- 鍵・パスワード・接続文字列の値は、チャット・ファイル・コミットに書かない。入れる先は Vercel の環境変数（Sensitive）か Infisical だけ（infra/STAGING.md §1）

## 実施事項

1. Vercel → Add New → Project → 同じリポジトリ → Root Directory `apps/web`・Framework Next.js
2. `NEXT_PUBLIC_API_BASE=https://<kaname-api の URL>`
3. Deploy → この URL を `WEB_BASE_URL` に入れて API を Redeploy（CORS）
