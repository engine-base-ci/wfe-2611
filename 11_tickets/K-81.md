## 目的

staging から本物のメール（確認のメール・再設定・知らせ）を送れるようにする（infra/STAGING.md S3）。統合テストは本物のメールで流す（D-128.144）。

## 完了の条件

- [ ] staging 用の API キーを作り、K-80 で `RESEND_API_KEY` に入れる準備ができた
- [ ] 送信ドメイン engine-base.com が検証済みのままか見た

## 前提と制約

- 送信ドメインは 2026-09-20 に検証済み
- `MAIL_SUPPRESS_PREFIX` は staging では空（必ず送る）
- 鍵・パスワード・接続文字列の値は、チャット・ファイル・コミットに書かない。入れる先は Vercel の環境変数（Sensitive）か Infisical だけ（infra/STAGING.md §1）

## 実施事項

1. https://resend.com → API Keys → staging 用のキーを作る（送るだけの権限）
2. Domains で engine-base.com が Verified か見る
3. 値を K-80 で Vercel に入れる
