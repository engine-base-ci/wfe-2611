## 目的

管理者が、メンバーの 1 人（鈴木 一郎など）の今を 1 画面で見られるようにする（行為 A61「所属・権限を決める」・A62 の入口）。道 `/members/<id>`（flow.json の画面 `member-detail`）。外枠の中の頭（WsHead）・第 2 ナビ（WsSub「メンバー」が今の場所）・本文（頭：名前・メール・入った日／5 つの区画：グループと役割・担当しているもの・分身・ログイン・最近の記録）。口は `getMember`（K-810）を 1 回読むだけ。

この葉は**読む画面と入口**まで。グループを移す・兼ねる（K-820）・止める・戻す（K-821）・外す（K-822）は、この葉が置く「小窓の登録口」（`DO_DIALOGS`）に 1 行ずつ足して入る。それまでそのボタンは押せない形（グレー・隠さない）。人ごとの「できること」の欄と小窓は作らない（D-154.10）・「2 段階認証を戻す」「今月の実行・人ごとの枠」は後のフェーズ（押せない形）。

## 前提と制約

分類: PERM

- **口の答えの形は K-810 の「画面が使う答えの形」**（`getMember` → `{ data: { member, groups, assigned, clone, login, recent_events } }`・`Cache-Control: private, no-store`）。鍵の名前・形は K-810 のまま（`member` の鍵に「会社を作った人か」`is_owner` が在る・K810-API-001）。違えば `f10-kit.ts` の `detailBody` だけを合わせる
- **外枠**：前からの `TicketShell`（screen `member-detail`・パンくず「ワークスペースの管理 › メンバー（押すと /members）› <名前>」）・`WsHead`・`WsSub active="members"`（K-420・K-710 の物）。本文は `<div className="k-me-wrap"><WsSub …/><MemberPage …/></div>`（モックの `WsFrame tail` と同じ組み立て）
- **権限**：見られるのは管理者（flow.json の `member-detail` の役 R1・R2。K-420 が R1 を足す・D-148.49）。見られない人（閲覧のみ・メンバー）は `useMyRoles()` で入れ物が先に止め、`NoAccess`（モック mb-no-access と同じ作り・「この画面を見る権限がありません」）を外枠の中の `section aria-label="メンバーの 1 人"` に出す。口を呼ばない（K819-UI-013）。口が 403 のとき（権限を外された直後）も同じ画面（K819-UI-019）
- **答え → 部品の値**（`member-shape.ts`・画面の外の純粋な関数・`@/` を読まない）：
  - 頭：名前・`<メール> ・ <入った日 YYYY-MM-DD（日本時間）> から`
  - グループと役割：主のグループ（`groups` の `primary`）の名前と役割の字。役割の字＝管理者（`member.role` が admin）・マネージャー・メンバー・閲覧のみ（グループの `role` か、無ければ会社の役割）。注＝役割を変えた記録があれば `<MM/DD> に<前の役割>から（<変えた人の名前>）`・会社を作った人なら `ワークスペースを作った人`（仮・`is_owner`）。兼ねるグループ＝主でない `groups` の名前を「・」でつなぐ・無ければ「なし」（兼務・D-154.15。役割はグループごとなので、兼ねる側の役割はメンバーの画面の行（K-818）で見る）
  - 担当しているもの：`担当 <tickets> 件 ・ 期限切れ <overdue> ・ 渡し中 <handing>`（承認する人の件数は出さない。承認は担当者が受け持つ・D-154.36）
  - 分身：`clone.pc` が ok＝`PC つながっている（<端末>）`（端末が無ければ括弧なし）・away＝`PC <N> 日つながっていない`・never＝`PC をまだつないでいない`・none＝`分身なし（見るだけ）`。`今月の実行 — ・ 人ごとの枠 —`（後のフェーズ・口に鍵が無い・押せない形のまま）・`止まった（7 日） <stuck>`
  - ログイン：入り方＝パスキーだけ `パスキー <N> つ`・パスワードだけ `パスワード`・両方 `パスワードとパスキー <N> つ`・どちらも無ければ `入り方なし`（仮）／2 段階認証＝付けていれば `付けている（認証アプリ）`・付けていなくてパスキーがあれば `付けていない（パスキーで入るので要らない）`・どちらでもなければ `付けていない`／最後に入った＝`MM/DD HH:mm`（日本時間）・無ければ `まだ入っていません`（仮）
  - 最近の記録：`recent_events`（新しい順・5 件まで）を `<MM/DD HH:mm>`＋`<ことば>（<起こした人>）`。ことば＝member.role_change `役割が変わった`・member.groups_change `グループが変わった`・member.suspend `一時的に止めた`・member.resume `戻した`・member.remove `外した`・member.joined `入った`（書く葉が無い・仮。参加は security_events の invitation_accepted で audit_events に書く葉は無いので、本番の記録には出ない。下絵 md-self の見本の字と K819-UI-001 の差し替えの答えに合わせて表に置く）・知らない action は `ほかの操作`（内部の字を出さない）。起こした人が無ければ括弧なし
  - 止まっている（`member.suspended`）：帯「一時的に止まっています」・「戻す」を出し「一時的に止める」を出さない（部品のとおり）。自分（`member.self`）：止める・外すは aria-disabled（部品のとおり・title「自分は…」）。**自分のときは自分の title が勝つ**：止める・外すの登録（DO_DIALOGS）がまだ無くても、`disabledActions` の title「まだ使えません」で上書きしない（部品は自分の扱いを先に見て、自分でないときだけ disabledActions の title を付ける・K819-UI-006）
- **押せる形の判定**（`disabledActions`）：`DO_DIALOGS`（`detail-dialogs.tsx`）に登録の無い操作（move・also・suspend・resume・remove）のボタンを aria-disabled・title「まだ使えません」にする。登録が足されると（K-820〜K-822）押せる形になる。`?do=<キー>` で開いた直後に、そのキーの小窓があれば開き、URL から `do` を消す（`router.replace`）。開いた小窓は読み直しでは開き直さない
- **下絵との突き合わせ（K819-UI-001）**：下絵の md-view・md-suspended は頭の「一時的に止める」（止まっている人は「戻す」）「ワークスペースから外す」を押せる形で描き、本番はこの葉では登録が無いので aria-disabled（不透明度 0.55）。突き合わせの組 F10_PAIRS の `acts`（`.k-page-acts button`）は 1 つ目のボタンの濃さと色を比べるので、登録の無い操作がある間は matchMock に `skip: ["acts:opacity", "acts:color"]` を渡す（K-420 と同じ訳。数・大きさ・字は比べる）。md-self は下絵も自分で押せない形なので全部比べる。下絵に disabledActions を渡す形は選ばない（下絵は押せる形が正）
- **「記録をすべて見る」**：記録の画面（flow.json の `audit`・`/audit`）が道の一覧（`BUILT_ROUTES`）に在れば `/audit?member=<id>` へ（K-825 が `member` を読む：まとめ役に頼む）。無ければ aria-disabled で押しても動かない（隠さない・K819-UI-015）
- **失敗の出し分け**（答えの `code` と状態で決める）：404 E-MEM-002（もう居ない・別の会社・外した）・422（id の形）→ `ErrorState code="E-PAGE-001" acts={["/members"]}`（モック md-failed）／503 E-PAGE-003 → `ErrorState`（調子が悪い）に「もう一度読む」／403 → `NoAccess`
- スマホ（767 以下）は崩れず読めて押せる（D-154.13）：区画は 1 列・行は折り返す。幅 320 でも横のはみ出し 0
