## 目的

AI が「始める前に出す守る物の一覧」「開いたページ」「守れていなかった決まり」を、チケットのやり取り（右のパネルのタブ「やり取り」）に**下絵 v2 の形**で出す（行為 A114・A107・決め 4・5）。

- 3 つの行は口の葉が `ticket_messages`（`kind = 'change'`・作者なし）に書く（`app.knowledge_ticket_line`・K-697）。段 7 の読む口 `listTicketTimeline` は `changes` を中身を見ずに並びのまま返す（K-383）ので、**画面が `changes` から行を作る**。追加の鍵（`must`・`opened`・`page_id`）も口がそのまま通す
- 「守る物」の一覧は、いちばん新しい行のときだけ AI の書き込みとして広げる（下絵 tk-guard）。**後ろに行が 1 つでもあると 1 行に畳む**（「AI が、このチケットで守る物を並べた（必ず守る 3・開いたページ 2）」・下絵 tk-opened）
- 「開いたページ」の行・「守れていなかった決まり」の行は 1 行ずつ（下絵 tk-opened）
- ページの題名は押すとそのページが開く（新しいタブ・見られない人には K-682 の「見られない」画面）
- 段 7 の変換には **1 回の呼びだけ**足す（K-574 の `stage5ChangeText` と同じやり方）。下絵の部品 `features/F9/knowledge/ticket-views.tsx`（K-672 が運ぶ）を本番がそのまま使う

- **行を ThreadItem にする**（`ticket-rows.tsx`）：`knowledgeRowOf(changes: unknown, o: { time: string; expanded: boolean }): ThreadItem | null`。3 つのどれでもなければ null（段 7・段 5 の字に任せる）。`ThreadItem` は型だけを `to-items`・`views` から import する（値を import しない＝循環させない）
  - 守る物：`expanded` なら `{ kind: "node", node: <GuardPost time must opened /> }`、畳むなら `{ kind: "line", who: AI, text: <GuardLineText …/>, time }`
  - 開いたページ：`{ kind: "line", who: AI, text: <OpenedText ai="AI" title place href />, time }`
  - 守れていなかった決まり：`{ kind: "line", who: AI, text: <BreachText … />, time }`
  - `AI` は `{ name: "AI", initial: "AI" }`（K-392 の `personOf(null)` と同じ。K-574 の決め「作者の無い行は名前も顔も AI」）。**名前は常に「AI」**（下絵は「高本のAI」と描いてあるが、口の行に人の名前が無い。下の「代表に聞くこと」の 2）
  - `GuardPost` は下絵の描き手がこれまで自分で持っていた「AI の書き込みの外枠（顔・名前・時刻）＋ `GuardList`」の組み立てで、**この葉で `ticket-rows.tsx` に移し、下絵と本番が同じ物を使う**（`aria-label` は「AI <時刻>」）。`GuardLineText`・`BreachText` も同じ（下絵の描き手の文を移す）
- **畳み方**：`to-items.ts` がやり取りの答えを古い順に歩くとき、**答えの並び（絞り込み前でなく、読んだ分）のいちばん後ろ**の行だけ `expanded: true`。表示の並び（古い順・新しい順）では決めない。口が答えを返し直す（新しい行が着く）と、それまで広げていた行は後ろに行ができて 1 行に畳まれる。**畳んだ行に「開く」操作は付けない**（同じ中身は右のパネルの確認項目〔必ず守る〕と、下の「開いたページ」の行に残る）
- **リンク**：題名は `<a href="/knowledge/<id>" target="_blank" rel="noopener noreferrer">`。部品 `GuardList` に任意の `hrefOf?: (p: GuardPage) => string | null`、`OpenedText` に任意の `href?: string | null` を足す（渡さない呼び方＝下絵は今の `#…` のまま）。`pageHref` が null（id が無い・uuid でない）なら**リンクにせず字だけ**で出す。見えないページも題名は出る（口が行に題名を書く＝K-699 の決め）。押して見られなければ K-682 の画面が 404 のまま「見られない」を出す（この画面は口を呼ばない）
- **段 7 の変換への足し方**（`to-items.ts`・K-574 と同じ場所）：change の行の変換の**いちばん最初**で `knowledgeRowOf(it.changes, { time, expanded: isExpanded(i, answer.length) })` を 1 回呼び、返れば使う。null なら今までの流れ（K-574 の `stage5ChangeText` → 段 7 の字）。**`to-items.ts` に `guard_list`・`knowledge_open`・`knowledge_breach` の字を書かない**（K702-MK-002）
- **`views.tsx` に足すのは 1 種類**：`ThreadItem` に `{ kind: "node"; node: ReactNode }`・`ThreadList` の切り替えに「そのまま描く」1 行。形・クラス・字・ほかの種類は変えない（K-392 が足した口と並びは触らない）
- 画面の言葉は「グループ」「お知らせ」。設計の言葉・内部の ID（`guard_list` など）を画面に出さない。題名・場所・理由は字として描く（`dangerouslySetInnerHTML` を使わない）。画面は役の名前で出し分けない
- **字（下絵が正）**：守る物の見出し・「始める前に、このチケットで守る物を並べました。」・「必ず守る（N）」「確認項目に入れました」・「このチケットのために開いたページ（M）」は `GuardList` の今の字。畳んだ行は「AI が、このチケットで守る物を並べた（必ず守る N・開いたページ M）」。開いたページは「AI がナレッジの 〈題名〉（〈場所〉） を開いた」。守れていなかった決まりの `ai_self_reported` は「守れていなかった決まりが 1 つ：〈題名〉（〈理由〉）。AI が直した」（理由が無ければ括弧ごと省く）。**下絵に無い字は仮**：`ai_unchecked` の「（AI が終わりを知らせたのに、チェックが付いていなかった）」・`human_unchecked` の「（AI が付けたチェックが外された）」
