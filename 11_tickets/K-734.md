## 目的

人が AI を止められるようにする（今は［止める］が押せない形）。正の絵は下絵 `/dev/mock/f5/stop-*`（代表が 2026-11-23 に OK）。**字・並び・ボタンは下絵が正**。

1. **動いている実行を止める**：任せる帯の作っている箱（作る段）と、承認と実行の帯の「実行中」の箱（承認の後の実行）の［止める］→ 確かめの小窓「AI を止めます」→ 口 `stopActionRun`（K-731）→ 止めた後は止まった実行を読み直し、人が止めた実行は赤い箱でなく白い箱「〈名〉のAI を止めました」（要約「〈止めた人〉が MM/DD HH:MM に止めました。止める前にできていた物は残っています」）
2. **承認待ちを止める**：承認の帯の［止める］→ 確かめの小窓「承認待ちの成果物を使わずに止めます」→ 口 `stopApproval`（K-732）→ 作業中に戻ったチケットの帯は「承認待ちの成果物を止めました」（要約「この成果物は送っていません。チケットは作業中に戻りました」）と帯の下の 1 行「〈名〉が承認待ちを止めました（成果物の版 N は残っています）」
3. **断られたとき**：帯の上の知らせ（下絵 stop-conflict・stop-denied・stop-approval-denied）

口は新しく作らない（`apis: []`）。帯と器は触らず、K-730 が置いた差し込み口の先 `features/F5/more/fills/stop.tsx` の中身だけを本物に替える（`StopRunActFill`・`RunStoppedFill`・`StopApprovalActFill`）。

## 前提と制約

分類: AI, PERM

- **出し分け**：画面は役の名前で出し分けない。［止める］は帯がその箱を出すときはいつも押せる形で出し、止められない人（担当者でない・承認する人でない）が押したら口の 403 を帯の上の知らせに出す（下絵 stop-denied・stop-approval-denied のとおり）
- **実行を止める**（`StopRunActFill`・`where: "make" | "execute"`）：
  - ボタンは `Button variant="outlined"`「止める」。押すと確かめの小窓（components/k の `Confirm`・tone は既定の赤）：題「AI を止めます」・本文「〈番号 題名〉。〈名〉のAI の作業を止めます（止められるのは担当者だけです）。止めたあとに届いた結果は使いません。もう一度 AI に任せることもできます」（〈名〉は実行の `by.display_name`・無ければ「自分」）・足「やめる」「止める」。小窓に下絵と同じスマホの下から出す印 `<i className="k-more-sheetmark" hidden aria-hidden="true" />` を入れる
  - 小窓は components/k の `Confirm`（@base-ui の AlertDialog・役 alertdialog・頭に × は無い・閉じ方は「やめる」と Esc）。試験は役 alertdialog で探す
- 小窓の「止める」→ `call("stopActionRun", { params: { id: run.id }, body: {}, screenId: "tickets" })`。答えを待つ間は主ボタンが処理中（`busy`）で、「やめる」・Esc・× でも閉じない。二度押しでも口は 1 回
  - 201：小窓を閉じ、実行の一覧・今の実行（`runsKey(ticketId)`・`["k62","run",…]`）と `timelineKey(ticketId)` を読み直させ、`onChanged()`
  - 409・E-RUN-002：小窓を閉じ、帯の上の知らせ（`pushNotice`）に**画面の字**「この AI はもう止まっていました。表示を読み直しました」（下絵 stop-conflict。口の文と違うので画面の定数）を出し、読み直す
  - 403・E-RUN-001：小窓を閉じ、帯の上の知らせに正本の文（`errorText`・「この AI を止められるのは担当者です」）。帯は動いたまま
  - それ以外（404・429・503 E-PAGE-003）：小窓を閉じ、帯の上の知らせに正本の文（`messageOf`）。401 は入り直し（共通）
- **止めた後の箱**（`RunStoppedFill`）：実行の `stopped_reason` が「〈名〉が止めました」の形（`/^(.+)が止めました$/`・K-731 が書く字）なら、赤い箱の代わりに `Band tone="plain"`：題「〈実行の名〉のAI を止めました」・要約「〈名〉が 〈finished_at の MM/DD HH:MM〉 に止めました。止める前にできていた物は残っています」（finished_at が無ければ「〈名〉が止めました。止める前にできていた物は残っています」）・acts は受けた箱と同じ（［自分で直す］は持ち主の差し込み口のまま。［直し方を AI に伝える］は代表の決め answer=4d049789b537 で K-730 が外した）。ほかの理由（PC・期限・権限など）は受けた赤い箱のまま
- 下絵の止めた後の帯（StoppedBand）の中の［AI に任せる］は出さない：段 5 の K-573 で「AI に任せる」は題の行のボタンにした（帯は持たない）。題の行のボタンは同じ条件で出る（下の「代表に聞くこと」1）
- **承認待ちを止める**（`StopApprovalActFill`）：
  - ボタンは `Button variant="outlined"`「止める」（ほかの帯のボタンが送っている間は押せない）。押すと確かめの小窓：題「承認待ちの成果物を使わずに止めます」・本文「〈番号 題名〉。この成果物は送りません。チケットは作業中に戻ります（止められるのは承認する人だけです）」・足「やめる」「止める」
  - 小窓の「止める」→ `call("stopApproval", { params: { id: approval.id }, body: {}, screenId: "tickets" })`。待つ間と二度押しは上と同じ
  - 201：小窓を閉じ、`pushBand(ticketId, { title: "承認待ちの成果物を止めました", sub: "この成果物は送っていません。チケットは作業中に戻りました" })`・`pushTrail(ticketId, "〈自分の名〉が承認待ちを止めました（成果物の版 〈今見ている版〉 は残っています）")`（名は `me()` の display_name・無ければ「自分」・版は承認の 1 件の `artifact_version.version`）・`timelineKey` を読み直させ `onChanged()`（チケットを読み直す）
  - 403（FORBIDDEN）：帯の上の知らせに**画面の字**「承認待ちを止められるのは、承認する人だけです」（下絵 stop-approval-denied。口は汎用の 403 なので画面の定数）
  - 409・E-CONF-003：知らせに正本の文（「この承認はもう処理されています」）を出して読み直す。それ以外は正本の文（`messageOf`）
- 止めた後に PC から届いた結果を使わなかった 1 行「止めたので、届いた結果は使いませんでした」（下絵 stop-ignored-result）は、口が書くやり取りの行（D-153.20・K-731）で、右のパネルの「やり取り」に出る（段 7 の K-392 の一覧）。帯の下の 1 行には出さない（字を探して照らす作りにしない・PM の決め）。下絵との突き合わせは帯の箱だけを比べる
- 文は全部文字として出す（HTML を作らない）。エラーの文は正本（errors.json）から引く。生の色・大きさを書かない
