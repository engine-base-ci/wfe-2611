## 目的

自分が決めた承認（承認・差し戻し・止める）を、あとから見返せるようにし、実行がまだ始まっていない承認はその場で取り消せる（＝承認の取り下げ）ようにする（D-153.31・D-153.21）。正の絵は下絵 `/dev/mock/f5/history-*`（代表が 2026-11-23 に OK）。**字・並び・ボタンは下絵が正**。

- 承認待ちの道具の行と空の画面の［決めた履歴］→ 右から出る板「決めた履歴」：札（すべて・承認・差し戻し・数つき）・期間「この 1 週間 ▾」・日ごとの見出しと行（時刻・決め・番号と題名・下の 1 行）・取り下げられる行の［取り消す］・下の注記
- ［取り消す］→ 確かめの小窓「この承認を取り下げます」→ 口 `withdrawApproval`（K-733）
- 間に合わなかった（409・E-APR-010）は承認待ちの画面の上に「もう実行が始まっているので、取り消せません。差し戻しの書き込みで知らせてください」

口は新しく作らない（`apis: []`）。K-730 の差し込み口の先 `features/F5/more/fills/queue-history.tsx`（`QueueHistoryFill`）の中身だけを本物に替える。

  - **［取り消す］**：`can_withdraw` が true の行だけ `Button size="sm" variant="outlined"`。押すと確かめの小窓（`Confirm`・`tone="primary"`）：題「この承認を取り下げます」・本文「〈番号〉 〈題名〉。実行はまだ始まっていないので、承認待ちに戻せます」・足「やめる」「取り下げる」
  - 下の注記（いつも）：「「取り消す」は、実行がまだ始まっていない承認だけ。実行が始まったあとは、差し戻しの書き込みで」

  - 読めない（503 ほか）：板の中に「決めた履歴を読み込めませんでした」と［もう一度］
- **取り下げ**：`call("withdrawApproval", { params: { id: 行の id }, body: {}, screenId: "approvals" })`。待つ間は主ボタンが処理中で閉じない・二度押しでも口は 1 回。201：小窓を閉じ、決めた履歴と承認待ち（`queueKey`）を読み直す（承認待ちに戻った行が一覧に出て、履歴のその行は［取り消す］が消える）。409・E-APR-010：小窓を閉じ、承認待ちの画面の上（`Callout tone="danger"`・今の知らせの置き場）に**画面の字**「もう実行が始まっているので、取り消せません。差し戻しの書き込みで知らせてください」（下絵 history-undo-late。口の文と違うので画面の定数）・決めた履歴を読み直す。409・E-APR-011・012・403・503：同じ置き場に正本の文・読み直す
