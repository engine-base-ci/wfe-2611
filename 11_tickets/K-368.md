## 目的

「PC と使った量」（/setup/bridge・K-57 の `features/F3/connect-pc`）の「つないでいる PC」の行に、**その PC で AI が使うブラウザ**を選ぶ欄（自分の Chrome（既定）／Bridge 専用のブラウザ／使わない・D-119・D-120）を出し、押すと口 `updateMyDevice`（K-364）をその PC の id で呼ぶ。今の値は一覧 `listMyDevices` の `browser`（K-364）。

その PC の自己診断の Chrome の行が ✗ で、選んでいるのが自分の Chrome のときだけ、選ぶ欄の下にその場の一手（BrowserFix：つなぎ方を見る・もう一度確かめる・Bridge 専用に切り替える）を出す。「もう一度確かめる」は口 `checkMyDeviceBrowser`（K-365）をその PC の id で呼び、一覧のその PC の `health_at`（K-360）が新しくなるのを待って（上限 90 秒）結果を出す。

会話の 1 行の一手（`components/ai/browser-fix.tsx`・自分のAIと話す）も同じ処理（`lib/device-browser.ts`）に替え、前の道すじ `/api/auth-ext/agent/browser`・`/agent/browser-check` を呼ばなくする（L-008：同じ処理は 1 つ。前の道すじを消すのは K-367）。会話の一手の見た目と字は変えない。

代表の答え（2026-11-19・下絵 /dev/mock/f3-pc の OK と A の 1〜8）：ラジオ 3 つを常に出す（A-2 ①）・Claude Code が無い／ログインしていない間はブラウザの欄を出さない（A-3）・眠っている PC の文は下絵どおり（A-8）。決めた中身は下絵の字が正。
