## 目的

自分のパスキー・2 段階・予備のコード・パスワード・ログインしている端末を見て直せる口を作る。

## 完了の条件

- [ ] パスキーでも本人確認を取り直せる（KN-56 から移した）
- [ ] 契約の口が hooks（apps/api/src/hooks）か共通の処理で動き、まだの口の 501 で止まらない
- [ ] 口ごとの生成の試験（apps/api/test/generated）の it.todo が全部本物の試験になって緑
- [ ] 行の守り（RLS の場合表・G33）と権限の試験（G41）が、この口の分も緑
- [ ] 契約 fuzz（G36）が、この口を回して緑
- [ ] CI が緑

## 前提と制約

- 決定ログで決まっていることは聞かずに進め、ここに「決定に従った」と残す。決まっていないことはまとまりごとにまとめて聞く（D-128.118）
- 権限の言葉・本人確認・行の確かめは入口（KN-51・KN-52）が見る。hooks の中でも行の守り（RLS）が効く

## 実施事項

- [ ] パスキーでの本人確認の取り直し（KN-56 から移した）：取り直しの口（POST /auth/step-up）がパスキーの確かめ（Better Auth の passkey）も受け、通ったらセッションに時刻を付ける。試験はブラウザの仮の認証器（Playwright の WebAuthn）で
- [ ] getMySecurity（GET /api/v1/me/security）
- [ ] renamePasskey（PATCH /api/v1/me/passkeys/:id）
- [ ] deletePasskey（DELETE /api/v1/me/passkeys/:id）
- [ ] changePassword（PATCH /api/v1/me/password）
- [ ] listMySessions（GET /api/v1/me/sessions）
- [ ] revokeMySession（DELETE /api/v1/me/sessions/:id）
- [ ] revokeOtherSessions（POST /api/v1/me/sessions/revoke-others）
- [ ] startTwoFactor（POST /api/v1/me/two-factor/enable）
- [ ] confirmTwoFactor（POST /api/v1/me/two-factor/confirm）
- [ ] disableTwoFactor（DELETE /api/v1/me/two-factor）
- [ ] regenerateBackupCodes（POST /api/v1/me/backup-codes）
