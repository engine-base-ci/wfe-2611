## 目的

API ごとの「誰が呼べるか」（08_api の permission）を契約に載せ、入口（op.ts）で会社の段の言葉（admin の能力・運営のできること ops:〜）と本人確認の取り直し（15 分）を確かめる。

## 完了の条件

- [ ] 契約（@kaname/contracts の ENDPOINTS）に perm（言葉・能力）と stepUp が出る
- [ ] admin の口は、その能力（招く・書き出す・プランと支払い・ワークスペースを消す・表ごとの edit）を持つ人だけ
- [ ] ops:〜 の口は、そのできること（caps）を持つ運営の人だけ
- [ ] 本人確認が要る口は、直前 15 分以内の取り直しが無ければ 403（STEP_UP_REQUIRED）
- [ ] zt_gate の step_up_missing が 0
- [ ] CI が緑のまま

## 前提と制約

- 能力の当て方は機械で決める（表の名前＋読む／書く、招く・書き出す・お金・消すは決まった能力）。決まりから外れる口は理由を付けて表に書く
- 本人確認の取り直しの時刻はセッション（sessions）に持つ

## 実施事項

- [ ] contract.mjs：perm と stepUp を出す
- [ ] op.ts：会社の段の確かめと本人確認
- [ ] sessions に step_up_at を足し、本人確認の口で付ける

## テスト仕様と確認の結果

| 確認項目 | 種類 | 判定のしかた | 結果 |
|---|---|---|---|
| admin の口は能力の無い人を止める | ① 機械 | `apps/api/src/contract/authz.test.ts` | |
| ops:〜 はできることの無い運営の人を止める | ① 機械 | 同上 | |
| 本人確認が古いと 403 | ① 機械 | 同上 | |
