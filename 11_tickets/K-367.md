## 目的

前の「PC をつなぐ」画面（T-U-09・道 /setup/bridge/legacy・802 行）を消す。この画面は D-128.150・D-128.164 で「Claude Code を入れてログインする（K-89）・AI が使うブラウザを選ぶ（K-90）・端末を外す（K-91）が新しい画面に移るまで」残していた。
3 つが移った後（K-361・K-363・K-365・K-366）は、使うのは前からの試験と、新しい画面の「前の設定の画面」のリンクだけになるので、それらを片付けてから消す。前の画面にだけあった「OS の警告の越え方」と「Bridge が古いときの入れ直す口」も、K-374・K-375 が新しい画面へ移してから消す（代表の答え answer=7cf148a79dc9・2026-11-19）。前の画面だけが呼ぶ前の道すじ `POST /api/auth-ext/agent/bridge-revoke` と画面の口 `agentRevokeBridge` も消す（外すのは契約の口 revokeMyDevice・K-362）。あわせて、契約の口に移った後は誰も呼ばない前のブラウザの道すじ `POST /api/auth-ext/agent/browser`・`/agent/browser-check`（画面の選ぶ欄と会話のその場の一手は K-368 が契約の口へ）・`/bridge/browser`（Bridge の窓は K-366 が setBridgeBrowser へ）と画面の口 `agentSetBrowser`・`agentBrowserCheck` を消す（2026-11-19 まとめ役）。
あわせて K-96（前の画面が接続コードを 2 回出す）を閉じる（直す先の画面が無くなるので・PM の決め 2026-11-18 ②）。

段 3 の K-337（前の道すじを消す・前からの試験と道具を切る段で替えて carry で運ぶ）と同じ形。
