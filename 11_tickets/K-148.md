## 目的

押した人が止められた（停止・退会・権限を外された）とき、サーバーは実行を止めて段を作業中に戻す（D-129.7・K-62 の K62-API-018）。ところがその人の PC の Bridge は、すでに走っている Claude Code の実行を終わらせない（`apps/bridge/src/main.ts`・`runner.ts` の stopCurrent は画面の止めるボタンからしか呼ばれない）。サーバー側では止まっているのに、PC 側の実行が最後まで走り続ける。K-62 の作る役が見つけた（2026-11-08）。K-62 と関係なく前からある Bridge の問題なので、その場で直さず起票した。

## 完了の条件

- [ ] Bridge が、仕事の止めの知らせ（getJobControl の止めた・鍵が効かない 401）を受けたら、走っている Claude Code の実行を止める（stopCurrent）
- [ ] 止めたあと、結果を送らない（送っても届かない形で、承認待ちにしない）
- [ ] 試験：止められた後の 0 秒・知らせを見る間隔の内側・次の見に行きで、実行が止まる（G-12）
- [ ] チケットの CI（act）が緑

## 前提と制約

分類: AI, EXT

- 止めの知らせの口（getJobControl）は K-62 が作る。そのあとにする（depends_on）
