## 目的

作る画面の会話で AI が出した**チケットの案（題名・本文・確認項目）を、全部か選んだ欄だけ左の欄に入れられる**ようにする（行為 A99・D-153.17）。入れた欄には「AI の案」、その後に人が直した欄には「直しました」の印が付き、次に話すときに直した欄だけが AI に渡る（K-767 の edited）。人が直した欄と案が食い違っても小窓を出さない（会話で AI が聞く・answer=85c6211ac1b5）。

- 正の絵は下絵 `/dev/mock/f5` の create-talk-proposal・create-talk-select・create-talk-applied-all・create-talk-applied-some（代表 OK：2026-11-23）。部品は K-730 が運ぶ `features/F5/room/proposal.tsx` の `ProposalCard`（値で描く部品・この葉が持ち主）。**字・並び・ボタンは下絵が正**
- 案の形は K-775（`proposal { title?, body?, checks?[] }`・出した欄だけ・K-757 の MessageView の `proposal`）。口は新しく作らない（`apis: []`）

## 前提と制約

分類: AI, CRUD

- **カード**（`ProposalCard`・持ち主）：案の行（`who: "ai"`・`proposal` が在る）を `kind: "proposal"` の行としてカードで出す（K-767 の会話の行の組み立てに足す）。行は出した欄だけ・名前は「題名」「本文」「確認項目（N 件）」・中身は題名はそのまま・本文は先頭の 1〜2 行（80 字で切って「…」）・確認項目は「<1 件目> ほか <N-1> 件」（1 件ならそのまま）。字は書かれたとおり（HTML を作らない）
- **［全部使う］**：出した欄を全部左の欄に入れる。**［選んで使う］**：欄ごとの四角（最初は全部に印・`ChoiceRow`）と［選んだ欄を使う（<印の数> 件）］［やめる］（やめるで元に戻る）。印が 0 なら［選んだ欄を使う（0 件）］は押せない
- **欄へ書き込む口**：K-767 の `CreateTalkAside` に `onApply(next: { title?: string; body?: string; checks?: string[] }, keys)` を足し、作る面 `create-ticket.tsx`（K-442 の版・K-767 が aside を置いた所）がそれを受けて今の欄の値を新しい値に入れ替える（題名＝`d.title`・本文＝本文の道具に 1 本の字として入れる・確認項目＝K-450 の `SpecsItem` の `lines`）。欄の名前の横の札（「AI の案」「直しました」）は `create-ticket.tsx` が欄ごとの印（`marks`）を持って題名・本文・確認項目の見出しの横に出す（部品 `create-talk.tsx` の `Mark` と同じ札）
- **本文のひな形**：本文の道具に種別のひな形の薄い節（K-442）が残っていれば、案の字で替えるときに薄い節ごと消して案の字だけにする（「ひな形を消す」と同じ形）
- **欄に入れる**（`proposal-apply.ts` の `applyProposal(form, proposal, pick)`・新しい値を作って返す）：題名は案の字に替える・本文は案の字に替える（K-442 の本文の道具に 1 本の字として入れる）・確認項目は**今の物を残して案の物を後ろに足す**（同じ字は 2 つにしない）。人が先に書いていた欄でも小窓を出さず替える（answer=85c6211ac1b5・食い違いは AI が会話で聞く）
- **使った後のカード**：全部なら「全部の欄に入りました」・選んだなら「選んだ欄に入りました」、各行は「欄に入りました」「使っていません」。ボタンは出さない。印は画面が持つ（口は印を持たない・K-775 の申し送り）
  - **読み直し**（同じ画面で言った後・流れの合図）：使った結果は画面の中で覚えていて、カードは使った後の形のまま
  - **開き直し**（作る画面を開き直して同じ会話が出たとき）：覚えていないので、欄の今の中身と案を欄ごとに比べ、どの欄も同じなら使った後の形（同じ欄は「欄に入りました」・違う欄は「使っていません」）、どれも違えば元のカード（［全部使う］［選んで使う］）
  - **案が 2 つ以上**（K-775 は 1 仕事に 3 回まで）：どのカードも別々に使える。後から使ったカードの字が欄に入り、前に使ったカードの行は欄の字と比べて「使っていません」に替わる
- **欄の印**（K-767 の作る面の欄の名前の横・`create-talk.tsx` の `Mark` と同じ札）：入れた欄に「AI の案」。その欄を人が直すと「直しました」。印は画面の中だけ（作る口に送らない）
- **edited の基準**：案を入れたら、K-767 の `useDraftTalk` の「前に AI に渡した中身」をその欄について案の中身に替える（案のままの欄は edited に入れない・K777-UI-009）。入れた後に人が直した欄だけが次の edited に入る（K777-UI-008）
- 口は呼ばない（欄に入れるだけ・作るのは人が［作る］を押したとき）
