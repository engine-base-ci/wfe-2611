## 目的

メールを変えたい人が、新しいアドレスを入れ、本人確認を通して、新しいアドレスに届く確かめのリンクを押して変えられるようにする（行為 A74）。プロフィール（K-839）の「メール［変える］」で小窓を開き、送ると行が「確かめ待ち」になる。リンクは外枠の外の画面 `/account/email-confirm?token=…` で、押すとメールが変わる（変わった・期限切れ・もう使った・使えない）。口は `requestEmailChange`・`verifyEmailChange`（K-835）。確かめのリンクは **24 時間・1 回だけ**（D-154.12）。

この葉は**小窓・確かめ待ちの行・リンクの先の画面**まで。待っている変更を「やめる」口は無いので、［やめる］は押せない形（K-835 の申し送り）。

## 前提と制約

分類: AUTH, CRUD

- **口の答えの形は K-835 の「画面が使う答えの形」**：`requestEmailChange` → 201 `{ data: { pending_email, expires_at } }`・`verifyEmailChange` → 201 `{ data: { changed: true, email } }`。待っている宛ては K-833 の `getMe` の `member.email_pending`。断りの番号：E-ME-020（形・422）・E-ME-021（もう使われている・409）・E-ME-026（今のメールと同じ・409）・E-ME-024（送りすぎ・429）・E-ME-025（送れなかった・502）・確かめる口の E-ME-022（期限切れ）・E-ME-023（もう使った）・E-PAGE-006（使えない）。違えば `f10-ops-kit.ts` の `me()`・`emailChange`・`emailVerify` の既定だけを合わせる
- **小窓**（下絵 me-email・me-email-error）：K-839 の登録口 `PROFILE_DIALOGS` に `email: EmailChange` を 2 字下げの 1 行で足す（足すと「変える」が押せる形に変わる・K839-UI-015）。題「メールを変える」・説明「新しいアドレスに確かめのメールを送ります。リンクを押すまでは、今のメールのままです」・今のメール（書き換えられない）・新しいメール・足のボタン［やめる］［本人確認して送る］。**打つと形を見る**：前後の空白（全角を含む）を削り NFKC でそろえてから `^[^@\s]+@[^@\s]+\.[^@\s]+$`（口 K-835 の形と同じ字）に当てる。合わなければ欄の下「メールの形が違います。「名前@会社.example」のように入れてください」・押しても送らない（口 0 回・取り直しも出さない）。空のままでも送らない。送る字は**そろえた字**（`requestEmailChange { email }`・体の鍵は email だけ）。下絵の「使われている」の判定（モックだけの見本の 1 件）は本番に持ち込まず、口の 409 に任せる
- **送る**：処理中は主ボタンが処理中で二度押しでも 1 回（メールを 2 通送らない）。201 → 小窓を閉じ、自分を 1 回読み直す（`reloadMe()`・待っている宛てを読む）。行が確かめ待ちになる（部品のとおり：札「確かめ待ち」・「確かめのメールを <宛て> に送りました。リンクを押すと変わります。それまでは <今のメール> で入れます」・［送り直す］［やめる］）。今のメールは変わらない。**403 STEP_UP_REQUIRED** → `getMySecurity` を 1 回読んで `StepUp`（features/F1/security/step-up.tsx・パスキーだけの人はパスキー・D-154.3）。理由「メールを変える前に、本人か確かめます」（**仮**）。通ったら同じ体で 1 回だけやり直す・やめたら何も送らずメールの小窓に戻る（打った字は残す・K-363 と同じ形）。**409 E-ME-021** → 欄の下に「このメールは、もう別のアカウントで使われています。別のメールを入れてください」・開いたまま・字は残る。**409 E-ME-026** → 欄の下「今のメールと同じです」（**仮**）。**429 E-ME-024** → 小窓の中「メールを送りすぎです。しばらくしてからやり直してください」（**仮**）。**502 E-ME-025** → 小窓の中「確かめのメールを送れませんでした。少し待ってやり直してください」（**仮**）・行は確かめ待ちにしない（送れたと嘘をつかない）。**503**・網の切れ → 小窓の中に E-PAGE-003 の文の赤い箱・開いたまま
- **［送り直す］**：待っている宛てで `requestEmailChange { email: <待っている宛て> }` を 1 回。201 → `role="status"`「確かめのメールを送り直しました」（**仮**）・宛ては変わらない。取り直しが要れば同じ形で 1 回だけやり直す。429 → 行に「メールを送りすぎです。…」。ほかの断りも行に口の文。処理中は二度押しで 1 回
- **［やめる］**：口が無いので**押せない形**（aria-disabled・title「まだ使えません」・押しても口を呼ばない・隠さない）。待っている変更は 24 時間で切れ、新しい頼みが前の頼みを無効にする（K-835）
- **確かめのリンクの先**（`/account/email-confirm?token=<印>`・外枠の外の画面＝`(outside)` の道・段 1 の verify-email と同じ入口の枠 `AuthFrame`）：開くと**1 回だけ** `verifyEmailChange { token }` を呼ぶ（印は 1 回しか使えない：StrictMode の二重の呼びで「もう使った」にしない・読みは鍵 `["k840","verify",token]` の `useQuery`・`retry: false`・`staleTime: Infinity`）。印が無い道は口を呼ばず「使えない」の形。結果の形（下絵 me-email-done の 3 つ＋仮の 1 つ）：201 → 札「✓」・題「メールを変えました」・「これからは新しいメールで入れます。知らせも新しいメールに届きます」・［自分の設定へ戻る］／409 E-ME-022 → 札「期」・題「リンクの期限が切れました」・「確かめのメールのリンクは、送ってから一定の時間で切れます。自分の設定からもう一度メールを変えてください」／409 E-ME-023 → 札「済」・題「このリンクはもう使いました」・「メールはすでに変わっています。もう一度押す必要はありません」／409 E-PAGE-006・印なし → 札「✕」・題「このリンクは使えません」・本文は正本 E-PAGE-006 の文（**仮**・部品 `EmailDoneCard` に kind `unusable` を足す）。どれにも［自分の設定へ戻る］（/account）。201 のあと自分の読み（`["k839","me"]`）を無効にする（戻ると新しいメールが出る）。503・網の切れ → `ErrorState`（E-PAGE-007 の形）＋「もう一度読む」（印は使われていないので確かめ直せる）。401 は call が入り直しへ送る（戻り先はこの道・印つき）
- スマホ（767 以下）は崩れず読めて押せる（D-154.13）。幅 320 でも小窓・確かめ待ちの行・リンクの先の 4 つの形・長いメールで横のはみ出し 0
