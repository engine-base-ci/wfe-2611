## 目的

承認待ちが溜まったときに、**AI の成果物を 1 件ずつ全画面で見て、キーで次々に決められる**ようにする（行為 A15・D-153.12）。今は見出しの［続けて裁く（N 件）］が押せない形。押すと全画面の「続けて裁く」が開き、承認（確かめの小窓を通す）・差し戻す・自分で直す・飛ばす・次・前をキーかボタンで選び、最後に終わりの面（承認・差し戻し・飛ばした数）が出る。

- 正の絵は下絵 `/dev/mock/f5` の focus-card・focus-confirm・focus-done（代表 OK：2026-11-23）。下絵の部品 `more/queue.tsx` の `FocusView`・`FocusDone` は見本の値を中に持つので**触らない**（side-notes「段6-画面の葉-切り方の決め」）。この葉は自分のファイル（`more/focus/`）に本物の部品を作り、`components/k` の Button・Dialog と `more.css` の `k-more-focus*` のクラスを使う。**字と並びは下絵が正**
- 差し込み口は K-730 の `QueueFocusSlot`（`queue.tsx` の見出しの［続けて裁く（N 件）］・props `{ rows, total }`）。この葉は先のファイル `more/fills/queue-focus.tsx` の `QueueFocusFill` の中身だけを替える
- 口は新しく作らない（`apis: []`）。並びは K-748 の `kind=artifact` と今の `sort`（K-749 の `useQueueQuery()` の query の sort・無ければ既定）に従う（K-748 の申し送り）

## 前提と制約

分類: CRUD, PERM

- **見出しのボタン**（`QueueFocusFill({ rows, total })`）：字は今のまま「続けて裁く（<total> 件）」（下絵のとおり）。`rows` に AI の成果物（`kind === "artifact"`）が 1 件も無ければ押せない形（`aria-disabled`・title「1 件ずつ決めるものがありません」）。押すと道に `?focus=1` を付けて全画面の層を開く。スマホの下の［続けて裁く（N 件・1 件ずつ）］は、本番の承認待ちに置き場が無い（K-730 の表の QueueFocusSlot は見出し 1 か所）ので、この葉では作らない（スマホも見出しのボタンから開く・下の申し送り）。押せる・押せないは、今の一覧の行（`rows`・札で絞った後の行）に AI の成果物が在るかで決める（K-730 の props は rows と total だけ）
- **全画面の層**（`focus/focus-view.tsx` の `FocusView`）：`role="dialog"`・名前「続けて裁く」・見出し h1「続けて裁く」・右上に「<今> / <全部> 件」と［‹ 一覧に戻る］。Esc でも閉じる（小窓が開いていないとき）。閉じたら `?focus` を消して一覧を読み直す（`queueKey` を invalidate）。`?focus=1` で開き直すと 1 件目から始まる
- **並び**（`focus/use-focus.ts`）：開いたときに `listApprovalQueue`（`kind=artifact`・今の `sort`〔K-749 の `useQueueQuery()` の query の sort・無ければ `due`〕・`limit=200`）を 1 回だけ読む（直列 1 段・続きは読まない＝200 件まで・G-16）。開いた後に増えた承認待ちは入れない（開いたときの並びで回る）。0 件なら終わりの面（数は全部 0）。読めなければ層の中に読めない箱と［もう一度］
- **1 件の面**：区画「いま決めるもの」（`region`）に見出し h2「<番号> <題名>」・下の 1 行（一覧の行の「誰から」の字 ・ 期限〔過ぎていれば「（N 日過ぎ）」〕 ・ 一覧の行の `note`）・確認の表（K-730 の `ChecksSlot where="approval"`・K-740 が中身を持つ）・成果物（`getApproval` の `artifact_version` を前からの `ArtifactCard`）。詳細は今の 1 件と次の 1 件だけを読む（先読み 1 件・鍵 `["k752", "detail", id]`）
- **キーと操作**（`focus/focus-keys.ts`・焦点が入力欄・小窓の中のときは効かない）：
  - J・［次へ］は次の 1 件・K は前の 1 件（端では動かない）
  - A・［承認して送る → 次へ］→ 前からの確かめの小窓 `ApproveConfirm`（`Confirm`＝alertdialog・K-740 がチェックの無い確認項目を足す）→ 主ボタンで `approveApproval` 1 回（二度押しでも 1 回）→ 承認の数を 1 足して次へ。**取り消せない物かは 1 件の詳細の答え（`getApproval` の `irreversible`）で決める**：真なら字は「承認して送る → 次へ」で、小窓は「成果物を目で見た」に印を付けるまで主ボタンを押せない（K-229 の決めのまま）・偽なら「承認する → 次へ」
  - R・［差し戻す］→ 前からの `ReturnDialog`（K-745 が「次は誰が直すか」を足す）→ 差し戻したら数を 1 足して次へ
  - E・［自分で直す］→ そのチケットの詳細 `/tickets/<ticket_id>` へ移り、層を閉じる（自分で直すは詳細の承認の帯の物・K-743）
  - S・［飛ばす］→ 決めずに次へ（飛ばした数を 1 足す・口は呼ばない）
  - ［止める］→ K-730 の `StopApprovalActSlot`（K-734 が中身・確かめの小窓を通って止める口）を今の 1 件の承認で置き、`onChanged` を受けたら次へ（数には入れない）
  - 決めた 1 件へ K で戻ったら、面に「承認しました」「差し戻しました」「止めました」の字を出し、承認・差し戻す・止める・自分で直すは効かない（口を呼ばない）
  - キーの押しっぱなし（`repeat` の keydown）は数えない（1 回押した分だけ動く）
  - 下の 1 行「次：<番号> <題名> ・ <番号> <題名>」（次の 2 件・無ければ出さない）
- **断り**：承認・差し戻しの口が 409（先に決まっていた）・404 なら、層の上に正本の文（`messageOf`）を出して次へ（数に入れない）。503 ほかは同じ 1 件のまま文を出し（差し戻しは差し戻す小窓の中）、押し直すと通る。401 は入り直し。詳細が読めない（503）ときはその面に読めない箱と［もう一度］（J・K・S は効く）
- **終わりの面**（最後の 1 件を決めた・飛ばした後）：見出し h2「決め終わりました」・結果の並び（list「結果」）「承認 N 件」「差し戻し N 件」「飛ばした N 件」・飛ばした物が在れば「飛ばした N 件は、承認待ちに残っています」・［承認待ちに戻る］（閉じて読み直す）・下に「決めた物は、承認待ちの［決めた履歴］で見られます」・位置は「<全部> / <全部> 件」
- 権限：承認待ちの口が自分の決める物だけを返す（K-161）。画面は役の名前で出し分けない
- 渡された行（`kind="handover"`）は続けて裁くに入れない（受ける・断るは 1 件ずつ一覧で・K-412）
