  - `rowView(row, me, now)`：id・who（asker.name）・ws（workspace.name）・at（今日は HH:mm・昨日は「昨日」・ほかは MM/DD・日本時間）・title・kind（usage 使い方／trouble うまく動かない／billing お金・プラン／other ほか）・state（open 進行中／waiting 返事待ち／later 後で／done 済み）・mine（owner.member_id が自分）
  - `messageView(m, now)`：head（customer「<人> ・ HH:mm」／reply・note「<人>（運営） ・ HH:mm」）・body・memo（note だけ true）
  - `sideView(d)`：rows（プラン「<plan_name か —> ・ <members> 人」・この人の PC（connected つながっている／paired 切れている／never まだつないでいない）・止まった実行（7 日）「N 件」・請求（0 なら「期限を過ぎた請求なし」・ほか「期限を過ぎた請求 N 件」））・context「付いてきた情報：画面 <path> ・ <browser> ・ PC つながっている／つながっていない」

  - `laterOf(choice, now)`：明日の朝＝翌日 9:00（日本時間）・来週＝次の月曜 9:00・選び直し（none）＝null
- **押したとき**：［自分が持つ］＝`PATCH { take: true }`／［外す］＝`{ release: true }`／［済みにする］＝`{ state: "done" }`／［後で］の選び肢＝`{ later_until: laterOf(...) }`（none は `{ later_until: null }`）／［返す］＝`POST replies { body }`（成功で欄を空に・1 件と一覧を読み直す）／［社内メモにする］＝`POST notes { body }`。送っている間は 2 回目を送らない。409 E-OPS-005 → 1 件を読み直し、ほかの人の担当の形に（「<名前> さんが担当になりました」の下絵の Callout・答えの owner が無ければ errors.d の「ほかの人が担当しています」）。409 E-OPS-008 → 後での赤い箱。ほかの失敗 → 赤い箱（role alert）で書いた返事は残る
