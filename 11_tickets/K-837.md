## 目的

自分の設定 › 知らせ（下絵 me-notify・me-notify-quiet・me-notify-copy・me-notify-failed）が使う 3 つの口。知らせの受け方は**ワークスペースごと**に決める。

- `getNotificationSettings`（GET /api/v1/me/notification-settings）：1 つのワークスペースの受け方（メールのまとめ・静かにする時間・いま止めているか・止めていても知らせる急ぎ・出来事ごとのベルとメール）
- `updateNotificationSettings`（PATCH …）：変えたらすぐ保存（1 行ずつ）
- `copyNotificationSettings`（POST …/copy）：「この設定をほかのワークスペースにも写す」

**保存だけ作る**（D-154.24）。保存した受け方を読んで受け箱・メールを出すのは F7（K-67）の持ち物で、この葉は受け箱の行・メールの送出・会社の記録を作らない。F7 が読めるよう、出来事の名前の一覧は 1 か所（`apps/api/src/features/F10/me/notify-events.ts`）に置く。

**画面が使う答えの形**（K-843 の正）：

```
GET・PATCH 200 { data: { workspace_id, email_digest: boolean, quiet_hours: { preset: "weekdays_night_weekend"|"every_night"|"weekend_only"|"off" },
                         paused_until: ISO 8601|null, urgent_override: ["approval_due_today"|"clone_stopped"],
                         events: [{ key, bell: boolean, mail: boolean, fixed: boolean }]（7 つ・下の順） } }
POST copy 201 { data: { copied_to: [workspace_id, …] } }
```

出来事 7 つ（key・下絵の字・既定のベル／メール）：`approval_waiting`（承認を待っている・両方）・`mentioned`（@ で呼ばれた・やり取りで知らせる人にされた・両方）・`handed_over`（渡された・配られた・両方）・`clone_stopped`（分身が止まった・落ちて直せない・両方）・`clone_finished`（分身が実行を終えた・ベルだけ）・`ticket_changed`（自分が担当・承認するチケットが動いた・ベルだけ）・`new_device`（新しい端末で入った・両方・**止められない＝fixed**）。画面の字は画面の葉が key から出す。

## 前提と制約

分類: CRUD, PERM

- **だれが呼べるか**：本人だけ（契約のまま・member の束）。入口の共通（401・429・同意し直し 403・strict の形・NUL 422）が先に効く。道・体に**人を指す欄を持たない**（`workspace_id` は会社だけ）
- **どのワークスペースか**：`workspace_id`（GET は query・PATCH は体・無ければ今の会社）。同じログインがその会社に active か suspended で入っているときだけ（`app.account_members`・D-125.150）。入っていない・抜けた・別の人の会社・無い会社は**同じ 404**（欄・details を付けない）。uuid でなければ入口が 422
- **値**：`email_digest` は真偽（既定は真＝読んでいないものを 30 分ごとにまとめて送る）・`quiet_hours.preset` は `weekdays_night_weekend`（平日 20:00〜8:00・土日・既定）・`every_night`（毎日 20:00〜8:00）・`weekend_only`（土日だけ）・`off`（使わない）の 4 つ・`urgent_override` は `approval_due_today`・`clone_stopped` の部分集合（既定は 2 つとも・空にしてよい）・`events` は 7 つの鍵のうち送った行だけ（行ごとに `bell`・`mail` の少なくとも 1 つ・真偽）。契約の enum・maxItems で 422（欄の名前つき）
- **いま止める**：体の `pause` は `"1h"`（今から 1 時間）・`"today"`（今日いっぱい＝その人の時間帯の次の 0 時）・`"tomorrow_morning"`（明日の朝まで＝その人の時間帯の明日の 8:00）・`null`（止めるのをやめる）。口が `paused_until` に入れる（`paused_until` を直に送る体は 422）。時間帯は members.timezone（`Asia/Tokyo`・`UTC`）
- **止められない出来事**：`new_device`（新しい端末で入った・安全のため）のベルかメールを偽にする体は 409・E-ME-040（「この知らせは安全のため止められません」＝下絵 me-notify の字から）。**同じ体の中のほかの変更も入れない**（全部か無しか）。真にする（入れ直す）のは通る
- **写す**：`from_workspace_id` の受け方（email_digest・quiet_hours・urgent_override・出来事の行）を `to_workspace_ids`（1〜20・重ならない uuid）のワークスペースに**置き換える**（写し先の今の出来事の行も写し元に合わせる）。**止めている印（paused_until）は写さない**（一時的な物・写し先は変えない）。写し元と写し先は全部、同じログインが入っている会社だけ（1 つでも違えば 404 で 1 つも写さない）。写し先に写し元を含めれば 409・E-ME-041（「写し先に、写し元は選べません」＝仮）。全部か無しか（1 つの取引）
- **保存の形**：会社ごと・人ごとに `notification_settings`（0075・unique (tenant_id, member_id)）を 1 行・出来事の行は `notification_preferences`（0015・event_kind_id が key・channel_id が `bell`／`mail`・enabled）。この葉の migration が `notification_preferences` に (tenant_id, member_id, event_kind_id, channel_id) の一意の索引（消していない行）を足す。行が無い出来事は既定を返す
- **記録しない**：自分の受け方の保存は会社の記録（audit_events）にも受け箱にも載せない（K-833 と同じ・D-154.55）
- **同時**：同じ人・同じ会社の同時の保存は、送った項目ごとに後に通った方が残る（別の出来事どうしは両方残る・行は重ならない）
- 読む口の答えは `Cache-Control: private, no-store`。DB の失敗は 503・E-PAGE-003（何も残らない）
- 断る番号は控え帳どおり（422＝契約に書ける形の誤り／404 は欄・details を付けない／409 は欄・details を付けない／503）

### DB の関数（20261126003700_me_notify.sql）

`security definer`・`set search_path = public, app, pg_temp`・`revoke all … from public`・`grant execute … to kaname_app`。先頭で `create unique index if not exists notification_preferences_member_event_ch_uq on notification_preferences (tenant_id, member_id, event_kind_id, channel_id) where deleted_at is null and member_id is not null`。**索引を作る文の前に**、同じ (tenant_id, member_id, event_kind_id, channel_id) で deleted_at が null の行が 2 つ以上あれば、updated_at の新しい 1 行を残してほかに deleted_at = now() を入れる文を置く（前の行が在っても migration が落ちない。リスクの 1 行目）。

| 関数 | 形 |
|---|---|
| `app.me_notify_read(p_tenant uuid) returns jsonb` | p_tenant（null なら今の会社）に同じログインが入っていなければ null。入っていれば `{ workspace_id, email_digest, quiet_hours, paused_until, urgent_override, rows: [{ key, channel, enabled }] }`（行が無ければ既定の値・出来事の既定のかぶせは口） |
| `app.me_notify_update(p_tenant uuid, p_patch jsonb) returns jsonb` | 入っていなければ null。送った項目だけを upsert（notification_settings は (tenant_id, member_id)・出来事は (tenant_id, member_id, event_kind_id, channel_id)）。`pause` の時刻は口が計算して `paused_until` で渡す。更新後の読みを返す |
| `app.me_notify_copy(p_from uuid, p_to uuid[]) returns jsonb` | 写し元・写し先の全部に同じログインが入っていなければ `{"error":"not_found"}`・写し先に写し元が含まれれば `{"error":"same"}`。1 つの取引で写し先の email_digest・quiet_hours・urgent_override を写し元に合わせ、出来事の行は写し先の今の行を消して（deleted_at）写し元の行を写す。paused_until は触らない。`{"ok": true, "copied_to": […]}` |
