## 目的

どの画面からでも、右上の顔を押すと自分のメニュー（自分が誰で・今どのワークスペースにいて・PC がつながっているか、自分の設定・見た目・ログアウト）が、左上の会社の ▾ を押すと入っているワークスペースの一覧が開くようにする（行為 A74・D-154.14）。下絵 me-menu・me-org の部品（K-801 の `features/F10/account/menu.tsx` の `MeMenuPanel`・`OrgPanel`）を、本番の外枠（`components/k/shell.tsx` の `Shell` と、それを使う `TicketShell`）に載せる。

左上の会社の行を押すと、口 `switchWorkspace`（K-851）でそのワークスペースに切り替わり、画面はチケットの一覧を開き直す（D-154.81）。届いた招待は口 `listMyInvitations`（K-851）の数を「届いた招待 N ›」で出すが、**押した先は代表の答えを待つ間は押せない形**（D-154.81）。「新しいワークスペースを作る」は段 11 では作らない（D-154.15・段 14）ので押せない形（グレー・隠さない・D-145.9）。

## 前提と制約

分類: PERM

- **口の答えの形は K-833 と K-851 の「画面が使う答えの形」**：`switchWorkspace` → 200 `{ data: { tenant_id, switched } }`・`listMyInvitations` → 200 `{ data: { invitations: [...], total } }`。`getMe` → `{ data: { member: { name, call_name, avatar: { kind, initial, url }, … }, workspaces: [{ tenant_id, name, role, group, current, own, … }], workspace_name } }`。鍵は K-839 の `use-me.ts` と同じ `["k839","me"]`（/account では読み直さない）。違えば試験の `me()` だけを合わせる
- **外枠の差し込み口**（`components/k/shell.tsx`・任意の props だけを足す）：`meMenu?: ReactNode`（渡されたとき、自分のメニューの箱の中身を今の「名前・項目・見た目・ログアウト」から差し込んだ物に替える。引き金「自分のメニュー」・開き方・閉じ方・置き場は今のまま）・`orgMenu?: ReactNode`（渡されたとき、左上の会社の ▾ を押せる引き金〔`aria-label`「ワークスペースを切り替える」〕にして、開いた箱に差し込んだ物を出す。渡さないときは今の押せない ▾「会社を切り替える（準備中）」のまま）。渡さない呼び方（外枠の見本 /dev/k/shell・下絵・段 2〜4 のモック）は今のまま
- **載せる所**：`TicketShell`（features/F4/create-ticket/ticket-shell.tsx）が `meMenu={<MeMenuBox … />}`・`orgMenu={<OrgMenuBox … />}` を渡す（チケット・承認待ち・PC・ログインと安全・預けたログイン情報・メンバー・自分の設定など、TicketShell を使う全部の画面に出る）
- **開いたときだけ読む**：`MeMenuBox`・`OrgMenuBox` は箱が開いて中身が描かれたとき `getMe` を `useQuery(["k839","me"], …)`（`retry: false`・`staleTime: Infinity`・`screenId` は今の画面）で読む。画面を開いただけでは読まない（外枠の口を増やさない）。2 回目に開いたときは読み直さない
- **自分のメニュー**（`MeMenuPanel` に足す任意の props：`who?: { name, line, face: { kind, initial, url } }`・`pc?: { connected: boolean }`・`theme?: Theme`・`onTheme?(t)`・`onSignOut?()`・`settingsHref?`）：
  - 誰か：名前は getMe の `member.name`（読み中・読めないときは外枠の `member.name`）。2 行目は今いるワークスペース（`current`）の「<会社名> ・ <主のグループ>」（グループが無ければ会社名だけ・兼務があっても主だけ・D-154.15）。読めないときは 2 行目を出さない
  - 顔：getMe の `member.avatar`。`kind` が image なら写真（`img`・クラス `k-f10a-photo`・alt「顔の写真」）、text なら 1 文字。**顔の写真は今いるワークスペースの物だけ**（D-154.50。getMe の答えは今の会社の行の顔なので、ほかの会社で写真を置いていても今の会社に無ければ文字）。右上の引き金の顔は今のまま（外枠の 1 文字）
  - PC：外枠の `bridgeConnected` から。つながっている「PC がつながっている」・副「分身はこの PC で実行する」／つながっていない「PC をまだつないでいない」・副「つなぐと分身が動く」（**仮**・下絵の「高本の MacBook」の端末の名前は外枠が持たないので出さない）
  - 項目（下絵の並びのとおり）：分身の部屋（押せない形・副は「<呼ばれ方（無ければ名前）>のAI」＝**仮**・覚えたいことの数は出さない・D-154.60）・自分の設定（`/account` へ・押せる）・自分の使った量（押せない形・副「使った量は、あとで見られるようになります」・K-73）・見た目（明るい・暗い・PC に合わせる の 3 つの丸）・キーボードの操作（押せない形）・困ったとき・お知らせ（押せない形）・ログアウト（押せる・外枠の `onSignOut` と同じ動き）。押せない形は `aria-disabled`・`title`「まだ使えません」で、字に「準備中」を出さない（D-144.1）。押せる項目は `role="menuitem"`
  - 見た目：今の値は外枠の `theme`。選ぶと `applyTheme`（components/k/theme・cookie に残す）で今の画面を切り替える。口は呼ばない（アカウント全体に残すのはプロフィールの画面 K-839 の「見え方」）
- **ワークスペースの切り替え**（`OrgPanel` に足す任意の props：`rows?: { id, mark, name, role, now }[]`・`onPick?(id)`・`invites?: ReactNode`・`createDisabled?: boolean`・`notice?: ReactNode`）：
  - 行：getMe の `workspaces` の順。印は会社名の 1 文字目・名前・役割の字（管理者・マネージャー・メンバー・閲覧のみ・依頼する側〔**仮**〕・自分だけの場所は「自分だけ」）。今いる会社（`current`）は ✓（読み上げ「いま開いている」）で押す物にしない
  - ほかのワークスペースの行：押せる（`role="menuitem"`）。押すと `call("switchWorkspace", { params: { id: tenant_id }, body: {}, screenId })`。答えを待つ間はどの行も押せない（二度押しで 1 回）。200 → `window.location.assign("/tickets")`（画面を開き直して読みの鍵を全部捨てる・D-154.81）。404（止められた・抜けた・会社が無い）→ 箱の中に「そのワークスペースには入れません」（**仮**）を出し、自分を読み直す（getMe 1 回・その会社の行が消える）・移らない。503・網の切れ → 箱の中に正本 E-PAGE-003 の文・移らない・もう一度押せる。401 → `call` が入り直しへ
  - 届いた招待：箱を開いたとき getMe と並べて `listMyInvitations` を 1 回読む（鍵 `["k844","invitations"]`・`staleTime: Infinity`）。区切りの下に 1 行：`total` が 1 以上なら「届いた招待 N ›」、0 なら「届いた招待はありません」（**仮**）、読めなければ「届いた招待 ›」。**どれも押せない形**（`aria-disabled`・`title`「まだ使えません」・押した先は代表の答え待ち・D-154.81）
  - 新しいワークスペースを作る：押せない形（D-154.14・D-154.15）
  - 読めない（getMe が 503・網の切れ・答えの形が違う）：今いる会社（外枠の `workspace.name`）の 1 行だけと、箱の中に「ワークスペースの一覧を読めませんでした」（**仮**）＋［もう一度読む］
- 箱の `menu` の役は 1 つだけ（外枠の箱の役に名前「自分のメニュー」／「ワークスペースを切り替える」を付け、部品の `role="menu"` を重ねない。前からの試験が `getByRole("menu")` を 1 つとして読む）
- 閉じ方：Esc・箱の外を押す・項目を押す。閉じたら引き金に焦点が戻る（今の外枠のまま）
- スマホ（767 以下）は上の帯の「自分のメニュー」から同じ箱が開く（崩れず読めて押せる・D-154.13）
- 作らない物：届いた招待を押した先（代表の答え待ち）・新しいワークスペースを作る・Kaname の中で招待を受ける（段 14）・メニューから見た目をアカウント全体に保存する・覚えたいことの数（D-154.60）
