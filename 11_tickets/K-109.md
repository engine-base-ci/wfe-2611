## 目的

K-107 の実装（2026-11-06）で見つかった。v3-gate.yml の database の組は、DB の入れ物の番号をホストの 5432 番に出す（`ports: ['5432:5432']`）。台の上で実装の役が手元の試験のために Postgres（/usr/lib/postgresql/16）を 5432 番で立ち上げていると、CI の database の組が立ち上がらず、CI が止まる。unit の組は 5433〜5435 番などに分けてあるが、database の組だけ手元と同じ番号になっている。

## 完了の条件

- [ ] 手元の試験の DB が動いていても、CI（act）の database の組が立ち上がる（番号を分けるか、ホストに出さない形にする）
- [ ] GitHub でも同じ workflow で動く
- [ ] workflow の全部（act）が緑

## 前提と制約

- 台ごとの違いは ~/.actrc に置き、workflow は GitHub と同じにする（D-128.147）

## 実施事項

- [ ] 作る役：database の組の DATABASE_URL と ports の番号を他の組と同じ形（空いている番号）にそろえる案と、試験の行

## テスト仕様と確認の結果

| 確認項目 | 種類 | 判定のしかた | 結果 |
|---|---|---|---|
| 手元の DB が 5432 番で動いていても database の組が緑 | ② 結合 | 台の Postgres を 5432 番で立ち上げたまま act_ci.sh で流す | |
