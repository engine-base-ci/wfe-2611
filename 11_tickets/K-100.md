## 目的

手元の CI（act）は、終わるまで経過が見えず、結果は PM が記録を読んで報告するしかない。GitHub の Actions のように、組（job）ごと・段（step）ごとに「待ち・実行中・緑・赤・かかった時間」と、赤の段の記録の該当部分を、流れている最中に画面で見られるようにする（2026-11-06 高本さん「CICD の経過を GitHub みたいに可視化」）

## 完了の条件

- [ ] CI を流すと画面の口が立ち上がり、アプリの横の画面で開ける
- [ ] workflow の組と段が GitHub の Actions と同じ並び（needs の順）で出て、状態と時間が数秒ごとに変わる
- [ ] 赤の段は、その段の記録の該当部分が開ける
- [ ] 過去の回（コミット・始まり・終わり方）が一覧で見られる
- [ ] どのプロジェクトでも使える（ai-team-delivery の CI に入れる・workflow は変えない）
- [ ] workflow の全部（act）が緑

## 前提と制約

- 部品は入れない（標準の道具だけ）。記録は act が出すもの（組・段の始まりと終わり・成否）を読む
- 回の記録は回ごとに別のファイルに残す（K-101 と合わせる）

## 実施事項

- [ ] act の記録の形（--json か通常の記録）を確かめ、組・段・成否・時間を取り出す
- [ ] ai-team-delivery の scripts/ci/ に画面の台本を足し、act_ci.sh が回の記録をファイルに残して画面を立ち上げる
- [ ] references/ci.md に使い方を書く
- [ ] スキルを入れ直し、.skill を作り直す

## テスト仕様と確認の結果

| 確認項目 | 種類 | 判定のしかた | 結果 |
|---|---|---|---|
| 流れている最中に組・段の状態が変わる | ② 結合 | 小さな workflow と Kaname の workflow で、画面を開いたまま流す | |
| 赤の段の記録が開ける | ② 結合 | わざと落とす段を持つ workflow | |
| 過去の回が一覧に出る | ② 結合 | 2 回流して一覧を見る | |
