## 目的

2026-11-06、K-52 の CI（回 20261106-110330-c9034b456b）の web の組で、K-52 と関係の無い前からある試験 apps/web/tests/components.spec.ts の KN104-005 が赤になった。K-107 の回（同じ試験・同じ部品）では緑だった。

原因：タブの部品（base-ui の Tabs）は、切り替えの動きの間、前の中身（inert・data-ending-style）と新しい中身（data-starting-style）を一瞬 2 つ並べて出す。試験の `page.getByRole("tabpanel")` は 1 つだと思って `toHaveText` を当てるので、2 つ並んだ瞬間に当たると strict mode の違反で落ちる。動きの速さ次第で落ちる、試験の側の書き方の誤り（部品の動きは正しい）。

- [x] 同じ書き方（`getByRole("tabpanel")` を 1 つと決めて当てる）を apps/web/tests の中で全文検索し、同じ型の所も直す（L-008）
- [x] 直した試験を 20 回続けて流して 20 回とも緑
- [ ] チケットの CI（act）が緑
