## 目的

ゲストのグループ（K-876）の名前を直す・消すを作る（D-155.46・D-155.51）。口は 2 本：

- `updateGuestGroup`（PATCH /guest-groups/:id・体 `{ name }`）→ 200 `{ data: { id, name } }`。中のゲストと届け先はそのまま
- `deleteGuestGroup`（DELETE /guest-groups/:id）→ 200 `{ data: { id } }`。**消すと**：中のゲストは入れなくなる（会社から抜けた扱い・生きているセッションをすぐ切る・G-14）・受けていない招待は取り消す・見せていたチケットから外れる（K-881 の関数 `app.ticket_guest_shares_drop_group` を同じ取引の中で呼ぶ）。**チケット・依頼・やり取りは残る**（依頼の `guest_group_id` は消えたグループを指したまま・グループの名前は今までどおり読める）

画面（名前を直す小窓・消す確かめ）は K-928。口の形は K-928 が仮に置いた物（`updateGuestGroup` は `{ name }`・`{ id, name }`／`deleteGuestGroup` は `{ id }`・無い物は 404・E-GST-001・同じ名前は 409・E-GST-002）と同じにした（新しいエラー番号は作らない・枠 E-GST-015〜029 は使わない）。

## 前提と制約

分類: CRUD, PERM

- **権限は、メンバーを直せる人**（`has_permission(app.user_id(), 'members', null, 'edit')`＝管理者と権限を付けた人・マネージャー・普通のメンバー・ゲストは 403）。招く権限だけの人は名前を直せず消せない（作るのは招く権限でもよいが、直す・消すは重いので edit・D-128.97）
- 名前：前後の空白を取り、1〜80 字（K-876 と同じ）。表記ゆらぎをそろえた鍵 `name_key`（生成列）で会社の中で一意（自分の名前の大文字小文字・空白だけを直すのは通る）。重なれば 409・E-GST-002（欄・details なし・在る名前を漏らさない）。DB が最後の砦（一意の索引）
- 道の :id のグループが、この会社に無い・消した・別の会社の物なら 404・E-GST-001（欄・details なし）。同じグループを 2 回消すと 2 回目は 404
- **消す手順（1 つの取引・`app.guest_group_delete`）**：① `app.ticket_guest_shares_drop_group(グループ)`（見せる相手を外す・証跡は K-881 の物）② グループの生きている所属（`guest_group_members`）の人ごとに：`members.deleted_at = now()`・`tenant_memberships.status = 'left'`・`app.revoke_all_sessions(人, 'guest_group_deleted')`（新しい失効の理由）・所属の行に `deleted_at` ③ このグループの受けていない・取り消していない招待（`invitations.guest_group_id` が同じ・`accepted_member_id` が空・`revoked_at` が空）に `revoked_at = now()` ④ グループに `deleted_at = now()` ⑤ 証跡 `guest_group.deleted`（payload は `guest_group_id`・`guest_count`・`share_count` だけ・名前もメールも載せない）。**どれかが落ちたら全部戻る**
- 消したあとの読み：ゲストは次の要求から入れない（セッションは切れ・もう一度ログインしても会社から抜けた人なので会話が開かない）・K-878 の判定 `app.my_guest_group()` は null・見せていたチケットは見えない（K-881 の判定）
- **残る物**：チケット（`tickets`）・依頼（`client_requests`・状態も変えない）・依頼のやり取り・チケットのチャット（ゲストが書いた物も本文は残る・書いた人の行は消えた人として残る）・ゲストが書いた/受け取ったお知らせ。消したグループの名前は社内の読み（K-892）で今までどおり出る（グループの行は消さず `deleted_at` だけ付ける）
- 名前を直す・消すで、ゲストへメールやお知らせは送らない（入れなくなる人へは何も送らない・D-155.46）。外の呼び出しは無い
- 同じ名前でもう一度作る（K-876）は、消したグループの名前とは重ならない（一意は消していない物だけ・K927-API-018）
- 関門の宣言（頭の欄 choke_points）は [C2]（DB に書く）。メール・外のサービスは呼ばない
