## 目的

決める人の決定 D-129.45（2026-11-08）：見た目の最初は「システムに合わせる」ではなく**明るい**に統一する。いまは K-24 の作りで、選んでいない人（cookie が無い人）は OS（Mac など）の設定に合わせて暗くなる（`apps/web/lib/theme.ts` の `parseTheme` の既定が `system`・`styles/k-tokens.css:220` の `@media (prefers-color-scheme: dark)`）。staging の登録の画面を見た決める人が「なんで暗くなっているの」と気づいた。

切り替え（システム・明るい・暗い）は残す（D-128.55）。設定はアカウントに持たせ、web も後で作るアプリも同じ設定を読む。

## 完了の条件

- [ ] 見た目を選んでいない人（cookie もアカウントの設定も無い）は、OS が暗くても明るい画面になる
- [ ] 「暗い」を選んだ人は暗い画面、「システム」を選んだ人は OS に合わせる（今と同じ）
- [ ] ログインの前の画面（登録・ログイン・メールの確認など）も、選んでいなければ明るい
- [ ] 試験：OS を暗くしたブラウザ（Playwright の colorScheme: dark）で、選んでいない人の画面が明るい／暗いを選ぶと暗い／システムを選ぶと暗い
- [ ] チケットの CI（act）が緑

## 実施事項

作り方（切る段で決めた）：選んでいない人の既定を `system` から `light` にする。明るいときはサーバーが `<html data-theme="light">` を付け、今の CSS（`apps/web/styles/k-tokens.css:221` の `:root:not([data-theme="light"])`）が OS の暗さを無視する。「システム」を選んだ人は今までどおり data-theme を付けず OS に合わせる。CSS は変えない。

1. `apps/web/lib/theme.ts` の `parseTheme`：知らない値・無い値の既定を `"light"` にする（先頭の注も「選んでいなければ明るい（D-129.45）」に直す）
2. `apps/web/app/global-error.tsx`（根の layout で落ちたときの画面・自分で `<html>` を持つ・"use client"）：`document.cookie` の `k-theme` を読み、根の layout と同じ `themeAttr(parseTheme(…))` で `<html data-theme>` を付ける（選んでいなければ light）
3. 試験：`apps/web/tests/k/k147-theme.spec.ts`（新・画面 6 行）・`apps/web/test/k147-theme.test.ts`（新・部品 1 行）。前からの `apps/web/test/k-tokens.test.ts`（K-24）と `apps/web/test/k-app-files.test.ts`（K-30）は、既定が変わった所だけ直す

使っている所（直さない・振る舞いが変わる所を確かめた）：`apps/web/app/layout.tsx:19`（根で data-theme を付ける・light が付くようになる）・`apps/web/components/k/theme.tsx`（押した値を付ける・変わらない）・`apps/web/app/(dev)/dev/k/page.tsx`・`shell/page.tsx`・`showcase/page.tsx`（切り替えの最初の選び・「明るい」が選ばれるようになる）。前からの画面の試験 `apps/web/tests/components.spec.ts` の KN104-009 と `apps/web/tests/k/showcase.spec.ts` の KSC-03-001 は「システムを押すと data-theme が無い」を見ていて、変わらない。

アカウントに見た目を持たせる（`members.theme`・`packages/db/migrations/0078_people_tenant_ops.sql` の既定 'system'）は、口がまだ無い。このチケットでは触らない。受け持つのは **K-56**（段 4 F3 使い始めの準備・自分の設定）：K-56 に申し送りを書いた（列の既定を light に替える migration・今ある 'system' は選んでいない扱いで light に替える〔D-139.1・answer=731a86e168e4〕・cookie とアカウントの設定がずれたときはアカウントを正にする）。
