## 目的

管理者が「チケットの設定 › 項目」で、会社の項目を **足す**（名前・型・選ぶ物・必須・説明・どの種別で出すか）・**消す**（値が見えなくなることを確かめてから）ができる画面（行為 A118・切り方 0.13・土台-settings.md の 5 章）。K-709 が「押せない形」で置いた「項目を足す」「この項目を消す…」を押せる形にして、小窓を口につなぐ。口は K-706（`createTicketField`）と K-717（`deleteTicketField`）。

K-709 の差し込み口 `fields-slots.ts` に **1 行**足して入る（K-709 の申し送りのとおり）。小窓の見た目は切る段で作り終えてある（`field-dialogs.tsx`・下絵に無かった 2 つの状態 `set-field-add`・`set-field-delete`＝字は仮・代表がまだ見ていない絵）。

  - **選ぶ物の欄**は型が「1 つ選ぶ」「複数選ぶ」のときだけ出る：1 行ごとに名前の欄と「外す」・下に「選ぶ物を足す」（足すと空の欄が増えて焦点）。**並べ替えの操作は作らない**（足した後に直す画面でできる・小窓は短く）。ほかの型にすると欄が消える（中身は小窓の中に持ち、選ぶ型に戻すと出る）
  - **入力の確かめ**は JS が先に働く（口を呼ばない）：`fieldProblems(draft)`（K-709）の文を欄の下に出す（名前＝`TextField` の `error`・選ぶ物＝欄の下の `.k-err`・種別＝欄の下の `.k-err`・`aria-invalid`）。直すと消える・小窓は閉じない。最初の誤りの欄に焦点
  - **足す**：「足す」で `createTicketField`（`POST /ticket-fields`）。体は `fieldCreateBody(draft, allKindIds)`＝`{ name（前後の空白〔全角も〕を落とす）, field_type, kind_ids（全部の種別の並びの順・チェックの物だけ）, required（必ず送る）, description?（空は送らない）, options?（選ぶ型のときだけ・`[{ name }]`・id なし・並びの順）}`・冪等の鍵あり。成功で小窓を閉じ、お知らせ（`useNotify`）「項目「<名前>」を足しました」（**仮**）・項目を `invalidate` で 1 回読み直し（種別は読み直さない）・**足した項目を選ぶ**（`ctx.select(答えの id)`＝K-709 の離れる前の確かめを通る）
  - **口の断り**：409 E-FMS-001（同じ名前）＝名前の欄の下に正本の文／409 E-FMS-004（同じ名前の選ぶ物）＝選ぶ物の欄の下に正本の文／404 E-PAGE-001（開いている間に種別が消された）＝小窓の上の赤い箱（`NoticeBox`）に正本の文＋**種別を読み直す**（消えた種別のチェックが無くなる・残りは残る）／403 → E-PAGE-002・503 → E-PAGE-003・網の切れ → E-PAGE-007＝小窓の上の赤い箱。**どれも小窓は閉じず、入れた中身と選びは残り、押し直せる**。答えを待つ間は「足す」を押せない（二度押しでも口 1 回）
  - やめる・Esc・右上の×は口を呼ばず閉じ、焦点は「項目を足す」に戻る。入れた字は捨てる（開き直すと空）。会社が足した項目が 0 件のときも一覧の下の「項目を足す」から同じ小窓で足せる（K-709 の `Empty` の下に在る）
- **「この項目を消す…」**（`delete`）：確かめの小窓 `FieldDeleteDialog`（`Confirm`・焦点は「やめる」・見出し「項目「<名前>」を消しますか」・赤い注意を 1 行ずつ）。注意の文は `deleteCaution(value_count)`：値が入っているとき「<N> 件のチケットに入っている値が見えなくなります。」＋「消すと元に戻せません。」／0 件のときは後ろの 1 行だけ。「消す」で `deleteTicketField`（`DELETE /ticket-fields/:id`）。成功で小窓を閉じ、お知らせ「項目「<名前>」を消しました」（**仮**）・項目を読み直して**先頭の項目を選ぶ**（残りが 0 件なら右の欄は出ない）。元に戻す画面は作らない
  - **口の断り**：404 E-PAGE-001（もう消されていた）＝確かめの中の赤い箱に正本の文＋項目を読み直す（一覧から消える・小窓は「やめる」で閉じる）／403・503・網の切れ＝赤い箱。項目は一覧に残り、押し直せる。答えを待つ間は「消す」「やめる」を押せず、二度押しでも口 1 回
  - 値の数（`value_count`）は K-706 の答えの数をそのまま使う（画面で数え直さない）
- **この葉は項目の並べ替え・型の変更・直すを持たない**（直す・並べる選ぶ物は K-709・項目の並べ替えは画面に出さない）
