## 前提と制約

分類: CRUD, PERM

- **選んだ物の置き場**（`bulk/use-bulk.ts`）：頁の中の store（`useSyncExternalStore`・承認の id の集合）。頭・行・帯・カードの 5 か所が同じ物を読む。更新は新しい集合を作って入れ替える。一覧を読み直したら、一覧に無くなった id は外す。確かめの口に送る id の並びは、押した順でなく一覧の並び
- **先の部品の名前**：K-730 の決め（`<器の名前>Fill`）のとおり `QueueBulkFill`
- **選べる数**：50 件まで（口の上限）。50 件を選んでいるとき、選んでいない四角は押せない形（title「まとめて承認は 50 件までです」）・頭の四角で全部選ぶときも 50 件で止める。**押せない形は四角の `<input type="checkbox">` に素の `disabled` を付けて表す**（aria-disabled だけにしない＝押すと選べてしまうため。title は disabled でも付けたまま）。上限は頭の四角だけでなく行の四角（表とカードの両方）にも入れる（代表の決め answer=0574d6e78a2a・K769-UI-021 が toBeDisabled と「押しても選ばれない」を見る）
- **選べる行**：`kind === "artifact"`（AI の成果物）だけ。渡された行は四角を出さず「—」（title「1 件ずつ決める」・下絵のとおり＝K-730 の既定のまま）
- **頭の四角**（head）：aria-label「まとめて選べるものをすべて選ぶ」。読み込んだ AI の成果物の行を全部選ぶ（50 件まで）／全部外す（一部だけなら indeterminate）
- **選んだ帯**（band）：1 件以上選ぶと「<N> 件を選んでいます」と［選んだものを承認］（region「選んだもの」）。本物の帯は先のファイル（`fills/queue-bulk.tsx` か `bulk/` の部品）に、下絵の `BulkBar` と同じ形 `<div className="k-more-bulkbar" data-at={at} role="region" aria-label="選んだもの">`（中は `<p>` の字と［選んだものを承認］の `Button` を直の子に）で作る。`data-at` は差し込み口の `at` をそのまま付ける（必須・無いと more.css の幅の出し分けと貼り付きが当たらない）。下絵の `BulkBar` は見本で押せないので使わない・触らない。PC は表の上（`at="table"`）、スマホ（767 以下）はカードの後ろ（`at="mobile"`）に置いて画面の下（下のタブの上）に貼り付く（代表の決め answer=0050b3906ae6）。幅で片方だけが見える（more.css の `data-at`）ので、region「選んだもの」は見える形で 1 つ。2 つの置き場は同じ選んだ物の置き場を読む
- **［まとめて承認（全部）］**（tool）：選んだ物に関わらず、全部を対象にする
- **確かめ**：［選んだものを承認］は `previewBulkApproval`（体 `{ approval_ids: 選んだ id の並び（一覧の並び）}`）、［まとめて承認（全部）］は体 `{}`（approval_ids を付けない。呼び手 call.ts は書き込みに必ず体を付け、口 K-768 も体を JSON で読むため）で読む。答えの `eligible` が 0 件なら小窓を開かず「まとめて承認できるものがありません」の帯と一覧の読み直し。409・E-APR-030 は小窓を開かず正本の文（D-153.37）。403 は正本 E-PAGE-002 の文・422・503 ほかは正本の文の帯（承認の口は呼ばない）
- **確かめの小窓**（`bulk/bulk-confirm.tsx`・`Confirm tone="primary"`・下絵の `BulkConfirm` と同じ並び）：題 全部は「AI の成果物 <count> 件をまとめて承認します」・選んだ物は「選んだ <count> 件をまとめて承認します」／注意 `irreversible_count` が 1 以上なら「取り消せない物が <N> 件含まれます」／区画（`k-more-pending`）「チェックの無い確認項目が <unchecked_count> 件あります」（0 件なら区画を出さない）と「1 件ずつ中身を見ていない承認も含まれます。付けなくても承認できます」／主ボタン「<count> 件を承認する」・［やめる］（Esc も）は口を呼ばず閉じ、選んだ印は残る
- **承認**：主ボタンで `bulkApprove`（体 `{ approval_ids: eligible の approval_id の並び }`＝確かめで見た物だけ・K-768）。答えを待つ間は主ボタンが処理中で小窓は閉じない・二度押しでも 1 回。201 なら小窓を閉じ、選んだ印を外し、一覧を読み直し、帯を出す：
  - `updated` が 1 件以上：「<N> 件を承認しました。実行は 1 件ずつ順に始まります（<number を「・」でつないだ並び>）。決めた履歴から確かめられます」（info）
  - `skipped` が 1 件以上（warn・updated の帯の代わりに 1 つにまとめる）：「<N> 件は承認できませんでした：」の後に、番号の在る物を「<number> <title> は、<理由の文>」で 1 件ずつ「・」でつなぐ。理由の文は decided「先にほかの人が決めていました」・not_approver「担当者が変わっていました」・not_writable「この物を直す権限が無くなっていました」。番号の無い unavailable は数えて「<N> 件は見つかりませんでした」（「承認できませんでした」と別の文・番号の在る物が無ければこちらだけ）。`updated` が 1 件以上なら最後に「<承認した number を「・」でつないだ並び> は承認しました」・0 件なら出さない。内部の言葉（decided など）を画面に出さない（K-768 の申し送り）
  - **帯は 1 つ**：押すたびに前の帯を消して入れ替える
  - 503 ほか：小窓の中に正本の文・閉じない・押し直せる。401 は入り直し
- **字**（`bulk/bulk-words.ts`・1 か所）：上の文を作る関数（新しい値を作って返す）
- 権限：口が承認する人の物だけを確かめで返し、1 件ずつ守りを通す（K-768）。画面は役の名前で出し分けない
