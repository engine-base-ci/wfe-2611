## 目的

古い K-89「Claude Code を入れてログインする」の Bridge（PC 側）の分。画面（K-361）が PC の行に「足りない物と直し方」を出し、押した後の様子を見せられるように、Bridge の側を整える。

- 自己診断の Claude Code の 2 行（ある・ログインできている）を、electron を読まずに試せる関数 `claudeChecks()` に外へ出し、直し方（fix：install／repair／login）とエラーの ID（code：repair は E-CONN-011・login は E-CONN-010）を付ける
- 「入れる」は 2 つ重ならない（押し重ねたら走っている方の結末を返す）・最長 10 分で走らせた物（npm）を止める・途中の行をこの PC の口 `GET /install-progress` で画面にも流す
- ログインは今の形（claude auth login がブラウザの入口を出す → 本人が承認 → 出たコードを貼る）のまま。**ログインが確定するのは、Bridge が `claude auth status` に聞いて「入れている」と返った時点**（コードを渡しただけで合格にしない）
- この PC の口 `/login-code` は本文が JSON として読めないとき 422 で返し、口ごと落ちない
- 画面が「この行はこの PC か」を見分けられるように、Bridge は生きている知らせの答えの `device_id`（K-360 が足す）を覚え、この PC の口 `/ping` で返す

本人の資格情報（パスワード・コード・トークン）は Bridge も Kaname も AI も持たない（D-017・D-092 ①）。コードは Claude Code の標準入力にそのまま渡すだけで、Kaname のサーバーには届かない。
