## 目的

ゲストのグループの名前を直す・消す（代表の答え answer=695325c0630f）。K-874 が出した「⋯」（名前を直す・消す。押せない形）を押せる形にして、口 `updateGuestGroup`・`deleteGuestGroup`（K-927）につなぐ。

- 「名前を直す」：小窓（今の名前が入っている）。直しても中のゲストと見せているチケットはそのまま

- **K-874 の後**（同じ `features/F10/invite/` のゲストのタブを触る）。口は K-927
- **口の名前・答えは K-927 の確定**：`updateGuestGroup`（PATCH /guest-groups/:id・入力 `{ name }`・200 `{ data: { id, name } }`・同じ名前は 409・E-GST-002・無い／消した物は 404・E-GST-001）・`deleteGuestGroup`（DELETE /guest-groups/:id・200 `{ data: { id } }`・無い／消した物は 404・E-GST-001）。**直す・消すは管理者と「メンバーを直せる権限」を付けた人だけ**（招く権限だけの人・マネージャー・普通のメンバーは口が 403・K927-API-005・012）
- 「中のゲスト（N 人・招待中 M）」は、一覧の口（listGuestGroups・K-876 の確定）が返した `guests`・`invitations` の数から出す（確かめを開くために口を足さない）。**止めているゲスト（`suspended` が true）も人数に数える**（K-927 は止めたゲストも入れなくするので、消す確かめには含める・行の字は変えない）。ゲストが 0 人・招待中 0 のグループは「中のゲスト」の行を出さない
- 名前の空白（前後・全角）は取って送り、空は口を呼ばず「名前を入れてください」。同じ名前の判定（全角半角・大文字小文字・空白の違いも同じ）は口が最後の砦
- 画面は役の名前で出し分けない。直す・消す権限が無ければ口が 403 を返し、小窓（確かめ）の中の赤の知らせに権限の文（errors.json の E-PAGE-002 の頭「この画面を見る権限がありません」）を出す（K928-UI-014）。小窓は閉じず値は残る
- 消した後は一覧を読み直して消える（作る応答の写しで消さない・G-02）。知らせは「ゲストのグループ「…」を消しました」
- 画面に「取引先」の字を出さない・新しい migration・DB は無い
