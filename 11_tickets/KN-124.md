## 目的

GitHub Actions が手順の前に 2 秒で落ちる形で止まっている（2026-11-04・利用枠か支払いの疑い）。ai-team-delivery のスキルの CI（dagci）を Kaname に入れ、GitHub の v3-gate と同じ検査をこの台の容れ物の中で流す。

## 完了の条件

- [x] ci.yaml を置き、段は v3-gate.yml から機械で導く（scripts/ci/ci_stages.py・手で写さない）
- [x] GitHub の検査がどれも段に 1 対 1 で入っているかを機械で確かめる（ci_stages.py --check・G52）
- [ ] `dagci run --all` が全部の段で緑
- [ ] CI の正をどちらにするかを決めてもらい、決定ログに残す
- [ ] v3-gate.yml の検査の番号の重なり（G27・G28 が static と spec に 2 回ずつ）を直す

## 前提と制約

- 外す job：task-gate（task/ の枝の PR だけ）・e2e（staging が要る・KN-110）・auto-merge（GitHub の取り込みの道具）

## 実施事項

- [x] dagci setup（Docker・Dagger 0.21.10 のエンジン）
- [x] ci.yaml（道具箱 node:22・Python・pnpm 10.28.2・Postgres（pgvector/pg16）・Playwright の chromium）
- [x] Node が OS の証明書を読まず、中継の内側で npm が落ちる → toolbox.env に NODE_EXTRA_CA_CERTS（スキルの雛形にも足した）
