## 目的

K-144 の完成確認（Q5 回 8・2026-11-09）が、実 Chrome で作る面（create-ticket）を触ったときに見つけた。種別・担当者・優先度の「選ぶ」を開くと、320・375・768 の幅では選択肢の一覧が作る面の下に隠れ、どれも選べない（1440 では選べる）。原因と見ているのは `apps/web/components/k/select.tsx:56` の `S.Positioner` と `apps/web/components/k/k.css:196` の `.k-select-popup` に重なりの順（z-index）が無く、作る面（k.css:401・406 の z-index 80・81）より下に出ること。K-144 の差分とは関係なく前からある別の場所の問題なので、K-144 に入れず起票した（D-129.32・PM の判断 2026-11-09）。

## 完了の条件

- [ ] 「選ぶ」の選択肢の一覧が、それを開いた面（作る面・ほかの重なる面）より上に出る。重なりの順は共通の値（css の変数）で 1 か所に置き、面ごとに数を書かない
- [ ] 同じ部品（apps/web/components/k の Positioner を使う部品：選ぶ・メニュー・ツールチップ など）を全文検索で全部出し、同じ形の重なりの抜けをそろえる
- [ ] 実 Chrome（本番の形で組み立てた画面）で、作る面の種別・担当者・優先度を 320・375・768・1440 の 4 幅で開き、選択肢を押して値が入る試験が緑
- [ ] チケットの CI（act）が緑
