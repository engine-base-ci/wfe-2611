## 目的

操作が無いと 12 時間・最長 7 日で切る。国か端末が変わったら切って入り直させ、同じ国の中で IP だけ変わったら記録だけ残す。新しい端末でのログインは本人に知らせる。管理者はもっと短くできる。

## 完了の条件

- [ ] 12 時間操作が無い・7 日たったセッションは 401
- [ ] 国（x-vercel-ip-country）か端末（ブラウザの種類・OS）が変わると 401 で、セッションは閉じる
- [ ] 同じ国の中で IP だけ変わったら切らず、security_events に残る
- [ ] 新しい端末でログインすると、本人に知らせが届く
- [ ] 管理者が会社の長さを短くできる（長くはできない）
- [ ] zt_gate の session_idle・session_geo が 0
- [ ] CI が緑

## 前提と制約

- 暗号の中身は Better Auth に任せる（D-128.91）

## 実施事項

- [ ] sessions に国・端末・IP の列。tenants に操作が無いときの長さ・最長の長さ
- [ ] app.session_check：要求ごとに確かめ、切るときは理由（idle・max_age・country_changed・device_changed）を付けて閉じる
- [ ] 解決（resolver）が国・IP・端末を渡す
- [ ] 新しい端末：知らせ（画面・メール）
