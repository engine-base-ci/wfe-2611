## 目的

操作が無いと 12 時間・最長 7 日で切る。国か端末が変わったら切って入り直させ、同じ国の中で IP だけ変わったら記録だけ残す。新しい端末でのログインは本人に知らせる。管理者はもっと短くできる。

## 完了の条件

- [x] 12 時間操作が無い・7 日たったセッションは 401
- [x] 国（x-vercel-ip-country）か端末（ブラウザの種類・OS）が変わると 401 で、セッションは閉じる
- [x] 同じ国の中で IP だけ変わったら切らず、security_events に残る
- [x] 新しい端末でログインすると、本人に知らせが届く
- [x] 管理者が会社の長さを短くできる（長くはできない）
- [x] zt_gate の session_idle・session_geo が 0
- [ ] CI が緑（手元で変えたところの試験を確かめた。GitHub の結果は push 後に見る）

## 前提と制約

- 暗号の中身は Better Auth に任せる（D-128.91）

## 実施事項

- [x] sessions に国・端末・IP の列。tenants に操作が無いときの長さ・最長の長さ（0083）
- [x] app.session_check：要求ごとに確かめ、切るときは理由（idle・max_age・country_changed・device_changed）を付けて閉じる。国・端末で閉じたときは security_events に suspicious_connection
- [x] 解決（resolver）が国（x-vercel-ip-country）・IP・端末（ブラウザの種類／OS・版の数字は見ない）を渡す
- [x] 新しい端末：画面の知らせ（notifications・security.new_device）とメール（送れなくてもログインは止めない）
- [x] PC に常駐する Bridge は時間では切らない（D-128.121。確かめた）
- [x] zt_gate の ZT6 の確かめを、言葉が書いてあるかではなく、解決が app.session_check を呼び、その関数が 4 つの理由で閉じるかにした
