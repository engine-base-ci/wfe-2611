## 目的

管理者（と「誰ができるか」で消すが可になった人・D-154.83）が、ワークスペースを消す手続きを始め、14 日のあいだ取り消せるようにする（行為 A75）。設定の画面（K-831）の「ワークスペースを消す」の［消す手続き］で小窓を開き、名前を打って確かめ、本人確認を取り直して始める。始めると設定の上に帯「このワークスペースは、消す手続き中です（あと N 日）」が出て、［本人確認して取り消す］で取り消せる。口は `requestWorkspaceDeletion`・`cancelWorkspaceDeletion`（K-830）。帯の元は `getWorkspaceSettings`（K-827）の `deletion`。

**手続き中も全員いつもどおり使える**（D-154.5）：何も止めない。**先に書き出せるは作らない**（D-154.4：消す前にデータを外へ持ち出す形を作らない。プランをやめるときは削除する）。14 日を過ぎたら運営が消す（段 11 は消す仕組みを持たない）。

## 前提と制約

分類: CRUD, PERM

- **口の答えの形は K-830・K-827 の「画面が使う答えの形」**：始める `POST /workspace/deletion {confirm_name}` → 200 `{ data: { deletion: { requested_at, delete_at, days_left } } }`・取り消す `DELETE` → 200 `{ data: { deletion: { 全部 null } } }`。小窓の「消えるもの」の数と帯は設定の読み（`deletion.preview`・`requested_at`・`days_left`・`requested_by`）から。違えば `f10-ops-kit.ts` の `settings()`・`deletion` の既定だけを合わせる
- **入口**：設定の画面（K-831）の［消す手続き］。小窓の登録口 `SETTINGS_DIALOGS`（K-831 の `settings-dialogs.tsx`）に `delete: DeleteFlow` を 2 字下げの 1 行で足す（足すと K-831 の「押せない形」が「押せる形」に変わる・K831-UI-019）。手続き中は［消す手続き］を出さず、部品の札「手続き中」を出す（下絵のとおり）
- **押せる人（D-154.83）**：設定の読みの `access.delete_workspace` が true の人（管理者・「管理者とマネージャー」にしたマネージャー・個別に付けた人）だけ［消す手続き］と帯の［本人確認して取り消す］が押せる。false の人（支払いだけが可の人など）には帯と札は出すが、ボタンは押せない形（aria-disabled・口を呼ばない・隠さない）（K832-UI-024）
- **小窓（下絵 st-delete・st-delete-ready）**：題「ワークスペースを消す」・字「<名前> を消す ・ 消すと戻せません」・消えるもの「チケット N 件・記録・預けたログイン情報・メンバー M 人の分身の記憶（このワークスペースの分）」（N・M は口の `preview`）・箇条 2 つ（メンバーのアカウントは消えない・消す手続きから 14 日は取り消せる）・名前の欄（確かめのため、ワークスペースの名前を打ってください）。**名前が完全に同じ**になるまで主ボタン「本人確認して消す手続きをする」は押せない（全角半角・大文字小文字・前後の空白を同じとみなさない＝口の比べ方と同じ・打ち間違いで消えるのを防ぐ）・欄の下は「名前が合うと押せる」→ 合うと「名前が合いました」。**先に書き出せるの字・ボタンは無い**
- **送る**：`call("requestWorkspaceDeletion", { body: { confirm_name: 打った字 } })`。処理中は主ボタンが処理中で二度押しでも 1 回。200 → 小窓を閉じ、設定を読み直す（帯の「始めた人」と日時は読みにしか無い）。**403 STEP_UP_REQUIRED** → `getMySecurity` を 1 回読んで `StepUp`（features/F1/security/step-up.tsx・パスキーだけの人はパスキー・D-154.3）。理由「ワークスペースを消す手続きを始める前に、本人か確かめます」（**仮**）。通ったら同じ体で 1 回だけやり直す・やめたら何も送らず名前の小窓に戻る（打った字は残す・K-363 と同じ形）。**409 E-WS-030**（名前が合っていない・口の最後の砦）→ 欄の下に口の文・小窓は開いたまま。**409 E-WS-031**（すでに手続き中）→ 小窓を閉じて設定を読み直す（帯が出る）。**503**・網の切れ → 小窓の中に E-PAGE-003 の文の赤い箱・開いたまま・もう一度押せる。**403（STEP_UP_REQUIRED でない）**→ 小窓を閉じ、権限なしの画面（K-831 と同じ）に替える
- **帯（下絵 st-deleting）**：設定の答えの `deletion.days_left` が null でないとき、部品の `Band`（赤）：「このワークスペースは、消す手続き中です（あと N 日）」・サブ「いまのうちは取り消せます。そのあと、チケット・記録・分身の記憶がすべて消えます」・ボタン「本人確認して取り消す」・`BandLine`「手続きを始めた人：<名前> ・ MM/DD HH:mm」（日本時間・`requested_by` が null のときはこの行を出さない）。「あと N 日」は答えの数のまま（1 日・0 日も同じ字）。区画の札は「手続き中」
- **取り消す**：`call("cancelWorkspaceDeletion")`。200 → 帯を消し［消す手続き］を戻す・設定を 1 回読み直す。**403 STEP_UP_REQUIRED** → 取り直し（理由「消す手続きを取り消す前に、本人か確かめます」・**仮**）→ 1 回だけやり直す・やめたら 0 回で帯は残る。**409 E-WS-032**（14 日を過ぎた）→ 帯の下に口の文の赤い箱・設定を読み直す。**409 E-WS-033**（すでに取り消されていた）→ 設定を読み直す（帯が消える）。503・網の切れ → 帯は残し E-PAGE-003 の文の赤い箱・もう一度押せる。処理中は二度押しでも 1 回
- **手続き中も全員使える**：帯が出ていても、名前・ロゴ・誰ができるか・左のバー・第 2 ナビは何も止めない（aria-disabled にしない・口を呼ぶ）。帯は設定の画面だけ（D-154.74。設定の口は管理者と D-154.83 の人だけが読めるので全員の画面には出せない）
- スマホ（767 以下）は崩れず読めて押せる（D-154.13）。幅 320 でも小窓・帯で横のはみ出し 0
