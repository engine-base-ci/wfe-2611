## 目的

1 社の画面（K-971）の頭のボタンから、運営が中を見る・止める・再開する・この 1 社にお知らせを送るを行えるようにする（行為 A64・A127）。中を見ている間と止めている間は、頭の下に帯を出す（D-128.68）。

- **代表の答え 2026-11-23（D-156.23）**：止める日までの間はその会社の管理者にお知らせと帯（口の葉 K-970）。止めた後は止められた画面（顧客の側・K-1008）。運営の側は止めている帯と［再開する］
- 中を見る：理由（その会社の済みでない問い合わせ・障害の調べ・請求の確認・ほか（書く））・見る時間（30 分・1 時間）・開く前に本人確認（パスキー）

- お知らせを送る：題・本文・出す場所（画面の上の帯・お知らせの一覧・どちらも）。この 1 社の人だけに届く（口は K-978）

## 前提と制約

分類: PERM

- **下絵をそろえる：済み**（2026-11-23 の下絵の直しで入った・作る人は待たない）：止める小窓の理由は reason_key の 4 つ（STOP_REASONS）・中を見るの見る時間は 30 分／1 時間・お知らせの出す場所は 画面の上の帯／お知らせの一覧／どちらも・止めた後は止められた画面・止めている帯に止めた人の名前なし。お知らせを送る小窓には「誰に」（この会社の人みんな／管理者だけ）と注「管理者だけのお知らせは、お知らせの一覧にだけ出ます（上の帯には出しません）」が在る
- **頭のボタン**（K-971 の `TenantFrame` の `acts`）：［お知らせを送る］は notice・［中を見る］は peek・［⋯ › 止める／再開する］は stop を caps に持つ人だけ押せる。持たない人には押せない形（`aria-disabled`・title「この操作はできません」・隠さない・D-145.9）で、押しても口を呼ばない
- **値と体（`ws-dialogs-shape.ts`・純粋な関数・`@/` を読まない）**：
  - `peekReasons(inquiries)`：済みでない問い合わせごとに「問い合わせ「<題>」（<聞いた人>・<MM/DD>）」・障害の調べ・請求の確認・ほか（書く）。`peekBody(form, inquiries)`：問い合わせ → `{ reason: "問い合わせ「<題>」", minutes, inquiry_id }`・障害・請求 → `{ reason: <字>, minutes }`・ほか → 書いた字（前後の空白を落とす）。空・minutes が 30／60 でない → null（送らない）
  - `peekBandView(ws, now)`：`ws.peek` があり期限の前なら `{ id, title: "<会社> の中を見ています（見るだけ）", rest: "残り <切り上げの分> 分" }`・ほかは null
  - `STOP_REASONS`・`canStopNow(reason)`（violation・danger だけ）・`stopDefault(now)`（unpaid・scheduled・7 日後・空）・`stopBody(form)`（scheduled は stop_on・now は stop_on なし・note と admin_notice は空白を落として空なら付けない・now で unpaid／request は null）・`stopLabel(form)`（「<M/D> に止める」／「すぐ止める」）
  - `stopBandView(ws)`：止めている（stopped_at がある・か stop_on が今日以前）なら `{ reason: <理由の字>, since: <stopped_at か stop_on の M/D・日本時間> }`・ほかは null
  - `noticeBody(form)`：題・本文は空白を落とし、どちらかが空なら null・placements は band → ['band']・list → ['list']・both → ['band','list']。誰に（`to`：all〔既定〕・admins）：all は admins_only を付けない・admins は `admins_only: true` を付け、出す場所が band・both なら null（送らない・契約の「管理者だけ × 上の帯」は 422・D-156.57）
- **中を見る**：［見るだけで開く］で `POST /ops/workspaces/<id>/peeks`（体は peekBody）。201 → 小窓を閉じ、1 社を読み直す（`ws.peek` で帯）。403 STEP_UP_REQUIRED → K-962 と同じ形で `getMySecurity` を 1 回・`StepUp`（features/F1/security/step-up.tsx・パスキー・理由「中を見る前に、本人か確かめます」（仮））。通ったら同じ体で 1 回だけやり直す・やめたら何も送らない。409 E-OPS-001 → 小窓の中の赤い箱（errors.d の字・K-969）。ほかの失敗 → 赤い箱（E-PAGE-003 の字）
- **小窓の対象の字**：3 つの小窓の対象は「<ws.name> ・ <ws.members.count> 人」（人数は K-1006 の members＝会社の生きているメンバーの数・K-966。PC の数を人数として出さない・PM の決め 2026-11-25・レビュー Q81）
- **見ている間の帯**（下絵 op-peek-open の `PeekBand`・外枠の banner）：題・残りの分（1 分ごとに描き直し・期限を過ぎたら 1 社を 1 回読み直す）・理由（「理由：<ws.peek.reason>」・K-1006 の peek.reason＝開いたときの字・K-966。null の前からの行は、この画面で開いた間だけ覚えた理由・どちらも無ければ理由を出さない・PM の決め 2026-11-25）。［閉じる］で `DELETE /ops/peeks/<ws.peek.id>`（K-969 の閉じる口の id）を 1 回・200 か 409 E-OPS-002 のどちらでも 1 社を読み直す（帯が消える）。`PeekPanel`（いま見られる物）は下絵のとおり見るだけの行を出す
- **止める**：［⋯ › 止める］で小窓。既定は stopDefault。すぐは canStopNow の理由のときだけ選べる（ほかは押せない形）。日の欄は日本の暦の日付・明日以降だけ選べる（`min` は明日）。押すと `POST /ops/workspaces/<id>/stop`（体は stopBody）。403 STEP_UP_REQUIRED → 中を見ると同じ取り直し（理由「止める前に、本人か確かめます」（仮））。201 → 小窓を閉じ、1 社を答えの 14 欄で置き換える・日を決めたなら role=status「<M/D> に止めます」（仮）・すぐなら止めている帯。409 E-OPS-003・E-OPS-006 → 赤い箱（K-970 の errors.d の字）
- **止めている帯**（下絵 op-stopped の `TenantFrame` の stopped）：stopBandView の値。［再開する］（帯と ⋯ の両方）で `POST /ops/workspaces/<id>/resume`（体 `{}`）・取り直しは同じ・201 → 1 社を置き換え（使っている・帯が消える）・409 E-OPS-004 → 1 社を読み直す
- **お知らせを送る**：題（1〜100・契約の上限にそろえる＝欄の `maxLength` 100）・本文（1〜4000）・出す場所・誰に（この会社の人みんな／管理者だけ・下絵の「誰に」）。「管理者だけ」を選ぶと出す場所を「お知らせの一覧」にし、「画面の上の帯」「どちらも」の選び肢を選べない形（`disabled`・隠さない）にする（帯は会社の全員の画面に出るので・D-156.57）。どちらかが空（空白だけを含む）のうちは［送る］が押せない。押すと `POST /ops/workspaces/<id>/notices`（体は noticeBody）を 1 回。201 → 小窓を閉じ role=status「送りました」（仮）・失敗は赤い箱で書いた字は残る
- 送っている間は 2 回目を送らない（`useRef`）。［やめる］と Esc は何も送らない
- **部品に足す物（見た目と並びは変えない・任意の props だけ）**：`tenant-dialogs.tsx` の `PeekDialog`・`StopDialog`・`NoticeDialog` に値と `onChange`・`onSubmit`・`busy`・`error`（赤い箱）・誰に（`to`・`onTo`・「管理者だけ」のとき出す場所の帯とどちらもを `disabled`）、`PeekBand` に `title`・`rest`・`reason`・`onClose`。`tenant-frame.tsx` の止めている帯に `stopBand`・`onResume`。渡さない呼び方（モック）は今の見た目のまま
