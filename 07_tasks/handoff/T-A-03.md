# T-A-03 API 入れなくなったときに、自分でパスワードを再設定したい — データ・A（1 endpoint）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://127.0.0.1:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

## 手順

1. **http://127.0.0.1:3124/login** を開く。見出しが「ログインする」で、横にスクロールしない
2. 「ログイン」を押す → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
3. 「6桁」を入れる（状態：6桁の入力） → **入れた値がそのまま入る（送信に載る）**
4. 「この端末では30日間きかない」を切り替える（状態：6桁の入力） → **切り替わる**
5. 「今日の画面へ」を押す（状態：6桁の入力） → **/today が開く**（今日）。戻る
6. 「端末を失くした（回復コードで入る）」を押す（状態：6桁の入力） → **/password-reset が開く**（パスワードの再設定）。戻る
7. わざと「メールアドレスかパスワードが違います。あと4回で15分間ロックします。…」になる操作をする（状態：失敗） → **その文言と、直す導線が出る**
8. 「メールアドレス」を入れる（状態：通常） → **入れた値がそのまま入る（送信に載る）**
9. 「パスワード」を入れる（状態：通常） → **入れた値がそのまま入る（送信に載る）**
10. 「パスワードを表示」を押す（状態：通常） → **伏せ字（●●●）が読める文字に変わる。アイコンが目に斜線になり、もう一度押すと伏せ字に戻る**
11. 「パスワードをお忘れの方」を押す（状態：通常） → **/password-reset が開く**（パスワードの再設定）。戻る
12. 「アカウントを作る」を押す（状態：通常） → **/signup が開く**（アカウントを作る）。戻る
13. **http://127.0.0.1:3124/mfa-setup** を開く。見出しが「2段階認証を設定する」で、横にスクロールしない
14. 「登録する」を押す → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
15. 「パスワード」を入れる（状態：パスワードの確認） → **入れた値がそのまま入る（送信に載る）**
16. 「パスワードを表示」を押す（状態：パスワードの確認） → **伏せ字（●●●）が読める文字に変わる。アイコンが目に斜線になり、もう一度押すと伏せ字に戻る**
17. 「認証アプリを登録する」を押す（状態：パスワードの確認） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
18. 「安全な場所に保管しました」を切り替える（状態：回復コード） → **切り替わる**
19. 「コピー」を押す（状態：回復コード） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
20. 「ファイルで保存」を押す（状態：回復コード） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
21. 「次へ（PCをつなぐ）」を押す（状態：回復コード） → **/setup/bridge が開く**（自分のPCをつなぐ）。戻る
22. 「アプリに出た6桁」を入れる（状態：登録） → **入れた値がそのまま入る（送信に載る）**
23. **http://127.0.0.1:3124/password-reset** を開く。見出しが「パスワードの再設定」で、横にスクロールしない
24. 「再設定メールを送る」を押す → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
25. 「メールアドレス」を入れる（状態：再設定を送る） → **入れた値がそのまま入る（送信に載る）**
26. 「回復コード」を入れる（状態：再設定を送る） → **入れた値がそのまま入る（送信に載る）**
27. 「回復コードで入る」を押す（状態：再設定を送る） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
28. 「新しいパスワード」を入れる（状態：新しいパスワード） → **入れた値がそのまま入る（送信に載る）**
29. 「もう一度」を入れる（状態：新しいパスワード） → **入れた値がそのまま入る（送信に載る）**
30. 「パスワードを表示」を押す（状態：新しいパスワード） → **伏せ字（●●●）が読める文字に変わる。アイコンが目に斜線になり、もう一度押すと伏せ字に戻る**
31. 「変更してログイン」を押す（状態：新しいパスワード） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
32. 「ログインへ戻る」を押す（状態：送信後） → **/login が開く**（ログインする）。戻る
33. **http://127.0.0.1:3124/verify-email** を開く。見出しが「メールを確認する」で、横にスクロールしない
34. 「はじめの設定をはじめる」を押す → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
35. 「はじめから登録し直す」を押す（状態：申し込みが残っていない） → **/signup が開く**（アカウントを作る）。戻る
36. 「ログイン」を押す（状態：申し込みが残っていない） → **/login が開く**（ログインする）。戻る
37. 「はじめの設定をはじめる（PCをつなぐ）」を押す（状態：登録できた） → **/setup/bridge が開く**（自分のPCをつなぐ）。戻る
38. 「もう一度送る」を押す（状態：送信済み） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
39. 「入力し直す」を押す（状態：送信済み） → **/signup が開く**（アカウントを作る）。戻る

## 結果

よければ次の 1 行を書いて保存してください（このまま貼って、日付と名前を変える）。

```
OK: YYYY-MM-DD 名前
```

違うところがあれば `NG: 何が違うか` を書いてください。1 行で構いません。
