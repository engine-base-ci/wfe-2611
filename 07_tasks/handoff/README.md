その 1 行が入ったチケットだけ staging に上げます（dev → stg → prd）。


- 運営（ENGINE BASE）の宛先は **info@engine-base.com**（問い合わせの届け先・運営アカウントのログイン名）
- **メールが届かないときは http://127.0.0.1:3124/dev/mail を開いてください。** 送ったリンクが並んでいて、そこから押して先へ進めます（ローカルで確かめるためだけの画面）
