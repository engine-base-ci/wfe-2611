# T-US-00 apps/web の土台（Next.js 15 App Router の雛形・Playwright と実ブラウザの検査・ナビ href ⇔ 実在ルートの照合・CI のブラウザ job・ローカル起動）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）

## 手順

1. 入っていない人が / を開くと 入る画面（login）へ送られる（素のプレースホルダを出さない・D-086）（前提：入っていない）：/ を開く → **/login が開く**
2. 入っている人が / を開くと 製品の時点の画面へ送られる（PC をつないでいなければ 自分のPCをつなぐ）（前提：入っている・Bridge 未接続）：/ を開く → **/setup/bridge が開く**
3. 入っている人（PC をつないだ後）が / を開くと 今日 へ送られる（前提：入っている・Bridge 接続済み）：/ を開く → **今日（/today）がまだ無い間は、ある画面（会話モード /ai/chat）が開く。入口はまだ無い画面へ送り返さない（404 → 入口 → 404 の輪を作らない）。今日 ができたら /today が開く**
4. 存在しないパスは「この画面はありません」と戻る導線を出す（素の 404 にしない・D-086）：/no-such-page を開く → **文言と戻る導線が出て、押すと入口か入る画面へ**
5. その権限で見えない画面に直接 URL で来たら「この権限では見えない」と見える画面への導線を出す（無言の空画面にしない・D-086）（前提：閲覧のみで入っている）：その権限で見えない画面の URL を開く → **文言と導線が出る**
6. はじめの設定を 1 つも通していない人がログインすると 自分のPCをつなぐ（段 1）へ送られる（今日 へ飛ばさない）（前提：登録直後・段 0）：ログインする → **/setup/bridge が開く**
7. 途中まで通した人がログイン・/ を開くと、次にやる段へ送られる（進んだところまで戻す）（前提：段 1 まで通した）：ログインし直す／/ を開く → **/onboard/interview（段 2）が開く**
8. 通していない人が先の段の画面を直接 URL で開くと、今の段へ戻される（先の画面の中身を一瞬も見せない）（前提：段 1 まで通した）：/settings/credentials（段 4）を開く → **/onboard/interview（段 2）へ戻る**
9. いま開いている画面がその段そのものなら通す（戻し続けてその段から出られなくならない）（前提：段 3 まで通した）：/settings/credentials（段 4）を開く → **そのまま開く**
10. 進み具合は戻らない。先の段まで通した人が前の段を開き直しても、記録は下がらない（前提：段 3 まで通した）：段 2 の画面を開いて操作する → **記録は 3 のまま（/ を開くと段 4 へ）**
11. 手順バーに、通し終わった段が済（チェック）で出る（前提：段 1 まで通した）：はじめの設定の画面を開く → **段 1 にチェック・読み上げが「1 PCをつなぐ（済）」**
12. ブラウザで Bridge が動いている人には、ダウンロードもコードも出さず、見つけた時点でつながる（押す操作も要らない）（前提：Bridge を起動する）：自分のPCをつなぐ を開く → **ダウンロードが消え、押さずにつながる。うまくいかないとき用に押す道だけ残っている**
13. アプリ（Bridge の窓）の中で開いた人は、入れる作業も接続コードも要らず自動でつながる（前提：Bridge の窓から開く）：自分のPCをつなぐ を開く → **ダウンロードも手順 1〜4 も出ず、そのままつながる**
14. Bridge がこの PC の中だけで開く口は、許可した画面の出どころ以外には応えない（居ることも教えない）（前提：Bridge を起動する）：別の出どころから ping を投げる → **403。接続コードの総当たりも 1 分 5 回で止まる**
15. 設計にあってまだ作っていない画面の URL を直接開くと、画面の名前つきで「まだありません」と戻る導線が出る（素の 404 にしない）：未実装の画面の URL を開く → **「〈画面名〉はまだありません」と戻る導線**
16. ログインは生きているが会社の人が無い人が画面を開くと、空白で止まらず 入る画面（login?next=）へ送られ、手元の鍵は捨てられる（前提：会社の人を消したアカウントでログイン済み）：ログイン情報・自分のAIと話す を開く → **どちらも /login?next=… に移り、空白にならない**
17. **http://localhost:3124/dev/shell** を開き、役割（R1〜R6）と時点（PS0〜PS4）を切り替えて、サイドバー・下タブ・自分のAIのパネルの項目を押す（見本の画面。dev でだけ出る）

## 今はまだ押せないもの（理由つき・触らなくてよい）

- ブラウザで Bridge が入っていない人には、ダウンロード（インストール動線）と手順 1〜4 が出 … この PC には Bridge が入っているので「入っていない人」を作れない（BLOCKED：入っていない PC か staging で流す
- 画面の L1・流れの L2 を流す staging（本番と同じ構成をもう 1 組）が存在し、apps … staging は高本さんが作る：infra/STAGING.md S0〜S5。できるまで画面の L1 はローカルの実ブラウザで流し、この行
