## 手順

1. **http://127.0.0.1:3124/ai/chat** を開く。見出しが「分身の部屋：会話と知っていること」で、横にスクロールしない
2. **http://127.0.0.1:3124/policies** を開く。見出しが「ルール」で、横にスクロールしない
3. 許可の問いに 今回だけ／いつも／しない ＋ 一言 で答えられ、答えは証跡に残る（前提：作業中に許可の問い）：いつも を押す → **次から同じ道具・対象は聞かれない。permission_rules と証跡に行**
4. 「いつも」にしたものは ルール › 個人 で一覧・取り消しでき、取り消すと次から聞かれる（前提：いつも許可が 1 件）：取り消す → 同じ頼み → **また聞かれる**
5. 入力欄で許可のモードを切り替えると、その会話の仕事に公式のモードとして渡る（前提：会話を開く）：計画だけ にして頼む → **Claude Code が動かず進め方だけ返す**
6. 全部許可は本人が選んだときだけで、既定にしない。選ぶときに何が起きるかを出す。検査（claude-terms）は「本人が選んだとき以外に渡していない」を見る（前提：既定の会話）：何も選ばずに頼む → **bypassPermissions は渡らない。選んだ会話だけ渡る**
7. 自分のAI からの問い合わせ（選択肢・見本・複数の問い）に答えると、その答えで続きが動く（前提：問い合わせを出す頼み）：答えて送る → **答えが自分のAI に届いて続きが動く**
8. 許可のモードに関わらず、銀行・規約で自動操作が禁止のサービスは関門で止まる（前提：全部許可の会話）：禁止のサービスを操作させる → **関門が止め、人へのハンドオフになる**
