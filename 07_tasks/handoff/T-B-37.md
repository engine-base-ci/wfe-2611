# T-B-37 AI がブラウザを動かす土台（本人の Chrome＝Claude in Chrome が既定・Bridge 専用のブラウザ＝Playwright MCP・Bridge の窓で選ぶ・つながらないときは会話と自己診断に理由を出す・禁止の宛先は開く前と開いた後の両方で止める・Stagehand はやめる）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://127.0.0.1:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

## 手順

1. **http://127.0.0.1:3124/setup/bridge** を開く。見出しが「自分のPCをつなぐ」で、横にスクロールしない
2. **http://127.0.0.1:3124/ai/chat** を開く。見出しが「自分のAIと話す」で、横にスクロールしない
3. 既定では本人の Chrome（Claude in Chrome）で開き、読み、押し、タブを閉じる。本人の画面で動くのが見える（前提：Chrome と拡張機能「Claude in Chrome」がつながっている）：会話で「example.com を開いてリンクを押して」と頼む（本物の Claude Code） → **開いて読み、リンクの先の URL を答え、開いたタブを閉じる**
4. Bridge の窓で「Bridge 専用のブラウザ」を選ぶと、Playwright MCP がインストール済みの Chrome を Bridge の置き場のログインの状態で開く（前提：専用のブラウザを選んだ）：同じ頼みごとをする（本物の Claude Code） → **開いて読み、リンクの先の URL を答える。ログインの状態は Bridge の置き場に残る**
5. Bridge の窓で 自分の Chrome／Bridge 専用のブラウザ／使わない を選べ、既定は自分の Chrome。会話の無い仕事（記憶のまとめ）はブラウザを使わない（前提：Bridge の窓）：選び直して次の仕事を出す → **次の仕事の起動の引数が選んだものになり、記憶のまとめには付かない**
6. 拡張機能が無い・Chrome が閉じている・切れた・専用のブラウザを用意できない は、会話に理由と一手の 1 行が出て、自己診断にも出る（黙って終わらない）（前提：拡張機能がつながっていない）：ブラウザを使う頼みごとをする → **会話に「AI が Chrome を使えませんでした。…」が 1 回だけ出て、自己診断の Chrome の行が赤になる**
7. リンクを押して禁止の宛先に着いたら、そのタブではその先の操作をさせない（閉じる・別の宛先へ移るだけ許す）。止めた記録は証跡に残る（前提：禁止の一覧に入った宛先へのリンクがあるページ）：リンクを押してその先で読ませる（本物の Claude Code） → **着いた直後に止まり、そのタブで読む・押すは止められ、AI は本人に手で操作する手順を案内する**
8. PC の画面で 自分の Chrome／Bridge 専用のブラウザ／使わない を選べ、次の仕事から効く。使わないからも戻せる。Bridge の窓にも同じ値が出る（前提：つないだ PC で「使わない」）：PC の画面で「自分の Chrome」を選び直し、ブラウザを使う頼みごとをする → **選んだものに印が付き、次の仕事に Chrome が渡る**
9. 会話の 1 行と PC の画面の行から、つなぎ方の手順と公式の入口を開ける（文だけにしない）（前提：Chrome とつながっていない）：「つなぎ方を見る」を押す → **3 つの手順と Chrome ウェブストアの入口が出る**
10. 「もう一度確かめる」で Bridge が小さな仕事で試し、結果がその場と PC の画面の行に出る。会話には出さない（前提：拡張機能を直した後）：「もう一度確かめる」を押す → **「つながりました」が出て、PC の画面の行が「できる」になる。会話に吹き出しは増えない**
11. その場で Bridge 専用のブラウザに切り替えられる（前提：Chrome とつながっていない）：「Bridge 専用のブラウザに切り替える」を押す → **PC の画面の選択が専用のブラウザになり、次の仕事から使う**

## 結果

よければ次の 1 行を書いて保存してください（このまま貼って、日付と名前を変える）。

```
OK: YYYY-MM-DD 名前
```

違うところがあれば `NG: 何が違うか` を書いてください。1 行で構いません。
