## 手順

1. **http://127.0.0.1:3124/ai/chat** を開く。見出しが「自分のAIと話す」で、横にスクロールしない
2. 動いている間は送るボタンが止めるに変わり、押すと止まって「止まりました（あなたが止めました）」が出る（前提：作業中）：止めるを押す → **Claude Code のプロセスが終わり、仕事は stopped・理由つき**
3. 動いている間に送った「止めずに直す」文は、次の区切りで動いている作業に渡る（前提：作業中）：「宛先は鈴木さんで」と送る → **作業が止まらず、次の区切り以降の動きに反映される（steer の出来事が残る）**
4. 動いている間に送った文は順番待ちに並び、× で取り消せる。今の作業が終わると順に動く（前提：作業中）：2 つ送り、1 つ取り消す → **取り消した方は動かず（cancelled）、残った方だけ次に動く**
5. 止まったら理由だけ出し、ボタンは置かない。次に送る文で続き・別の話が決まる（前提：止まった会話）：「続けて」と送る → **同じセッションで続きから動く**
6. PC が応答せず止める合図が届かないときは、止めたことにしない（前提：Bridge を落とす）：止めるを押す → **E-CHAT-003 の文言**
