# T-B-33 会話の固定枠（1024 以上で会話の箱だけを画面の残りの高さにし、吹き出しだけがスクロールする。段の帯・見出し・右の欄・入力欄は動かない。会話を本文に出す画面は全部 1 つの部品で）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://127.0.0.1:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

## 手順

1. **http://127.0.0.1:3124/ai/chat** を開く。見出しが「自分のAIと話す」で、横にスクロールしない
2. **http://127.0.0.1:3124/onboard/interview** を開く。見出しが「自分のAIと話す」で、横にスクロールしない
3. **http://127.0.0.1:3124/onboard/draft** を開く。見出しが「たたき台を確かめる」で、横にスクロールしない
4. 1024 以上では、ページ全体は動かず、会話の中だけがスクロールし、段の帯・分かったこと・入力欄は動かない（前提：長い会話（1440 と 1024））：会話を上へ戻す → **ページは動かず、段の帯と分かったことの位置は変わらず、入力欄は画面の中**
5. 会話モード（/ai/chat）でも、会話の名前と入力欄は動かず、会話の中だけがスクロールする（前提：長い会話（1440））：会話を上へ戻す → **会話の名前の位置は変わらず、入力欄は画面の中**
6. 1023 以下は今までどおりページごとに流れ、会話の中に別のスクロールを作らない（前提：長い会話（375））：開く → **会話の中は溢れず、ページごと流れ、横に溢れない**

## 結果

よければ次の 1 行を書いて保存してください（このまま貼って、日付と名前を変える）。

```
OK: YYYY-MM-DD 名前
```

違うところがあれば `NG: 何が違うか` を書いてください。1 行で構いません。
