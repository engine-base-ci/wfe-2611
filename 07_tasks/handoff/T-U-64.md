# T-U-64 画面 運営：開示資料（3 状態・R6・段階 2）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://localhost:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

## 手順

1. **http://localhost:3124/ops/disclosure** を開く。見出しが「運営：開示資料」で、横にスクロールしない
2. 「雛形を差し替える」を押す（状態：DPA とサブプロセッサ） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
3. 「足す」を押す（状態：DPA とサブプロセッサ） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
4. 「新しい版を出す」を押す（状態：版） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
5. 「出す（全社にお知らせ）」を押す（状態：版） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
6. 「戻す先にする」を押す（状態：版） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
7. 「版を出す」を押す（状態：空） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
8. 全角／半角：メール・数値・コードを全角で入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
9. 前後と途中の空白：空白付きで入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
10. 記号の種別（ハイフン・長音）：‐ ー − を混ぜる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
11. Unicode 正規化（NFC/NFD）：macOS の入力（NFD）で入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
12. 大文字小文字：メールを大文字で入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
13. 成果物と公開中の版に差分があるのに版を出していない（前提：成果物を変える）：運営の開示資料を開く → **文言「公開中の開示資料（第 7 版）は設計より古くなっています。新しい版を出して全社にお知らせしてください」が出て、一手「新しい版を出す」が押せる。守っている層：UI／API**
14. **自分の受信箱**を開く → **届いている**（迷惑メールも見る）。件名・差出人・本文が読め、リンクを押すと目的の画面が開く
15. 本文を読む → **内部の言葉（ID・テーブル名）が無く、誰宛てで何をすればよいかが分かる**
16. `.dev-logs/api.log` の `[mail]` の行を見る → **「送った → 自分のアドレス」が出ている**。「送れなかった」が出ていたら、その理由が NG の中身
17. ブラウザの幅を **375px** にして **http://localhost:3124/ops/disclosure** を開き直す → **横スクロールが出ない。文字が読める大きさ（11px 以上）で、入力欄を押しても勝手に拡大しない（16px 以上）。ボタンが指で押せる（24px 以上）。スマホで使わせない画面なら『PC で開いてください』と出て、崩れた画面を見せない**
18. ブラウザの幅を **768px** にして **http://localhost:3124/ops/disclosure** を開き直す → **横スクロールが出ない。ヘッダ・ナビが箱からはみ出さない（縮んだタブ・チップの文字が切れない）**
19. ブラウザの幅を **1024px** にして **http://localhost:3124/ops/disclosure** を開き直す → **横スクロールが出ない。第2ナビと本文が重ならない**
20. ブラウザの幅を **1440px** にして **http://localhost:3124/ops/disclosure** を開き直す → **横スクロールが出ない。本文が 720px 以上あり、左に寄らない**

## 結果

よければ次の 1 行を書いて保存してください（このまま貼って、日付と名前を変える）。

```
OK: YYYY-MM-DD 名前
```

違うところがあれば `NG: 何が違うか` を書いてください。1 行で構いません。
