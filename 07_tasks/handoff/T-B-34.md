# T-B-34 はじめの設定の「分かったこと」は自分のAI が覚えた事実を「項目：内容」で出す（聞き取りの間だけは分かった事実をその場で覚える・送った文は並べない）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://localhost:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

## 手順

1. **http://localhost:3124/onboard/interview** を開く。見出しが「自分のAIと話す」で、横にスクロールしない
2. 分かったことには、自分のAI が覚えた事実だけが「項目：内容」で並び、送った文は並ばない（前提：覚えた事実が 2 つある会話）：話す画面を開く → **2 つが項目と内容に分かれて並び、「続けて」は並ばない。「記憶に落ちています」が出る**
3. まだ何も覚えていなければ「まだ何もありません」で、送った文は並べない（前提：送った文だけの会話）：話す画面を開く → **「まだ何もありません」が出て、送った文は並ばない**
4. 聞き取りの間は、分かった事実を remember で「項目：内容」の形で残す決まりが渡り、それ以外は「覚えて」と言われたときだけ。Bridge の控えも同じ文（前提：会話の決まり）：決まりを読む → **聞き取りの決まりが入っていて、控えとずれていない**
5. はじめの設定から言ったときだけ、自分のAI への依頼に「聞かずに覚える」の 1 行が添えられる（決まりだけでは聞き返していた）（前提：はじめの設定から言う／会話モードから言う）：依頼を見る → **はじめの設定のときだけ 1 行が入る**
6. 覚える道具の説明は「項目：内容」の形を求める（「1 件 1 文」だと文で書かれて分かれない）（前提：Kaname の道具）：説明を読む → **「項目：内容」があり、「1 件 1 文」が無い**

## 結果

よければ次の 1 行を書いて保存してください（このまま貼って、日付と名前を変える）。

```
OK: YYYY-MM-DD 名前
```

違うところがあれば `NG: 何が違うか` を書いてください。1 行で構いません。
