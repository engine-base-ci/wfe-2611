# T-B-20 自分のAIの使用量（Bridge が Claude Code から 5 時間の枠・週の枠といつ戻るかを受け、アカウントに出す。近い・達したら会話に案内）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://127.0.0.1:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

## 手順

1. **http://127.0.0.1:3124/account** を開く。見出しが「自分の設定」で、横にスクロールしない
2. **http://127.0.0.1:3124/ai/chat** を開く。見出しが「分身の部屋：会話と知っていること」で、横にスクロールしない
3. アカウント › 自分のAIの使用量 に 5 時間の枠と週の枠の割合と、いつ戻るかが出る（前提：使用量の知らせを受けた）：開く → **2 つの枠と戻る時刻**
4. 枠の 8 割を越えると会話に案内が出て、達したら戻る時刻まで動けないと出る（前提：枠 82%）：会話を開く → **案内の帯と使用量へのリンク**
