# T-B-27 作業中の行が本当のいまを出す（考えている・問い合わせを書いている・返事を書き始めたの切り替わりと最後の動き・PC が応答しなくなったらそう言う・途中で止まった Bridge の仕事は戻ってきたときに理由つきで止める）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://localhost:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

## 手順

1. **http://localhost:3124/ai/chat** を開く。見出しが「分身の部屋：会話と知っていること」で、横にスクロールしない
2. **http://localhost:3124/onboard/interview** を開く。見出しが「自分のAIと話す」で、横にスクロールしない
3. CLI の切り替わり（考えている・道具を準備している・返事を書き始めた）を読み、人が読む 1 行にして送る。前の書きかけは消す（前提：問い合わせの後にまた考え始めた）：仕事を流す → **作業の行が「考えています」「あなたへの問い合わせを書いています」「返事を書いています」の順に変わる**
4. 作業中は、いまの動きを「〇〇しています…」の一言で出す（秒数は出さない）（前提：考えている最中）：会話を見る → **作業の行が「考えています…」で、最後の動きの秒数は出ない**
5. Bridge が途中で止まって戻ってきたら、動いたまま残った仕事は理由つきで止まり、次の仕事が渡る（前提：動いている途中で Bridge が止まった）：Bridge を戻す → **「PC の Bridge が途中で止まったので、ここで止まりました」が出て、書いています のまま残らない**
6. 作業中に PC の Bridge が応答しなくなったら、作業の行で「応答がありません（最後の知らせは N 分前）」と言い、書いています と言い続けない（前提：作業中に Bridge が止まった）：会話を見る → **作業の行に 応答がありません と最後の知らせの時刻**

## 結果

よければ次の 1 行を書いて保存してください（このまま貼って、日付と名前を変える）。

```
OK: YYYY-MM-DD 名前
```

違うところがあれば `NG: 何が違うか` を書いてください。1 行で構いません。
