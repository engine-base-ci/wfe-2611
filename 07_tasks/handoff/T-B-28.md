# T-B-28 この PC の Bridge が別のアカウントでつながっているときは黙って切り替えない（理由を出し、本人が「このアカウントに切り替える」を押したときだけつなぐ）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://127.0.0.1:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

## 手順

1. **http://127.0.0.1:3124/setup/bridge** を開く。見出しが「自分のPCをつなぐ」で、横にスクロールしない
2. この PC の Bridge が別のアカウントでつながっている（前の鍵がまだ通る）なら、つなぐ画面を開いても黙って切り替えず、理由を出す（前提：Bridge が別のアカウントでつながっている）：つなぐ画面を開く → **「すでに別のアカウントでつながっています」と出て、Bridge はつなぎ直さない**
3. 本人が「このアカウントに切り替える」を押したときだけ、この PC の Bridge をこのアカウントにつなぎ直す（前提：理由が出ている）：「このアカウントに切り替える」を押す → **このアカウントでつながり、仕事を渡せる**
