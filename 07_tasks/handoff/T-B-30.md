# T-B-30 作業中は 1 行が切り替わる・内部の名前を出さない・絵文字を出さない・選んでもらう質問は問い合わせで（会話の決まりは Kaname が仕事ごとに渡す）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://127.0.0.1:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）

## 手順

1. **http://127.0.0.1:3124/ai/chat** を開く。見出しが「自分のAIと話す」で、横にスクロールしない
2. **http://127.0.0.1:3124/onboard/interview** を開く。見出しが「自分のAIと話す」で、横にスクロールしない
3. 作業中は道具の行を並べず、いまの動きを 1 行で出して切り替える（前提：道具を続けて使う仕事）：会話を見る → **作業の行は 1 行だけで、道具の行が並ばない**
4. 作業の行に mcp__… ・select:… ・ToolSearch を出さず、人の言葉にする（前提：たたき台に置く仕事）：会話を見る → **「たたき台に目標を置いています：〇〇」と出て、画面のどこにも mcp__ が無い**
5. 自分のAI の返事に絵文字は出さない（書いてきても消して描く）（前提：絵文字を含む返事）：会話を見る → **絵文字が消えて、文だけが出る**
6. 本人に選んでもらう質問は問い合わせで出させる（会話の決まりに書き、仕事ごとに渡す）（前提：会話の仕事）：Bridge が受け取る仕事を見る → **決まりに「AskUserQuestion の問い合わせで出す」「絵文字は使わない」が入って渡る**

## 結果

よければ次の 1 行を書いて保存してください（このまま貼って、日付と名前を変える）。

```
OK: YYYY-MM-DD 名前
```

違うところがあれば `NG: 何が違うか` を書いてください。1 行で構いません。
