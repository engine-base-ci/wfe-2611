## 手順

1. **http://127.0.0.1:3124/settings/app** を開く。見出しが「アプリと通知」で、横にスクロールしない
2. 「通知を許可する」を押す → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
3. 「checkbox」を切り替える（状態：アプリと通知） → **切り替わる**
4. 「Bridge の窓で開く」を押す（状態：アプリと通知） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
5. 「App Store」を押す（状態：アプリと通知） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
6. 「Google Play」を押す（状態：アプリと通知） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
7. 「保存する」を押す（状態：アプリと通知） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
8. 「設定の開き方を見る」を押す（状態：許可が無い・つながっていない） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
9. 「もう一度たずねる」を押す（状態：許可待ち） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
10. 全角／半角：メール・数値・コードを全角で入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
11. 前後と途中の空白：空白付きで入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
12. 記号の種別（ハイフン・長音）：‐ ー − を混ぜる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
13. Unicode 正規化（NFC/NFD）：macOS の入力（NFD）で入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
14. 大文字小文字：メールを大文字で入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
15. スマホの通知が許可されていない（前提：通知を拒否した端末）：アプリを入れて通知を拒否 → **文言「iPhone の通知が許可されていません。承認待ちはメールと PC にだけ届きます。iPhone の設定 › 通知 › Kaname で許可すると、ここに戻ります」が出て、一手「設定の開き方を見る」が押せる。守っている層：UI**
16. アプリがインターネットにつながっていない（前提：機内モード）：アプリを開く → **文言「インターネットにつながっていません。最後に見た「今日」「タスク」「承認待ち」は読めます。書くのはつながってから」が出て、一手「つながったら自動で続く」が押せる。守っている層：UI**
17. **自分の受信箱**を開く → **届いている**（迷惑メールも見る）。件名・差出人・本文が読め、リンクを押すと目的の画面が開く
18. 本文を読む → **内部の言葉（ID・テーブル名）が無く、誰宛てで何をすればよいかが分かる**
19. `.dev-logs/api.log` の `[mail]` の行を見る → **「送った → 自分のアドレス」が出ている**。「送れなかった」が出ていたら、その理由が NG の中身
20. ブラウザの幅を **375px** にして **http://127.0.0.1:3124/settings/app** を開き直す → **横スクロールが出ない。文字が読める大きさ（11px 以上）で、入力欄を押しても勝手に拡大しない（16px 以上）。ボタンが指で押せる（24px 以上）。スマホで使わせない画面なら『PC で開いてください』と出て、崩れた画面を見せない**
21. ブラウザの幅を **768px** にして **http://127.0.0.1:3124/settings/app** を開き直す → **横スクロールが出ない。ヘッダ・ナビが箱からはみ出さない（縮んだタブ・チップの文字が切れない）**
22. ブラウザの幅を **1024px** にして **http://127.0.0.1:3124/settings/app** を開き直す → **横スクロールが出ない。第2ナビと本文が重ならない**
23. ブラウザの幅を **1440px** にして **http://127.0.0.1:3124/settings/app** を開き直す → **横スクロールが出ない。本文が 720px 以上あり、左に寄らない**

## 結果

よければ次の 1 行を書いて保存してください（このまま貼って、日付と名前を変える）。

```
OK: YYYY-MM-DD 名前
```

違うところがあれば `NG: 何が違うか` を書いてください。1 行で構いません。
