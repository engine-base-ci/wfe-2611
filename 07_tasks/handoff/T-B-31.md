# T-B-31 自分のAI の会話は本人の PC の Claude Code の記録が正本（文を記録と同じ id で写す・つながったとき／仕事の後に記録から写し漏れを取り戻す・同じ文を二度入れない・結末で答えを重ねない）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://localhost:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

## 手順

1. **http://localhost:3124/ai/chat** を開く。見出しが「分身の部屋：会話と知っていること」で、横にスクロールしない
2. **http://localhost:3124/onboard/interview** を開く。見出しが「自分のAIと話す」で、横にスクロールしない
3. 自分のAI の文は、Claude Code が流すたびに記録と同じ id で Kaname に写り、吹き出しになる。仕事の結末で答えを重ねて足さない（前提：会話の仕事）：返事を待つ → **文ごとに吹き出しが出て、同じ答えが 2 つ並ばない。作業の記録は最後の文に付く**
4. 本人の PC の記録を session の id で探し、自分のAI の文だけを読む（考えている中身・道具の返り値・本人の文は読まない）（前提：本人の PC の記録）：読む → **自分のAI の文だけが、記録の id と時刻のまま取り出せる**
5. 途中で Bridge が止まって返事が Kaname に届かなくても、つなぎ直すと本人の PC の記録から返事を取り戻す。同じ文は二度入らない（前提：考えている途中で Bridge が止まった）：つなぎ直す → **記録にある返事が 1 回だけ会話に出る**
6. 別の人の会話には写せない。id の形が違う・空の文は入れない（前提：別の人の会話）：写す口を呼ぶ → **入らない**
7. 文を写さない古い Bridge からの仕事は、今までどおり結末で答えが 1 つ入る（前提：古い Bridge）：結末を返す → **答えが 1 つ入る**
8. 仕事が区切りの一言を取りに行った後、結末の前に届いた一言は捨てず、送ったときのモードで次の仕事として並ぶ（本人が止めた仕事では並べない）（前提：返事が出て仕事が閉じる直前）：続けて送る → **次の仕事として並び、送ったときのモードで動く**

## 結果

よければ次の 1 行を書いて保存してください（このまま貼って、日付と名前を変える）。

```
OK: YYYY-MM-DD 名前
```

違うところがあれば `NG: 何が違うか` を書いてください。1 行で構いません。
