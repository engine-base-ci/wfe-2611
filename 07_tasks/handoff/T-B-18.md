# T-B-18 資料と画像を付ける（＋・ドラッグ・貼り付け・長い文は自動で添付・送る前に外せる。置き場に置き、Bridge が期限つきの署名 URL で受け取って自分のAI に渡す）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://localhost:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

## 手順

1. **http://localhost:3124/ai/chat** を開く。見出しが「分身の部屋：会話と知っていること」で、横にスクロールしない
2. ＋・ドラッグ・貼り付けで付けると、入力欄の上に一覧が出て、送る前に × で外せる（前提：会話を開く）：画像を貼り付け → 1 つ外す → **一覧に出て、外したものは送られない**
3. 付けた資料は会社の置き場に置かれ、Bridge が期限つきの署名 URL で受け取り、自分のAI が読める（前提：Bridge がつながっている）：PDF を付けて「要点を」と頼む → **自分のAI が中身を読んで答える。保存先の鍵は AI への指示に出ない**
4. 長い文を貼ると自動で添付になる：1 万字を貼る → **入力欄ではなく添付の一覧に入る**
5. 置き場に置けなかったら送ったことにせず、付けた一覧と文を残す（前提：置き場を止める）：送る → **E-CHAT-002 の文言。一覧と文が残る**
6. 大きすぎる資料は置く前に断る（前提：60MB のファイル）：付ける → **E-LIM-002 の文言**

## 結果

よければ次の 1 行を書いて保存してください（このまま貼って、日付と名前を変える）。

```
OK: YYYY-MM-DD 名前
```

違うところがあれば `NG: 何が違うか` を書いてください。1 行で構いません。
