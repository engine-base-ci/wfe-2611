# T-B-06 配布（インストーラ・macOS の公証・Windows の署名・自動更新：署名までは指紋を確かめて自分で入れ替え、署名後は electron-updater）

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://127.0.0.1:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）

## 手順

1. **http://127.0.0.1:3124/setup/bridge** を開く。見出しが「自分のPCをつなぐ」で、横にスクロールしない
2. 配布（インストーラ・macOS の公証・Windows の署名・自動更新：署名までは指紋を確かめて自分で入れ替え、署名後は electron-updater）（前提：Bridge を入れた PC）：手順どおり操作する → **macOS / Windows のインストーラが出て、入れた人に自動で新しい版が届く（指紋を確かめて自分で入れ替える）**
3. ダウンロードは Kaname のサーバーから落ちてくる（顧客に GitHub など外のサービスを見せない）（前提：配布物を置いた）：つなぐ画面の「macOS 版」を押す → **Kaname の口から実物が落ちてくる**
4. 顧客の手順は ①受け取る ②開く ③初回だけ許可 の 3 つだけ。コマンドも接続コードも打たせない（前提：配布物を受け取った）：ダブルクリックして開き、許可を押す → **3 手だけでつながる（画面が自分で気づく）**
5. 署名が済むまでは OS の警告が出るが、手順は変えない。越え方だけ案内する（Mac は「完了」→ システム設定 → プライバシーとセキュリティ →「このまま開く」。いまの macOS では右クリック → 開く では越えられない。Windows は「詳細情報」→「実行」）（前提：署名前の版）：開く → **つなぐ画面の「『開いていません』と出たとき」を開くと、Mac と Windows の越え方が出る。コマンドは出さない**
6. PC を立ち上げると Bridge も一緒に立ち上がる（入れた時点で登録。人が毎回開かない）（前提：入れて 1 度開いた）：PC を再起動する → **Bridge が立ち上がっていて、画面は最初からつながっている**
7. Bridge は起動時・1 時間ごと・Kaname に古いと言われたときに見に行き、新しければ裏で受け取る（前提：新しい版を置いた）：Bridge を開いたまま待つ → **受け取りが始まる（顧客は何もしない）**
8. 受け取ったものは指紋と大きさが目録と合うときだけ使う。合わなければ捨てて、理由を 1 回窓に出す（前提：置き場の中身が目録と違う）：Bridge を開く → **入れ替えず「確かめられなかったので使いませんでした」と出る**
9. 仕事を動かしていない間にだけ入れ替え、立ち上げ直す。つなぎ直しは要らない（前提：新しい版を受け取った）：仕事が終わるのを待つ → **仕事中は入れ替えず、終わったら新しい版で立ち上がり直し、つながったまま**
10. 書けない場所・開発中の起動なら入れ替えず、入れ直しを案内する（前提：書けない場所に入っている）：Bridge を開く → **「新しい版があります。…入れ直してください」と出て、受け取りにも行かない**
