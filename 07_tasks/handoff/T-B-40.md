# T-B-40 会話の画面を詰める・広げる（見出しと説明を 1 行に・入力欄を低く・「会話を広げる」で会話だけ・Esc で戻る・測り直しても読んでいる位置を動かさない）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://127.0.0.1:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

## 手順

1. **http://127.0.0.1:3124/onboard/interview** を開く。見出しが「自分のAIと話す」で、横にスクロールしない
2. **http://127.0.0.1:3124/onboard/draft** を開く。見出しが「たたき台を確かめる」で、横にスクロールしない
3. 画面が低くても、見出しと説明は 1 行に詰まり、会話に高さが渡る。「Shift+Enter」の行は書いている間だけ出る（前提：長い会話（1512×640））：開く・入力欄に入る・1 文字書く・空のまま許可のしかたを押す → **会話が 260px 以上（詰める前は 179px）。見出しと説明が同じ行。案内は書いている間だけ出る。入力欄に入っただけでは形が変わらず、下のボタンを押し損ねない**
4. 「会話を広げる」で段の帯・説明・分かったことを閉じて会話だけになり、「元に戻す」か Esc で戻る。広げても読んでいた所のまま（前提：長い会話）：広げる → Esc → 広げる → 元に戻す → **縦にも横にも広がり、いちばん下のまま。ページは動かない。戻すと元の形**

## 結果

よければ次の 1 行を書いて保存してください（このまま貼って、日付と名前を変える）。

```
OK: YYYY-MM-DD 名前
```

違うところがあれば `NG: 何が違うか` を書いてください。1 行で構いません。
