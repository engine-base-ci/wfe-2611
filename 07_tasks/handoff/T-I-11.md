# T-I-11 流れ J-03 P2 毎日 ── 自分のAIと回す を最後まで通す（L2）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** 登録から最後まで、止めずに続けて通します。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）

招待の URL は画面がまだ無いので、次で作ってください（出た URL をブラウザに貼る）。

```bash
bash scripts/dev/invite.sh
```

## 手順

1. 流れ J-03 P2 毎日 ── 自分のAIと回す を最後まで通す（L2）：データ 0 件の会社で最初から通す（前提：新しいテスト会社）：最初から最後まで操作 → **各段で空状態が出て、途中で詰まらない**
2. メールとパスワードと6桁を入れる（http://127.0.0.1:3124/login） → **トークンを発行**
3. 申し送りを読む（http://127.0.0.1:3124/today） → **タスクと承認待ちを集約**
4. 昨日の会話をまとめる（http://127.0.0.1:3124/today） → **memory_digests に 1 行（溜まった日数・結果）。個人の記憶は memories に自動で入れ、整理の前後を残す**
5. 候補にチェックを入れて「今日を確定」を押す（http://127.0.0.1:3124/today） → **daily_plans に確定を保存。tasks.planned_for＝今日**
6. 中身を見て押す／止める（http://127.0.0.1:3124/approvals） → **承認したら実行、止めたらAI社員へ戻る**
7. 木を開いて、止まっているところを見る（http://127.0.0.1:3124/ai-staff/activity） → **AI社員ごとのセッション履歴・関門通過を読む**
8. 自分のAIとAI社員のやりとりを見る（http://127.0.0.1:3124/ai/thread） → **差し戻しの履歴**
9. 自分のタスクを終える（http://127.0.0.1:3124/tasks） → **タスクの状態を更新し、目標の実績に積む**
10. 詰まっている理由を見て、理由ごとの一手を押す（http://127.0.0.1:3124/tasks） → **tasks.blocked_reason_id・blocked_since。催促は通知、承認は approvals へ**
11. 残りを 消す／明日へ／引き継いでもらう に振り分ける（http://127.0.0.1:3124/today） → **tasks.planned_for を更新。引き継ぎは task_handovers。消すは ended_at**
12. やることを書いて、どの目標かを選ぶ（http://127.0.0.1:3124/tasks） → **タスクを保存。目標が無ければ「行き先のないタスク」に**
13. 誰に引き継いでもらうか選ぶ（負荷を見て）（http://127.0.0.1:3124/tasks） → **担当を移す（合意 or 指示）。goal_id は変えない。task_handovers に記録**
14. 残っている仕事から引き継ぐ（http://127.0.0.1:3124/tasks） → **タスクの担当を移す（合意 or そのまま）。task_handovers に記録**
15. 1件を開いて中を見る（http://127.0.0.1:3124/records/:id） → **レコードと関連（タスク・添付・証跡）を読む**
16. 段階を次へ動かす（http://127.0.0.1:3124/records/:id） → **レコード更新→タスク生成→目標の実績**
17. 聞く・頼む（http://127.0.0.1:3124/ai/chat） → **会話を記憶へ。指示をAI社員へ。道具の呼び出しは名前・対象・成否・時間だけ残し、中身の全文は本人の PC に置いたまま。サービス台帳で禁止・銀行のドメインは、仕事を渡すたびに使わない道具として渡し、道具を使う直前のフックでも止める（許可のモードに関わらず）**
18. 会話を分けて始める・一覧から戻る（http://127.0.0.1:3124/ai/chat） → **conversations に 1 行（agent_session_id は最初の返事で決まる）。一覧・探す（本文の PGroonga）・星・名前を直す・消す・記憶に使わない会話（毎朝のまとめから外す）**
19. 止める・止めずに直す・順番待ちを取り消す（http://127.0.0.1:3124/ai/chat） → **bridge_jobs の状態（止めた＝理由つき）。順番待ちは待っている行、取り消すと やめた**
20. 資料や画像を付けて渡す（http://127.0.0.1:3124/ai/chat） → **attachments に 1 行、実体は会社の置き場（関門 C4）。messages.attachments は参照だけ**
21. 許可に答える・許可のモードを選ぶ（http://127.0.0.1:3124/ai/chat） → **答えは bridge_job_events と証跡に。「いつも」は permission_rules に。全部許可は本人が選んだときだけ・既定にしない**
22. 一覧を見る（http://127.0.0.1:3124/records） → **見える範囲だけのレコードを読む**
23. 見え方を切り替える（URL に残る）（http://127.0.0.1:3124/tasks） → **同じデータを別の見え方で読む（書き込み無し）**
24. 言葉で探す（http://127.0.0.1:3124/search） → **台帳・記憶・証跡の本文の PGroonga 索引を横断（候補は行レベルの制御の内側だけ）。ベクトルは境を越えてから（本人の PC で作る）**
