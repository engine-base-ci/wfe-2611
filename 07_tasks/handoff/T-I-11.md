発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** 登録から最後まで、止めずに続けて通します。

招待の URL は画面がまだ無いので、次で作ってください（出た URL をブラウザに貼る）。

## 手順

1. メールとパスワードと6桁を入れる（http://127.0.0.1:3124/login） → **トークンを発行**
2. 申し送りを読む（http://127.0.0.1:3124/today） → **タスクと承認待ちを集約**
3. 候補にチェックを入れて「今日を確定」を押す（http://127.0.0.1:3124/today） → **daily_plans に確定を保存。tasks.planned_for＝今日**
4. 中身を見て押す／止める（http://127.0.0.1:3124/approvals） → **承認したら実行、止めたらAI社員へ戻る**
5. 木を開いて、止まっているところを見る（http://127.0.0.1:3124/ai-staff/activity） → **AI社員ごとのセッション履歴・関門通過を読む**
6. 自分のAIとAI社員のやりとりを見る（http://127.0.0.1:3124/ai/thread） → **差し戻しの履歴**
7. 自分のタスクを終える（http://127.0.0.1:3124/tasks） → **タスクの状態を更新し、目標の実績に積む**
8. 詰まっている理由を見て、理由ごとの一手を押す（http://127.0.0.1:3124/tasks） → **tasks.blocked_reason_id・blocked_since。催促は通知、承認は approvals へ**
9. 残りを 消す／明日へ／引き継いでもらう に振り分ける（http://127.0.0.1:3124/today） → **tasks.planned_for を更新。引き継ぎは task_handovers。消すは ended_at**
10. やることを書いて、どの目標かを選ぶ（http://127.0.0.1:3124/tasks） → **タスクを保存。目標が無ければ「行き先のないタスク」に**
11. 誰に引き継いでもらうか選ぶ（負荷を見て）（http://127.0.0.1:3124/tasks） → **担当を移す（合意 or 指示）。goal_id は変えない。task_handovers に記録**
12. 残っている仕事から引き継ぐ（http://127.0.0.1:3124/tasks） → **タスクの担当を移す（合意 or そのまま）。task_handovers に記録**
13. 1件を開いて中を見る（http://127.0.0.1:3124/records/:id） → **レコードと関連（タスク・添付・証跡）を読む**
14. 段階を次へ動かす（http://127.0.0.1:3124/records/:id） → **レコード更新→タスク生成→目標の実績**
15. 聞く・頼む（http://127.0.0.1:3124/ai/chat） → **会話を記憶へ。指示をAI社員へ**
16. 一覧を見る（http://127.0.0.1:3124/records） → **見える範囲だけのレコードを読む**
17. 見え方を切り替える（URL に残る）（http://127.0.0.1:3124/tasks） → **同じデータを別の見え方で読む（書き込み無し）**
18. 言葉で探す（http://127.0.0.1:3124/search） → **台帳・記憶・証跡を横断**
