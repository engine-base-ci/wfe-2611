# T-B-36 はじめの設定の進み方（次へ進むボタンは画面の下の帯に 1 つ・進めないときは理由・押せない段は何をすれば開くかを出す・次の段がまだ無いときは行き止まりにしない）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://127.0.0.1:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

## 手順

1. **http://127.0.0.1:3124/onboard/draft** を開く。見出しが「たたき台を確かめる」で、横にスクロールしない
2. **http://127.0.0.1:3124/onboard/interview** を開く。見出しが「自分のAIと話す」で、横にスクロールしない
3. **http://127.0.0.1:3124/setup/bridge** を開く。見出しが「自分のPCをつなぐ」で、横にスクロールしない
4. **http://127.0.0.1:3124/settings/credentials** を開く。見出しが「ログイン情報を預ける」で、横にスクロールしない
5. 画面が低くても、たたき台の「これでいく」は下の帯に見えていて、押すと段 3 を通して 4 へ進む。主ボタンは 1 つ（前提：たたき台がある（1512×700））：帯のボタンを押す → **スクロールせずに見えて、押すとログイン情報へ移り、段 3 を通したと記録される**
6. 押せない段を押すと、いまの段で何をすれば開くかが出る。まだ作っていない段はそう出る（前提：段 3 にいる）：4 と 5 を押す → **「いまの段『3. たたき台』で…と開きます」「まだ作っていません」が出る**
7. まだ自分のAI に答えていないと、話すの帯は押せず、何をすれば進めるかが出る（前提：段 1 まで通した）：話すを開く → **帯のボタンが押せず「自分のAI に 1 つ答えると進めます」**
8. 段 4 を通すと、次の段がまだ無いことを書き、「Kaname を開く」で行き止まりにならない（前提：段 4 まで通した）：帯のボタンを押す → **「まだ使えません」が出て、押すといま使える画面へ移る（5・6 には行かない）**

## 結果

よければ次の 1 行を書いて保存してください（このまま貼って、日付と名前を変える）。

```
OK: YYYY-MM-DD 名前
```

違うところがあれば `NG: 何が違うか` を書いてください。1 行で構いません。
