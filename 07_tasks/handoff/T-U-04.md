# T-U-04 画面 2段階認証を設定する（3 状態・R1/R2/R3）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://localhost:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

## 手順

1. **http://localhost:3124/mfa-setup** を開く。見出しが「安全の設定」で、横にスクロールしない
2. 「パスワード」を入れる（状態：パスワードの確認） → **入れた値がそのまま入る（送信に載る）**
3. 「パスワードを表示」を押す（状態：パスワードの確認） → **伏せ字（●●●）が読める文字に変わる。アイコンが目に斜線になり、もう一度押すと伏せ字に戻る**
4. 「認証アプリを登録する」を押す（状態：パスワードの確認） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
5. 「安全な場所に保管しました」を切り替える（状態：回復コード） → **切り替わる**
6. 「コピー」を押す（状態：回復コード） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
7. 「ファイルで保存」を押す（状態：回復コード） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
8. 「次へ（PCをつなぐ）」を押す（状態：回復コード） → **/setup/bridge が開く**（PC をつなぐ）。戻る
9. 「アプリに出た6桁」を入れる（状態：登録） → **入れた値がそのまま入る（送信に載る）**
10. 「登録する」を押す（状態：登録） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
11. 全角／半角：メール・数値・コードを全角で入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
12. 前後と途中の空白：空白付きで入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
13. 記号の種別（ハイフン・長音）：‐ ー − を混ぜる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
14. Unicode 正規化（NFC/NFD）：macOS の入力（NFD）で入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
15. 大文字小文字：メールを大文字で入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
16. 2 段階認証のコードが違う（時刻のずれ・古いコード）（前提：2 段階認証の設定中）：違う 6 桁を入力 → 10 回続ける → **文言「コードが違います。認証アプリの時刻が合っているか確かめてください」が出て、一手「もう一度入力する／時刻を合わせる」が押せる。守っている層：UI／API**
17. ブラウザの幅を **375px** にして **http://localhost:3124/mfa-setup** を開き直す → **横スクロールが出ない。文字が読める大きさ（11px 以上）で、入力欄を押しても勝手に拡大しない（16px 以上）。ボタンが指で押せる（24px 以上）。スマホで使わせない画面なら『PC で開いてください』と出て、崩れた画面を見せない**
18. ブラウザの幅を **768px** にして **http://localhost:3124/mfa-setup** を開き直す → **横スクロールが出ない。ヘッダ・ナビが箱からはみ出さない（縮んだタブ・チップの文字が切れない）**
19. ブラウザの幅を **1024px** にして **http://localhost:3124/mfa-setup** を開き直す → **横スクロールが出ない。第2ナビと本文が重ならない**
20. ブラウザの幅を **1440px** にして **http://localhost:3124/mfa-setup** を開き直す → **横スクロールが出ない。本文が 720px 以上あり、左に寄らない**

## 結果

よければ次の 1 行を書いて保存してください（このまま貼って、日付と名前を変える）。

```
OK: YYYY-MM-DD 名前
```

違うところがあれば `NG: 何が違うか` を書いてください。1 行で構いません。
