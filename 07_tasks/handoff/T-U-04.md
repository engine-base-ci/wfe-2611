# T-U-04 画面 2段階認証を設定する（3 状態・R1/R2/R3）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://127.0.0.1:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

## 手順

1. **http://127.0.0.1:3124/mfa-setup** を開く。見出しが「2段階認証を設定する」で、横にスクロールしない
2. 「登録する」を押す → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
3. 「パスワード」を入れる（状態：パスワードの確認） → **入れた値がそのまま入る（送信に載る）**
4. 「パスワードを表示」を押す（状態：パスワードの確認） → **伏せ字（●●●）が読める文字に変わる。アイコンが目に斜線になり、もう一度押すと伏せ字に戻る**
5. 「認証アプリを登録する」を押す（状態：パスワードの確認） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
6. 「安全な場所に保管しました」を切り替える（状態：回復コード） → **切り替わる**
7. 「コピー」を押す（状態：回復コード） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
8. 「ファイルで保存」を押す（状態：回復コード） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
9. 「次へ（PCをつなぐ）」を押す（状態：回復コード） → **/setup/bridge が開く**（自分のPCをつなぐ）。戻る
10. 「アプリに出た6桁」を入れる（状態：登録） → **入れた値がそのまま入る（送信に載る）**

## 結果

よければ次の 1 行を書いて保存してください（このまま貼って、日付と名前を変える）。

```
OK: YYYY-MM-DD 名前
```

違うところがあれば `NG: 何が違うか` を書いてください。1 行で構いません。
