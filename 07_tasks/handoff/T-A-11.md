# T-A-11 API 目標に届くのか、届かないなら何を変えるか知りたい — データ・API（6 endpoint）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://localhost:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

招待の URL は画面がまだ無いので、次で作ってください（出た URL をブラウザに貼る）。

```bash
bash scripts/dev/invite.sh
```

## 手順

1. **http://localhost:3124/ai/chat** を開く。見出しが「分身の部屋：会話と知っていること」で、横にスクロールしない
2. **http://localhost:3124/company-model** を開く。見出しが「会社モデル」で、横にスクロールしない
3. **http://localhost:3124/goals/:id/allocation** を開く。見出しが「目標の配分」で、横にスクロールしない
4. **http://localhost:3124/goals/:id/edit** を開く。見出しが「目標を改訂する」で、横にスクロールしない
5. **http://localhost:3124/goals** を開く。見出しが「目標」で、横にスクロールしない
6. **http://localhost:3124/my-progress** を開く。見出しが「自分の目標」で、横にスクロールしない
7. **http://localhost:3124/onboard/draft** を開く。見出しが「たたき台を確かめる」で、横にスクロールしない
8. **http://localhost:3124/onboard/golive** を開く。見出しが「本番に切り替える」で、横にスクロールしない
9. **http://localhost:3124/tasks** を開く。見出しが「タスク」で、横にスクロールしない
10. 本番に切り替えるとき、未設定（ログイン情報が無い担当業務・目標の無い AI社員）が残っている（前提：たたき台あり・ログイン情報未登録）：本番に切り替えるを押す → **文言「本番に切り替える前に 2 つ足りません：経理社員の freee のログイン情報／営業社員の目標。埋めると切り替えられます」が出て、一手「足りないものを埋める／その AI社員は止めたまま本番へ」が押せる。守っている層：UI／API／DB**

## 結果

よければ次の 1 行を書いて保存してください（このまま貼って、日付と名前を変える）。

```
OK: YYYY-MM-DD 名前
```

違うところがあれば `NG: 何が違うか` を書いてください。1 行で構いません。
