## 手順

1. **http://127.0.0.1:3124/setup/bridge** を開く。見出しが「PC をつなぐ」で、横にスクロールしない
2. kaname-api の /health が 200 で版を返し、起動時確認 4／4 がログに出る（前提：S0〜S3 を済ませた）：curl で /health → **200。落ちていれば 503 と理由（黙って 502 にしない）**
3. Supabase の Transaction pooler に kaname_app／kaname_auth で入れる（前提：S1 の接続文字列を入れた）：/health と登録を 1 回 → **DB に書ける（custom role が pooler を通る）**
4. Bridge は仕事が動いていない間 5 秒ごと、動いている最中だけ最長 20 秒待ち受ける（前提：Bridge をつないだ）：1 時間放っておいた後に言う → **関数の呼び出しが 1 時間あたり約 720 回・言ってから数秒で動き出す**
5. staging では資格情報が Infisical に預けられる（メモリには置かない）（前提：S2 で Infisical を用意した）：資格情報を保存する → **預けられ、Infisical の /tenants/<会社> に暗号文だけがある**
6. 新規登録 → 確認メール → Bridge をつなぐ → 自分のAIと話す が staging で通る（前提：S0〜S4 を済ませた）：実ブラウザで 1 周 → **全部通る（L2）**
