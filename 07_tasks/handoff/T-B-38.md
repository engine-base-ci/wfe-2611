# T-B-38 ログイン情報を預けたらその場で 1 回ログインだけ試す（入れたらそのまま出る・ほかの操作はしない・結果を預けたものの行に出す）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://127.0.0.1:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

## 手順

1. **http://127.0.0.1:3124/settings/credentials** を開く。見出しが「ログイン情報を預ける」で、横にスクロールしない
2. 預けたら 1 回ログインし、入れたらそのまま出る。ほかの操作はしない（前提：正しいログイン情報を預けた）：保存する → **預けたものの行に「ログインできました」と出る**
3. 入れなければ理由を出す（パスワードが違う／2 段階が要る／CAPTCHA／規約で禁止なので試さない）（前提：違うパスワード・CAPTCHA のサービス）：保存する → **理由と次の一手が出る。何度も試さない**
4. 鍵は実行の間だけ受け取り、入力したら捨てる。ディスクにも AI にも渡らない（前提：預けたログイン情報）：ログインに使う → **入力された後、鍵がメモリにもファイルにも残っていない**

## 結果

よければ次の 1 行を書いて保存してください（このまま貼って、日付と名前を変える）。

```
OK: YYYY-MM-DD 名前
```

違うところがあれば `NG: 何が違うか` を書いてください。1 行で構いません。
