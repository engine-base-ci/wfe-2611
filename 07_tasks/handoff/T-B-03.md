## 手順

1. **http://127.0.0.1:3124/setup/bridge** を開く。見出しが「自分のPCをつなぐ」で、横にスクロールしない
2. 動いている間、何をしているか（使っている道具・書いている文）が会話に出る（1 行 1 イベント）（前提：仕事を渡した）：Bridge が途中経過を返す → **「…を使っています」の行が会話に出る。無言で待たせない**
3. 自分のAIが「これを実行していいか」と聞くと、会話に確認カード（何を・どう・許可する／許可しない）が出る（前提：仕事が動いている）：Bridge が確認を返す → **確認カードが出て、答えるまで自分のAIは待つ**
4. 「許可する」を押すと Bridge に allow が渡り、動き直す。答えは会話の記録と証跡（誰が・いつ・何を）に残る（前提：確認待ち）：許可する を押す → **Bridge が allow を受け取り、会話に「許可しました」の記録が出て、証跡に bridge.tool_allowed が残る**
5. 「許可しない」を押すと Bridge に deny が渡る。勝手に許可しない（前提：確認待ち）：許可しない を押す → **Bridge が deny を受け取り、会話に「許可しませんでした」の記録が出る**
6. result の is_error で成否を決める。終了コード 0 でも失敗は失敗（ログインが要る／上限）（前提：仕事を渡した）：is_error の result を返す → **「終わった」にならず、理由（ログイン・上限）が止まりましたに出る**
