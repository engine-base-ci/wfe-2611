# T-B-07 関門の迂回 55 件を片付けて、関門の検査を CI に並べる（画面の fetch を C1 の対象外にするか例外台帳に載せるかを 1 件ずつ決める）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://localhost:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

## 手順

1. **http://localhost:3124/setup/bridge** を開く。見出しが「PC をつなぐ」で、横にスクロールしない
2. 関門の迂回 55 件を片付けて、関門の検査を CI に並べる（画面の fetch を C1 の対象外にするか例外台帳に載せるかを 1 件ずつ決める）（前提：Bridge を入れた PC）：手順どおり操作する → **node scripts/ci/choke.mjs --all が緑になり、CI から呼ばれている（迂回は 0 か、理由つきで台帳にある）**
