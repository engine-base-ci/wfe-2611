# T-I-10 流れ J-02 P1 はじめの設定 ── PCをつないで、自分のAIと作る（初日〜3日） を最後まで通す（L2）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** 登録から最後まで、止めずに続けて通します。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）

## 手順

1. 流れ J-02 P1 はじめの設定 ── PCをつないで、自分のAIと作る（初日：データ 0 件の会社で最初から通す（前提：新しいテスト会社）：最初から最後まで操作 → **各段で空状態が出て、途中で詰まらない**
2. Bridge を入れて開き、「Claude Code を入れる」を押し、ログインを 1 回承認して、つなぐ（http://localhost:3124/setup/bridge） → **端末を登録、トークン発行。LLM経路＝Bridge を確定**
3. 自分のAIの質問に答える（http://localhost:3124/onboard/interview） → **会話を記憶へ、業種の手がかりを保存**
4. 出てきたたたき台を見る（http://localhost:3124/onboard/draft） → **会社モデルの下書きを保存（道具の口 /bridge/tool が DB の関数で書き、証跡に残す）**
5. 違うところを言う（http://localhost:3124/onboard/draft） → **会社モデルの下書きを更新**
6. 使うサービスを選びログイン情報を入れる（http://localhost:3124/settings/credentials） → **vaultに暗号化保管。AIには参照IDのみ。資格情報は会社ごとの鍵で暗号化して Infisical の会社の置き場へ（AI には参照 ID だけ）。Bridge は Infisical に入らず、実行の間だけ値を受け取って捨てる**
7. 試しに動かして結果を見る（http://localhost:3124/onboard/testrun） → **テスト実行の証跡を残す**
8. 本番に切り替える（http://localhost:3124/onboard/golive） → **会社モデルを確定、自動実行を有効化**
