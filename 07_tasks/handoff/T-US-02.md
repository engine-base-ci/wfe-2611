# T-US-02 自分のAIのパネルと会話の部品（会話は AgentChat 1 つ・右パネルは共通の枠が必ず出す・選択肢・承認カード・受領・引用・取り消し・別の作りは chat_one で赤）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）

## 手順

1. 右パネルで言ったことは、会話モードを開くと同じ会話の続きとして出る（部品は AgentChat 1 つ）（前提：Bridge をつないだ）：右パネルで言う → 会話モードを開く → **会話モードに同じ言葉が出る。会話モードには右パネルを出さない**
2. 右パネルで言うと、自分のAI への指示に見ている画面（と選んでいる 1 件）が前置きされ、会話の吹き出しには出ない（前提：Bridge をつないだ）：目標の画面の右パネルで言う → **指示に「いま見ている画面：目標」が付き、吹き出しには本人の言葉だけ**
3. **http://127.0.0.1:3124/dev/shell** を開き、役割（R1〜R6）と時点（PS0〜PS4）を切り替えて、サイドバー・下タブ・自分のAIのパネルの項目を押す（見本の画面。dev でだけ出る）

## 結果

よければ次の 1 行を書いて保存してください（このまま貼って、日付と名前を変える）。

```
OK: YYYY-MM-DD 名前
```

違うところがあれば `NG: 何が違うか` を書いてください。1 行で構いません。
