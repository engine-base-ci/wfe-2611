## 手順

1. 流れ J-04 P3 毎週 を最後まで通す（L2）：データ 0 件の会社で最初から通す（前提：新しいテスト会社）：最初から最後まで操作 → **各段で空状態が出て、途中で詰まらない**
2. 届くか見る（http://localhost:3124/goals） → **目標と実績を突き合わせ、未配分を計算**
3. かけたものと出たものを並べて見る（http://localhost:3124/goals） → **ledger_records/tasks の goal_id・measure_id を読んで集計**
4. 誰に・どれだけ降ろすか決める（http://localhost:3124/goals/:id/allocation） → **配分を保存**
5. 止まっている案件を動かす（http://localhost:3124/records） → **レコード一覧**
6. 自分の担当分の進みを見る（http://localhost:3124/my-progress） → **自分に配られた分だけを読む**
7. 自分の目標を直す・自主目標を足す（http://localhost:3124/my-progress） → **個人層の目標を保存（本人は即反映）**
