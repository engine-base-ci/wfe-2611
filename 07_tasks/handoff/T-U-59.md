# T-U-59 画面 支払い方法を登録する（4 状態・R1/R2・段階 2）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://127.0.0.1:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

## 手順

1. **http://127.0.0.1:3124/billing-setup** を開く。見出しが「支払い方法を登録する」で、横にスクロールしない
2. 「登録する」を押す → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
3. 「別のカードで登録する」を押す（状態：カードが拒否された） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
4. 「請求書払いにする」を押す（状態：カードが拒否された） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
5. 「エントリー · 30,000 円／月一人社長・個人事業。税込。上限は「プランと請」を選ぶ（状態：登録） → **選べる**
6. 「スタンダード · 80,000 円／月中小・ベンチャー。税込。上限は「プランと請」を選ぶ（状態：登録） → **選べる**
7. 「プロ · 150,000 円／月中堅。税込。上限は「プランと請求」で見られます」を選ぶ（状態：登録） → **選べる**
8. 「カード（Stripe）Stripe の画面で登録。番号は Kaname を通らな」を選ぶ（状態：登録） → **選べる**
9. 「請求書払い毎月の請求書を受け取り、振込で払う。運営が入金を記録」を選ぶ（状態：登録） → **選べる**
10. 「Stripe で登録する」を押す（状態：登録） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
11. 「PC をつなぐへ進む」を押す（状態：登録できた） → **/setup/bridge が開く**（自分のPCをつなぐ）。戻る
12. 全角／半角：メール・数値・コードを全角で入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
13. 前後と途中の空白：空白付きで入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
14. 記号の種別（ハイフン・長音）：‐ ー − を混ぜる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
15. Unicode 正規化（NFC/NFD）：macOS の入力（NFD）で入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
16. 大文字小文字：メールを大文字で入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
17. カード会社が承認しなかった（残高・利用停止・不正の疑い）（前提：Stripe のテストカード（拒否））：Stripe の画面で拒否されるカードを入れる → Kaname に戻る → **文言「カードが拒否されました。別のカードを使うか、カード会社に確認してください。請求書払いに切り替えることもできます」が出て、一手「別のカードで登録する／請求書払いにする」が押せる。守っている層：UI／API**
18. カードの本人確認（3D セキュア）が終わらずに戻ってきた（前提：3D セキュアが要るテストカード）：本人確認の途中で閉じる → **文言「カードの本人確認が終わっていません。Stripe の画面でもう一度、カード会社の確認を済ませてください」が出て、一手「Stripe の画面に戻る」が押せる。守っている層：UI／API**

20. ブラウザの幅を **768px** にして **http://127.0.0.1:3124/billing-setup** を開き直す → **横スクロールが出ない。ヘッダ・ナビが箱からはみ出さない（縮んだタブ・チップの文字が切れない）**
21. ブラウザの幅を **1024px** にして **http://127.0.0.1:3124/billing-setup** を開き直す → **横スクロールが出ない。第2ナビと本文が重ならない**
22. ブラウザの幅を **1440px** にして **http://127.0.0.1:3124/billing-setup** を開き直す → **横スクロールが出ない。本文が 720px 以上あり、左に寄らない**
