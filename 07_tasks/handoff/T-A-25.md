# T-A-25 API 運営として、各社に配るもの（AI社員・担当業務・ルール・テンプレ）と（2 endpoint）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://127.0.0.1:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

招待の URL は画面がまだ無いので、次で作ってください（出た URL をブラウザに貼る）。

```bash
bash scripts/dev/invite.sh
```

## 手順

1. **http://127.0.0.1:3124/ai-staff/activity** を開く。見出しが「AI社員の動き」で、横にスクロールしない
2. **http://127.0.0.1:3124/ai-staff** を開く。見出しが「AI社員」で、横にスクロールしない
3. **http://127.0.0.1:3124/ai-staff/:id** を開く。見出しが「AI社員の1体」で、横にスクロールしない
4. **http://127.0.0.1:3124/ops/catalog** を開く。見出しが「運営：配るもの」で、横にスクロールしない
5. **http://127.0.0.1:3124/ops** を開く。見出しが「運営：会社の一覧」で、横にスクロールしない
