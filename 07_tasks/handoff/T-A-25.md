# T-A-25 API 運営として、問い合わせに答え、お知らせと稼働状況を出し、各社の請求・（2 endpoint・段階 2）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://127.0.0.1:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

## 手順

1. **http://127.0.0.1:3124/ops/disclosure** を開く。見出しが「運営：開示資料」で、横にスクロールしない
2. 「高本AI」を押す → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
3. 「版を出す」を押す → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
4. 「AI は止まっています」を押す → **/automations/:id/repair が開く**（覚え直させる）。戻る
5. 「PC をつなぐと話せます」を押す → **/setup/bridge が開く**（自分のPCをつなぐ）。戻る
6. 「雛形を差し替える」を押す（状態：DPA とサブプロセッサ） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
7. 「足す」を押す（状態：DPA とサブプロセッサ） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
8. 「新しい版を出す」を押す（状態：版） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
9. 「出す（全社にお知らせ）」を押す（状態：版） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
10. 「戻す先にする」を押す（状態：版） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
11. **http://127.0.0.1:3124/ops/llm** を開く。見出しが「運営：AI の経路と使用量」で、横にスクロールしない
12. 「高本AI」を押す → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
13. 「許可する」を押す → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
14. 「AI は止まっています」を押す → **/automations/:id/repair が開く**（覚え直させる）。戻る
15. 「PC をつなぐと話せます」を押す → **/setup/bridge が開く**（自分のPCをつなぐ）。戻る
16. 「会社の詳細を開く」を押す（状態：従量に切り替わった会社） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
17. 「止める」を押す（状態：経路と使用量） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
