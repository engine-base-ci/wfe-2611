# T-U-61 画面 AI の経路（4 状態・R1/R2・段階 2）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://127.0.0.1:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

## 手順

1. **http://127.0.0.1:3124/settings/llm** を開く。見出しが「AI の経路」で、横にスクロールしない
2. 「Bridge（あなたの PC で、あなたのサブスク）既定。PC が開いている間に」を選ぶ（状態：AI の経路） → **選べる**
3. 「自分の API キー（Anthropic・OpenAI・Google）PC が閉」を選ぶ（状態：AI の経路） → **選べる**
4. 「運営マネージド運営のキーで動く。プランの上限まで含み、超えた分は同じ請求書に従量」を選ぶ（状態：AI の経路） → **選べる**
5. 「待つ（起きたら順に片づける）段階 1 と同じ。外に出るものは止まったまま」を選ぶ（状態：AI の経路） → **選べる**
6. 「自分の API キーで動かすサーバー経路。承認が要るものは承認待ちで止まる」を選ぶ（状態：AI の経路） → **選べる**
7. 「運営マネージドで動かす上限に近づくと自分のAIが先に言う」を選ぶ（状態：AI の経路） → **選べる**
8. 「保存する」を押す（状態：AI の経路） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
9. 「キーを預ける」を押す（状態：AI の経路） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
10. 「失効させる」を押す（状態：AI の経路） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
11. 「預ける」を押す（状態：AI の経路） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
12. 「新しいキーを預ける」を押す（状態：キーが無効・上限に届いた） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
13. 「Bridge に戻す」を押す（状態：キーが無効・上限に届いた） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
14. 「従量で続ける」を押す（状態：キーが無効・上限に届いた） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
15. 「API キー」を入れる（状態：キーを預ける） → **入れた値がそのまま入る（送信に載る）**
16. 「パスワードを表示」を押す（状態：キーを預ける） → **伏せ字（●●●）が読める文字に変わる。アイコンが目に斜線になり、もう一度押すと伏せ字に戻る**
17. 「確かめて預ける」を押す（状態：キーを預ける） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
18. 「やめる」を押す（状態：キーを預ける） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
19. 全角／半角：メール・数値・コードを全角で入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
20. 前後と途中の空白：空白付きで入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
21. 記号の種別（ハイフン・長音）：‐ ー − を混ぜる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
22. Unicode 正規化（NFC/NFD）：macOS の入力（NFD）で入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
23. 大文字小文字：メールを大文字で入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
24. 預けた API キーを提供者が拒否した（無効・失効・権限なし）（前提：無効なキーを預ける）：API キーを預ける → 提供者が 401 → **文言「Anthropic のキーが無効です（提供者が拒否）。新しいキーを預けるか、経路を Bridge か運営マネージドに戻してください。動いていた仕事は止めてあります」が出て、一手「新しいキーを預ける／Bridge に戻す」が押せる。守っている層：UI／API／DB**
25. 提供者のサービスが落ちている・応答しない（前提：提供者の API を切る）：自分のAIに話す → **文言「OpenAI が応答しません。この経路の仕事は止めてあります。Bridge に戻すか、しばらくしてから再開してください」が出て、一手「Bridge に戻す／あとで再開」が押せる。守っている層：UI／API**
26. 運営マネージドの月の上限に届いた（前提：usage_meters を上限に）：運営マネージドで実行 → **文言「運営マネージドが今月の上限（100 万）に届きました。超えた分は従量で同じ請求書に乗ります。止めるなら経路を Bridge に戻してください」が出て、一手「従量で続ける／Bridge に戻す」が押せる。守っている層：UI／API／DB**
27. 3 社で揃わない能力（画像の読み取り 等）を使おうとした（前提：画像を添付して読ませる）：会話で画像の読み取りを頼む → **文言「この機能はまだ使えません（提供者の間で揃っていないため、どの経路でも出していません）」が出て、一手「別のやり方（文字で伝える）」が押せる。守っている層：UI／API**
28. PC が閉じている・Bridge が切れている・覚え直し待ちで、この画面の AI の部分（拾う・配る・一次確認する・提案する）が動いていない（前提：本番稼働中に Bridge を切る（PC を閉じる））：この画面を開く → 上の帯と右上の「AI は止まっています」を確認 → 人の操作（見る・押す・保存）ができることを確認 → Bridge をつなぎ直して帯が消えることを確認 → **文言「AI は止まっています。人が見る・押すものはそのまま。AI が拾う・配る・一次確認する部分だけ止まっています。止まった理由と直し方は「止まっているものを直す」にあります」が出て、一手「止まっているものを直す（覚え直させる・PC をつなぐ）を開く」が押せる。守っている層：UI／API**
29. ブラウザの幅を **375px** にして **http://127.0.0.1:3124/settings/llm** を開き直す → **横スクロールが出ない。文字が読める大きさ（11px 以上）で、入力欄を押しても勝手に拡大しない（16px 以上）。ボタンが指で押せる（24px 以上）。スマホで使わせない画面なら『PC で開いてください』と出て、崩れた画面を見せない**
30. ブラウザの幅を **768px** にして **http://127.0.0.1:3124/settings/llm** を開き直す → **横スクロールが出ない。ヘッダ・ナビが箱からはみ出さない（縮んだタブ・チップの文字が切れない）**
31. ブラウザの幅を **1024px** にして **http://127.0.0.1:3124/settings/llm** を開き直す → **横スクロールが出ない。第2ナビと本文が重ならない**
32. ブラウザの幅を **1440px** にして **http://127.0.0.1:3124/settings/llm** を開き直す → **横スクロールが出ない。本文が 720px 以上あり、左に寄らない**
