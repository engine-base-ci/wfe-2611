発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://127.0.0.1:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

## 手順

1. **http://127.0.0.1:3124/onboard/testrun** を開く。見出しが「テストで動かす」で、横にスクロールしない
2. 「本番に切り替える」を押す → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**

4. 「もう少し試す」を押す（状態：動かした） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
5. 「1. PCをつなぐ」を押す（状態：動かした） → **/setup/bridge が開く**（自分のPCをつなぐ）。戻る
6. 「2. 話す」を押す（状態：動かした） → **/onboard/interview が開く**（自分のAIと話す）。戻る
7. 「3. たたき台」を押す（状態：動かした） → **/onboard/draft が開く**（たたき台を確かめる）。戻る
8. 「4. ログイン情報」を押す（状態：動かした） → **/settings/credentials が開く**（ログイン情報を預ける）。戻る
9. 「営業社員を動かす」を押す（状態：最初） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
10. 「経理社員を動かす」を押す（状態：最初） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
11. 「ブラウザで開く」を押す（状態：止まった） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
12. 「この仕事はやめる」を押す（状態：止まった） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
13. 外部サービスの画面が変わって、覚えた操作が途中で止まった（前提：覚えた操作あり）：対象ページの要素名を変える（テスト用のモック画面） → AI社員を動かす → **文言「発注ナビの画面が変わり、営業社員の覚えた操作が手順 3 で止まりました。覚え直させると再開できます」が出て、一手「覚え直させる／このまま止めておく」が押せる。守っている層：UI／API**
14. 外部サービスで CAPTCHA が出た（突破しない・人に渡す）（前提：CAPTCHA を出すモック画面）：AI社員を動かす → **文言「発注ナビで本人確認（CAPTCHA）が出たので止めました。あなたが一度通すと、続きから動きます」が出て、一手「自分で通しに行く／あとで」が押せる。守っている層：API／DB**
15. ブラウザの幅を **375px** にして **http://127.0.0.1:3124/onboard/testrun** を開き直す → **横スクロールが出ない。文字が読める大きさ（11px 以上）で、入力欄を押しても勝手に拡大しない（16px 以上）。ボタンが指で押せる（24px 以上）。スマホで使わせない画面なら『PC で開いてください』と出て、崩れた画面を見せない**
16. ブラウザの幅を **768px** にして **http://127.0.0.1:3124/onboard/testrun** を開き直す → **横スクロールが出ない。ヘッダ・ナビが箱からはみ出さない（縮んだタブ・チップの文字が切れない）**
17. ブラウザの幅を **1024px** にして **http://127.0.0.1:3124/onboard/testrun** を開き直す → **横スクロールが出ない。第2ナビと本文が重ならない**
18. ブラウザの幅を **1440px** にして **http://127.0.0.1:3124/onboard/testrun** を開き直す → **横スクロールが出ない。本文が 720px 以上あり、左に寄らない**
