# T-A-05 API 今日なにをすればいいか、迷わず決めたい — データ・API・権限（2/3）（6 endpoint）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://127.0.0.1:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

## 手順

1. **http://127.0.0.1:3124/account** を開く。見出しが「自分の設定」で、横にスクロールしない
2. **http://127.0.0.1:3124/login** を開く。見出しが「ログインする」で、横にスクロールしない
3. **http://127.0.0.1:3124/mfa-setup** を開く。見出しが「安全の設定」で、横にスクロールしない
4. **http://127.0.0.1:3124/password-reset** を開く。見出しが「パスワードの再設定」で、横にスクロールしない
5. **http://127.0.0.1:3124/tasks** を開く。見出しが「タスク」で、横にスクロールしない
6. **http://127.0.0.1:3124/today** を開く。見出しが「今日」で、横にスクロールしない
7. **http://127.0.0.1:3124/verify-email** を開く。見出しが「メールを確認する」で、横にスクロールしない

## 結果

よければ次の 1 行を書いて保存してください（このまま貼って、日付と名前を変える）。

```
OK: YYYY-MM-DD 名前
```

違うところがあれば `NG: 何が違うか` を書いてください。1 行で構いません。
