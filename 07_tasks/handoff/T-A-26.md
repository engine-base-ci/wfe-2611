# T-A-26 API 自分のアカウント・会社の設定・既存データの取り込み・外部サービスの連（2 endpoint・段階 2）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://127.0.0.1:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

## 手順

1. **http://127.0.0.1:3124/settings/app** を開く。見出しが「アプリと通知」で、横にスクロールしない
2. 「高本AI」を押す → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
3. 「通知を許可する」を押す → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
4. 「AI は止まっています」を押す → **/automations/:id/repair が開く**（覚え直させる）。戻る
5. 「PC をつなぐと話せます」を押す → **/setup/bridge が開く**（自分のPCをつなぐ）。戻る
6. 「checkbox」を切り替える（状態：アプリと通知） → **切り替わる**
7. 「Bridge の窓で開く」を押す（状態：アプリと通知） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
8. 「App Store」を押す（状態：アプリと通知） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
9. 「Google Play」を押す（状態：アプリと通知） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
10. 「保存する」を押す（状態：アプリと通知） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
11. 「設定の開き方を見る」を押す（状態：許可が無い・つながっていない） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
12. 「もう一度たずねる」を押す（状態：許可待ち） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
13. **http://127.0.0.1:3124/settings/llm** を開く。見出しが「AI の経路」で、横にスクロールしない
14. 「高本AI」を押す → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
15. 「保存する」を押す → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
16. 「AI は止まっています」を押す → **/automations/:id/repair が開く**（覚え直させる）。戻る
17. 「PC をつなぐと話せます」を押す → **/setup/bridge が開く**（自分のPCをつなぐ）。戻る
18. 「止まっているものを直す」を押す（状態：AI が止まっている） → **/automations/:id/repair が開く**（覚え直させる）。戻る
19. 「Bridge（あなたの PC で、あなたのサブスク）既定。PC が開いている間に」を選ぶ（状態：AI の経路） → **選べる**
20. 「自分の API キー（Anthropic・OpenAI・Google）PC が閉」を選ぶ（状態：AI の経路） → **選べる**
21. 「運営マネージド運営のキーで動く。プランの上限まで含み、超えた分は同じ請求書に従量」を選ぶ（状態：AI の経路） → **選べる**
22. 「待つ（起きたら順に片づける）段階 1 と同じ。外に出るものは止まったまま」を選ぶ（状態：AI の経路） → **選べる**
23. 「自分の API キーで動かすサーバー経路。承認が要るものは承認待ちで止まる」を選ぶ（状態：AI の経路） → **選べる**
24. 「運営マネージドで動かす上限に近づくと高本AIが先に言う」を選ぶ（状態：AI の経路） → **選べる**
25. 「キーを預ける」を押す（状態：AI の経路） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
26. 「失効させる」を押す（状態：AI の経路） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
27. 「預ける」を押す（状態：AI の経路） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
28. 「新しいキーを預ける」を押す（状態：キーが無効・上限に届いた） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
29. 「Bridge に戻す」を押す（状態：キーが無効・上限に届いた） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
30. 「従量で続ける」を押す（状態：キーが無効・上限に届いた） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
31. 「API キー」を入れる（状態：キーを預ける） → **入れた値がそのまま入る（送信に載る）**
32. 「確かめて預ける」を押す（状態：キーを預ける） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
33. 「やめる」を押す（状態：キーを預ける） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**

## 結果

よければ次の 1 行を書いて保存してください（このまま貼って、日付と名前を変える）。

