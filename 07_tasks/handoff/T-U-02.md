# T-U-02 画面 メールを確認する（5 状態・R1/R2）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://127.0.0.1:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

## 手順

1. **http://127.0.0.1:3124/verify-email** を開く。見出しが「メールを確認する」で、横にスクロールしない
2. 「はじめの設定をはじめる」を押す → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
3. 「はじめから登録し直す」を押す（状態：申し込みが残っていない） → **/signup が開く**（アカウントを作る）。戻る
4. 「ログイン」を押す（状態：申し込みが残っていない） → **/login が開く**（ログインする）。戻る
5. 「はじめの設定をはじめる（PCをつなぐ）」を押す（状態：登録できた） → **/setup/bridge が開く**（PC をつなぐ）。戻る
6. 「もう一度送る」を押す（状態：送信済み） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
7. 「入力し直す」を押す（状態：送信済み） → **/signup が開く**（アカウントを作る）。戻る
8. 登録が終わった人が、確認のリンクをもう一度押した／待つ画面に戻って「もう一度送る」を押した（前提：リンクを押して登録を終えた）：ブラウザで戻る → 「もう一度送る」を押す → **文言「このメールアドレスの登録は確認まで終わっています。ログインしてください」が出て、一手「ログインへ」が押せる。守っている層：UI／API**
9. 宛先が受け取らない（受信箱が満杯・存在しない・拒否された）（前提：保留の申し込みがある状態）：受け取らない宛先に送る → 結果を見る → **文言「このメールアドレスは受け取れませんでした。受信箱がいっぱいか、アドレスが違うかもしれません」が出て、一手「受信箱を空ける／入力し直して別のアドレスで登録する」が押せる。守っている層：API**
10. 保留の申し込みが残っていないのに「もう一度送る」を押した（30 分を過ぎた・もう確認した）（前提：保留を消したあと）：確認の画面で「もう一度送る」を押す → **文言「この申し込みは残っていません。もう一度はじめからやり直してください」が出て、一手「はじめから登録し直す」が押せる。守っている層：API**
11. **自分の受信箱**を開く → **届いている**（迷惑メールも見る）。件名・差出人・本文が読め、リンクを押すと目的の画面が開く
12. 本文を読む → **内部の言葉（ID・テーブル名）が無く、誰宛てで何をすればよいかが分かる**
13. `.dev-logs/api.log` の `[mail]` の行を見る → **「送った → 自分のアドレス」が出ている**。「送れなかった」が出ていたら、その理由が NG の中身
14. ブラウザの幅を **375px** にして **http://127.0.0.1:3124/verify-email** を開き直す → **横スクロールが出ない。文字が読める大きさ（11px 以上）で、入力欄を押しても勝手に拡大しない（16px 以上）。ボタンが指で押せる（24px 以上）。スマホで使わせない画面なら『PC で開いてください』と出て、崩れた画面を見せない**
15. ブラウザの幅を **768px** にして **http://127.0.0.1:3124/verify-email** を開き直す → **横スクロールが出ない。ヘッダ・ナビが箱からはみ出さない（縮んだタブ・チップの文字が切れない）**
16. ブラウザの幅を **1024px** にして **http://127.0.0.1:3124/verify-email** を開き直す → **横スクロールが出ない。第2ナビと本文が重ならない**
17. ブラウザの幅を **1440px** にして **http://127.0.0.1:3124/verify-email** を開き直す → **横スクロールが出ない。本文が 720px 以上あり、左に寄らない**

## 結果

よければ次の 1 行を書いて保存してください（このまま貼って、日付と名前を変える）。

```
OK: YYYY-MM-DD 名前
```

違うところがあれば `NG: 何が違うか` を書いてください。1 行で構いません。
