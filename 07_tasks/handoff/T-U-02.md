# T-U-02 画面 メールを確認する（3 状態・R1/R2）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://127.0.0.1:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

## 手順

1. **http://127.0.0.1:3124/verify-email** を開く。見出しが「メールを確認する」で、横にスクロールしない
2. 「はじめの設定をはじめる」を押す → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
3. 「新しいリンクを送る」を押す（状態：期限切れ） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
4. 「はじめの設定をはじめる（PCをつなぐ）」を押す（状態：確認できた） → **/setup/bridge が開く**（自分のPCをつなぐ）。戻る
5. 「もう一度送る」を押す（状態：送信済み） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
6. 「入力し直す」を押す（状態：送信済み） → **/signup が開く**（アカウントを作る）。戻る
7. **自分の受信箱**を開く → **届いている**（迷惑メールも見る）。件名・差出人・本文が読め、リンクを押すと目的の画面が開く
8. 本文を読む → **内部の言葉（ID・テーブル名）が無く、誰宛てで何をすればよいかが分かる**

## 結果

よければ次の 1 行を書いて保存してください（このまま貼って、日付と名前を変える）。

```
OK: YYYY-MM-DD 名前
```

違うところがあれば `NG: 何が違うか` を書いてください。1 行で構いません。
