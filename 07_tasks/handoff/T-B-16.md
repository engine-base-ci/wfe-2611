## 手順

1. **http://localhost:3124/ai/chat** を開く。見出しが「分身の部屋：会話と知っていること」で、横にスクロールしない
2. 本人の Claude Code が途中の文を出せるか（--include-partial-messages 等）を実物で確かめ、出せないなら「終わってから一度に」のままにして理由を記録する（前提：この PC の Claude Code）：短い頼みを 1 件流す → **途中の文が届く・届かないが 07_tasks/audit/T-B-16.md に残る**
3. 返事は書きながら少しずつ出る（全部書き終わるまで空で待たせない）（前提：Bridge がつながっている）：長めの返事を頼む → **吹き出しの文が伸びていき、終わると result と同じになる**
4. 作業中は吹き出しを出さず「〇〇を調べています…」・手順（済の印）・経過時間・道具の行が出る。終わると「N つの操作・時間」の 1 行に畳まれる（前提：道具を使う頼み）：頼む → **作業の行が出て、終わると 1 行に畳まれて吹き出しの上に残る**
