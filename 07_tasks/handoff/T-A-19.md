## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://127.0.0.1:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

招待の URL は画面がまだ無いので、次で作ってください（出た URL をブラウザに貼る）。

```bash
bash scripts/dev/invite.sh
```

## 手順

1. **http://127.0.0.1:3124/ops** を開く。見出しが「運営：ワークスペースの一覧」で、横にスクロールしない
2. **http://127.0.0.1:3124/ops/support** を開く。見出しが「運営：問い合わせ」で、横にスクロールしない
3. **http://127.0.0.1:3124/ops/tenants/:id** を開く。見出しが「運営：ワークスペースの 1 社」で、横にスクロールしない
