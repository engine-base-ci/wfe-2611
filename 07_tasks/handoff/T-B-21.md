# T-B-21 記憶の毎朝のまとめ（「今日」の一番上のボタン → 溜まった会話と承認・差し戻しを自分のAI が読む → 覚えた／まとめた／上げる候補／捨てた。個人は自動で入れ、整理は前後を残す）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://127.0.0.1:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

## 手順

1. **http://127.0.0.1:3124/today** を開く。見出しが「今日」で、横にスクロールしない
2. **http://127.0.0.1:3124/clone-memory** を開く。見出しが「」で、横にスクロールしない
3. 時間では動かない。「昨日の会話をまとめる」を押したときだけ始まる（前提：朝・溜まった会話あり）：何もしない → 押す → **押すまで memory_digests に行ができない。押すと始まる**
4. 押さない日は溜まり、ボタンに何日分・会話いくつが出る。次に押すと溜まった分をまとめる（前提：2 日押さなかった）：今日 を開く → 押す → **「2 日分・会話 7」→ from_on〜to_on が 2 日分**
5. 読むのは自分のAI との会話（記憶に残さない会話を除く）と、その日の承認・差し戻し（前提：承認 1・差し戻し 1・記憶に残さない会話 1）：押す → **読んだ数に承認と差し戻しが入り、記憶に残さない会話は入らない**
6. 結果は 覚えた／まとめた／上げる候補／捨てた に分けて出て、その場で直す・戻す・拾い直すができる（前提：まとめ済み）：まとめたものを 戻す → **前の記憶に戻り、superseded_by が外れる**
7. 「これ覚えて」と言うと、朝を待たずその場で入り「覚えました」が出る（前提：会話）：「初回は値引きしない。覚えて」 → **memories に 1 行・会話に「覚えました」と記憶の画面へのリンク**
8. PC が閉じていたら始めたことにせず、溜まっている量も減らさない（前提：Bridge を止める）：押す → **E-MEM-001 の文言。溜まった量が変わらない**

## 結果

よければ次の 1 行を書いて保存してください（このまま貼って、日付と名前を変える）。

```
OK: YYYY-MM-DD 名前
```

違うところがあれば `NG: 何が違うか` を書いてください。1 行で構いません。
