# T-B-15 会話を分ける（新しく話す＝新しいセッション・一覧・探す（名前も中身も）・名前は自動で付き直せる・星・消す・記憶に残さない会話）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://127.0.0.1:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

## 手順

1. **http://127.0.0.1:3124/ai/chat** を開く。見出しが「自分のAIと話す」で、横にスクロールしない
2. 「新しく話す」を押すと新しい会話ができ、次の一言は新しいセッションで始まる（前の会話の続きにならない）（前提：会話が 1 つある）：新しく話す → 言う → **一覧に 2 つ並び、新しい方の agent_session_id は前と違う**
3. 一覧から前の会話を選ぶと、その会話の続きとして話せる（同じセッションを --resume）（前提：会話が 2 つある）：前の会話を選んで言う → **前の会話の吹き出しの下に続きが出て、agent_session_id が前と同じ**
4. 名前は最初の一言から自動で付き、直すとそれが残る（自動で上書きしない）（前提：新しい会話）：言う → 名前を直す → もう一度言う → **直した名前のまま・title_auto が false**
5. 一覧で探すと名前も中身も当たり、当たった所が見える（前提：中身に「着手金」を含む会話）：一覧で「着手金」と探す → **その会話が出て、当たった文が 1 行見える**
6. 記憶に残さない会話は、毎朝のまとめで読まれない（前提：記憶に残さない会話で話した）：翌朝「昨日の会話をまとめる」を押す → **その会話はまとめの読んだ数に入らない**

## 結果

よければ次の 1 行を書いて保存してください（このまま貼って、日付と名前を変える）。

```
OK: YYYY-MM-DD 名前
```

違うところがあれば `NG: 何が違うか` を書いてください。1 行で構いません。
