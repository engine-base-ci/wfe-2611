# T-B-13 自分のAI の仕事の記録（使った量と道具の呼び出しを残す・中身の全文は集めない）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://127.0.0.1:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

## 手順

1. **http://127.0.0.1:3124/ai/chat** を開く。見出しが「自分のAIと話す」で、横にスクロールしない
2. 道具を使うたびに、名前・対象・成功／失敗・時間が残る（前提：仕事を渡した）：自分のAI にファイルを読ませる → **bridge_job_events に kind=tool の行（name・target・ok・ms）が残る**
3. 仕事が終わると、使った量（往復数・時間・量・費用の見込み）が結末より先に残る（前提：仕事を渡した）：最後まで動かす → **kind=usage の行が残り、その後に結末が書かれる**
4. 道具の記録と使った量は会話の途中経過に出ない（前提：記録がある仕事）：会話を開く → **会話には「…を使っています」の 1 行だけが出る**

## 結果

よければ次の 1 行を書いて保存してください（このまま貼って、日付と名前を変える）。

```
OK: YYYY-MM-DD 名前
```

違うところがあれば `NG: 何が違うか` を書いてください。1 行で構いません。
