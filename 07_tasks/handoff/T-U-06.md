# T-U-06 画面 パスワードの再設定（3 状態・R1/R2/R3）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://127.0.0.1:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

## 手順

1. **http://127.0.0.1:3124/password-reset** を開く。見出しが「パスワードの再設定」で、横にスクロールしない
2. 「メールアドレス」を入れる（状態：再設定を送る） → **入れた値がそのまま入る（送信に載る）**
3. 「再設定メールを送る」を押す（状態：再設定を送る） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
4. 「新しいパスワード」を入れる（状態：新しいパスワード） → **入れた値がそのまま入る（送信に載る）**
5. 「もう一度」を入れる（状態：新しいパスワード） → **入れた値がそのまま入る（送信に載る）**
6. 「パスワードを表示」を押す（状態：新しいパスワード） → **伏せ字（●●●）が読める文字に変わる。アイコンが目に斜線になり、もう一度押すと伏せ字に戻る**
7. 「変更してログイン」を押す（状態：新しいパスワード） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
8. 「ログインへ戻る」を押す（状態：送信後） → **/login が開く**（ログインする）。戻る
9. 全角／半角：メール・数値・コードを全角で入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
10. 前後と途中の空白：空白付きで入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
11. 記号の種別（ハイフン・長音）：‐ ー − を混ぜる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
12. Unicode 正規化（NFC/NFD）：macOS の入力（NFD）で入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
13. 大文字小文字：メールを大文字で入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
14. 再設定リンクの期限切れ・使用済み（前提：再設定メール発行済み）：リンクを 1 回使う → 同じリンクをもう一度開く → **文言「このリンクはもう使えません。もう一度、再設定メールを送ってください」が出て、一手「再設定メールを送る」が押せる。守っている層：API／DB**
15. **自分の受信箱**を開く → **届いている**（迷惑メールも見る）。件名・差出人・本文が読め、リンクを押すと目的の画面が開く
16. 本文を読む → **内部の言葉（ID・テーブル名）が無く、誰宛てで何をすればよいかが分かる**
17. `.dev-logs/api.log` の `[mail]` の行を見る → **「送った → 自分のアドレス」が出ている**。「送れなかった」が出ていたら、その理由が NG の中身
18. ブラウザの幅を **375px** にして **http://127.0.0.1:3124/password-reset** を開き直す → **横スクロールが出ない。文字が読める大きさ（11px 以上）で、入力欄を押しても勝手に拡大しない（16px 以上）。ボタンが指で押せる（24px 以上）。スマホで使わせない画面なら『PC で開いてください』と出て、崩れた画面を見せない**
19. ブラウザの幅を **768px** にして **http://127.0.0.1:3124/password-reset** を開き直す → **横スクロールが出ない。ヘッダ・ナビが箱からはみ出さない（縮んだタブ・チップの文字が切れない）**
20. ブラウザの幅を **1024px** にして **http://127.0.0.1:3124/password-reset** を開き直す → **横スクロールが出ない。第2ナビと本文が重ならない**
21. ブラウザの幅を **1440px** にして **http://127.0.0.1:3124/password-reset** を開き直す → **横スクロールが出ない。本文が 720px 以上あり、左に寄らない**

## 結果

よければ次の 1 行を書いて保存してください（このまま貼って、日付と名前を変える）。

```
OK: YYYY-MM-DD 名前
```

違うところがあれば `NG: 何が違うか` を書いてください。1 行で構いません。
