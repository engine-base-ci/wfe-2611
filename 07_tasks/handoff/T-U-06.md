## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://127.0.0.1:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）

## 手順

1. **http://127.0.0.1:3124/password-reset** を開く。見出しが「パスワードの再設定」で、横にスクロールしない
2. 「再設定メールを送る」を押す → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
3. 「メールアドレス」を入れる（状態：再設定を送る） → **入れた値がそのまま入る（送信に載る）**
4. 「回復コードで入る」を押す（状態：再設定を送る） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
5. 「新しいパスワード」を入れる（状態：新しいパスワード） → **入れた値がそのまま入る（送信に載る）**
6. 「もう一度」を入れる（状態：新しいパスワード） → **入れた値がそのまま入る（送信に載る）**
7. 「変更してログイン」を押す（状態：新しいパスワード） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
8. 「ログインへ戻る」を押す（状態：送信後） → **/login が開く**（ログインする）。戻る
9. **自分の受信箱**を開く → **届いている**（迷惑メールも見る）。件名・差出人・本文が読め、リンクを押すと目的の画面が開く
10. 本文を読む → **内部の言葉（ID・テーブル名）が無く、誰宛てで何をすればよいかが分かる**
