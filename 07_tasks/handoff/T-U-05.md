# T-U-05 画面 ログインする（3 状態・R1/R2/R3/R4）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://127.0.0.1:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

## 手順

1. **http://127.0.0.1:3124/login** を開く。見出しが「ログインする」で、横にスクロールしない
2. 「6桁」を入れる（状態：6桁の入力） → **入れた値がそのまま入る（送信に載る）**
3. 「この端末では30日間きかない」を切り替える（状態：6桁の入力） → **切り替わる**
4. 「今日の画面へ」を押す（状態：6桁の入力） → **/today が開く**（今日）。戻る
5. 「端末を失くした（回復コードで入る）」を押す（状態：6桁の入力） → **/password-reset が開く**（パスワードの再設定）。戻る
6. わざと「メールアドレスかパスワードが違います。あと4回で15分間ロックします。…」になる操作をする（状態：失敗） → **その文言と、直す導線が出る**
7. 「メールアドレス」を入れる（状態：通常） → **入れた値がそのまま入る（送信に載る）**
8. 「パスワード」を入れる（状態：通常） → **入れた値がそのまま入る（送信に載る）**
9. 「パスワードを表示」を押す（状態：通常） → **伏せ字（●●●）が読める文字に変わる。アイコンが目に斜線になり、もう一度押すと伏せ字に戻る**
10. 「ログイン」を押す（状態：通常） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
11. 「パスワードをお忘れの方」を押す（状態：通常） → **/password-reset が開く**（パスワードの再設定）。戻る
12. 「アカウントを作る」を押す（状態：通常） → **/signup が開く**（アカウントを作る）。戻る
13. 全角／半角：メール・数値・コードを全角で入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
14. 前後と途中の空白：空白付きで入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
15. 記号の種別（ハイフン・長音）：‐ ー − を混ぜる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
16. Unicode 正規化（NFC/NFD）：macOS の入力（NFD）で入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
17. 大文字小文字：メールを大文字で入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
18. メールアドレスかパスワードが違う（1〜4 回目は残り回数を出す）（前提：登録済みのアカウント）：誤ったパスワードで送信 → **文言「メールアドレスかパスワードが違います。あと 4 回で 15 分ロックします」が出て、一手「入力し直す／パスワードを忘れた」が押せる。守っている層：UI／API／DB**
19. パスワードを 5 回間違えた（連続失敗でロック）（前提：登録済みのアカウント）：誤ったパスワードで 5 回送信 → 6 回目に正しいパスワードで送信 → **文言「15 分間ロックしました。急ぐときはメールでロックを解除できます」が出て、一手「解除メールを送る／15 分待つ」が押せる。守っている層：API／DB**
20. メールアドレスとパスワードは合っているが、その人の会社の登録（会社の人）が見つからない（会社が消えた・登録の途中で壊れた）（前提：ログインはできるが会社の人の記録が無いアカウント）：そのメールアドレスとパスワードでログインする → **文言「このアカウントは、会社の登録が見つからないため使えません。もう一度アカウントを作るか、運営に連絡してください」が出て、一手「アカウントを作る／運営に連絡する」が押せる。守っている層：UI／API**
21. ブラウザの幅を **375px** にして **http://127.0.0.1:3124/login** を開き直す → **横スクロールが出ない。文字が読める大きさ（11px 以上）で、入力欄を押しても勝手に拡大しない（16px 以上）。ボタンが指で押せる（24px 以上）。スマホで使わせない画面なら『PC で開いてください』と出て、崩れた画面を見せない**
22. ブラウザの幅を **768px** にして **http://127.0.0.1:3124/login** を開き直す → **横スクロールが出ない。ヘッダ・ナビが箱からはみ出さない（縮んだタブ・チップの文字が切れない）**
23. ブラウザの幅を **1024px** にして **http://127.0.0.1:3124/login** を開き直す → **横スクロールが出ない。第2ナビと本文が重ならない**
24. ブラウザの幅を **1440px** にして **http://127.0.0.1:3124/login** を開き直す → **横スクロールが出ない。本文が 720px 以上あり、左に寄らない**
