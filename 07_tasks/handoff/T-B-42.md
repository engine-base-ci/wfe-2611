## 手順

1. **http://localhost:3124/ai/chat** を開く。見出しが「分身の部屋：会話と知っていること」で、横にスクロールしない
2. 仕事が動いている間だけ OS に「寝ないで」を頼み、終わったら解く。待っているだけの間は頼まない・本人の電源の設定は変えない（前提：Bridge を入れた PC）：仕事を始める → 終える（単体：働いている状態の切り替わりで powerSaveBlocker の開始・停止が 1 回ずつ呼ばれる） → **working が入ったら 1 回だけ開始、空になったら 1 回だけ停止。同じ状態が続いても呼び直さない**
3. 道具が動いている最中に止めると、理由に「◯◯（対象）は途中だったので、その結末は分かりません。先方の画面で確かめてください」が付く（前提：道具が動いている仕事（偽の CLI：SLOW_TOOL））：止める（偽の CLI で道具の最中に stopCurrent） → **結末の理由に道具の名前と対象が入る（E-SIG-003）。文を書いている最中に止めたときは付かない**
4. 前の記録が PC に無いとき、同じ仕事を --resume 無しで 1 回だけやり直し、会話に 1 行知らせる（前提：記録に無い id（偽の CLI：--resume sess-lost は stderr『No conversation found…』・result is_error・num_turns 0 を返す））：記録に無い id の仕事を流す（偽の CLI） → **新しいセッションの id で結末が返り、notice（E-NF-003）が 1 回。2 回目の失敗はやり直さず理由を出して止まる**
5. 本物の Claude Code が記録の無い id の --resume で何を返すか（前提：この PC の Claude Code（2.1.283））：存在しない id で 1 回呼ぶ（本物・短い頼み） → **stderr『No conversation found with session ID』・result is_error・error_during_execution・num_turns 0・本文なし（2026-10-20 実測）。偽の CLI はこの形を写している**
6. 記録があるときはやり直さない・知らせない（前提：記録のある id）：普通に続きを頼む（偽の CLI） → **notice は出ない・同じ id のまま 1 回で終わる**
7. 止めた理由と記録の無い知らせが会話に出る（前提：つないだ PC（本物の Bridge の輪＋偽の CLI））：会話で「道具の最中に止めて」→ 止める／「記録を失って」と送る → **「ここで止まりました」の理由に途中の道具の文が入る／吹き出しの外に E-NF-003 の 1 行が出て、返事は新しいセッションで返る**
