## 手順

1. 流れ J-09 P8 運営（段階2） を最後まで通す（L2）：データ 0 件の会社で最初から通す（前提：新しいテスト会社）：最初から最後まで操作 → **各段で空状態が出て、途中で詰まらない**
2. 顧客のデータを見ずに直す（http://localhost:3124/ops/support） → **構成と失敗の型だけを見る**
3. 配布物を直す・プランに割り当てる（http://localhost:3124/ops/catalog） → **運営層の定義を版で更新し、各社の「使う／使わない」に反映**
4. 会社の一覧を見る（http://localhost:3124/ops） → **各社のプラン・体数・稼働・詰まりの型だけを集計（中身は読まない）**
5. 問い合わせに答える（http://localhost:3124/ops/support） → **受信箱（問い合わせ＋詰まり）。返答は顧客の問い合わせと証跡に残る**
6. お知らせを出す（http://localhost:3124/ops/notices） → **お知らせ・稼働状況を公開（対象プラン・公開日時）。全社に通知**
7. 請求・入金・利用量を見る（http://localhost:3124/ops/billing） → **各社の請求・入金・未収・利用量／上限を集計（中身は見ない）**
8. セキュリティの出来事を見る（http://localhost:3124/ops/audit） → **失敗したログイン・鍵の失効・不審な接続の記録**
9. サービス台帳を更新する（http://localhost:3124/ops/services） → **可否と理由を版で更新。全社に効く**
10. プランの定義と目標スキルを扱う（http://localhost:3124/ops/catalog） → **価格・上限を版で更新。目標スキルは配るものに載せる**
11. スキルを構築・アップロード・テストして配る（http://localhost:3124/ops/skills） → **版を保存（C4）・配布先の会社に版の更新を通知・装着の状況を集計**
12. 使えるスキルを見て絞る（http://localhost:3124/ai-staff/:id） → **装着の有効／無効を会社の範囲で保存。外したスキルはその AI社員では動かない**
13. 公開の申請を審査する（http://localhost:3124/ops/review） → **匿名化の確認・承認／却下を版で記録**
14. 会社の 1 社を扱う（http://localhost:3124/ops/tenants/:id） → **会社の詳細の 8 面。入金の記録・返答・承認・対処・個別のお知らせはここから。中身は読まない**
15. 運営の証跡を見る（http://localhost:3124/ops/audit） → **運営側の操作記録と運営メンバーの権限**
