# T-B-26 自分のAI の仕事の並びを画面が正しく見せる（開き直すと動いている・答えを待っている会話が出る・別の会話の仕事の後ろで待っている文は、どこを待っているかとそこへの道を出す）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://127.0.0.1:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

## 手順

1. **http://127.0.0.1:3124/ai/chat** を開く。見出しが「分身の部屋：会話と知っていること」で、横にスクロールしない
2. **http://127.0.0.1:3124/onboard/interview** を開く。見出しが「自分のAIと話す」で、横にスクロールしない
3. 何も選ばずに開くと、自分のAI が動いている・答えを待っている会話が先に出る。読んだ印で更新時刻が動いても古い会話に戻らない（前提：直して送り直した新しい会話が答えを待っている・前の会話に読んだ印）：開き直す → **答えを待っている問い合わせが出る**
4. 別の会話の仕事（動いている・答えを待っている）の後ろで待っている文は、黙って止まって見せず、どの会話を待っているかとその会話を開く道を出す（前提：別の会話が答えを待っている）：前の会話で送る → **「別の会話で、自分のAI があなたの答えを待っています」と順番待ちに文が出て、その会話を開ける**

## 結果

よければ次の 1 行を書いて保存してください（このまま貼って、日付と名前を変える）。

```
OK: YYYY-MM-DD 名前
```

違うところがあれば `NG: 何が違うか` を書いてください。1 行で構いません。
