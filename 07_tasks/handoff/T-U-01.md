# T-U-01 画面 アカウントを作る（2 状態・R1/R2）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://127.0.0.1:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

## 手順

1. **http://127.0.0.1:3124/signup** を開く。見出しが「アカウントを作る」で、横にスクロールしない
2. 「はじめる」を押す → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
3. 「入り直す」を押す（状態：既に登録済み） → **/password-reset が開く**（入り直す）。戻る
4. わざと「このメールアドレスは既に登録されています。ログインするか、入り直すへ。…」になる操作をする（状態：既に登録済み） → **その文言と、直す導線が出る**
5. 「メールアドレス」を入れる（状態：通常） → **入れた値がそのまま入る（送信に載る）**
6. 「パスワード」を入れる（状態：通常） → **入れた値がそのまま入る（送信に載る）**
7. 「会社名（または屋号）」を入れる（状態：通常） → **入れた値がそのまま入る（送信に載る）**
8. 「利用規約とプライバシーポリシーに同意します」を切り替える（状態：通常） → **切り替わる**
9. 「ログイン」を押す（状態：通常） → **/login が開く**（ログインする）。戻る

## 結果

よければ次の 1 行を書いて保存してください（このまま貼って、日付と名前を変える）。

```
OK: YYYY-MM-DD 名前
```

違うところがあれば `NG: 何が違うか` を書いてください。1 行で構いません。
