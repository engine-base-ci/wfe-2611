# T-U-01 画面 アカウントを作る（2 状態・R1/R2）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://localhost:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

## 手順

1. **http://localhost:3124/signup** を開く。見出しが「アカウントを作る」で、横にスクロールしない
2. 「パスワードの再設定」を押す（状態：既に登録済み） → **/password-reset が開く**（パスワードの再設定）。戻る
3. わざと「このメールアドレスは既に登録されています。ログインするか、パスワードの再設定へ。…」になる操作をする（状態：既に登録済み） → **その文言と、直す導線が出る**
4. 「メールアドレス」を入れる（状態：通常） → **入れた値がそのまま入る（送信に載る）**
5. 「パスワード」を入れる（状態：通常） → **入れた値がそのまま入る（送信に載る）**
6. 「会社名（または屋号）」を入れる（状態：通常） → **入れた値がそのまま入る（送信に載る）**
7. 「利用規約とプライバシーポリシーに同意します」を切り替える（状態：通常） → **切り替わる**
8. 「パスワードを表示」を押す（状態：通常） → **伏せ字（●●●）が読める文字に変わる。アイコンが目に斜線になり、もう一度押すと伏せ字に戻る**
9. 「はじめる」を押す（状態：通常） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
10. 「ログイン」を押す（状態：通常） → **/login が開く**（ログインする）。戻る
11. 全角／半角：メール・数値・コードを全角で入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
12. 前後と途中の空白：空白付きで入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
13. 記号の種別（ハイフン・長音）：‐ ー − を混ぜる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
14. Unicode 正規化（NFC/NFD）：macOS の入力（NFD）で入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
15. 大文字小文字：メールを大文字で入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
16. 同じメールアドレスで登録済み（前提：登録済みのメール）：同じメールで登録 → **文言「このメールアドレスは既に登録されています。ログインするか、パスワードを再設定してください」が出て、一手「ログイン／パスワードを再設定」が押せる。守っている層：UI／API／DB**
17. メールアドレスの形式が違う。全角・前後の空白は直して通す（表記ゆらぎ）（前提：登録画面）：「ａｂｃ＠example.com」で送信 → 通る → 「abc@」で送信 → 出る → **文言「メールアドレスの形式が違います」が出て、一手「入力し直す」が押せる。守っている層：UI／API**
18. ブラウザの幅を **375px** にして **http://localhost:3124/signup** を開き直す → **横スクロールが出ない。文字が読める大きさ（11px 以上）で、入力欄を押しても勝手に拡大しない（16px 以上）。ボタンが指で押せる（24px 以上）。スマホで使わせない画面なら『PC で開いてください』と出て、崩れた画面を見せない**
19. ブラウザの幅を **768px** にして **http://localhost:3124/signup** を開き直す → **横スクロールが出ない。ヘッダ・ナビが箱からはみ出さない（縮んだタブ・チップの文字が切れない）**
20. ブラウザの幅を **1024px** にして **http://localhost:3124/signup** を開き直す → **横スクロールが出ない。第2ナビと本文が重ならない**
21. ブラウザの幅を **1440px** にして **http://localhost:3124/signup** を開き直す → **横スクロールが出ない。本文が 720px 以上あり、左に寄らない**

## 結果

よければ次の 1 行を書いて保存してください（このまま貼って、日付と名前を変える）。

```
OK: YYYY-MM-DD 名前
```

違うところがあれば `NG: 何が違うか` を書いてください。1 行で構いません。
