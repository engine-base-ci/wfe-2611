# T-U-03 画面 招待を受けて参加する（3 状態・R3/R4）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://127.0.0.1:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

招待の URL は画面がまだ無いので、次で作ってください（出た URL をブラウザに貼る）。

```bash
bash scripts/dev/invite.sh
```

## 手順

1. **http://127.0.0.1:3124/invite/:token** を開く。見出しが「招待を受けて参加する」で、横にスクロールしない
2. 「お名前」を入れる（状態：担当者として） → **入れた値がそのまま入る（送信に載る）**
3. 「メールアドレス」を入れる（状態：担当者として） → **入れた値がそのまま入る（送信に載る）**
4. 「パスワード」を入れる（状態：担当者として） → **入れた値がそのまま入る（送信に載る）**
5. 「パスワードを表示」を押す（状態：担当者として） → **伏せ字（●●●）が読める文字に変わる。アイコンが目に斜線になり、もう一度押すと伏せ字に戻る**
6. 「参加する」を押す（状態：担当者として） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
7. 全角／半角：メール・数値・コードを全角で入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
8. 前後と途中の空白：空白付きで入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
9. 記号の種別（ハイフン・長音）：‐ ー − を混ぜる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
10. Unicode 正規化（NFC/NFD）：macOS の入力（NFD）で入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
11. 大文字小文字：メールを大文字で入れる（前提：入力欄がある状態）：入力して保存 → **同一として扱われ、サーバー側で正規化されて保存される（クライアント側だけに頼らない）**
12. 招待が取り消された・期限切れ・既に使われた（前提：発行済みの招待）：管理者が招待を取り消す → 招待リンクを開く → **文言「この招待は取り消されています。招いた人にもう一度送ってもらってください」が出て、一手「招いた人に連絡する」が押せる。守っている層：API／DB**
13. ブラウザの幅を **375px** にして **http://127.0.0.1:3124/invite/:token** を開き直す → **横スクロールが出ない。文字が読める大きさ（11px 以上）で、入力欄を押しても勝手に拡大しない（16px 以上）。ボタンが指で押せる（24px 以上）。スマホで使わせない画面なら『PC で開いてください』と出て、崩れた画面を見せない**
14. ブラウザの幅を **768px** にして **http://127.0.0.1:3124/invite/:token** を開き直す → **横スクロールが出ない。ヘッダ・ナビが箱からはみ出さない（縮んだタブ・チップの文字が切れない）**
15. ブラウザの幅を **1024px** にして **http://127.0.0.1:3124/invite/:token** を開き直す → **横スクロールが出ない。第2ナビと本文が重ならない**
16. ブラウザの幅を **1440px** にして **http://127.0.0.1:3124/invite/:token** を開き直す → **横スクロールが出ない。本文が 720px 以上あり、左に寄らない**

## 結果

よければ次の 1 行を書いて保存してください（このまま貼って、日付と名前を変える）。

```
OK: YYYY-MM-DD 名前
```

違うところがあれば `NG: 何が違うか` を書いてください。1 行で構いません。
