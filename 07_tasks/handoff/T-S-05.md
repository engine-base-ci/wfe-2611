# T-S-05 スキル制作 構築メタ「目標の分解（年→四半期→月→週）」（元ネタ strategic-goal-system・annual-okr）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://127.0.0.1:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

## 手順

1. **http://127.0.0.1:3124/ops/skills** を開く。見出しが「運営：スキル」で、横にスクロールしない
2. 「高本AI」を押す → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
3. 「版を出す」を押す → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
4. 「AI は止まっています」を押す → **/automations/:id/repair が開く**（覚え直させる）。戻る
5. 「PC をつなぐと話せます」を押す → **/setup/bridge が開く**（自分のPCをつなぐ）。戻る
6. 「第 5 版を出す（テスト通過後）」を押す（状態：1 つの中身） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
7. 「テストで動かす」を押す（状態：1 つの中身） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
8. 「戻す先にする」を押す（状態：1 つの中身） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
9. 「旧版の会社に版の更新を知らせる」を押す（状態：1 つの中身） → **/ops/notices が開く**（運営：お知らせ）。戻る
10. 「何を変えたか（版に残る）」を入れる（状態：アップロード） → **入れた値がそのまま入る（送信に載る）**
11. 「スキル」を選ぶ（状態：アップロード） → **選べる**
12. 「上げてテストで動かす」を押す（状態：アップロード） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
13. 「下書き」を押す（状態：アップロード） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
14. 「新しい版を上げる」を押す（状態：スキル） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**
15. 「開く」を押す（状態：スキル） → **画面が変わる・保存される・文言が出る（押しても何も起きないなら NG）**

## 結果

よければ次の 1 行を書いて保存してください（このまま貼って、日付と名前を変える）。

```
OK: YYYY-MM-DD 名前
```

違うところがあれば `NG: 何が違うか` を書いてください。1 行で構いません。
