# T-B-41 自分のAI が作ったファイル・調べた結果を道具 artifact_put で成果物として渡す（PC 側の Bridge が読んで上げる・置き場は C4・台帳は DB・会話の横で開ける・20 MB・ホームの中・仕事の間だけ）

発注者が触って確かめる手順です。所要 15〜30 分。**dev（ローカル）で確かめます。** この 1 枚を触って確かめます。

## その前に

1. `bash scripts/dev/up.sh` を実行する（DB → API → 画面が立つ）
2. http://127.0.0.1:3124/signup で会社を作る（メールの確認リンクは `.dev-logs/api.log` の「verify →」の行をブラウザに貼る）
3. そのまま入った状態で下へ

## 手順

1. **http://127.0.0.1:3124/ai/chat** を開く。見出しが「分身の部屋：会話と知っていること」で、横にスクロールしない
2. 自分のAI が作ったファイル（画像・PDF・表・文書）を道具 artifact_put で渡すと成果物（版 1）になり、返事の下に資料のカードが並ぶ（前提：会話で自分のAI に頼む（PC をつないで Bridge が動いている））：「請求のまとめを成果物にして」と送る → **返事の下にカードが 4 枚並び、横で開くと 画像が見える・PDF が読める・CSV が表・文書が読める。artifacts に行・版 1**
3. 中身は置き場（C4）、台帳は DB。元のファイルは PC に残る（前提：渡した成果物）：DB と置き場を見る（API） → **artifact_versions に storage_ref・size・source_job_id が入り、中身は DB に無い。本人の PC のファイルは消えていない**
4. 画像・PDF・表・文書は会話の横で見え、表計算（xlsx）は落として開く（前提：渡した成果物）：カードを押す → **画像は img・PDF は枠の中・CSV は表・md は文書。xlsx は「落として開いてください」と落とす**
5. 20 MB 超・受けない種類・ホームの外のファイル・終わった仕事の鍵は断る（前提：道具の鍵）：大きいファイル／.exe／ホームの外／終わった仕事の鍵で渡す（API と道具のサーバー） → **413・422・401 で断り、行も置き場の中身もできない。道具のサーバーはホームの外・無いファイルを Kaname に送らない**
6. 渡したことは証跡に名前・種類・大きさで残り、中身は書かない（前提：渡した成果物）：証跡を見る → **audit_events に agent.artifact_put（title・format・size・job_id）。中身は無い**
7. 道具を呼んだときだけ渡る。仕事の中で AI が読んだだけのファイルは渡らない（前提：記録がある仕事）：道具を呼ばない仕事を最後まで動かす → **成果物は増えない（道具の呼び出しの行だけが残る）**

## 結果

よければ次の 1 行を書いて保存してください（このまま貼って、日付と名前を変える）。

```
OK: YYYY-MM-DD 名前
```

違うところがあれば `NG: 何が違うか` を書いてください。1 行で構いません。
