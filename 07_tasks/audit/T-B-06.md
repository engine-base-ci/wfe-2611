# T-B-06 配布と自動更新（署名までは指紋を確かめて自分で入れ替える・D-109）

## 着手前に確かめたこと（2026-09-28）
- 自動更新の骨組み（electron-updater）は一度も動いていなかった：版の番号が 0.1.0 のまま／置き場に更新の情報（latest-mac.yml・zip）を置いていない／Mac の入れ替え（Squirrel.Mac）は署名の無い版を受け付けない／起動時に 1 回しか見ない
- user の選択：署名が入るまでは「指紋を確かめて自分で入れ替える」。署名が入ったら electron-updater に戻す

## 作ったもの
- `apps/bridge/scripts/release.mjs`（`pnpm --filter @kaname/bridge release`）：日時の版 0.YYMMDD.HHMM・mac の zip と dmg（`--win` で exe）・置き場に目録 `kaname-bridge.json`（sha256・大きさ）を最後に書く
- `apps/api/src/auth/bridge-release.ts` と `/bridge/latest?os=&arch=`・`/bridge/file/:name`（目録に載った名前だけ）・`/bridge/download`（目録のインストーラを先に）
- `apps/bridge/src/update.ts`：起動時・1 時間ごと・`outdated` のときに見に行く／受け取りながら sha256 と大きさを数える／zip の中の Bundle ID と版を確かめる／仕事をしていない間だけ入れ替え、失敗したら元に戻す／書けない場所・開発中の起動なら受け取りにも行かず案内／立ち上がったら残りを片づける
- 例外台帳 X-006（C1）・X-007（C4）：目録を読むのは bridge-release.ts だけ

## 実行した結果（2026-09-28）
- Bridge：apps/bridge/test/update.test.ts・release.test.ts ほか 72 本 PASS（2 回連続）。入れ替えは本物の ditto・plutil・sh で、偽の .app を一時フォルダに置いて流した（手元の /Applications には触らない）
- API：apps/api/test/bridge_release.test.ts 6 本 PASS（目録が無い・その CPU の中身・目録に無い名前と置き場の外は 404・壊れた目録）。既存の bridge_* と合わせて 17 本 PASS
- 実物で 1 周：0.260928.1515 の実物を一時フォルダに置いて起動 → 0.260928.1518 を置く → 約 8 秒で受け取り・確かめ・入れ替え・同じ場所から立ち上がり直した（別の userData で流した）
- 実 Chrome：bridge-loop.spec.ts の BRG-06 系 3 本 PASS・2 本は理由つきで飛ばす（配布物を置いた環境・Bridge が入っている PC では作れない）
