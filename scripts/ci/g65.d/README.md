# G65 の段の命令の並び（チケットごとのファイル・K-376）

自己試験を足すチケットは、ここに `K-<自分の番号>.txt` を置き、1 行に 1 つの命令を書く（`&&`・`;`・`|`・`&`・`#`・`` ` ``・`$(` は書けない。つなぐのは作り手だけ）。
作り手（05_flow/build_testplan.py）が `_base.txt` → `K-` の番号の順に読んで、CI の定義（.github/workflows/v3-gate.yml）と試験計画に書く。置いたら作り手を流し直す。
同じ命令が 2 つの行にあれば作り手が止める。置ける名前は `_base.txt`・`K-<数字>.txt`（0 で始めない）・`README.md` だけ。
G65 の最後は k248 の試験（scripts/ci/k248_scope_reach_test.py）。どのファイルに書いてあっても作り手が最後に動かす。
