# カレンダーの部品の決め（段 8・K-460）

**決め：外の部品は入れない。** 下絵の格子（`apps/web/features/F7/calendar/calendar-grid.tsx`・`month.ts`）をそのまま本番の部品にする（PM の決め P15「W0 で選ぶ」への答え・段 8 の切る段の決め 2026-11-20）。

- 理由 1：キャンバス Calendar が求めるのは、日曜はじまりの月の格子・1 日 2 件と「ほか N 件」・日を押すと日の小窓・期限が決まっていない物の置き場だけ。時間割の重なりの計算・週の時間軸・繰り返しの予定は求めていない。外の部品の力が要る場面が無い
- 理由 2：見た目は DESIGN のトークンだけで書く決まり（design_gate の D1〜D8）。外の部品（FullCalendar・schedule-x・react-big-calendar）は自分の CSS を持ち、上書きの数が多く、色・角丸・字の大きさを正本に合わせ直す手間が、すでにある格子より大きい。ガントは svar-gantt を使うが、あれは「依存の線・つかんで動かす」が部品の本体で、カレンダーとは事情が違う（D-079）
- 理由 3：1 画面の JS の量の上限（app page は gzip で 300kb）。外の部品を足すと、使わない週・時間割の部品まで画面に載る。格子は `month.ts`（日付の計算）だけ
- 残す決め（K-481 が切る段で決める）：日から日へ期限を動かす操作を何で作るか（キーボードで動かす道・スマホでつかまずに動かす道を含む）。この葉は「外の部品を入れない」までを決める

技術の選定（`02_tech_stack/selected-stack.json` の `stack.frontend.task_views`）：`calendar` は自前の格子、`timeline` は svar-gantt（`@svar-ui/react-gantt`・D-079）に直した（「未定」を消した）。
