# Backlog の画面（参考・2026-11-02 user 提供）

user が自社で使っている Backlog（fbehc.backlog.jp）の画面を 20 枚撮ったもの。design-md の参考（D-128.4・D-128.7）

> ⚠ 取引先の会社名・プロジェクト名・メンバーの名前・課題の中身が写っている。リポジトリは非公開のまま扱う。19 の API キーは塗りつぶした（元の PDF はリポジトリに入れない）

見返すときは `index.html` をブラウザで開く（画像と所見が並ぶ）。所見を直すときは `notes.json` を直して `python3 gen_index.py`。

## 全体で採るもの・採らないもの

| | Backlog | Kaname では |
|---|---|---|
| 採る | 今いる場所の見出し（プロジェクト名＋キー）が必ず中身の上にある | 各画面の上に見出し（グループ名・画面名）を必ず出す（D-128.1 ③の答え） |
| 採る | 主ボタンは見出しの横か表のすぐ上に 1 つ（〇〇の追加） | 1 画面 1 主ボタン。同じボタンを 2 か所に置かない（D-128.1 ②） |
| 採る | 設定は左に 2 列目の小さなメニュー＋右に中身（プロジェクト設定・個人設定） | 「会社」「AI」「自分のメニュー」は 2 列目のメニューで中を分ける。上の帯をなくした分（D-128.6）をここで受ける |
| 採る | 表は細い罫線・行は低い・並べ替えは左のつまみ（⋮⋮）を掴む | マスタ（種別・分類の値・作業の段）の表はこの形。並べ替えはつまみ |
| 採る | 種別・状態は色つきの札。件数を札の横に出す | 種別と状態の札。件数を横に |
| 採る | 期限切れは日付を赤＋炎の印 | D-125.61 の期限の印（炎）と同じ。日付を赤にするのも採る |
| 採る | 検索条件を保存・短い URL | チケットの絞り込みを保存（D-125.44）。短い URL は採らない（URL がそのまま共有できる作りにする） |
| 採らない | 上の帯（ダッシュボード・プロジェクト・最近見た項目・フィルタ・検索・ベル）＋その下の色帯の左メニュー の二重 | 上の帯は置かない（D-128.6）。最近見た項目・検索・ベルは左のバーに寄せる |
| 採らない | 緑一色の太い左メニュー（画面で一番目立つのがメニューになる） | 左のバーは淡い面。今いる項目だけ紺で示す（色は紺・D-128.2） |
| 採らない | 広い画面で中身が左に寄り、右が大きく空く（設定・ファイル） | フォームは読みやすい幅に収めつつ、右の空きに補助（説明・最近の変更）を置くか、2 列にする |
