# ゼロトラストの決まり（2026-11-03・D-128.88）

「社内のネットワークだから」「ログインしているから」「自分の PC だから」で信じない。**呼ばれるたびに、誰が・何に・どの範囲で・何をしてよいかを確かめ、最小の権限だけ渡し、破られる前提で記録する。**

土台にしたもの：
- NIST SP 800-207（ゼロトラストの 7 原則：資源ごと・通信は場所によらず守る・1 回ごとに許す・ポリシーで動的に決める・資産の状態を見る・許す前に必ず確かめる・集めて良くする）https://csrc.nist.gov/pubs/sp/800/207/a/final ／ https://www.netscout.com/what-is/nist-sp-800-207
- OWASP ASVS 5.0（V8 権限：すべての層で最小権限・権限の昇格を防ぐ・資源の境を守る。V7 セッション：失効・絶対の期限・大事な変更の前の本人確認）https://cheatsheetseries.owasp.org/IndexASVS.html ／ https://cornucopia.owasp.org/taxonomy/asvs-5.0/07-session-management/05-defenses-against-session-abuse

## 2. 権限の言葉（API の「誰が呼べるか」）

| 言葉 | 誰か |
|---|---|
| `public` | ログイン前（登録・ログイン・パスワード再設定・招待を受ける） |
| `read` | そのワークスペースのメンバー（閲覧のみを含む）で、その行のグループを見られる人 |
| `write` | メンバー以上（閲覧のみは不可）で、その行のグループの人 |
| `assignee` | その行の担当者（分身に任せた持ち主を含む）と、そのグループのマネージャー |
| `approver` | その承認の承認する人（上位の承認は上位の人） |
| `recipient` | 渡された・判断を仰がれた相手 |
| `self` | 本人のもの（自分の設定・知らせ・保存した検索条件・自分の書き込み） |
| `manager` | そのグループのマネージャーと管理者 |
| `admin` | ワークスペースの管理者と、その操作の権限を付けた人 |
| `client` | 取引先の人（クライアントの場所だけ・自分の取引先の中だけ） |
| `device` | その人の PC（Bridge）。接続コード（10 分・1 回だけ）でつなぐとできる印で呼ぶ。本人のセッションに結ばれ、本人が切られたら止まる。口は全部 `/bridge/` の下（D-128.93） |
| `ops:<できること>` | 運営の人で、そのできること（問い合わせ・中を見る・お金・止める・お知らせ・配るもの・値段の案・値段を決める・運営の人）を持つ人。`ops:any` は運営の人なら誰でも（ワークスペースの一覧など、数と種類だけのもの） |

`step_up` が付いた API は、直前（15 分以内）の本人確認が無いと 403。
