全部の流れ・全部のチケットに効く決まりの一覧（D-128.125 の「はじめに 1 回」・D-128.130）。チケットには書き写さず、ここを読む。新しく決めたら決定ログに足し、ここにも 1 行足す。

| 決まり | 中身 | 決定 |
|---|---|---|
| エラー | エラーは正本（07_qa/test-specs/errors.json）から引き、文言と次の一手をコードに書かない。画面ごとのエラーの出し方 | D-069・D-128.63 |
| 権限 | 役割の束を付け、必要な人だけ個別に足す・外す（誰に × 何に × どの層で × できること） | D-125.120・D-073 |
| 記録（証跡） | 契約中はずっと残す。退会で消す。実行の記録の出し方 | D-125.133・D-125.106 |
| 言語 | 第1フェーズは日本語だけ。画面の文字は言語ごとの辞書から出す | D-128.56 |
| 秘密・外とのつなぎ | 外に出る・保存する・AI を呼ぶ・ファイル・プロセス・通知・決済・秘密は関門 C1〜C8 だけを通す。ゼロトラストの決まり（03_architecture/ゼロトラストの決まり.md） | D-128.113 ほか |
| 日付と時刻 | 時刻は DB で世界標準時の印つき（timestamptz）で持ち、画面では日本時間で出す。期限のように日付だけのものは date（時差でずれない） | D-128.130 |
| お金 | 円は小数を持たない整数として扱う（DB の型は numeric のまま整数を入れる）。消費税は請求書ごと・税率ごとに 1 回だけ端数を処理し、端数は切り捨て | D-128.130・D-125.125 |
| ログ | ログは共通の 1 か所から出す（console を直に使わない）。1 行 1 件の JSON で、どの依頼のログかが分かる ID を付ける。秘密・パスワード・個人の連絡先は出さない | D-128.130 |
| フォルダの切り方 | 機能（流れと操作）ごとにまとめる。API は apps/api/src/features/<流れ>/<操作>/、画面の中身は apps/web/features/<流れ>/<操作>/。共通の部品と関門は packages/* と apps/web/components/k のまま。今のファイルは、その流れのチケットで触るときに移す | D-128.130 |
| 部品の版 | 部品は出てから 21 日を過ぎた版だけ | D-128.124 |
| 分岐の型 | 入力・対象の状態・時間の流れ・入口・利用者の状態・失敗・操作の揺れ・守り の 8 つの観点。書いていない＝漏れ。状態を持つものは「対象の状態 × 入口 × 利用者の状態」の表を書き、どのマスにも結果・受け持ち・テスト | D-128.133 |
