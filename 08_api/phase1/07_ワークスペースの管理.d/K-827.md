### 設定（WsSettings・プランを変える・ワークスペースを消す・値段が変わる知らせ）
| 設定（名前とロゴ・誰ができるか・決まっている物・消す手続きの状態・押せる区画） | `GET /workspace` | `write` | 管理者と、「誰ができるか」で可になった人（口の中で `app.workspace_can` を見る・どちらでもなければ 403・D-154.83）。答えは `{ workspace: { id, name, logo: { kind, url } }, permissions: [{ key, name, detail, value, options }], fixed_rules: [{ key, text }], deletion: { requested_at, delete_at, days_left, requested_by, preview: { tickets, members } }, access: { admin, billing, delete_workspace } }`。プランと支払い・請求書・依頼の届け先（段 13 の口）・取引先の見える人の既定・書き出しは読まない（D-154.22・D-154.4・K-827） | — |
| 名前を保存 | `PATCH /workspace` | `admin` | 管理者だけ（可になったマネージャーも名前は直せない）。体は `{ name }` だけ（strict）。前後の空白（全角を含む）を削り、1〜100 字（コードポイントで数える＝サロゲート対は 1 字）。空は 422・E-WS-001・101 字は 422・E-WS-002。同じ名前は書かない。保存すると記録 `workspace.renamed`（前と後）・答えは `{ workspace }`（K-827） | — |
