### グループと層（小窓）
| 層の一覧（グループの小窓の「層 ▾」・層の名前と並びを直す小窓） | `GET /layers` | `read` | ワークスペースのメンバーなら誰でも読める（役を見ない）。答えは 200 `{ data: [{ id, key, label, order_no, group_count, created_at }], meta: { limit } }`（order_no の順・消した層と別の会社の層は出ない・group_count はその層の消していないグループの数・ページを持たない）（K-803） | — |
| 層を足す（グループを足す小窓の「層」から） | `POST /layers` | `admin` | 同上（layers の edit・会社全体）。体は `{ label, order_no? }`（名前 1〜40 文字・並びは 1 以上の整数で、指した位置に入り以降が 1 つずつ下がる・無いか層の数を超えれば最後。key はサーバーが作る）。答えは 201 `{ data: { id, key, label, order_no, group_count, created_at } }`。層は 8 段まで（D-154.8）。名前は消していない層と重ならない（大文字小文字・全角半角は同じ・消した層とは重なってよい）。断り：403／409 E-GRP-013（8 段）・019（同じ名前）／422 E-GRP-006・008（K-803） | — |
| 層の名前・並びを直す | `PATCH /layers/:id` | `admin` | 同上。体は `{ label?, order_no? }`（どちらか 1 つは要る・並びは指した位置に動き間の層が 1 つずつずれる・層の数を超えれば最後）。答えは 200 で足す口と同じ 6 つの鍵。層は消せない（D-154.8）。名前を直しても人に知らせない。断り：403／404 E-GRP-007（無い・別の会社・消した層）／409 E-GRP-019（ほかの層と同じ名前・自分の名前の大文字小文字の直しは通る）／422 E-GRP-004・006・008（K-803） | — |
