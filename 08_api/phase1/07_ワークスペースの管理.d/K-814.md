### メンバーの 1 人（WsMember・外す）
| 一時的に止める（入れなくなる・分身も止まる・担当はそのまま） | `POST /members/:id/suspend` | `admin` | 管理者と、メンバーを直す権限（members の edit）を付けた人。体は受けない（空）。答えは 200 `{ data: { member_id, suspended: true, suspended_at } }`。止めた瞬間に、その人の画面・PC・API のセッションを全部切り（理由 suspended）、待っている・動いている PC の仕事をやめる（理由の字つき）。担当・所属・個別の権限はそのまま（役割の束の権限は止めている間だけ無い）。自分は 409・E-MEM-005、最後の管理者（止めた管理者は数えない）は 409・E-MEM-004、もう止まっている人は 409・E-MEM-009、無い・別の会社・外した・消した・AI は 404・E-MEM-002、DB の失敗は 503・E-PAGE-003（何も残らない）。証跡 `member.suspend`（切った数だけ）・K-814 | 要る |
| 止めたのを戻す | `POST /members/:id/resume` | `admin` | 同上。体は受けない（空）。答えは 200 `{ data: { member_id, suspended: false, suspended_at: null } }`。止めを解き、役割の束の権限を作り直す。**切ったセッションと取り消した PC の仕事は戻さない**（入り直し）。止まっていない人は 409・E-MEM-010、相手が無いのは 404・E-MEM-002、DB の失敗は 503・E-PAGE-003。証跡 `member.resume`・K-814 | 要る |
