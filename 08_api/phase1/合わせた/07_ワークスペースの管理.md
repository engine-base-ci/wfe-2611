# 第1フェーズの API ── ワークスペースの管理（案・2026-11-03）

キャンバスのワークスペースの管理（メンバー・決まり・記録・設定）と、そこから開く小窓・請求書から逆に出した（D-128.78）。入口は権限のある人だけに出る（D-128.48）ので、API も `admin`（管理者と、その操作の権限を付けた人）を基本にする。読むだけのもの（グループの並び・決まり・渡すときの決まり・自分に関わる記録）は `read`。

## 1. 画面 → API・誰が呼べるか

### メンバー（WsPeople・招く・グループを足す・メンバーの操作）

| ゲストのグループを作る（名前と依頼が届く社内のグループ） | `POST /guest-groups` | `admin` | 社内の人で、メンバーを招く権限か直す権限を持つ人（マネージャー・普通のメンバー・ゲストは 403）。入力は `{ name（前後の空白を取って 1〜80 字）, request_scope_id（依頼が届く社内のグループ）}`。同じ名前（全角半角・大文字小文字・空白の違いだけでも同じ）は 409・E-GST-002、届け先が無い・消した・別の会社は 404・E-GST-003。答えは `{ group: { id, name, request_scope: { id, name } } }`。届け先はゲストのグループが持ち、招待は持たない（D-155.40・D-155.51・K-876） | — |
| ゲストのグループの名前を直す（「⋯」・K-927） | `PATCH /guest-groups/:id` | `self` | メンバーを直す権限（members の edit）の人だけ（管理者・権限を付けた人）。同じ名前（表記ゆらぎを含む）は 409・E-GST-002、無い・消したグループは 404・E-GST-001。中のゲストと届け先はそのまま | — |
| ゲストのグループを消す（「⋯」・K-927） | `DELETE /guest-groups/:id` | `self` | 同上。消すと中のゲストは入れなくなり（会社から抜けた扱い・セッションはすぐ切れる）、受けていない招待は取り消し、見せていたチケットから外れる。チケット・依頼・やり取りは残る。メール・お知らせは送らない（D-155.46） | — |

記録を探す口（K-823）：
- 入力：`kind`（perm・out・device・ai・deleted・ops）・`member_id`・`ticket_id`（uuid）・`from`（含む）・`to`（含まない・ISO 8601 の日時）・`cursor`（`<時刻（UTC・マイクロ秒）>_<id>` を base64url にした 1〜200 字）・`limit`（1〜100・既定 50）。形の誤り（知らない札・日時でない期間・100 を超える件数）は 422・E-AUD-001（欄ごと）・ほどけない続きの印は 422・E-AUD-002。uuid でない人とチケット・件数の 0 と数でない値・base64url でない印・NUL は入口が 422・VALIDATION_ERROR。答えの occurred_at はミリ秒の ISO。ことば（q）は K-850

## 2. 守りの決まり

- **招く・役割を変える・外すは管理者と、その権限を付けた人だけ**。マネージャーの束には入れない（D-128.97）
- **見えるもの・入れるかどうかが変わる操作は本人確認を取り直す**：役割・グループを移す／兼ねる・できることを足す外す・一時的に止める／戻す・外す・「誰ができるか」・プランを変える・ワークスペースを消す・書き出す。管理者として招くときも（ZT5・D-128.97）
- 自分の役割を変える・自分に権限を足す・自分を外す（抜けるのは自分の設定から）・最後の管理者を外す はできない（権限の昇格を防ぐ・ASVS V8）
- 「誰ができるか」を変えられるのは管理者だけ。権限を付けた人でも変えられない
- 外すと、個人の記憶・会話・預けたログイン情報・PC の接続・出した招待はすぐ消える（D-128.96）
- 書き出しの受け取りは頼んだ本人だけ・期限つきの署名 URL（関門 C4）
- 記録は追記だけ（消せない・直せない・ZT12）
- **記録をことばで探す**（`GET /audit_events?q=…`・K-850）：q は 1〜100 字（空・空白だけ・101 字以上は 422・E-AUD-010・欄 q）。q も探される字（起こした人の名前・対象の名前・行の文・理由・端末・action の名前）も NFKC → 小文字 → 空白を 1 つにそろえてから部分一致で見る。空白で分けたことばを全部含む行だけ（AND）。% _ \ は字のまま探す。読める範囲・札・人・チケット・期間の絞りは q が無いときと同じで、絞った行の中で探す。新しい順に 500 行ずつ、1 回の問い合わせで 5000 行まで読む。上限に届いて読み終えていなければ、そこまでの当たりと `scan_capped: true`（続きの印は付けない・期間か札で狭める）。答えの `scan_capped` は q があるときだけ付く

### 自分のこと（/me）をゲストが読むとき（K-875・D-155.35）
