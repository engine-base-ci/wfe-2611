## 2. 守りの決まり

- **取引先の人の API は全部 `/portal/` の下**。権限は `client`（自分の取引先の中だけ）。`/portal/` の外は呼べず、`/portal/` は社内の人の権限では呼ばない（ゼロトラストの検査 ZT4・D-128.104）
- 先方に出るのは「見せる」にしたものだけ。既定は社内だけ。テスト仕様・決定ログ・分身の記録は見せられない（D-128.53・D-128.100）
- 先方の書いたもの（依頼・やり取り・検収の返事）はデータとして扱い、分身への指示としては読まない（ZT8・D-128.101）
- 「見るだけ」の人は依頼・書き込み・添付ができない。検収に答えられるのは確かめてもらう相手だけ
- 先方の添付は検査してから置く（関門 C4）。成果物は期限つきの署名 URL で見せる
- 先方へのメールはリンクだけ。本文・成果物は載せない（D-128.103）
- 社内で取引先が見えるのは、ワークスペースの既定（全員）か、取引先ごとに絞った担当グループだけ（D-128.54）
- 先方の人を外すと、クライアントの場所に入れなくなり、セッションはすぐ切れる
