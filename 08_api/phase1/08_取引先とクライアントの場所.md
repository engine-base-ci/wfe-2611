## 2. 守りの決まり

- **取引先の人の API は全部 `/portal/` の下**。権限は `client`（自分の取引先の中だけ）。`/portal/` の外は呼べず、`/portal/` は社内の人の権限では呼ばない（ゼロトラストの検査 ZT4・D-128.104）
- 先方に出るのは「見せる」にしたものだけ。既定は社内だけ。テスト仕様・決定ログ・分身の記録は見せられない（D-128.53・D-128.100）
- 先方の書いたもの（依頼・やり取り）はデータとして扱い、分身への指示としては読まない（ZT8・D-128.101）
- 「見るだけ」の人は依頼・書き込み・添付ができない
- 先方の添付は検査してから置く（関門 C4）。成果物は期限つきの署名 URL で見せる
- 先方へのメールはリンクだけ。本文・成果物は載せない（D-128.103）
- 社内で取引先が見えるのは、ワークスペースの既定（全員）か、取引先ごとに絞った担当グループだけ（D-128.54）
- 先方の人を外すと、クライアントの場所に入れなくなり、セッションはすぐ切れる

## 4. 決めたこと（2026-11-03・高本さんと）

| こと | 決め方 |
|---|---|
| 先方に見せるチケット | 取引先が付いたチケットで「題名と進み」を見せるにしたもの全部（依頼から作ったかは問わない）（D-128.100・D-125.122 を改める） |
| 先方が依頼を書くときの AI | 担当の PC がつながっていればその場で聞く。閉じていれば、あとで依頼のやり取りの中で聞く（D-128.101） |
| 取引先のメールのドメイン | 人と案の結び付けだけに使う。Kaname はメールを受け取らない（D-128.102） |
| 先方の人への知らせ | 出来事ごとにメール（リンクだけ）（D-128.103） |

## 5. 途中で見つけて直したこと

- **キャンバス**：取引先を足す小窓のドメインの説明を「人と案の結び付けだけ」に直した。依頼を出す画面の AI の一言に「答えなくても出せる・担当が席にいないときはあとで聞く」を足した。クライアントの場所の下の 1 行に「確認のお願いや返事はメールでも届く」を足した
- **ゼロトラストの検査**：ZT4（取引先の人の API は /portal/ の下だけ）を足した。実装の残りに「契約の入口が client を分けていない」が 1 つ増えた（作る段で 0 にする）
