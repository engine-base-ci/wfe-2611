# 自分の設定の逆算（2026-11-02）

決定ログ（D-125.137〜.143・.146・.148・.150、D-126.3）をもとに、「人が何をしに来るか」から逆に出す。先に近いツールを調べた。

## 1. なぜあるか

アカウントは 1 人 1 つで、いくつものワークスペースに入れる。その人だけのことを置く。

- 自分であること（名前・顔・ログイン）
- 自分の分身が動く場所（PC）と、分身に使わせるもの（預けたログイン情報）
- 自分への知らせ方
- 自分の使った量

## 2. いつ来るか

毎日来る場所ではない。来るのはこういうとき。

| とき | すること |
|---|---|
| はじめ（はじめにやること・D-125.146） | パスキーを付ける・PC をつなぐ・ログイン情報を預ける |
| 何かが止まったとき | PC が切れた・預けたログイン情報が切れた → 直す（D-125.143 の理由ごとの直し方） |
| 知らせが多い・少ないとき | 何を・どこに・いつ知らせるか を変える |
| 知らない端末で入られた知らせが来たとき | 端末を見て、切る |

## 3. ほかのツールを調べて分かったこと

| ツール | 仕組み | 取り入れること |
|---|---|---|
| GitHub（Secrets） | 保存した値は二度と見られない。できるのは 上書き と 消す だけ。ログでは *** で隠れる | 預けたログイン情報は書くだけ。保存したら値は誰にも（自分にも分身にも）見せない。上書き・消す・いつ使われたか だけ |
| Linear（Notifications） | 受け箱にはいつも届く。そのうえで デスクトップ・スマホ・メール・Slack ごとに、出来事の種類をオンオフ。メールは読んでいなければまとめて遅れて送る | 受け箱（ベル）はいつも。出来事 × 届け先 の表でオンオフ。メールは未読のものだけまとめて |
| Slack（Preferences） | 知らせの設定はワークスペースごと。静かにする時間・一時停止 | 知らせはワークスペースごとに持つ。静かにする時間 |
| Google（セキュリティ） | 入っている端末の一覧と、端末ごとに切る。最近の安全の記録。パスキーの一覧と取り消し | 入っている端末・パスキー・最近の安全の記録 を 1 枚に。知らない端末は切る |
| Claude（Settings） | つないでいる道具（コネクタ）をここで足す・外す | 分身が使うログイン情報・つながりを 1 か所で足す・外す |

## 4. アカウント全体のものと、ワークスペースごとのもの（D-125.150 を詰める）

| もの | どこに効く |
|---|---|
| 名前・顔・言語・見た目 | アカウント全体 |
| ログインと安全（パスキー・パスワード・端末） | アカウント全体 |
| PC（分身が動く場所） | アカウント全体（どのワークスペースの分身も同じ PC で動く） |
| 預けたログイン情報 | ワークスペースごと（会社の Gmail は会社のワークスペースだけで使う） |
| 知らせ | ワークスペースごと |
| 使った量 | アカウント全体（ワークスペースごとの内訳も見られる） |

## 5. 画面

左のパネル：アカウント（プロフィール・ログインと安全）／分身（PC と使った量・預けたログイン情報）／知らせ

| 画面 | 中身 |
|---|---|
| プロフィール | 名前・顔・言語・見た目 |
| ログインと安全 | パスキー・パスワードと 2 段階・入っている端末（切る）・最近の安全の記録 |
| PC と使った量 | つないでいる PC（状態・最後に見えた時刻・切れたときの直し方）・5 時間の枠と今月の量（ワークスペースごとの内訳） |
| 預けたログイン情報 | 名前で並ぶ（例：GMAIL_WORK）。値は見せない。どのやり方（業務の型）が使うか・最後に使った日・期限。上書き・消す |
| 預ける（小窓） | 名前・値（書くだけ）・使えるワークスペース。保存の前に本人確認を取り直す |
| 知らせ | ワークスペースを選ぶ。出来事 × 届け先（受け箱・メール・デスクトップ・スマホ）の表。静かにする時間 |
