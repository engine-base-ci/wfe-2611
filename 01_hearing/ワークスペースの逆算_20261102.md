# ワークスペースの逆算（2026-11-02）

前の作りは要件定義書の決定（マスタの上限・区画・ログインの決まり など）を画面にそのまま写していた。ここでは「人が何をしに来るか」から逆に出す。

## 1. なぜワークスペースがあるか

人と、その人の分身が、同じ決まりの下で安心していっしょに働くための「囲い」。

- 誰が入っているか（人と分身）
- 誰が何をしてよいか（役割・承認の上限）
- 全員の分身に効く決まり（守ること・やり方）
- 何かあったときにたどれる記録

この 4 つが揃えば、チケットの仕事は回る。

## 2. 誰が、どれくらい来るか

| 人 | 来るとき | 頻度 |
|---|---|---|
| 管理者（小さな会社では代表が多い） | 始めるとき（招く・グループを作る）／人が入る・抜ける／決まりを変える／何かあったとき調べる | 始めは数回、あとは月に数回 |
| マネージャー | 自分のグループの人の様子・承認の上限・グループの守ること | 週に 1 回ほど |
| メンバー | ほぼ来ない（自分の役割と自分の記録を見るくらい） | ほとんど無い |

毎日来る場所ではない。だから重く作らない。

## 3. 来てすること（7 つ）と、置き場所

| すること | 頻度 | 置き場所 |
|---|---|---|
| 1 人を招く・外す（外すときは担当の引き継ぎ） | 時々 | ワークスペースの管理 › メンバー |
| 2 誰がマネージャーか・どのグループか を決める | 時々 | ワークスペースの管理 › メンバー（グループごとに人を並べ、その場で変える） |
| 3 分身が止まっている人に気づく（PC がつながっていない など） | 時々 | ワークスペースの管理 › メンバー の上に 1 行で出す |
| 4 全員の分身に効く決まり（守ること・やり方・承認の上限） | 時々 | ワークスペース › 決まり（分身の部屋の「必ず守ること」と同じ並べ方） |
| 5 チケットの形（種別・区画） | まれ | ワークスペースの管理 › 決まり › チケットの形 で見本を見ながら直す（チケットを作る画面には置かない） |
| 6 何かあったときに調べる | まれ | ワークスペース › 記録（探すことから始める） |
| 7 名前・プランと支払い・権限・消す | まれ | ワークスペース › 設定（変える人がいるものだけ） |

## 4. 出さないもの（決まっていて誰も変えないもの）

- 2 段階認証（パスワードの人は必須）・操作がないと切る時間・新しい端末の知らせ → 既定のまま。設定には 1 行の説明だけ置く
- 種別 10・段 8・軸 5 の上限 → 足そうとしたときにだけ伝える
- 分類の軸・作業の段 → 既定のまま。直すのはチケットを作る画面の「この形を直す」から
- 一緒に切り替えるもの（横渡しのとき） → 渡すときの小窓で聞く（既定は「毎回聞く」）

## 5. 画面

| 画面 | 中身 |
|---|---|
| メンバー | グループごとに人を並べる。役割はその場で変える。上に「気づいてほしいこと」1 行（PC がつながっていない人・招待中）。＋ 招く・＋ グループ |
| 招く（小窓） | メール・役割・グループ だけ。ほかは開いたら出す |
| 決まり | ワークスペースと層の「守ること」をアイコンで並べる（分身の部屋と同じ）。承認の上限（いくらから誰に回すか） |
| 記録 | 探す欄から始める（「鈴木さんが何をしたか」「持ち出し」など）。結果は 1 行ずつ |
| 設定 | 名前とロゴ・プランと支払い・権限（支払い・持ち出し・消す ができる人）・ワークスペースを消す |
| 決まり › チケットの形 | 種別を選び、見本を見ながら欄を 必須・出す・外す に切り替える（チケットを作る画面には置かない） |
| 左上の切り替え | ワークスペースの名前と自分の役割だけ。届いた招待は数だけ出し、押すと開く |

## 6. 前の作りから変えること

- 「メンバー」と「層とグループ」を 1 つ（人）にまとめる
- 「マスタ」の画面をなくす（チケットの形は使う場所で直す・ルールは決まりへ）
- 「証跡」は「記録」と呼び、探すことから始める
- 「ワークスペースの設定」から、決まっていて変えないスイッチを消す
- 左上の切り替えを軽くする
