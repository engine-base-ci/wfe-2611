# Kaname 機能分解結果（feature-decomposition v3・2026-09-29）

## 分解の方針

- 外界に出る道は関門 C1〜C8 だけ。権限は DB 層で 1 回。Foundation（A）が終わるまで Backend を解禁しない
- Backend は用事ごとの縦割り（データ・API・権限・テスト）、UI は画面ごと 1 PR（モックと 1 対 1・役割ごとの中身）
- 結線（D）を独立機能にした。部品を作っただけでは価値経路が通らない
